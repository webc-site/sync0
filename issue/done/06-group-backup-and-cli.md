# 06. 对等群组相互备份、CLI 与全量集成测试 (`s0_peer` + `sync0`)

## 目标
实现 Resilio Sync 风格的对等群组相互备份（全量或按路径前缀选择性备份）、统一 CLI 与端到端测试闭环。

## 任务清单
- [ ] 群组相互备份（`GroupMesh`）：
  - 多个对等节点通过 `GroupId` 加入同一群组
  - 每个节点可配置备份策略：全量相互备份（`prefix = ""`）或仅备份特定路径前缀（如 `prefix = "db/wal"`）
  - 群组内任一节点发生文件变更时，自动通过 P2P Swarm 分发同步至群组内所有匹配该前缀的节点
- [ ] 统一 CLI (`sync0`) 与测试脚本 (`./test.sh`)：
  - 实现 `sync0` 命令行工具
  - 编写完整集成测试（单文件/单目录/子路径同步、匿名与认证限速、长连接订阅参与 P2P 多节点并发分发、群组全量与前缀相互备份）
  - 运行 `./sh/clippy.sh` 与 `./test.sh`，调用子代理进行代码规范审查与优化，将全部 issue 归档至 `issue/done/`
