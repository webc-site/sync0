# 05. 对等节点引擎：分享、权限限速、长连接订阅与 Dragonfly P2P 分发 (`s0_peer`)

## 目标
实现全对称 `PeerNode`，每个节点既可分享文件夹、配置匿名/白名单认证与带宽限额，也可订阅下载并自动作为 P2P 分发节点向其他节点供块。

## 任务清单
- [ ] 对等身份与访问控制：
  - 支持随机临时 `iroh` 密钥对（默认零配置）或固定密钥对
  - 每个 Share 默认无需认证即可访问（适用默认带宽限额 `default_max_rate`），也可开启 `EndpointId` 白名单或读写密钥认证，并配置单节点专属带宽限额 `peer_max_rate`
- [ ] 文件夹分享与选择性拉取（`share` / `pull`）：
  - 支持拉取单个文件、单个目录或同步指定路径前缀下的全部文件
- [ ] 长连接订阅 + Dragonfly P2P 分发网络（`sub` + `swarm_pull`）：
  - 订阅节点（支持全量 `""` 或子路径前缀 `"sub/path"`）保持长连接并启动本地 UDP 块区间服务
  - 源节点/Tracker 维护每个 Share 下各订阅节点持有的 `root_hash` 与可用带宽权重
  - 当有节点拉取或收到订阅推送时，通过 `ParentSelector` + `PieceCollector` 同时连接多个持有该版本的对等节点（源节点 + 已完成订阅的对等节点），并发拉取不同 `[blk_lo, blk_hi)` 区间，慢/断连节点区间自动 Work-Stealing 重分配
