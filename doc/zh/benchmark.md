## 4. 复现命令与加速原理

```bash
# 运行真实跨国节点全套压测（输出保存至 bench/kernel-results.yml）
./bench.js

# 运行全网络拓扑离散事件仿真（千兆内网 / 跨洋专线 / 浅队列长肥网 / 高丢包弱网）
cargo nextest run -p s0_sim
```

- **不可压缩数据零开销直通**：首块自动检测文件魔数与香农熵，遇到已压缩归档（`.xz`、`.zst`、`.mp4`）立即旁路 Zstd，避免无效 CPU 开销。
- **可压缩大文件三级流水线**：发送端按网络队列水位动态调节 Zstd 压缩等级，接收端将 UDP 收包、多线程解压与 `compio` 异步定位落盘拆分为无锁流水线。
- **FastCDC 原位增量补丁**：文件局部修改或追加时仅传输差异块并原位 `pwrite` 更新，免除全文件重写；纯权限/时间修改通过 `FsOp::Meta` 原语零块传输。
- **海量小文件内存聚合**：路径前缀差分压缩（Front-Coding）+ 小文件内存连续打包 + 接收端异步批量落盘，消除逐文件网络往返与系统调用瓶颈。
