# sync0

Το `sync0` είναι ένα εργαλείο γραμμής εντολών για τη μεταφορά αρχείων σε δίκτυα, τον σταδιακό συγχρονισμό καταλόγων και την ταυτόχρονη διανομή δεδομένων σε πολλαπλά μηχανήματα.

## Πρωτότυπο σχέδιο σχεδίασης

Σε αίθουσες πολλαπλών μηχανών, χώρες ή περιβάλλοντα με καθυστερήσεις δικτύου και απώλεια πακέτων, εργαλεία όπως `rsync` και `scp` βασίζονται σε επιβεβαίωση μεμονωμένης ακολουθίας σύνδεσης, η οποία περιορίζει τη χρήση εύρους ζώνης. όταν πολλά μηχανήματα τραβούν δεδομένα από τον ίδιο διακομιστή ταυτόχρονα, η κάρτα δικτύου διακομιστή πηγής μπορεί εύκολα να γίνει εμπόδιο.

Ο στόχος του `sync0` είναι να λύσει δύο προβλήματα:

1. Αφήστε το συγχρονισμό αρχείου και καταλόγου μεταξύ των δύο μηχανών να εκτελείται με πλήρες φυσικό εύρος ζώνης και να μεταφέρετε το αλλαγμένο τμήμα μόνο όταν το αρχείο τροποποιηθεί μερικώς.
2. Πολλαπλές μηχανές μπορούν να μεταφέρουν μπλοκ δεδομένων μεταξύ τους όταν συγχρονίζουν τον ίδιο κατάλογο, μειώνοντας το φορτίο στον διακομιστή προέλευσης και συντομεύοντας τον συνολικό χρόνο συγχρονισμού.

## Σύγκριση ταχύτητας με rsync

Περιβάλλον δοκιμής: Ευρωπαϊκός κόμβος $\leftrightarrow$ Βορειοαμερικανικός κόμβος, καθυστέρηση μετ' επιστροφής 86 ms, μέτρηση της πλήρους χρονοβόρας, συμπεριλαμβανομένης της σάρωσης καταλόγου, της σύγκρισης αντιγραφής, της μετάδοσης δικτύου και της επαλήθευσης τοποθέτησης δίσκου:

| Σενάριο μετάδοσης | Μέγεθος δεδομένων | `sync0` | `rsync` | πολλαπλούς |
| :--- | :---: | :---: | :---: | :---: |
| 10.000 μικρά αρχεία | 77.6 MB | 0.90 s (688 Mbps) | 4.86 s (128 Mbps) | 5.4x |
| Πακέτα κώδικα και αρχειοθέτησης (`.tar`) | 512 MB | 1.94 s (2111 Mbps) | 9.36 s (438 Mbps) | 4.8x |
| Αρχείο βίντεο (`.mp4`) | 512 MB | 7.36 s (556 Mbps) | 12.11 s (338 Mbps) | 1.6x |
| Αυξητικός συγχρονισμός (τροποποίηση περιεχομένου 1%) | 512 MB | 0.12 s | 1.85 s | 15.4x |

## Μέθοδοι βελτίωσης της απόδοσης

- **Ταυτόχρονη μετάδοση UDP**: Αποστολή μπλοκ δεδομένων μέσω UDP και επαναμετάδοση μόνο χαμένων τμημάτων για να αποφευχθεί η απώλεια ενός πακέτου που εμποδίζει τις επόμενες μεταφορές αρχείων.
- **Τμηματοποίηση περιεχομένου και κατάργηση διπλότυπων**: Διαχωρίστε το αρχείο σε μπλοκ δεδομένων ανάλογα με το περιεχόμενο και υπολογίστε την τιμή ελέγχου. Το ίδιο περιεχόμενο που βρίσκεται ήδη στο άκρο λήψης επαναχρησιμοποιείται απευθείας τοπικά χωρίς να γίνεται αντιγραφή του δικτύου.
- **Αυτόματη προσαρμογή της συμπίεσης σύμφωνα με την ταχύτητα δικτύου**: Ενεργοποιήστε τη συμπίεση για συμπιέσιμο περιεχόμενο, όπως κείμενο και κώδικας. παραλείπει αυτόματα τη συμπίεση για βίντεο, εικόνες, συμπιεσμένα πακέτα ή σε LAN υψηλής ταχύτητας για μείωση της κατανάλωσης CPU.
- **Τραβήξτε κοντά σε πολλούς κόμβους**: Όταν πολλά μηχανήματα τραβούν τον ίδιο κατάλογο, τα μπλοκ δεδομένων θα τραβηχτούν ταυτόχρονα από τους ληφθέντες κόμβους στην ίδια πόλη ή με χαμηλότερο λανθάνοντα χρόνο.

## Εγκαθιστώ

### Μέθοδος 1: Εγκατάσταση μέσω Cargo

```bash
cargo install sync0
```

### Μέθοδος 2: Λήψη προμεταγλωττισμένων δυαδικών αρχείων

Μεταβείτε στο [GitHub Releases](https://github.com/webc-site/sync0/releases) για να κατεβάσετε το `.tar.xz` συμπιεσμένο πακέτο για το αντίστοιχο σύστημα (υποστηρίζει Linux x86_64/ARM64, macOS Apple Silicon/Intel, Windows x64/ARM64, Android ARM64/x86_64, FreeBSD, NetBSD). Μετά την αποσυμπίεση, τοποθετήστε το `sync0` στον κατάλογο `PATH`:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## Οδηγός χρήσης

### 1. Μεταφέρετε απευθείας αρχεία ή καταλόγους μεταξύ δύο μηχανών

Ξεκινήστε την παρακολούθηση στο μηχάνημα λήψης και καθορίστε τη διαδρομή λήψης και αποθήκευσης:

```bash
sync0 recv 0.0.0.0:9000 ./backup
```

Στείλτε ένα μόνο αρχείο ή έναν ολόκληρο κατάλογο από τη μηχανή αποστολής:

```bash
sync0 send ./project 192.168.1.10:9000
```

Παράμετροι που χρησιμοποιούνται συνήθως:

```bash
# Διαγραφή περιττών αρχείων που υπάρχουν στο άκρο λήψης αλλά όχι στο άκρο αποστολής (συγχρονισμός κατοπτρισμού)
sync0 send ./project 192.168.1.10:9000 --delete

# Περιορισμός ταχύτητας αποστολής (μονάδα: bytes/δευτερόλεπτο, για παράδειγμα 50 MB/s)
sync0 send ./project 192.168.1.10:9000 --rate 50000000

# Αθόρυβη λειτουργία (δεν εμφανίζεται γραμμή προόδου)
sync0 send ./project 192.168.1.10:9000 -q
```

### 2. Δημοσίευση κοινόχρηστων καταλόγων και έλξη από πολλούς κόμβους

Δημοσιεύστε έναν κοινόχρηστο κατάλογο (με όνομα `dataset`) στον διακομιστή προέλευσης:

```bash
sync0 share dataset ./data --region SHA
```

Τραβήξτε τον κοινόχρηστο κατάλογο σε άλλα μηχανήματα (μπορείτε να συμπληρώσετε πολλές διευθύνσεις κόμβων ταυτόχρονα, διαχωρισμένες με κόμματα για ταυτόχρονη λήψη):

```bash
sync0 pull 10.0.0.1:9000,10.0.0.2:9000 dataset ./local_data
```

Τραβήξτε μόνο έναν συγκεκριμένο υποκατάλογο στον κοινόχρηστο κατάλογο:

```bash
sync0 pull 10.0.0.1:9000 dataset ./local_data --subpath 2026/logs
```

Ωθήστε τις τοπικές αλλαγές πίσω στον απομακρυσμένο κοινόχρηστο κατάλογο:

```bash
sync0 push 10.0.0.1:9000 dataset ./local_data
```

### 3. Εγγραφείτε σε αυτόματες ενημερώσεις καταλόγου

Εγγραφείτε στον κοινόχρηστο κατάλογο του κόμβου προέλευσης. Όταν ένα αρχείο προστίθεται ή τροποποιείται στον κατάλογο προέλευσης, θα συγχρονίζεται αυτόματα με τον τοπικό υπολογιστή. Ταυτόχρονα, το τοπικό μηχάνημα θα χρησιμεύσει αυτόματα ως κόμβος για να τραβήξουν άλλα μηχανήματα:

```bash
sync0 sub 10.0.0.1:9000 dataset ./local_mirror
```

### 4. Αμφίδρομος συγχρονισμός ομάδων πολλών μηχανών

Πολλαπλές μηχανές ενώνονται στο ίδιο όνομα ομάδας και οι αλλαγές σε οποιονδήποτε κατάλογο κόμβων θα συγχρονιστούν αυτόματα με άλλους κόμβους της ομάδας:

```bash
sync0 group team-docs ./docs 10.0.0.1:9000,10.0.0.2:9000
```

### 5. Ταυτότητα κόμβου και προσωπική επαγγελματική κάρτα

Κάθε κόμβος υποστηρίζει τη ρύθμιση του ονόματος χρήστη, της πόλης, του email, του ιστότοπου και μιας εξατομικευμένης υπογραφής (μέγιστο 256 χαρακτήρες) και μεταβιβάζει τον έλεγχο ταυτότητας της υπογραφής του τοπικού ιδιωτικού κλειδιού:

```bash
# Προβολή του αναγνωριστικού τοπικού δημόσιου κλειδιού (καθορίστε τον κατάλογο διαμόρφωσης για να παραμείνει το κλειδί)
sync0 id -c ~/.config/sync0

# Δημιουργήστε και εμφανίστε επαγγελματικές κάρτες κόμβων με εξατομικευμένες υπογραφές
sync0 profile -c ~/.config/sync0 \
  -u alice \
  --region SHA \
  --email alice@example.com \
  --url https://example.com \
  -b "Shanghai backup node"
```

Τα `share`, `pull`, `sub`, `group` μπορούν επίσης να εκκινηθούν με αυτές τις παραμέτρους προφίλ:

```bash
sync0 share dataset ./data -c ~/.config/sync0 -u alice --region SHA -b "Shanghai backup node"
```

### 6. Εναλλαγή πολλών γλωσσών

`sync0` Υποστηρίζει 75 γλώσσες. Από προεπιλογή, η βοήθεια της γραμμής εντολών και οι προτροπές στην αντίστοιχη γλώσσα εμφανίζονται αυτόματα σύμφωνα με το γλωσσικό περιβάλλον του λειτουργικού συστήματος. Εάν η γλώσσα συστήματος δεν βρίσκεται στη λίστα που υποστηρίζεται, τα Αγγλικά χρησιμοποιούνται από προεπιλογή.

Για να καθορίσετε τη γλώσσα με μη αυτόματο τρόπο, ορίστε τη μεταβλητή περιβάλλοντος `SYNC0_LANG`:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
