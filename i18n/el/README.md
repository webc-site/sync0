# sync0

Το `sync0` είναι ένα εργαλείο κοινής χρήσης αρχείων και συγχρονισμού πολλών μηχανών peer-to-peer (P2P) που ανταγωνίζεται το Resilio Sync.

Κάθε μηχάνημα είναι ταυτόχρονα διακομιστής και πελάτης: οποιοσδήποτε κόμβος μπορεί να δημοσιεύσει πολλές ομάδες κοινής χρήσης αρχείων. Αφού συνδεθούν άλλοι κόμβοι, μπορούν να αποκτήσουν αυτόματα διαθέσιμους κόμβους εκκίνησης από τον ομότιμο διακομιστή και να τους τραβήξουν ταυτόχρονα από πολλές πηγές. Αφού ολοκληρωθεί ο συγχρονισμός, οι σπόροι θα δημιουργηθούν αυτόματα για περισσότερους κόμβους για την επιτάχυνση των λήψεων.

## Βασικά σημεία

- **Όλοι είναι ταυτόχρονα διακομιστής και πελάτης**: Συγκρίσιμο με το Resilio Sync, χωρίς εξάρτηση κεντρικού διακομιστή. Οποιοσδήποτε κόμβος μπορεί να δημιουργήσει πολλές ομάδες κοινής χρήσης αρχείων και μπορεί επίσης να συμμετάσχει σε ομάδες κοινής χρήσης άλλων ατόμων. οι κόμβοι ανταλλάσσουν αυτόματα και αποκτούν διαθέσιμους κόμβους σποράς για να επιτύχουν ταυτόχρονο τράβηγμα και συγχρονισμό σε πραγματικό χρόνο πολλαπλών μηχανών.
- **Διεύθυνση κόμβου χωρίς IP**: Από προεπιλογή, το κλειδί κόμβου και η κωδικοποιημένη `base64url` διεύθυνση `iroh` δημιουργούνται αυτόματα στο `~/.config/sync0` χωρίς να χρειάζεται να θυμάστε ή να εκθέσετε τη δημόσια IP.
- **Συγχρονισμός πολλαπλών επιλογών κατ' απαίτηση**: Υποστηρίζει συγχρονισμό ολόκληρης της ομάδας κοινής χρήσης και υποστηρίζει επίσης συγχρονισμό κατ' απαίτηση επιλέγοντας πολλά αρχεία ή υποκαταλόγους ταυτόχρονα.
- **Ιεραρχικά δικαιώματα μελών ομάδας και έλεγχος καταλόγου μεταφόρτωσης**: Υποστηρίζει δικαιώματα μόνο για ανάγνωση (`ro`), μεταφόρτωση ανάγνωσης-εγγραφής (`rw`) και διαχείρισης (`admin`) και μπορεί να καθορίσει μεμονωμένα το πρόθεμα διαδρομής που επιτρέπεται να μεταφορτώσει κάθε μέλος (από προεπιλογή, η μεταφόρτωση του κοινόχρηστου καταλόγου είναι ο ριζικός κατάλογος).
- **Πλήρης ταχύτητα και σταδιακός συγχρονισμός μεταξύ δικτύων**: Ταυτόχρονη μετάδοση μεγάλων αρχείων, συγκέντρωση τεράστιων μικρών αρχείων στη μνήμη και μόνο συγχρονισμένα μπλοκ δεδομένων όταν τα αρχεία τροποποιούνται μερικώς.

## Εγκαθιστώ

### Μέθοδος 1: Εγκατάσταση μέσω Cargo

```bash
cargo install sync0
```

### Μέθοδος 2: Λήψη προμεταγλωττισμένων δυαδικών αρχείων

Μεταβείτε στο [GitHub Releases](https://github.com/webc-site/sync0/releases) για να πραγματοποιήσετε λήψη του συμπιεσμένου πακέτου `.tar.xz` για το αντίστοιχο σύστημα (υποστηρίζει Linux, macOS, Windows, Android, FreeBSD, NetBSD), αποσυμπιέστε και βάλτε το στον κατάλογο `PATH`:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## Ξεκινήστε γρήγορα

Το `sync0` χρησιμοποιεί τον `~/.config/sync0` ως κατάλογο διαμόρφωσης από προεπιλογή (εάν χρειάζεται να μεταβείτε σε άλλους καταλόγους, μπορείτε να προσθέσετε `-c <κατάλογος>`).

### 1. Προβολή της διεύθυνσης τοπικού κόμβου και της επαγγελματικής κάρτας ρύθμισης

```bash
# Προβολή της διεύθυνσης του τοπικού κόμβου (το κλειδί δημιουργείται αυτόματα στο ~/.config/sync0 για πρώτη φορά)
sync0 id

# Δημιουργήστε μια προσωπική επαγγελματική κάρτα κόμβου (υποστηρίζει όνομα χρήστη, πόλη, email, ιστότοπο και υπογραφή εντός 256 λέξεων)
sync0 profile -u alice --region SHA --email alice@example.com --url https://example.com -b "Shanghai node"
```

### 2. Δημοσιεύστε πολλές ομάδες κοινής χρήσης αρχείων και ορίστε δικαιώματα μελών ομάδας (`.nt` Διαμόρφωση)

Το `sync0` έχει διαμορφωθεί σε μορφή [NestedText](https://nestedtext.org) (`.nt`). Κάθε χρήστης έχει ένα ξεχωριστό αρχείο διαμόρφωσης `.nt`. Μπορείτε να καθορίσετε τον κατάλογο προφίλ χρήστη μέσω του `users_dir` στο `config.nt` (το οποίο περιλαμβάνει αυτόματα όλα τα `.nt` αρχεία σε αυτόν τον κατάλογο). Τόσο ο χρήστης όσο και το πρόθεμα διαδρομής που επιτρέπεται να μεταφορτωθούν χρησιμοποιούν μια μη ταξινομημένη λίστα (`-`). **Όταν το πρόθεμα διαδρομής μεταφόρτωσης δεν είναι συμπληρωμένο, η μεταφόρτωση στον ριζικό κατάλογο του κοινόχρηστου στοιχείου επιτρέπεται από προεπιλογή**.

1. Δημιουργήστε ξεχωριστά αρχεία διαμόρφωσης `.nt` για κάθε μέλος στον κατάλογο `~/.config/sync0/users/`:

`~/.config/sync0/users/alice.nt` (μέλος μόνο για ανάγνωση, περιορισμένη τιμή `80MB`, `rate` υποστηρίζει μονάδες `GB`, `MB`, `KB`):

```yaml
id: 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c
perm: ro
rate: 80MB
```

`~/.config/sync0/users/bob.nt` (περιορισμένα μέλη μεταφόρτωσης: επιτρέπεται η μεταφόρτωση μόνο σε καταλόγους `uploads/bob` και `shared/common`):

```yaml
id: 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f
perm: rw
write_prefix:
  - uploads/bob
  - shared/common
```

`~/.config/sync0/users/charlie.nt` (Προεπιλεγμένη μεταφόρτωση μέλους: Όταν το `write_prefix` παραλείπεται, η μεταφόρτωση στον ριζικό κατάλογο του κοινόχρηστου στοιχείου επιτρέπεται από προεπιλογή):

```yaml
id: 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
perm: rw
```

2. Διαμορφώστε τον κατάλογο χρήστη και πολλές ομάδες κοινής χρήσης αρχείων στο `~/.config/sync0/config.nt`:

```yaml
users_dir: ./users

groups:
  dataset:
    path: ./data
    auth: false
    perm: ro
    rate: 50MB

  models:
    path: ./models
    auth: false
    perm: ro
    rate: 1GB

  team-vault:
    path: ./vault
    auth: true
    perm: ro
    rate: 512KB
    users:
      - alice
      - bob
      - charlie
```

Έναρξη υπηρεσίας κοινής χρήσης:

```bash
# Άμεση εκκίνηση (φορτώνει αυτόματα όλες τις διαμορφώσεις χρήστη .nt στους καταλόγους ~/.config/sync0/config.nt και users_dir)
sync0 share --region SHA

# Ή δημοσιεύστε γρήγορα πολλές ομάδες κοινής χρήσης και εξουσιοδοτήστε τα μέλη της ομάδας απευθείας μέσω της γραμμής εντολών
sync0 share dataset:./data team-vault:./vault \
  --auth \
  --allow-ro 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c \
  --allow-rw 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f:uploads/bob,shared/common \
  --allow-rw 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
```

### 3. Τραβήξτε όλο το περιεχόμενο ή επιλέξτε πολλά αρχεία και καταλόγους (`sync0 pull`)

Συνδεθείτε σε οποιονδήποτε ομότιμο κόμβο για να αποκτήσετε αυτόματα όλους τους διαθέσιμους κόμβους εκκίνησης στην ομάδα κοινής χρήσης και να τραβήξετε ταυτόχρονα από πολλούς κόμβους:

```bash
# Τραβήξτε ολόκληρη την ομάδα κοινής χρήσης δεδομένων στο τοπικό ./local_data
sync0 pull σύνολο δεδομένων:// ./local_data -p <διεύθυνση κόμβου>

# Συγχρονισμός πολλαπλών επιλογών: τραβήξτε ταυτόχρονα το μεμονωμένο αρχείο docs/readme.md και υποκαταλόγους στοιχεία/εικονίδια, src/core
sync0 pull σύνολο δεδομένων://docs/readme.md,assets/icons,src/core ./local_data -p <διεύθυνση κόμβου>
```

### 4. Μεταφόρτωση αρχείου ή καταλόγου σε μια ομάδα κοινής χρήσης (`sync0 push`)

Τα μέλη με δικαιώματα μεταφόρτωσης (`rw` ή `admin`) μπορούν να ανεβάζουν τοπικά αρχεία ή καταλόγους σε ομάδες απομακρυσμένης κοινής χρήσης:

```bash
# Μέλη με άδεια μεταφόρτωσης ριζικού καταλόγου: Μεταφορτώστε απευθείας στον κοινόχρηστο ριζικό κατάλογο
sync0 push team-vault:// ./new_release -p <διεύθυνση κόμβου>

# Μόνο μέλη εξουσιοδοτημένα για ένα συγκεκριμένο πρόθεμα (όπως μεταφορτώσεις/bob): μεταφόρτωση στο επιτρεπόμενο πρόθεμα διαδρομής
sync0 push team-vault://uploads/bob/report.pdf ./report.pdf -p <διεύθυνση κόμβου>
```

### 5. Εγγραφείτε στον αυτόματο συγχρονισμό και σπορά (`sync0 sub`)

Αφού εγγραφείτε στην ομάδα κοινής χρήσης ενός συγκεκριμένου κόμβου, ο τοπικός διακομιστής είναι ταυτόχρονα πελάτης λήψης και νέος διακομιστής σποράς. Όταν το αρχείο του κόμβου προέλευσης ενημερώνεται, συγχρονίζεται αυτόματα και παρέχει τμηματικές λήψεις για άλλους κόμβους:

```bash
# Εγγραφείτε σε ολόκληρη την ομάδα κοινής χρήσης και πραγματοποιήστε αυτόματη εμφάνιση
sync0 sub σύνολο δεδομένων:// ./local_mirror -p <διεύθυνση κόμβου>

# Μόνο πολλαπλή επιλογή για να εγγραφείτε σε καθορισμένα αρχεία και υποκαταλόγους και να τα εμφανίσετε
sync0 δευτερεύον σύνολο δεδομένων://models/llama.onnx,configs ./local_mirror -p <διεύθυνση κόμβου>
```

### 6. Συγχρονισμός ομότιμων ομάδων πολλών μηχανών (`sync0 group`)

Πολλαπλές μηχανές ενώνονται στην ίδια ομάδα κοινής χρήσης, ο ένας ο άλλος ανακαλύπτει αυτόματα διαθέσιμους κόμβους και διατηρεί αμφίδρομο συγχρονισμό (υποστηρίζει πλήρη συγχρονισμό ή πολλαπλή επιλογή αρχείων και καταλόγων):

```bash
# Πλήρης συμμετοχή στην ομάδα και αμφίδρομος συγχρονισμός
sync0 group team-docs:// ./docs -p <διεύθυνση κόμβου>

# Μόνο ο κατάλογος wal και το αρχείο meta.json στην ομάδα συγχρονισμού πολλαπλών επιλογών
sync0 group team-docs://wal,meta.json ./docs -p <διεύθυνση κόμβου>
```

### 7. Άμεση μετάδοση από σημείο σε σημείο μεταξύ δύο μηχανών (`send` / `recv`)

Δεν χρειάζεται να διαμορφώσετε εκ των προτέρων μια ομάδα και μπορείτε να μεταφέρετε προσωρινά αρχεία ή καταλόγους απευθείας μεταξύ δύο μηχανημάτων:

```bash
# Παρακολούθηση δέκτη
sync0 recv 0.0.0.0:9000 ./backup

# Το τέλος αποστολής μεταφέρει απευθείας αρχεία ή καταλόγους (προαιρετικό --διαγραφή καθρέφτη για καθαρισμό των περιττών αρχείων, -- όριο ταχύτητας ταχύτητας)
sync0 send ./project 192.168.1.10:9000
```

### 8. Εναλλαγή πολλών γλωσσών

Το `sync0` υποστηρίζει 75 γλώσσες και αλλάζει αυτόματα σύμφωνα με το περιβάλλον γλώσσας του συστήματος από προεπιλογή. μπορεί επίσης να καθοριστεί χειροκίνητα μέσω του `SYNC0_LANG`:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
