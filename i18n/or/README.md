# sync0

`sync0` ହେଉଛି ଏକ ବିକେନ୍ଦ୍ରୀକରଣ P2P ଫାଇଲ୍ ଅଂଶୀଦାର, ରିଅଲ୍ ଟାଇମ୍ ସିଙ୍କ୍ରୋନାଇଜେସନ୍ ଏବଂ ମଲ୍ଟି-ସୋର୍ସ ବଣ୍ଟନ ଉପକରଣ ଯାହା `rsync` କୁ ବଦଳାଇବା ପାଇଁ ବ୍ୟବହୃତ ହୁଏ - ଟ୍ରାନ୍ସକଣ୍ଟିନେଣ୍ଟାଲ୍ ୱାଇଡ୍ ଏରିଆ ନେଟୱାର୍କର ମାପାଯାଇଥିବା ବେଗ `rsync` (ଏକକ-ପଏଣ୍ଟ ଜ୍ୟାମିତିକ ହାରାହାରି ବେଗ ** 2.01 × **, P2P ଦ୍ୱ ual ତ ଉତ୍ସ ସିମୋନ୍ର ହାରାହାରି ** ସ୍ପିଡ୍) ** 7.19 × ** ପରି ଦ୍ରୁତ ଗତିରେ |

ପ୍ରତ୍ୟେକ ମେସିନ୍ ଉଭୟ ସର୍ଭର ଏବଂ କ୍ଲାଏଣ୍ଟ: କେନ୍ଦ୍ରୀୟ ସର୍ଭର କିମ୍ବା ସର୍ବସାଧାରଣ ନେଟୱାର୍କ ଠିକଣାର କ is ଣସି ଆବଶ୍ୟକତା ନାହିଁ, ବଣ୍ଟିତ ନେଟୱାର୍କ ସର୍ବସାଧାରଣ କି ଠିକଣା ଉପରେ ସ୍ୱୟଂଚାଳିତ ଗାତ ପଞ୍ଚିଂ, ଏବଂ ଏହା ଦୁଇଟି ମେସିନ୍ ମଧ୍ୟରେ ମଲ୍ଟି-ସେୟାରିଂ ଗ୍ରୁପ୍ ଅନୁମତି ହୋଷ୍ଟିଂ, ଚାହିଦା ଅନୁଯାୟୀ ସବଡିରେକ୍ଟୋରୀଗୁଡିକର ଏକାଧିକ ଚୟନ, ମିଲିସେକେଣ୍ଡ-ସ୍ତରୀୟ ରିଅଲ୍-ଟାଇମ୍ ବର୍ଦ୍ଧିତ ସିଙ୍କ୍ରୋନାଇଜେସନ୍ ଏବଂ P2P ମଲ୍ଟି-ସୋର୍ସ ଏକାଗ୍ର ତ୍ୱରଣକୁ ସମର୍ଥନ କରେ |

## ସଂସ୍ଥାପନ କରନ୍ତୁ |

### ପଦ୍ଧତି 1: କାର୍ଗୋ ସ୍ଥାପନ |

```bash
cargo install sync0
```

### ପଦ୍ଧତି ୨: ପୂର୍ବନିର୍ଦ୍ଧାରିତ ବାଇନାରୀଗୁଡ଼ିକୁ ଡାଉନଲୋଡ୍ କରନ୍ତୁ |

ସିଷ୍ଟମ୍ ସହିତ ଥିବା `.tar.xz` ସଙ୍କୋଚିତ ପ୍ୟାକେଜ୍ (ଲିନକ୍ସ, ମାକୋସ୍, ୱିଣ୍ଡୋଜ୍, ଆଣ୍ଡ୍ରଏଡ୍, ଆଇଓଏସ୍, ଫ୍ରିବିଏସ୍ଡି) କୁ ଡାଉନଲୋଡ୍ କରିବାକୁ [GitHub ରିଲିଜ୍] (/ 0) କୁ ଯାଆନ୍ତୁ, ଅନ୍ଜାଇପ୍ କରନ୍ତୁ ଏବଂ `PATH` ରେ ରଖନ୍ତୁ:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## ଶୀଘ୍ର ଆରମ୍ଭ କର |

### 1. ଦୁଇଟି ମେସିନ୍ ମଧ୍ୟରେ ଶୂନ-ବିନ୍ୟାସ ପ୍ରତ୍ୟକ୍ଷ ପ୍ରସାରଣ (`send` / `recv`)

ଏକ ଅଂଶୀଦାର ଗୋଷ୍ଠୀକୁ ବିନ୍ୟାସ କରିବାର କ need ଣସି ଆବଶ୍ୟକତା ନାହିଁ, ଉଚ୍ଚ ଯନ୍ତ୍ରରେ ଦୁଇଟି ମେସିନ୍ ମଧ୍ୟରେ ସିଧାସଳଖ ଫାଇଲ୍ କିମ୍ବା ଡିରେକ୍ଟୋରୀ ସ୍ଥାନାନ୍ତର କରନ୍ତୁ:

```bash
# ରିସିଭ୍ ଏଣ୍ଡ୍ ପୋର୍ଟରେ ଶୁଣେ ଏବଂ ./ ବ୍ୟାକଅପ୍ କୁ ଲେଖେ |
sync0 recv 0.0.0.0:9000 ./backup

# ପ୍ରେରକଙ୍କ ଠାରୁ ସିଧାସଳଖ ଟ୍ରାନ୍ସମିସନ୍ (ଅତିରିକ୍ତ ଫାଇଲଗୁଡିକ ସଫା କରିବା ପାଇଁ ଇଚ୍ଛାଧୀନ - ଡିଲିଟ୍ ଦର୍ପଣ, - 50MB ସ୍ପିଡ୍ ସୀମା)
sync0 send ./project 192.168.1.10:9000
```

### 2. ପୋଷ୍ଟ ସେୟାର୍ ଏବଂ ଅନ୍-ଡିମାଣ୍ଡ ଟାଣ / ଅପଲୋଡ୍ (`share` / `pull` / `push`)

```bash
# ସର୍ଭର: ଗୋଟିଏ ଧାଡି ନିର୍ଦ୍ଦେଶ ସହିତ ଅଂଶୀଦାର ଗୋଷ୍ଠୀ ପ୍ରକାଶ କରନ୍ତୁ (ଆରମ୍ଭ ହେବା ପରେ IP- ମୁକ୍ତ ଇରୋହ ନୋଡ ଠିକଣା ଆଉଟପୁଟ୍ କରନ୍ତୁ)
sync0 share dataset:./data

# କ୍ଲାଏଣ୍ଟ: ସମଗ୍ର ଡାଟାସେଟ୍ ଅଂଶୀଦାର ଗୋଷ୍ଠୀକୁ ସ୍ଥାନୀୟ ./local_data କୁ ଟାଣନ୍ତୁ |
sync0 ଟାଣ ଡାଟାସେଟ: // ./local_data -p <ନୋଡ ଠିକଣା> |

# କ୍ଲାଏଣ୍ଟ: ଚାହିଦା ଅନୁଯାୟୀ ଏକାଧିକ ଚୟନ ଟାଣନ୍ତୁ (କେବଳ ନିର୍ଦ୍ଦିଷ୍ଟ ଏକକ ଫାଇଲ ଏବଂ ସବ୍ ଡିରେକ୍ଟୋରୀକୁ ସିଙ୍କ୍ରୋନାଇଜ୍ କରନ୍ତୁ) |
sync0 pull dataset: //docs/readme.md,assets/icons,src/core ./local_data -p <node ଠିକଣା>

# କ୍ଲାଏଣ୍ଟ: ପ୍ରାଧିକୃତ ଅଂଶୀଦାର ଗୋଷ୍ଠୀକୁ ଫାଇଲ କିମ୍ବା ଡିରେକ୍ଟୋରୀଗୁଡିକ ଅପଲୋଡ୍ କରନ୍ତୁ |
sync0 push dataset: // ପ୍ରକାଶନ / v1 ./build_output -p <node ଠିକଣା> |
```

### 3. ରିଅଲ୍-ଟାଇମ୍ ସବସ୍କ୍ରିପସନ୍ ବିହନ ଏବଂ ମଲ୍ଟି-ମେସିନ୍ ଦୁଇ-ମାର୍ଗ ସିଙ୍କ୍ରୋନାଇଜେସନ୍ (`sub` / `group`)

ଏକ ଲମ୍ବା ସଂଯୋଗ ସ୍ଥାପନ କରିବା ପରେ, ଯଦି କ file ଣସି ଫାଇଲ୍ ** ଯୋଡିବା, ରୂପାନ୍ତର କରିବା, ବିଲୋପ କରିବା, ଅନୁମତି କିମ୍ବା ପରିବର୍ତ୍ତନ ସମୟ ** ରିମୋଟ ଏଣ୍ଡରେ ଘଟେ, ସ୍ଥାନୀୟ ଡିରେକ୍ଟୋରୀକୁ ରିଅଲ ଟାଇମରେ ମିଲିସେକେଣ୍ଡରେ ଅପଡେଟ୍ କରାଯିବ (ନୂତନ / ରୂପାନ୍ତରିତ ବଡ଼ ଫାଇଲଗୁଡ଼ିକ କେବଳ ପାର୍ଥକ୍ୟ ବ୍ଲକଗୁଡ଼ିକୁ ଟାଣିବ ଏବଂ ସେହି ସ୍ଥାନରେ ଅପଡେଟ୍ କରିବ, ଫାଇଲଗୁଡିକ ଡିଲିଟ୍ କରିବା ସ୍ୱୟଂଚାଳିତ ଭାବରେ ସ୍ଥାନୀୟ ଫାଇଲ୍ ଏବଂ ଖାଲି ଡିରେକ୍ଟୋରୀ ବଦଳାଇବ) |

- **`sync0 sub`（ଏକପଟା ରିୟଲ୍-ଟାଇମ୍ ଆଇନ୍‌ଡିକ୍ସ + ସ୍ୱୟଂଚାଳିତ ଟୋରେଣ୍ଟ ସୃଷ୍ଟି）**: ସ୍ଥାନୀୟ ଭାବେ ଶେୟାରିଂ ଡିଭାଇସର ଯୋଗାଯୋଗରେ ଫାଇଲ୍ ଯୋଗ/ମିଟା/ସଂଯୋଜନ ସମୟରେ ରିୟଲ୍-ଟାଇମ୍ ଅନୁସରଣ କରେ, ସହିତେ ସ୍ୱୟଂଚାଳିତ ଭାବେ P2P ସିଡ୍ ଉତ୍ସ ଭାବେ ଅନ୍ୟ ନୋଡ୍‌ମାନଙ୍କୁ ସଂଯୁକ୍ତ ଗତି ସହାୟତା ଦେଉଥାଏ।
- **`sync0 group`（ବହୁ-ମେସିନ୍ ସମାନଧାରା ଦ୍ୱି-ପଟା ରିୟଲ୍-ଟାଇମ୍ ସିଙ୍କ୍ରୋନାଇଜେସନ୍）**: ଗ୍ରୁପ୍ ମଧ୍ୟରେ ଯେକোনସି ଏକ ଯନ୍ତ୍ରରେ ଫାଇଲ୍ ଯୋଗ/ମିଟା/ସଂଯୋଜନ ହେଲେ, ସମସ୍ତ ଅନ୍ୟ ଅନ୍ଲାଇନ୍ ନୋଡ୍‌ମାନେ ରିୟଲ୍-ଟାଇମ୍ ଅପଡେଟ୍ ସିଙ୍କ୍ରୋନାଇଜ୍ ହୁଏ ଏବଂ ପ୍ରତ୍ୟେକରେ ସିଡ୍ ଭାବେ କାର୍ଯ୍ୟ କରନ୍ତି।

```bash
# ସମଗ୍ର ଅଂଶୀଦାର ଗୋଷ୍ଠୀକୁ ସବସ୍କ୍ରାଇବ କରନ୍ତୁ: ସୁଦୂର ଯୋଗ, ବିଲୋପ, ଏବଂ ପରିବର୍ତ୍ତନଗୁଡ଼ିକ ପ୍ରକୃତ ସମୟରେ ସ୍ଥାନୀୟ ଭାବରେ ସିଙ୍କ୍ରୋନାଇଜ୍ ହୁଏ ଏବଂ ସ୍ୱୟଂଚାଳିତ ଭାବରେ ବିହନ ପ୍ରାପ୍ତ ହୁଏ |
sync0 ସବ୍ ଡାଟାସେଟ୍: // ./local_mirror -p <ନୋଡ୍ ଠିକଣା> |

# ଅନ୍-ଡିମାଣ୍ଡ ମଲ୍ଟି-ସିଲେକ୍ଟ ସବସ୍କ୍ରିପସନ୍: କେବଳ ସିଙ୍କ୍ରୋନାଇଜ୍ ଏବଂ ବିହନ ନିର୍ଦ୍ଦିଷ୍ଟ ଏକକ ଫାଇଲ୍ ଏବଂ ସବ୍ ଡିରେକ୍ଟୋରୀକୁ ରିଅଲ୍ ସମୟରେ |
sync0 ସବ୍ ଡାଟାସେଟ୍: //models/llama.onnx,configs ./local_mirror -p <node ଠିକଣା>

# ମଲ୍ଟି ମେସିନ୍ ସାଥୀ ଗୋଷ୍ଠୀ ଦୁଇ-ମାର୍ଗ ରିଅଲ୍-ଟାଇମ୍ ସିଙ୍କ୍ରୋନାଇଜେସନ୍ (ପୂର୍ଣ୍ଣ କିମ୍ବା କମା ମଲ୍ଟି-ସିଲେକ୍ଟ ପଥକୁ ମଧ୍ୟ ସମର୍ଥନ କରେ)
sync0 ଗୋଷ୍ଠୀ ଦଳ-ଡକସ୍: // ./docs -p <ନୋଡ୍ ଠିକଣା> |
```

### 4. ଦଳ ମଲ୍ଟି-ସେୟାରିଂ ଗୋଷ୍ଠୀ ଏବଂ ସଦସ୍ୟ ଅନୁମତି ବିନ୍ୟାସ (`.nt` ବିନ୍ୟାସ)

ଡିଫଲ୍ଟ ବିନ୍ୟାସ ଡିରେକ୍ଟୋରୀ ହେଉଛି `~/.config/sync0` (ମିନିମାଲିଷ୍ଟ [NestedText] (/ 1) (`.nt`) ଫର୍ମାଟ୍ ବ୍ୟବହାର କରି <b class = "CODE"> - c <directory> ` ମାଧ୍ୟମରେ ସୁଇଚ୍ କରାଯାଇପାରିବ |
- ** ସାର୍ବଜନୀନ ନେଟୱାର୍କ ପ reading ଼ା ଉପରେ ପ୍ରତିବନ୍ଧକକୁ ସମର୍ଥନ କରେ (କେବଳ ସ୍ authorized ୀକୃତପ୍ରାପ୍ତ ଉପଭୋକ୍ତାମାନେ ପ read ିପାରିବେ) **: ଯେପର୍ଯ୍ୟନ୍ତ ଅଂଶୀଦାର ଗୋଷ୍ଠୀ ଏକ `users:` ସଦସ୍ୟ ତାଲିକା ସହିତ ବିନ୍ୟାସିତ ହୁଏ (କିମ୍ବା ନିର୍ଦ୍ଦେଶନାମା ନିର୍ଦ୍ଦିଷ୍ଟ କରେ `--allow-r` / `--allow-rw` / `--allow-w` / `--auth`), ସିଷ୍ଟମ ** ସ୍ୱୟଂଚାଳିତ ଭାବରେ ବ୍ୟକ୍ତିଗତ ନୋଡିକେସନ୍ (<b id = ") P2P ବିହନ ନୋଡକୁ ସବସ୍କ୍ରାଇବ କରିବା ମଧ୍ୟ ଏକକାଳୀନ ହ୍ it ାଇଟଲିଷ୍ଟକୁ ଉତ୍ତରାଧିକାରୀ କରିବ, କେବଳ ଅନୁମତି ପ୍ରାପ୍ତ ଉପଭୋକ୍ତାମାନଙ୍କୁ ପ read ିବାକୁ ଅନୁମତି ଦେବ | ଗୋଷ୍ଠୀଗୁଡିକୁ ଅଂଶୀଦାର କରିବା ଯାହା `users` ସହିତ ବିନ୍ୟାସ ହୋଇନଥାଏ ସର୍ବସାଧାରଣ ଏବଂ କେବଳ ଡିଫଲ୍ଟ ଭାବରେ ପ read ଼ାଯାଏ (ଯଦି ଆପଣ ସର୍ବସାଧାରଣ ଏବଂ କେବଳ ପଠନୀୟ ହେବାକୁ ଚାହାଁନ୍ତି ଏବଂ କେବଳ ନିର୍ଦ୍ଦିଷ୍ଟ ସଦସ୍ୟଙ୍କ ପାଇଁ ଅପଲୋଡ୍ କରିବାକୁ ଖୋଲା ହୁଅନ୍ତି, ତେବେ ଆପଣ ସ୍ପଷ୍ଟ ଭାବରେ `auth: false` ସେଟ୍ କରିପାରିବେ) |
- ** ସୂକ୍ଷ୍ମ-ଗ୍ରେଡ୍ ରିଡ୍-ଲିଖନ ଏବଂ ସବ୍ ଡିରେକ୍ଟୋରୀ ବିତରଣ ଅନୁମତି **: ସଦସ୍ୟମାନେ କେବଳ ଡିଫଲ୍ଟ ଭାବରେ ପ read ନ୍ତି (`r` ସ୍ପଷ୍ଟ ଭାବରେ ଲେଖିବା ଆବଶ୍ୟକ ନାହିଁ), ଏବଂ `r` (କେବଳ ପଠନୀୟ), `w` (କେବଳ ଡ୍ରପ୍ ବକ୍ସକୁ ଲେଖ, ପ read ଼ିବା ଯୋଗ୍ୟ ନୁହେଁ), `rw` ଅପଲୋଡ୍ କରୁଛି)

** ସଦସ୍ୟ ବିନ୍ୟାସ ଉଦାହରଣ (`~/.config/sync0/users/`): **

```yaml
# ~ / .config / sync0 / users / alice.nt (ଡିଫଲ୍ଟ କେବଳ ପଠନୀୟ, ଗତି ସୀମା 80MB)
id: 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c
rate: 80MB
```

```yaml
# ~ / .config / sync0 / users / bob.nt (ଅନୁମତି ପ read ଼ନ୍ତୁ ଏବଂ ଲେଖନ୍ତୁ, କେବଳ ନିର୍ଦ୍ଦିଷ୍ଟ ଉପଡିରେକ୍ଟୋରୀକୁ ଅପଲୋଡ୍ କରିବାକୁ ଅନୁମତି ଦିଆଯାଇଛି)
id: 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f
perm: rw
write_prefix:
  - uploads/bob
  - shared/common
```

```yaml
# ~ / .config / sync0 / users / charlie.nt (କେବଳ ବିତରଣ ଅନୁମତି ଲେଖ, ପ reading ିବା ନିଷେଧ)
id: 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
perm: w
```

** ଗୋଷ୍ଠୀ ବିନ୍ୟାସ ଉଦାହରଣ ବାଣ୍ଟିବା (`~/.config/sync0/config.nt`): **

```yaml
users_dir: ./users

groups:
  # ବିନ୍ୟାସିତ ଉପଭୋକ୍ତା ନୁହଁନ୍ତି: କେବଳ ଡିଫଲ୍ଟ ସର୍ବସାଧାରଣ ନେଟୱାର୍କ ପଠନୀୟ |
  dataset:
    path: ./data
    rate: 50MB

  # ବିନ୍ୟାସିତ ଉପଭୋକ୍ତା: ସ୍ୱୟଂଚାଳିତ ଭାବରେ ସର୍ବସାଧାରଣ ନେଟୱାର୍କ ପଠନକୁ ପ୍ରତିବନ୍ଧିତ କରନ୍ତୁ (କେବଳ ଆଲିସ୍ ଏବଂ ବବ୍ ପ can ିପାରିବେ, ଚାର୍ଲି କେବଳ ବିତରଣ ଏବଂ ଅପଲୋଡ୍ କରିପାରିବେ) |
  team-vault:
    path: ./vault
    users:
      - alice
      - bob
      - charlie
```

ସେବା ଆରମ୍ଭ କରନ୍ତୁ (ବିନ୍ୟାସ ଫାଇଲକୁ ଲୋଡ୍ କରନ୍ତୁ କିମ୍ବା ସର୍ବସାଧାରଣ ନେଟୱାର୍କ ପଠନକୁ ସୀମିତ ରଖିବା ଏବଂ ସଦସ୍ୟମାନଙ୍କୁ ଅନୁମତି ଦେବା ପାଇଁ ସିଧାସଳଖ ନିର୍ଦ୍ଦେଶନାମା ପାରାମିଟର ବ୍ୟବହାର କରନ୍ତୁ):

```bash
# ଆରମ୍ଭ କରିବାକୁ ~ / .config / sync0 / config.nt ଲୋଡ୍ କରନ୍ତୁ |
sync0 share --region SHA

# କିମ୍ବା ଶୁଦ୍ଧ କମାଣ୍ଡ୍ ଲାଇନ୍ ମାଧ୍ୟମରେ ଏକ ବ୍ୟକ୍ତିଗତ ଅଂଶୀଦାର ଗୋଷ୍ଠୀ ପ୍ରକାଶ କରନ୍ତୁ (ସର୍ବସାଧାରଣ ନେଟୱାର୍କ ପଠନକୁ ସ୍ୱୟଂଚାଳିତ ଭାବରେ ସୀମିତ ରଖିବା ପାଇଁ - allow- * ନିର୍ଦ୍ଦିଷ୍ଟ କରନ୍ତୁ ଏବଂ କେବଳ ପ୍ରାଧିକୃତ ଉପଭୋକ୍ତାମାନେ ଏହାକୁ ପ୍ରବେଶ କରିପାରିବେ) |
sync0 share team-vault:./vault \
  --allow-r 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c \
  --allow-rw 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f:uploads/bob,shared/common \
  --allow-w 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
```

### 5. ନୋଡ୍ ଠିକଣା, ବ୍ୟବସାୟ କାର୍ଡ ଏବଂ ମଲ୍ଟି ଭାଷା |

```bash
# ସ୍ଥାନୀୟ IP- ମୁକ୍ତ ନୋଡ୍ ଠିକଣା ଦେଖନ୍ତୁ (ପ୍ରଥମ ଚଲାଇବା ପାଇଁ ଚାବି ସ୍ୱୟଂଚାଳିତ ଭାବରେ ସୃଷ୍ଟି ହୁଏ)
sync0 id

# Ed25519 ସ୍ signed ାକ୍ଷରିତ ନୋଡ୍ ବ୍ୟବସାୟ କାର୍ଡ (ଡାକନାମ, ସହର କୋଡ୍, ଇମେଲ୍, ୱେବସାଇଟ୍, ପରିଚୟ) ସୃଷ୍ଟି କରନ୍ତୁ |
sync0 profile -u alice --region SHA --email alice@example.com -b "Shanghai node"

# ସେଠାରେ 75 ବିଲ୍ଟ-ଇନ୍ ଭାଷା ଅଛି, ଯାହା ଡିଫଲ୍ଟ ଭାବରେ ସିଷ୍ଟମ୍ ଭାଷା ଅନୁସରଣ କରେ ଏବଂ ପରିବେଶ ଭେରିଏବଲ୍ ମାଧ୍ୟମରେ ସୁଇଚ୍ ହୋଇପାରିବ |
SYNC0_LANG=en sync0 --help
```

### ମୂଳ ଉତ୍ପାଦ ବ features ଶିଷ୍ଟ୍ୟଗୁଡିକ |

- ** ସାର୍ବଜନୀନ ଚାବି ସ୍ୱୟଂଚାଳିତ ଗର୍ତ୍ତ ପଞ୍ଚିଂ **: କେନ୍ଦ୍ରୀୟ ସର୍ଭର ଏବଂ ସର୍ବସାଧାରଣ ନେଟୱାର୍କ ଠିକଣା, ବଣ୍ଟିତ ନେଟୱାର୍କ ସର୍ବସାଧାରଣ କି ଠିକଣା ଉପରେ ଆଧାର କରି ସ୍ୱୟଂଚାଳିତ NAT ଗାତର କ ing ଣସି ଆବଶ୍ୟକତା ନାହିଁ |
- ** ମିଲିସେକେଣ୍ଡ-ସ୍ତରୀୟ ରିଅଲ୍-ଟାଇମ୍ ସିଙ୍କ୍ରୋନାଇଜେସନ୍ ଏବଂ ମେଟାଡାଟା ସଚେତନତା **: ଦେଶୀ ଫାଇଲ୍ ଇଭେଣ୍ଟ ମନିଟରିଂ ଉପରେ ଆଧାର କରି (`FSEvents` / `inotify` / `ReadDirectoryChangesW`), ଫାଇଲ୍ ଯୋଗର ରିଅଲ୍-ଟାଇମ୍ ପୁସ୍, ଡିଲିଟ୍, POSIX ଅନୁମତି (`mode`) ଏବଂ ମିଲିସେକେଣ୍ଡ-ସ୍ତର ପରିବର୍ତ୍ତନ ସମୟ (<b id = "); ଶୂନ ଡାଟା ବ୍ଲକ୍ ଟ୍ରାନ୍ସମିସନ୍ ଯେତେବେଳେ କେବଳ ଅନୁମତି କିମ୍ବା ସମୟ ସଂଶୋଧିତ ହୁଏ |
