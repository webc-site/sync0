# sync0

ନେଟୱାର୍କରେ ଫାଇଲ ସ୍ଥାନାନ୍ତର କରିବା, ଡିରେକ୍ଟୋରୀକୁ କ୍ରମାଗତ ଭାବରେ ସିଙ୍କ୍ରୋନାଇଜ୍ କରିବା ଏବଂ ଏକାଧିକ ଯନ୍ତ୍ରରେ ତଥ୍ୟ ବଣ୍ଟନ କରିବା ପାଇଁ `sync0` ହେଉଛି ଏକ ନିର୍ଦ୍ଦେଶନାମା ଉପକରଣ |

## ମୂଳ ଡିଜାଇନ୍ ଉଦ୍ଦେଶ୍ୟ |

କ୍ରସ୍ ମେସିନ୍ ରୁମ୍, ଦେଶ, କିମ୍ବା ନେଟୱାର୍କ ବିଳମ୍ବ ଏବଂ ପ୍ୟାକେଟ୍ କ୍ଷତି ସହିତ ପରିବେଶରେ, `rsync` ଏବଂ `scp` ଉପକରଣଗୁଡ଼ିକ ଏକକ ସଂଯୋଗ କ୍ରମ ନିଶ୍ଚିତକରଣ ଉପରେ ଆଧାରିତ, ଯାହା ବ୍ୟାଣ୍ଡୱିଡଥ୍ ବ୍ୟବହାରକୁ ସୀମିତ କରେ | ଯେତେବେଳେ ଏକାଧିକ ମେସିନ୍ ସମାନ ସର୍ଭରରୁ ତଥ୍ୟ ଟାଣନ୍ତି, ଉତ୍ସ ସର୍ଭର ନେଟୱାର୍କ କାର୍ଡ ସହଜରେ ଏକ ପ୍ରତିବନ୍ଧକ ହୋଇପାରେ |

`sync0` ର ଲକ୍ଷ୍ୟ ହେଉଛି ଦୁଇଟି ସମସ୍ୟାର ସମାଧାନ:

1. ଦୁଇଟି ମେସିନ୍ ମଧ୍ୟରେ ଫାଇଲ୍ ଏବଂ ଡିରେକ୍ଟୋରୀ ସିଙ୍କ୍ରୋନାଇଜେସନ୍ ପୂର୍ଣ୍ଣ ଭ physical ତିକ ବ୍ୟାଣ୍ଡୱିଡଥ୍ ଚଲାଇବାକୁ ଦିଅ, ଏବଂ ଫାଇଲ୍ ଆଂଶିକ ରୂପାନ୍ତରିତ ହେଲେ କେବଳ ପରିବର୍ତ୍ତିତ ଅଂଶକୁ ସ୍ଥାନାନ୍ତର କର |
2. ସମାନ ଡିରେକ୍ଟୋରୀକୁ ସିଙ୍କ୍ରୋନାଇଜ୍ କରିବା, ଉତ୍ସ ସର୍ଭରରେ ଭାର ହ୍ରାସ କରିବା ଏବଂ ସାମଗ୍ରିକ ସିଙ୍କ୍ରୋନାଇଜେସନ୍ ସମୟକୁ ଛୋଟ କରିବା ସମୟରେ ଏକାଧିକ ମେସିନ୍ ପରସ୍ପରକୁ ଡାଟା ବ୍ଲକ୍ ସ୍ଥାନାନ୍ତର କରିପାରନ୍ତି |

## କାର୍ଯ୍ୟଦକ୍ଷତା ଉନ୍ନତି ପଦ୍ଧତି |

- ** UDP ଏକକାଳୀନ ଟ୍ରାନ୍ସମିସନ୍ **: UDP ମାଧ୍ୟମରେ ଡାଟା ବ୍ଲକ୍ ପଠାନ୍ତୁ, ଏବଂ ପରବର୍ତ୍ତୀ ଫାଇଲ୍ ସ୍ଥାନାନ୍ତରଣକୁ ଏକକ ପ୍ୟାକେଟ୍ କ୍ଷତିରୁ ରକ୍ଷା ପାଇବା ପାଇଁ କେବଳ ହଜିଯାଇଥିବା ଖଣ୍ଡଗୁଡ଼ିକୁ ପୁନ r ପଠାନ୍ତୁ |
- ** ବିଷୟବସ୍ତୁ ସେଗମେଣ୍ଟେସନ୍ ଏବଂ ଡିଡୁପ୍ଲିକେସନ୍ **: ବିଷୟବସ୍ତୁ ଅନୁଯାୟୀ ଫାଇଲକୁ ଡାଟା ବ୍ଲକ୍ରେ ବିଭକ୍ତ କର ଏବଂ ଚେକ୍ ମୂଲ୍ୟ ଗଣନା କର | ଗ୍ରହଣ ଶେଷରେ ଥିବା ସମାନ ବିଷୟବସ୍ତୁ ନେଟୱର୍କର ନକଲ ନକରି ସିଧାସଳଖ ସ୍ଥାନୀୟ ଭାବରେ ପୁନ used ବ୍ୟବହୃତ ହୁଏ |
- ** ନେଟୱର୍କ ଗତି ଅନୁଯାୟୀ ସ୍ୱୟଂଚାଳିତ ଭାବରେ ସଙ୍କୋଚନକୁ ସଜାଡନ୍ତୁ **: ସଙ୍କୋଚନୀୟ ବିଷୟବସ୍ତୁ ଯେପରିକି ପାଠ୍ୟ ଏବଂ କୋଡ୍ ପାଇଁ ସଙ୍କୋଚନ ଟର୍ନ୍ ଅନ୍ କରନ୍ତୁ | CPU ବ୍ୟବହାରକୁ ହ୍ରାସ କରିବା ପାଇଁ ଭିଡିଓ, ଚିତ୍ର, ସଙ୍କୋଚିତ ପ୍ୟାକେଜ୍ କିମ୍ବା ହାଇ ସ୍ପିଡ୍ LAN ପାଇଁ ସ୍ୱୟଂଚାଳିତ ଭାବରେ ସଙ୍କୋଚନକୁ ଛାଡିଦିଅ |
- ** ନିକଟସ୍ଥ ମଲ୍ଟି-ନୋଡ୍ ଟାଣିବା **: ଯେତେବେଳେ ଏକାଧିକ ମେସିନ୍ ସମାନ ଡିରେକ୍ଟୋରୀକୁ ଟାଣନ୍ତି, ସେହି ସହରରେ ଡାଉନଲୋଡ୍ ହୋଇଥିବା ନୋଡରୁ କିମ୍ବା ନିମ୍ନ ବିଳମ୍ବ ସହିତ ଡାଟା ବ୍ଲକ୍ ଏକାସାଙ୍ଗରେ ଟାଣି ହୋଇଯିବ |

## ସଂସ୍ଥାପନ କରନ୍ତୁ |

### ପଦ୍ଧତି 1: କାର୍ଗୋ ମାଧ୍ୟମରେ ସଂସ୍ଥାପନ କରନ୍ତୁ |

```bash
cargo install sync0
```

### ପଦ୍ଧତି ୨: ପୂର୍ବନିର୍ଦ୍ଧାରିତ ବାଇନାରୀଗୁଡ଼ିକୁ ଡାଉନଲୋଡ୍ କରନ୍ତୁ |

ସଂପୃକ୍ତ ସିଷ୍ଟମ୍ ପାଇଁ `.tar.xz` ସଙ୍କୋଚିତ ପ୍ୟାକେଜ୍ ଡାଉନଲୋଡ୍ କରିବାକୁ [GitHub ପ୍ରକାଶନ] (/ 0) କୁ ଯାଆନ୍ତୁ (ଲିନକ୍ସ x86_64 / ARM64, ମାକୋସ୍ ଆପଲ୍ ସିଲିକନ୍ / ଇଣ୍ଟେଲ, ୱିଣ୍ଡୋଜ୍ x64 / ARM64, ଆଣ୍ଡ୍ରଏଡ୍ ARM64 / x86_64, FreeBSD, NetBSD) | ଅନ୍ଜାଇପ୍ କରିବା ପରେ, `sync0` `PATH` ଡିରେକ୍ଟୋରୀରେ ରଖନ୍ତୁ:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## ଉପଯୋଗକର୍ତ୍ତା ଗାଇଡ୍ |

### 1. ଦୁଇଟି ମେସିନ୍ ମଧ୍ୟରେ ସିଧାସଳଖ ଫାଇଲ୍ କିମ୍ବା ଡିରେକ୍ଟୋରୀ ସ୍ଥାନାନ୍ତର କରନ୍ତୁ |

ଗ୍ରହଣ ଯନ୍ତ୍ରରେ ମନିଟରିଂ ଆରମ୍ଭ କରନ୍ତୁ ଏବଂ ଗ୍ରହଣ ଏବଂ ସଂରକ୍ଷଣ ପଥ ନିର୍ଦ୍ଦିଷ୍ଟ କରନ୍ତୁ:

```bash
sync0 recv 0.0.0.0:9000 ./backup
```

ପଠାଇବା ଯନ୍ତ୍ରରୁ ଗୋଟିଏ ଫାଇଲ୍ କିମ୍ବା ଏକ ସମ୍ପୂର୍ଣ୍ଣ ଡିରେକ୍ଟୋରୀ ପଠାନ୍ତୁ:

```bash
sync0 send ./project 192.168.1.10:9000
```

ସାଧାରଣ ବ୍ୟବହୃତ ପାରାମିଟରଗୁଡିକ:

```bash
# ରିସିଣ୍ଡାଣ୍ଟ ଫାଇଲଗୁଡ଼ିକୁ ଡିଲିଟ୍ କରନ୍ତୁ ଯାହା ରିସିଭ୍ ଶେଷରେ ଅଛି କିନ୍ତୁ ପ୍ରେରଣ ଶେଷରେ ନୁହେଁ (ଦର୍ପଣ ସିଙ୍କ୍ରୋନାଇଜେସନ୍)
sync0 send ./project 192.168.1.10:9000 --delete

# ପ୍ରେରଣ ହାର ସୀମିତ କରନ୍ତୁ (ୟୁନିଟ୍: ବାଇଟ୍ / ସେକେଣ୍ଡ୍, ଉଦାହରଣ ସ୍ୱରୂପ 50 MB / s)
sync0 send ./project 192.168.1.10:9000 --rate 50000000

# ନୀରବ ମୋଡ୍ (କ progress ଣସି ପ୍ରଗତି ଦଣ୍ଡିକା ଦେଖାଯାଇ ନାହିଁ)
sync0 send ./project 192.168.1.10:9000 -q
```

### 2. ଅଂଶୀଦାର ଡିରେକ୍ଟୋରୀଗୁଡିକ ପ୍ରକାଶନ କରିବା ଏବଂ ଏକାଧିକ ନୋଡରୁ ଟାଣିବା |

ମୂଳ ସର୍ଭରରେ ଏକ ଅଂଶୀଦାର ଡିରେକ୍ଟୋରୀ (ନାମ `dataset`) ପ୍ରକାଶ କରନ୍ତୁ:

```bash
sync0 share dataset ./data --region SHA
```

ଅନ୍ୟ ମେସିନ୍ ଗୁଡିକରେ ଅଂଶୀଦାରିତ ଡିରେକ୍ଟୋରୀକୁ ଟାଣନ୍ତୁ (ଆପଣ ଏକ ସମୟରେ ଏକାଧିକ ନୋଡ୍ ଠିକଣା ପୂରଣ କରିପାରିବେ, ଏକ ସମୟରେ ଟାଣିବା ପାଇଁ କମା ଦ୍ୱାରା ପୃଥକ):

```bash
sync0 pull 10.0.0.1:9000,10.0.0.2:9000 dataset ./local_data
```

ଅଂଶୀଦାର ଡିରେକ୍ଟୋରୀରେ କେବଳ ଏକ ନିର୍ଦ୍ଦିଷ୍ଟ ଉପଡିରେକ୍ଟୋରୀ ଟାଣନ୍ତୁ:

```bash
sync0 pull 10.0.0.1:9000 dataset ./local_data --subpath 2026/logs
```

ସୁଦୂର ଅଂଶୀଦାରୀ ଡିରେକ୍ଟୋରୀକୁ ସ୍ଥାନୀୟ ପରିବର୍ତ୍ତନଗୁଡ଼ିକୁ ପଛକୁ ଠେଲିଦିଅ:

```bash
sync0 push 10.0.0.1:9000 dataset ./local_data
```

### 3. ସ୍ୱୟଂଚାଳିତ ଅଦ୍ୟତନଗୁଡ଼ିକର କାଟାଲଗ୍ କୁ ସବସ୍କ୍ରାଇବ କରନ୍ତୁ |

ଉତ୍ସ ନୋଡର ଅଂଶୀଦାର ଡିରେକ୍ଟୋରୀକୁ ସବସ୍କ୍ରାଇବ କରନ୍ତୁ | ଯେତେବେଳେ ଏକ ଫାଇଲ୍ ଉତ୍ସ ଡିରେକ୍ଟୋରୀରେ ଯୋଡାଯାଏ କିମ୍ବା ରୂପାନ୍ତରିତ ହୁଏ, ଏହା ସ୍ୱୟଂଚାଳିତ ଭାବରେ ସ୍ଥାନୀୟ କମ୍ପ୍ୟୁଟର ସହିତ ସିଙ୍କ୍ରୋନାଇଜ୍ ହେବ | ସେହି ସମୟରେ, ସ୍ଥାନୀୟ ମେସିନ୍ ସ୍ୱୟଂଚାଳିତ ଭାବରେ ଅନ୍ୟ ମେସିନ୍ଗୁଡ଼ିକୁ ଟାଣିବା ପାଇଁ ଏକ ନୋଡ୍ ଭାବରେ କାର୍ଯ୍ୟ କରିବ:

```bash
sync0 sub 10.0.0.1:9000 dataset ./local_mirror
```

### 4. ମଲ୍ଟି ମେସିନ୍ ଗୋଷ୍ଠୀର ଦୁଇ-ମାର୍ଗ ସିଙ୍କ୍ରୋନାଇଜେସନ୍ |

ଏକାଧିକ ଗୋଷ୍ଠୀ ସମାନ ଗୋଷ୍ଠୀ ନାମରେ ଯୋଗ ଦିଅନ୍ତି, ଏବଂ ଯେକ any ଣସି ନୋଡ ଡିରେକ୍ଟୋରୀରେ ପରିବର୍ତ୍ତନଗୁଡ଼ିକ ସ୍ୱୟଂଚାଳିତ ଭାବରେ ଗୋଷ୍ଠୀର ଅନ୍ୟ ନୋଡଗୁଡ଼ିକ ସହିତ ସିଙ୍କ୍ରୋନାଇଜ୍ ହେବ:

```bash
sync0 group team-docs ./docs 10.0.0.1:9000,10.0.0.2:9000
```

### 5. ନୋଡ୍ ପରିଚୟ ଏବଂ ବ୍ୟକ୍ତିଗତ ବ୍ୟବସାୟ କାର୍ଡ |

ପ୍ରତ୍ୟେକ ନୋଡ୍ ବ୍ୟବହାରକାରୀ ନାମ, ସହର, ଇମେଲ୍, ୱେବସାଇଟ୍ ଏବଂ ଏକ ବ୍ୟକ୍ତିଗତ ସ୍ ature ାକ୍ଷର (ସର୍ବାଧିକ 256 ଅକ୍ଷର) ସେଟିଂକୁ ସମର୍ଥନ କରେ ଏବଂ ସ୍ଥାନୀୟ ବ୍ୟକ୍ତିଗତ କି ଦସ୍ତଖତ ପ୍ରାମାଣିକିକରଣ ପାସ୍ କରେ:

```bash
# ସ୍ଥାନୀୟ ସାର୍ବଜନୀନ କି ID ଦେଖନ୍ତୁ (ଚାବିକୁ ସ୍ଥିର କରିବା ପାଇଁ ବିନ୍ୟାସ ଡିରେକ୍ଟୋରୀ ନିର୍ଦ୍ଦିଷ୍ଟ କରନ୍ତୁ)
sync0 id -c ~/.config/sync0

# ବ୍ୟକ୍ତିଗତ ସ୍ atures ାକ୍ଷର ସହିତ ନୋଡ ବ୍ୟବସାୟ କାର୍ଡ ସୃଷ୍ଟି ଏବଂ ପ୍ରଦର୍ଶନ କରନ୍ତୁ |
sync0 profile -c ~/.config/sync0 \
  -u alice \
  --region SHA \
  --email alice@example.com \
  --url https://example.com \
  -b "Shanghai backup node"
```

ଏହି ପ୍ରୋଫାଇଲ୍ ପାରାମିଟରଗୁଡିକ ସହିତ `share`, `pull`, `sub`, `group` ମଧ୍ୟ ଲଞ୍ଚ କରାଯାଇପାରିବ:

```bash
sync0 share dataset ./data -c ~/.config/sync0 -u alice --region SHA -b "Shanghai backup node"
```

### 6. ଏକାଧିକ ଭାଷା ସୁଇଚ୍

`sync0` 75 ଭାଷା ସମର୍ଥନ କରେ | ଡିଫଲ୍ଟ ଭାବରେ, କମାଣ୍ଡ୍ ଲାଇନ୍ ସାହାଯ୍ୟ ଏବଂ ସଂପୃକ୍ତ ଭାଷାରେ ପ୍ରମ୍ପ୍ଟଗୁଡ଼ିକ ଅପରେଟିଂ ସିଷ୍ଟମର ଭାଷା ପରିବେଶ ଅନୁଯାୟୀ ସ୍ୱୟଂଚାଳିତ ଭାବରେ ପ୍ରଦର୍ଶିତ ହୁଏ | ଯଦି ସିଷ୍ଟମ୍ ଭାଷା ସମର୍ଥିତ ତାଲିକାରେ ନାହିଁ, ଡିଫଲ୍ଟ ଭାବରେ ଇଂରାଜୀ ବ୍ୟବହୃତ ହୁଏ |

ଭାଷାକୁ ହସ୍ତକୃତ ଭାବରେ ନିର୍ଦ୍ଦିଷ୍ଟ କରିବାକୁ, ପରିବେଶ ଭେରିଏବଲ୍ `SYNC0_LANG` ସେଟ୍ କରନ୍ତୁ:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
