# sync0

`sync0` ହେଉଛି ଏକ ସାଥି-ଟୁ-ପିଅର୍ (P2P) ଫାଇଲ୍ ଅଂଶୀଦାର ଏବଂ ମଲ୍ଟି ମେସିନ୍ ସିଙ୍କ୍ରୋନାଇଜେସନ୍ ଟୁଲ୍ ଯାହା ରେସିଲିଓ ସିଙ୍କ ସହିତ ପ୍ରତିଦ୍ୱନ୍ଦ୍ୱିତା କରେ |

ପ୍ରତ୍ୟେକ ମେସିନ୍ ଉଭୟ ସର୍ଭର ଏବଂ କ୍ଲାଏଣ୍ଟ: ଯେକ any ଣସି ନୋଡ୍ ଏକାଧିକ ଫାଇଲ୍ ଅଂଶୀଦାର ଗୋଷ୍ଠୀ ପ୍ରକାଶ କରିପାରିବ | ଅନ୍ୟ ନୋଡଗୁଡ଼ିକ ଯୋଗଦେବା ପରେ, ସେମାନେ ସ୍ୱୟଂଚାଳିତ ଭାବରେ ସାଥୀ ସର୍ଭରରୁ ଉପଲବ୍ଧ ବିହନ ନୋଡଗୁଡିକ ପାଇପାରିବେ ଏବଂ ଏକାଧିକ ଉତ୍ସରୁ ସେମାନଙ୍କୁ ଏକ ସମୟରେ ଟାଣି ପାରିବେ | ସିଙ୍କ୍ରୋନାଇଜେସନ୍ ସମାପ୍ତ ହେବା ପରେ, ଡାଉନଲୋଡ୍ କୁ ତ୍ୱରାନ୍ୱିତ କରିବା ପାଇଁ ମଞ୍ଜି ସ୍ୱୟଂଚାଳିତ ଭାବରେ ଅଧିକ ନୋଡ୍ ପାଇଁ ସୃଷ୍ଟି ହେବ |

## ମୂଳ ହାଇଲାଇଟ୍ |

- ** ସମସ୍ତେ ଉଭୟ ସର୍ଭର ଏବଂ କ୍ଲାଏଣ୍ଟ **: ରେସିଲିଓ ସିଙ୍କ ସହିତ ତୁଳନାତ୍ମକ, କ central ଣସି କେନ୍ଦ୍ରୀୟ ସର୍ଭର ନିର୍ଭରଶୀଳତା ନାହିଁ | ଯେକ Any ଣସି ନୋଡ୍ ଏକାଧିକ ଫାଇଲ୍ ଅଂଶୀଦାର ଗୋଷ୍ଠୀ ସୃଷ୍ଟି କରିପାରିବ, ଏବଂ ଅନ୍ୟ ଲୋକଙ୍କ ଅଂଶୀଦାର ଗୋଷ୍ଠୀରେ ମଧ୍ୟ ଯୋଗ ଦେଇପାରେ | ଏକାଧିକ ଯନ୍ତ୍ରର ଏକକାଳୀନ ଟାଣିବା ଏବଂ ରିଅଲ୍-ଟାଇମ୍ ସିଙ୍କ୍ରୋନାଇଜେସନ୍ ହାସଲ କରିବା ପାଇଁ ନୋଡଗୁଡ଼ିକ ସ୍ୱୟଂଚାଳିତ ଭାବରେ ବିନିମୟ ଏବଂ ଉପଲବ୍ଧ ବିହନ ନୋଡଗୁଡିକ ପ୍ରାପ୍ତ କରେ |
- ** IP- ମୁକ୍ତ ନୋଡ୍ ଠିକଣା **: ଡିଫଲ୍ଟ ଭାବରେ, ନୋଡ୍ କି ଏବଂ `base64url` ଏନକୋଡେଡ୍ `iroh` ଠିକଣା ସ୍ୱୟଂଚାଳିତ ଭାବରେ ସର୍ବସାଧାରଣ IP କୁ ମନେରଖିବା କିମ୍ବା ପ୍ରକାଶ କରିବା ଆବଶ୍ୟକ ନକରି `~/.config/sync0` ରେ ସୃଷ୍ଟି ହୁଏ |
- ** ଚାହିଦା ଉପରେ ମଲ୍ଟି-ସିଲେକ୍ଟ ସିଙ୍କ୍ରୋନାଇଜେସନ୍ **: ସମଗ୍ର ଅଂଶୀଦାର ଗୋଷ୍ଠୀର ସିଙ୍କ୍ରୋନାଇଜେସନ୍ କୁ ସମର୍ଥନ କରେ, ଏବଂ ଏକ ସମୟରେ ଏକାଧିକ ଫାଇଲ୍ କିମ୍ବା ସବ୍ ଡିରେକ୍ଟୋରୀ ଚୟନ କରି ଚାହିଦା ଅନୁଯାୟୀ ସିଙ୍କ୍ରୋନାଇଜେସନ୍ କୁ ମଧ୍ୟ ସମର୍ଥନ କରେ |
- ** ଗ୍ରୁପ୍ ସଦସ୍ୟ ହାଇରାର୍କିକାଲ୍ ଅନୁମତି ଏବଂ ଡିରେକ୍ଟୋରୀ ନିୟନ୍ତ୍ରଣ ଅପଲୋଡ୍ **: କେବଳ ପଠନୀୟ (`ro`), ପଠନ-ଲିଖନ ଅପଲୋଡ୍ (`rw`), ଏବଂ ପରିଚାଳନା (`admin`) ଅନୁମତିକୁ ସମର୍ଥନ କରେ ଏବଂ ପୃଥକ ଭାବରେ ନିର୍ଦ୍ଦିଷ୍ଟ କରିପାରିବ ଯେ ପ୍ରତ୍ୟେକ ସଦସ୍ୟଙ୍କୁ ଅପଲୋଡ୍ କରିବାକୁ ଅନୁମତି ଦିଆଯାଇଛି (ଡିଫଲ୍ଟ ଭାବରେ, ଅଂଶର ମୂଳ ଡିରେକ୍ଟୋରୀକୁ ଅପଲୋଡ୍ କରିବାକୁ ଅନୁମତି ଦିଆଯାଇଛି) |
- ** ନେଟୱାର୍କରେ ଫୁଲ୍ ସ୍ପିଡ୍ ଏବଂ ବର୍ଦ୍ଧିତ ସିଙ୍କ୍ରୋନାଇଜେସନ୍ **: ବଡ଼ ଫାଇଲଗୁଡ଼ିକର ଏକକାଳୀନ ପ୍ରସାରଣ, ସ୍ମୃତିରେ ବୃହତ ଛୋଟ ଫାଇଲଗୁଡ଼ିକର ଏକୀକରଣ, ଏବଂ ଫାଇଲଗୁଡ଼ିକ ଆଂଶିକ ରୂପାନ୍ତରିତ ହେଲେ କେବଳ ସିଙ୍କ୍ରୋନାଇଜଡ୍ ଡାଟା ବ୍ଲକ୍ |

### ପଦ୍ଧତି ୨: ପୂର୍ବନିର୍ଦ୍ଧାରିତ ବାଇନାରୀଗୁଡ଼ିକୁ ଡାଉନଲୋଡ୍ କରନ୍ତୁ |

ସଂପୃକ୍ତ ସିଷ୍ଟମ୍ ପାଇଁ `.tar.xz` ସଙ୍କୋଚିତ ପ୍ୟାକେଜ୍ (ଲିନକ୍ସ, ମାକୋସ୍, ୱିଣ୍ଡୋଜ୍, ଆଣ୍ଡ୍ରଏଡ୍, ଫ୍ରିବିଏସ୍ଡି, ନେଟବିଏସ୍ଡି) କୁ ଡାଉନଲୋଡ୍ କରିବାକୁ [GitHub ରିଲିଜ୍] (/ 0) କୁ ଯାଆନ୍ତୁ, ଏହାକୁ ଅନ୍ଜାଇପ୍ କରନ୍ତୁ ଏବଂ ଏହାକୁ `PATH` ଡିରେକ୍ଟୋରୀରେ ରଖନ୍ତୁ:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## ଶୀଘ୍ର ଆରମ୍ଭ କର |

`sync0` ଡିଫଲ୍ଟ ଭାବରେ ବିନ୍ୟାସ ଡିରେକ୍ଟୋରୀ ଭାବରେ `~/.config/sync0` କୁ ବ୍ୟବହାର କରିଥାଏ (ଯଦି ଆପଣଙ୍କୁ ଅନ୍ୟ ଡିରେକ୍ଟୋରୀକୁ ବଦଳାଇବାକୁ ପଡିବ, ତେବେ ଆପଣ <b ଶ୍ରେଣୀ = "କୋଡ୍"> - c <directory> `) ଯୋଗ କରିପାରିବେ |

### 1. ସ୍ଥାନୀୟ ନୋଡ୍ ଠିକଣା ଏବଂ ବ୍ୟବସାୟ କାର୍ଡ ସେଟିଂ ଦେଖନ୍ତୁ |

```bash
# ସ୍ଥାନୀୟ ନୋଡ୍ ଠିକଣା ଦେଖନ୍ତୁ (ଚାବି ସ୍ୱୟଂଚାଳିତ ଭାବରେ ~ / .config / sync0 ରେ ସୃଷ୍ଟି ହୁଏ)
sync0 id

# ଏକ ବ୍ୟକ୍ତିଗତ ନୋଡ୍ ବ୍ୟବସାୟ କାର୍ଡ ସୃଷ୍ଟି କରନ୍ତୁ (ବ୍ୟବହାରକାରୀ ନାମ, ସହର, ଇମେଲ୍, ୱେବସାଇଟ୍ ଏବଂ 256 ଶବ୍ଦ ମଧ୍ୟରେ ଦସ୍ତଖତକୁ ସମର୍ଥନ କରେ)
sync0 profile -u alice --region SHA --email alice@example.com --url https://example.com -b "Shanghai node"
```

### 2. ଏକାଧିକ ଫାଇଲ୍ ଅଂଶୀଦାର ଗୋଷ୍ଠୀ ପ୍ରକାଶ କରନ୍ତୁ ଏବଂ ଗୋଷ୍ଠୀ ସଦସ୍ୟ ଅନୁମତି ସେଟ୍ କରନ୍ତୁ (`.nt` ବିନ୍ୟାସ)

`sync0` [NestedText] (/ 1) (`.nt`) ଫର୍ମାଟରେ ବିନ୍ୟାସିତ ହୋଇଛି | ପ୍ରତ୍ୟେକ ଉପଭୋକ୍ତାଙ୍କର ଅଲଗା `.nt` ବିନ୍ୟାସ ଫାଇଲ ଅଛି | ଆପଣ `config.nt` ରେ `users_dir` ମାଧ୍ୟମରେ ଉପଭୋକ୍ତା ପ୍ରୋଫାଇଲ୍ ଡିରେକ୍ଟୋରୀକୁ ନିର୍ଦ୍ଦିଷ୍ଟ କରିପାରିବେ (ଯାହା ସ୍ୱୟଂଚାଳିତ ଭାବରେ ଏହି ଡିରେକ୍ଟୋରୀରେ ସମସ୍ତ `.nt` ଫାଇଲଗୁଡ଼ିକୁ ଅନ୍ତର୍ଭୂକ୍ତ କରେ) | ଅପଲୋଡ୍ ହେବା ପାଇଁ ଉଭୟ ଉପଭୋକ୍ତା ଏବଂ ପଥ ଉପସର୍ଗ ଏକ ଅଣସଂରକ୍ଷିତ ତାଲିକା ବ୍ୟବହାର କରନ୍ତୁ (`-`) | ** ଯେତେବେଳେ ଅପଲୋଡ୍ ପାଥ୍ ଉପସର୍ଗ ପୂର୍ଣ୍ଣ ହୁଏ ନାହିଁ, ଅଂଶର ମୂଳ ଡିରେକ୍ଟୋରୀକୁ ଅପଲୋଡ୍ କରିବା ଡିଫଲ୍ଟ ଭାବରେ ଅନୁମତି ପ୍ରାପ୍ତ ** |

1. `~/.config/sync0/users/` ଡିରେକ୍ଟୋରୀରେ ପ୍ରତ୍ୟେକ ସଦସ୍ୟଙ୍କ ପାଇଁ ପୃଥକ `.nt` ବିନ୍ୟାସ ଫାଇଲ ସୃଷ୍ଟି କରନ୍ତୁ:

`~/.config/sync0/users/alice.nt` (କେବଳ ପଠନୀୟ ସଦସ୍ୟ, ହାର ସୀମିତ `80MB`, `rate` `GB`, `MB`, `KB` ଏକକ):

```yaml
id: 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c
perm: ro
rate: 80MB
```

`~/.config/sync0/users/bob.nt` (ପ୍ରତିବନ୍ଧିତ ଅପଲୋଡ୍ ସଦସ୍ୟ: କେବଳ `uploads/bob` ଏବଂ `shared/common` ଡିରେକ୍ଟୋରୀକୁ ଅପଲୋଡ୍ କରିବାକୁ ଅନୁମତି ଦିଆଯାଇଛି):

```yaml
id: 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f
perm: rw
write_prefix:
  - uploads/bob
  - shared/common
```

`~/.config/sync0/users/charlie.nt` (ଡିଫଲ୍ଟ ସଦସ୍ୟ ଅପଲୋଡ୍: ଯେତେବେଳେ `write_prefix` ବାଦ ଦିଆଯାଏ, ଅଂଶର ମୂଳ ଡିରେକ୍ଟୋରୀକୁ ଅପଲୋଡ୍ କରିବା ଡିଫଲ୍ଟ ଭାବରେ ଅନୁମତିପ୍ରାପ୍ତ):

```yaml
id: 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
perm: rw
```

2. `~/.config/sync0/config.nt` ରେ ୟୁଜର୍ ଡିରେକ୍ଟୋରୀ ଏବଂ ଏକାଧିକ ଫାଇଲ୍ ଅଂଶୀଦାର ଗୋଷ୍ଠୀକୁ ବିନ୍ୟାସ କରନ୍ତୁ:

```yaml
users_dir: ./users

groups:
  dataset:
    path: ./data
    auth: false
    perm: ro
    rate: 50MB

  models:
    path: ./models
    auth: false
    perm: ro
    rate: 1GB

  team-vault:
    path: ./vault
    auth: true
    perm: ro
    rate: 512KB
    users:
      - alice
      - bob
      - charlie
```

ସେବା ବାଣ୍ଟିବା ଆରମ୍ଭ କରନ୍ତୁ:

```bash
# ସିଧାସଳଖ ଷ୍ଟାର୍ଟଅପ୍ (automatically / .config / sync0 / config.nt ଏବଂ users_dir ଡିରେକ୍ଟୋରୀରେ ସ୍ୱୟଂଚାଳିତ ଭାବରେ ସମସ୍ତ .nt ବ୍ୟବହାରକାରୀ ବିନ୍ୟାସଗୁଡ଼ିକୁ ଧାରଣ କରିଥାଏ)
sync0 share --region SHA

# କିମ୍ବା ଶୀଘ୍ର ଏକାଧିକ ଅଂଶୀଦାର ଗୋଷ୍ଠୀ ପ୍ରକାଶ କରନ୍ତୁ ଏବଂ କମାଣ୍ଡ୍ ଲାଇନ୍ ମାଧ୍ୟମରେ ଗୋଷ୍ଠୀ ସଦସ୍ୟମାନଙ୍କୁ ସିଧାସଳଖ ଅନୁମତି ଦିଅନ୍ତୁ |
sync0 share dataset:./data team-vault:./vault \
  --auth \
  --allow-ro 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c \
  --allow-rw 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f:uploads/bob,shared/common \
  --allow-rw 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
```

### 3. ସମସ୍ତ ବିଷୟବସ୍ତୁ ଟାଣନ୍ତୁ କିମ୍ବା ଏକାଧିକ ଫାଇଲ ଏବଂ ଡିରେକ୍ଟୋରୀ ଚୟନ କରନ୍ତୁ (`sync0 pull`)

ଅଂଶୀଦାର ଗୋଷ୍ଠୀର ସମସ୍ତ ଉପଲବ୍ଧ ବିହନ ନୋଡଗୁଡିକ ସ୍ୱୟଂଚାଳିତ ଭାବରେ ପାଇବାକୁ ଯେକ any ଣସି ସାଥି ନୋଡ ସହିତ ସଂଯୋଗ କରନ୍ତୁ, ଏବଂ ଏକକାଳୀନ ଏକାଧିକ ବିହନ ନୋଡରୁ ଟାଣନ୍ତୁ:

```bash
# ସମଗ୍ର ଡାଟାସେଟ୍ ଅଂଶୀଦାର ଗୋଷ୍ଠୀକୁ ସ୍ଥାନୀୟ ./local_data କୁ ଟାଣନ୍ତୁ |
sync0 ଟାଣ ଡାଟାସେଟ: // ./local_data -p <ନୋଡ ଠିକଣା> |

# ମଲ୍ଟି-ସିଲେକ୍ଟ ସିଙ୍କ୍ରୋନାଇଜେସନ୍: ଏକାସାଙ୍ଗରେ ଏକକ ଫାଇଲ୍ ଡକସ୍ / ରିଡମେ। Md ଏବଂ ସବ୍ ଡିରେକ୍ଟୋରୀ ସମ୍ପତ୍ତି / ଆଇକନ୍, src / କୋର୍ ଟାଣନ୍ତୁ |
sync0 pull dataset: //docs/readme.md,assets/icons,src/core ./local_data -p <node ଠିକଣା>
```

### 4. ଏକ ଅଂଶୀଦାର ଗୋଷ୍ଠୀକୁ ଏକ ଫାଇଲ୍ କିମ୍ବା ଡିରେକ୍ଟୋରୀ ଅପଲୋଡ୍ କରନ୍ତୁ (`sync0 push`)

ଅପଲୋଡ୍ ଅନୁମତି ଥିବା ସଦସ୍ୟମାନେ (`rw` କିମ୍ବା `admin`) ରିମୋଟ୍ ଅଂଶୀଦାର ଗୋଷ୍ଠୀକୁ ସ୍ଥାନୀୟ ଫାଇଲ୍ କିମ୍ବା ଡିରେକ୍ଟୋରୀଗୁଡିକ ଅପଲୋଡ୍ କରିପାରିବେ:

```bash
# ରୁଟ୍ ଡିରେକ୍ଟୋରୀ ସହିତ ସଦସ୍ୟମାନେ ଅପଲୋଡ୍ ଅନୁମତି: ଅଂଶୀଦାରିତ ରୁଟ୍ ଡିରେକ୍ଟୋରୀକୁ ସିଧାସଳଖ ଅପଲୋଡ୍ କରନ୍ତୁ |
sync0 push team-vault: // ./new_release -p <node ଠିକଣା> |

# କେବଳ ଏକ ନିର୍ଦ୍ଦିଷ୍ଟ ଉପସର୍ଗକୁ ଅନୁମତି ପ୍ରାପ୍ତ ସଦସ୍ୟମାନେ (ଯେପରିକି ଅପଲୋଡ୍ / ବବ୍): ଅନୁମୋଦିତ ପଥ ଉପସର୍ଗରେ ଅପଲୋଡ୍ କରନ୍ତୁ |
sync0 push team-vault: //uploads/bob/report.pdf ./report.pdf -p <ନୋଡ୍ ଠିକଣା>
```

### 5. ସ୍ୱୟଂଚାଳିତ ସିଙ୍କ ଏବଂ ବିହନକୁ ସବସ୍କ୍ରାଇବ କରନ୍ତୁ (`sync0 sub`)

ଏକ ନିର୍ଦ୍ଦିଷ୍ଟ ନୋଡର ଅଂଶୀଦାର ଗୋଷ୍ଠୀକୁ ସବସ୍କ୍ରାଇବ କରିବା ପରେ, ସ୍ଥାନୀୟ ସର୍ଭର ଉଭୟ ଗ୍ରହଣକାରୀ କ୍ଲାଏଣ୍ଟ ଏବଂ ଏକ ନୂତନ ବିହନ ସର୍ଭର ଅଟେ | ଯେତେବେଳେ ଉତ୍ସ ନୋଡ୍ ଫାଇଲ୍ ଅପଡେଟ୍ ହୁଏ, ଏହା ସ୍ୱୟଂଚାଳିତ ଭାବରେ ସିଙ୍କ୍ରୋନାଇଜ୍ ହୁଏ ଏବଂ ଅନ୍ୟ ନୋଡଗୁଡ଼ିକ ପାଇଁ ଖଣ୍ଡ ଡାଉନଲୋଡ୍ ପ୍ରଦାନ କରେ:

```bash
# ସମଗ୍ର ଅଂଶୀଦାର ଗୋଷ୍ଠୀକୁ ସବସ୍କ୍ରାଇବ କରନ୍ତୁ ଏବଂ ସ୍ୱୟଂଚାଳିତ ଭାବରେ ବିହନ ଦିଅନ୍ତୁ |
sync0 ସବ୍ ଡାଟାସେଟ୍: // ./local_mirror -p <ନୋଡ୍ ଠିକଣା> |

# ନିର୍ଦ୍ଦିଷ୍ଟ ଫାଇଲ୍ ଏବଂ ସବ୍ ଡିରେକ୍ଟୋରୀକୁ ସବସ୍କ୍ରାଇବ କରିବା ଏବଂ ସେଗୁଡିକୁ ବିହନ ଦେବା ପାଇଁ କେବଳ ମଲ୍ଟି-ସିଲେକ୍ଟ |
sync0 ସବ୍ ଡାଟାସେଟ୍: //models/llama.onnx,configs ./local_mirror -p <node ଠିକଣା>
```

### 6. ମଲ୍ଟି ମେସିନ୍ ଗ୍ରୁପ୍ ସାଥି ସିଙ୍କ୍ରୋନାଇଜେସନ୍ (`sync0 group`)

ଏକାଧିକ ମେସିନ୍ ସମାନ ଅଂଶୀଦାର ଗୋଷ୍ଠୀରେ ଯୋଗ ଦିଅନ୍ତି, ପରସ୍ପର ସ୍ୱୟଂଚାଳିତ ଭାବରେ ଉପଲବ୍ଧ ବିହନ ନୋଡଗୁଡିକ ଆବିଷ୍କାର କରନ୍ତି ଏବଂ ଦୁଇ-ମାର୍ଗ ସିଙ୍କ୍ରୋନାଇଜେସନ୍ ପରିଚାଳନା କରନ୍ତି (ପୂର୍ଣ୍ଣ ସିଙ୍କ୍ରୋନାଇଜେସନ୍ କିମ୍ବା ଫାଇଲ୍ ଏବଂ ଡିରେକ୍ଟୋରୀଗୁଡିକର ଏକାଧିକ ଚୟନକୁ ସମର୍ଥନ କରେ):

```bash
# ସମ୍ପୁର୍ଣ୍ଣ ଭାବରେ ଗୋଷ୍ଠୀ ଏବଂ ଦୁଇ-ମାର୍ଗ ସିଙ୍କ୍ରୋନାଇଜେସନ୍ରେ ଯୋଗ ଦିଅନ୍ତୁ |
sync0 ଗୋଷ୍ଠୀ ଦଳ-ଡକସ୍: // ./docs -p <ନୋଡ୍ ଠିକଣା> |

# ମଲ୍ଟି-ସିଲେକ୍ଟ ସିଙ୍କ୍ରୋନାଇଜେସନ୍ ଗ୍ରୁପ୍ ରେ କେବଳ ୱାଲ୍ ଡିରେକ୍ଟୋରୀ ଏବଂ meta.json ଫାଇଲ୍ |
sync0 ଗୋଷ୍ଠୀ ଦଳ-ଡକସ୍: //wal,meta.json ./docs -p <ନୋଡ୍ ଠିକଣା>
```

### 7. ଦୁଇଟି ମେସିନ୍ ମଧ୍ୟରେ ପଏଣ୍ଟ-ଟୁ-ପଏଣ୍ଟ ପ୍ରତ୍ୟକ୍ଷ ପ୍ରସାରଣ (`send` / `recv`)

ଗୋଷ୍ଠୀକୁ ପୂର୍ବ-ବିନ୍ୟାସ କରିବାର କ is ଣସି ଆବଶ୍ୟକତା ନାହିଁ, ଏବଂ ଆପଣ ଅସ୍ଥାୟୀ ଭାବରେ ଦୁଇଟି ମେସିନ୍ ମଧ୍ୟରେ ଫାଇଲ କିମ୍ବା ଡିରେକ୍ଟୋରୀ ସ୍ଥାନାନ୍ତର କରିପାରିବେ:

```bash
# ରିସିଭର୍ ମନିଟରିଂ |
sync0 recv 0.0.0.0:9000 ./backup

# ପ୍ରେରଣ ଶେଷ ଫାଇଲ କିମ୍ବା ଡିରେକ୍ଟୋରୀକୁ ସିଧାସଳଖ ସ୍ଥାନାନ୍ତର କରେ (ଅତିରିକ୍ତ ଫାଇଲଗୁଡିକ ସଫା କରିବା ପାଇଁ ବ al କଳ୍ପିକ - ଡିଲିଟ୍ ଦର୍ପଣ, - ସ୍ପିଡ୍ ସୀମା)
sync0 send ./project 192.168.1.10:9000
```

### 8. ଏକାଧିକ ଭାଷା ସୁଇଚ୍

`sync0` 75 ଭାଷାକୁ ସମର୍ଥନ କରେ, ଏବଂ ସ୍ୱୟଂଚାଳିତ ଭାବରେ ସିଷ୍ଟମ୍ ଭାଷା ପରିବେଶ ଅନୁଯାୟୀ ସ୍ୱିଚ୍ ହୁଏ; ଏହାକୁ `SYNC0_LANG` ମାଧ୍ୟମରେ ହସ୍ତକୃତ ଭାବରେ ନିର୍ଦ୍ଦିଷ୍ଟ କରାଯାଇପାରିବ:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
