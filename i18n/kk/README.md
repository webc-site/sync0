# sync0

`sync0` - бұл Resilio Sync-пен бәсекелесетін тең дәрежелі (P2P) файлды ортақ пайдалану және көп машинаны синхрондау құралы.

Әрбір машина сервер де, клиент те: кез келген түйін бірнеше файлды ортақ пайдалану топтарын жариялай алады. Басқа түйіндер қосылғаннан кейін олар тең серверден қол жетімді тұқымдық түйіндерді автоматты түрде ала алады және оларды бірнеше көздерден бір уақытта тарта алады. Синхрондау аяқталғаннан кейін жүктеулерді жылдамдату үшін көбірек түйіндер үшін тұқымдар автоматты түрде жасалады.

## Негізгі ерекшеліктер

- **Әрбір адам сервер де, клиент те**: Resilio Sync-пен салыстыруға болады, орталық серверге тәуелділік жоқ. Кез келген түйін бірнеше файлды ортақ пайдалану топтарын жасай алады, сонымен қатар басқа адамдардың ортақ топтарына қосыла алады; түйіндер бір мезгілде тарту және бірнеше машиналарды нақты уақытта синхрондауға қол жеткізу үшін қол жетімді тұқым түйіндерін автоматты түрде алмастырады және алады.
- **IP-сіз түйін мекенжайы**: Әдепкі бойынша түйін кілті және `base64url` кодталған `iroh` мекенжайы жалпыға ортақ IP мекенжайын есте сақтауды немесе көрсетуді қажет етпестен `~/.config/sync0` ішінде автоматты түрде жасалады.
- **Сұраныс бойынша көп таңдауды синхрондау**: бүкіл бөлісу тобының синхрондауына қолдау көрсетеді, сонымен қатар бір уақытта бірнеше файлдарды немесе ішкі каталогтарды таңдау арқылы сұраныс бойынша үндестіруді қолдайды.
- **Топ мүшесінің иерархиялық рұқсаттары және жүктеп салу каталогын басқару**: тек оқуға (`ro`), оқу-жазуды жүктеп салуға (`rw`) және басқаруға (`admin`) рұқсаттарды қолдайды және әрбір мүше жүктеп салуға рұқсат етілген жол префиксін жеке белгілей алады (әдепкі бойынша, директорияға бөлісуді жүктеп салуға рұқсат етіледі).
- **Желілер бойынша толық жылдамдықты және қадамдық синхрондау**: үлкен файлдарды бір мезгілде жіберу, жадтағы ауқымды шағын файлдарды біріктіру және файлдар ішінара өзгертілген кезде ғана синхрондалған деректер блоктары.

## Орнату

### 1-әдіс: Жүк арқылы орнату

```bash
cargo install sync0
```

### 2-әдіс: Алдын ала құрастырылған екілік файлдарды жүктеп алыңыз

Сәйкес жүйеге арналған (Linux, macOS, Windows, Android, FreeBSD, NetBSD қолдайды) `.tar.xz` қысылған буманы жүктеп алу үшін [GitHub шығарылымдары](https://github.com/webc-site/sync0/releases) бөліміне өтіңіз, архивтен шығарып, `PATH` каталогына салыңыз:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## Тез бастаңыз

`sync0` әдепкі бойынша конфигурация каталогы ретінде `~/.config/sync0` пайдаланады (басқа каталогтарға ауысу қажет болса, `-c <каталогы>` қосуға болады).

### 1. Жергілікті түйін мекенжайын және орнату визит картасын қараңыз

```bash
# Жергілікті түйін мекенжайын көру (кілт ~/.config/sync0 ішінде бірінші рет автоматты түрде жасалады)
sync0 id

# Жеке түйіннің визит картасын жасаңыз (пайдаланушы атын, қаланы, электрондық поштаны, веб-сайтты және 256 сөз ішінде қолтаңбаны қолдайды)
sync0 profile -u alice --region SHA --email alice@example.com --url https://example.com -b "Shanghai node"
```

### 2. Бірнеше файлды ортақ пайдалану топтарын жариялау және топ мүшелерінің рұқсаттарын орнату (`.nt` Конфигурация)

`sync0` [NestedText](https://nestedtext.org) (`.nt`) пішімінде конфигурацияланған. Әрбір пайдаланушының жеке `.nt` конфигурация файлы болады. Пайдаланушы профилінің каталогын `config.nt` ішіндегі `users_dir` арқылы көрсетуге болады (ол осы каталогтағы барлық `.nt` файлдарды автоматты түрде қамтиды). Пайдаланушы да, жүктеп салуға рұқсат етілген жол префиксі де ретсіз тізімді (`-`) пайдаланады. **Жүктеп салу жолы префиксі толтырылмаған кезде, әдепкі бойынша бөлісудің түбірлік каталогына жүктеп салуға рұқсат етіледі**.

1. `~/.config/sync0/users/` каталогындағы әрбір мүше үшін бөлек `.nt` конфигурация файлдарын жасаңыз:

`~/.config/sync0/users/alice.nt` (тек оқуға арналған мүше, тариф шектеулі `80MB`, `rate` `GB`, `MB`, `KB` бірліктерін қолдайды):

```yaml
id: 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c
perm: ro
rate: 80MB
```

`~/.config/sync0/users/bob.nt` (шектелген жүктеп салу мүшелері: тек `uploads/bob` және `shared/common` каталогтарына жүктеп салуға рұқсат етілген):

```yaml
id: 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f
perm: rw
write_prefix:
  - uploads/bob
  - shared/common
```

`~/.config/sync0/users/charlie.nt` (Әдепкі мүшені жүктеп салу: `write_prefix` көрсетілмегенде, әдепкі бойынша бөлісудің түбірлік каталогына жүктеп салуға рұқсат етіледі):

```yaml
id: 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
perm: rw
```

2. `~/.config/sync0/config.nt` ішінде пайдаланушы каталогын және бірнеше файлды ортақ пайдалану топтарын конфигурациялаңыз:

```yaml
users_dir: ./users

groups:
  dataset:
    path: ./data
    auth: false
    perm: ro
    rate: 50MB

  models:
    path: ./models
    auth: false
    perm: ro
    rate: 1GB

  team-vault:
    path: ./vault
    auth: true
    perm: ro
    rate: 512KB
    users:
      - alice
      - bob
      - charlie
```

Бөлісуді бастау:

```bash
# Тікелей іске қосу (~/.config/sync0/config.nt және users_dir каталогтарындағы барлық .nt пайдаланушы конфигурацияларын автоматты түрде жүктейді)
sync0 share --region SHA

# Немесе бірнеше ортақ топтарды жылдам жариялаңыз және топ мүшелеріне пәрмен жолы арқылы тікелей рұқсат беріңіз
sync0 share dataset:./data team-vault:./vault \
  --auth \
  --allow-ro 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c \
  --allow-rw 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f:uploads/bob,shared/common \
  --allow-rw 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
```

### 3. Барлық мазмұнды тартыңыз немесе бірнеше файлдар мен каталогтарды таңдаңыз (`sync0 pull`)

Ортақ тобындағы барлық қолжетімді тұқым түйіндерін автоматты түрде алу үшін кез келген тең түйінге қосылыңыз және бір уақытта бірнеше тұқымдық түйіндерден тартыңыз:

```bash
# Бүкіл деректер жиынын ортақ пайдалану тобын жергілікті ./local_data файлына тартыңыз
sync0 тарту деректер жинағы:// ./local_data -p <түйін мекенжайы>

# Көп таңдаулы синхрондау: бір уақытта docs/readme.md бір файлды және ішкі каталогтар активтерін/белгішелерін, src/core файлын тартыңыз
sync0 тарту деректер жинағы://docs/readme.md,assets/icons,src/core ./local_data -p <түйін мекенжайы>
```

### 4. Файлды немесе каталогты бөлісу тобына жүктеп салу (`sync0 push`)

Жүктеп салу рұқсаттары бар мүшелер (`rw` немесе `admin`) қашықтағы бөлісу топтарына жергілікті файлдарды немесе каталогтарды жүктеп сала алады:

```bash
# Түбірлік каталогты жүктеп салу рұқсаты бар мүшелер: ортақ түбірлік каталогқа тікелей жүктеп салу
sync0 push team-vault:// ./new_release -p <түйін мекенжайы>

# Арнайы префикске рұқсаты бар мүшелер (мысалы, жүктеп салулар/боб): рұқсат етілген жол префиксіне жүктеп салу
sync0 push team-vault://uploads/bob/report.pdf ./report.pdf -p <түйін мекенжайы>
```

### 5. Автоматты синхрондау және себуге жазылу (`sync0 sub`)

Белгілі бір түйіннің ортақ пайдалану тобына жазылғаннан кейін жергілікті сервер қабылдаушы клиент және жаңа сепкіш сервер болып табылады; бастапқы түйін файлы жаңартылған кезде, ол автоматты түрде синхрондалады және басқа түйіндер үшін бөлшектелген жүктеулерді қамтамасыз етеді:

```bash
# Бүкіл бөлісу тобына жазылыңыз және автоматты түрде себіңіз
sync0 ішкі деректер жинағы:// ./local_mirror -p <түйін мекенжайы>

# Көрсетілген файлдар мен ішкі каталогтарға жазылу және оларды септеу үшін тек бірнеше рет таңдаңыз
sync0 ішкі деректер жинағы://models/llama.onnx,configs ./local_mirror -p <түйін мекенжайы>
```

### 6. Көп машиналық топтық тең синхрондау (`sync0 group`)

Бірнеше машиналар бір ортақ пайдалану тобына қосылады, бір-бірімен қол жетімді тұқымдық түйіндерді автоматты түрде анықтайды және екі жақты синхрондауды қолдайды (толық синхрондауды немесе файлдар мен каталогтардың бірнеше таңдауын қолдайды):

```bash
# Толық топқа қосылу және екі жақты синхрондау
sync0 group team-docs:// ./docs -p <түйін мекенжайы>

# Көп таңдаулы синхрондау тобындағы wal каталогы мен meta.json файлы ғана
sync0 group team-docs://wal,meta.json ./docs -p <түйін мекенжайы>
```

### 7. Екі машина арасындағы нүктеден нүктеге тікелей жіберу (`send` / `recv`)

Топты алдын ала конфигурациялаудың қажеті жоқ және файлдарды немесе каталогтарды уақытша екі құрылғы арасында тікелей тасымалдауға болады:

```bash
# Қабылдаушыны бақылау
sync0 recv 0.0.0.0:9000 ./backup

# Жіберудің соңы файлдарды немесе каталогтарды тікелей тасымалдайды (қосымша - артық файлдарды тазалау үшін айнаны жою, - жылдамдықты шектеу)
sync0 send ./project 192.168.1.10:9000
```

### 8. Көп тілді ауыстыру

`sync0` 75 тілді қолдайды және әдепкі бойынша жүйе тіл ортасына сәйкес автоматты түрде ауысады; оны `SYNC0_LANG` арқылы қолмен де көрсетуге болады:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
