# sync0

`sync0` - файлдарды желілер арқылы тасымалдауға, каталогтарды қадамдық қадамдастыруға және деректерді бір уақытта бірнеше машиналарға таратуға арналған пәрмен жолы құралы.

## Түпнұсқа дизайн ниеті

Кросс-машиналар бөлмелерінде, елдерде немесе желі кідірістері және пакеттердің жоғалуы бар орталарда `rsync` және `scp` сияқты құралдар өткізу қабілеттілігін пайдалануды шектейтін жалғыз қосылым ретін растауға негізделген; бірнеше машина бір серверден деректерді бір уақытта шығарғанда, бастапқы сервердің желілік картасы оңай тығырықтан шығуы мүмкін.

`sync0` мақсаты екі мәселені шешу болып табылады:

1. Екі машина арасындағы файл мен каталогты синхрондау толық физикалық өткізу қабілеттілігін іске қосыңыз және файл жартылай өзгертілгенде ғана өзгертілген бөлікті тасымалдаңыз.
2. Бір каталогты синхрондау кезінде бірнеше машиналар деректер блоктарын бір-біріне тасымалдай алады, бастапқы сервердегі жүктемені азайтады және жалпы синхрондау уақытын қысқартады.

## rsync-пен жылдамдықты салыстыру

Сынақ ортасы: еуропалық түйін $\leftrightarrow$ Солтүстік Америка түйіні, бару кідірісі 86 мс, толық уақытты қажет ететін каталогты сканерлеуді, қайталауды салыстыруды, желіні жіберуді және дискіні орналастыруды тексеруді қоса алғанда:

| Тасымалдау сценарийі | Деректер өлшемі | `sync0` | `rsync` | бірнеше |
| :--- | :---: | :---: | :---: | :---: |
| 10 000 шағын файлдар | 77.6 MB | 0.90 s (688 Mbps) | 4.86 s (128 Mbps) | 5.4x |
| Код және мұрағат бумалары (`.tar`) | 512 MB | 1.94 s (2111 Mbps) | 9.36 s (438 Mbps) | 4.8x |
| Бейне файлы (`.mp4`) | 512 MB | 7.36 s (556 Mbps) | 12.11 s (338 Mbps) | 1.6x |
| Қосымша синхрондау (1% мазмұнды өзгерту) | 512 MB | 0.12 s | 1.85 s | 15.4x |

## Тиімділікті арттыру әдістері

- **UDP бір мезгілде жіберу**: деректер блоктарын UDP арқылы жіберіңіз және кейінгі файлдарды тасымалдауды блоктайтын бір пакет жоғалуын болдырмау үшін тек жоғалған фрагменттерді қайта жіберіңіз.
- **Мазмұнды сегменттеу және қайталау**: файлды мазмұнға сәйкес деректер блоктарына бөліп, тексеру мәнін есептеңіз. Қабылдаушы жақтағы бірдей мазмұн желіні қайталамастан тікелей жергілікті түрде қайта пайдаланылады.
- **Желі жылдамдығына сәйкес қысуды автоматты түрде реттеу**: мәтін және код сияқты қысылатын мазмұн үшін қысуды қосыңыз; процессорды тұтынуды азайту үшін бейнелер, суреттер, қысылған пакеттер немесе жоғары жылдамдықты LAN астында қысуды автоматты түрде өткізіп жіберіңіз.
- **Маңайдағы көп түйінді тарту**: Бірнеше машина бір каталогты тартқанда, деректер блоктары бір қаладағы жүктеп алынған түйіндерден бір уақытта немесе аз кідіріспен шығарылады.

## Орнату

### 1-әдіс: Жүк арқылы орнату

```bash
cargo install sync0
```

### 2-әдіс: Алдын ала құрастырылған екілік файлдарды жүктеп алыңыз

Сәйкес жүйеге (Linux x86_64/ARM64, macOS Apple Silicon/Intel, Windows x64/ARM64, Android ARM64/x86_64, FreeBSD, NetBSD қолдау көрсетеді) `.tar.xz` қысылған бумасын жүктеп алу үшін [GitHub шығарылымдары](https://github.com/webc-site/sync0/releases) бөліміне өтіңіз. Файлды ашқаннан кейін `sync0` каталогын `PATH` каталогына орналастырыңыз:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## Пайдаланушы нұсқаулығы

### 1. Екі машина арасында файлдарды немесе каталогтарды тікелей тасымалдау

Қабылдаушы машинада бақылауды бастаңыз және қабылдау және сақтау жолын көрсетіңіз:

```bash
sync0 recv 0.0.0.0:9000 ./backup
```

Жіберуші машинадан бір файлды немесе бүкіл каталогты жіберіңіз:

```bash
sync0 send ./project 192.168.1.10:9000
```

Жиі қолданылатын параметрлер:

```bash
# Қабылдаушы жақта бар, бірақ жіберу жағында емес артық файлдарды жою (айна синхрондау)
sync0 send ./project 192.168.1.10:9000 --delete

# Жіберу жылдамдығын шектеу (бірлік: байт/секунд, мысалы 50 МБ/с)
sync0 send ./project 192.168.1.10:9000 --rate 50000000

# Үнсіз режим (прогресс жолағы көрсетілмейді)
sync0 send ./project 192.168.1.10:9000 -q
```

### 2. Ортақ каталогтарды жариялау және бірнеше түйіндерден тарту

Бастапқы серверде ортақ каталогты (`dataset` атты) жариялаңыз:

```bash
sync0 share dataset ./data --region SHA
```

Ортақ каталогты басқа машиналарда тартыңыз (бір уақытта тарту үшін үтірмен бөлінген бірнеше түйін мекенжайларын бір уақытта толтыруға болады):

```bash
sync0 pull 10.0.0.1:9000,10.0.0.2:9000 dataset ./local_data
```

Ортақ каталогтағы белгілі бір ішкі каталогты ғана тартыңыз:

```bash
sync0 pull 10.0.0.1:9000 dataset ./local_data --subpath 2026/logs
```

Жергілікті өзгертулерді қашықтағы ортақ каталогқа қайтарыңыз:

```bash
sync0 push 10.0.0.1:9000 dataset ./local_data
```

### 3. Каталогтың автоматты жаңартуларына жазылыңыз

Бастапқы түйіннің ортақ каталогына жазылыңыз. Файл бастапқы каталогқа қосылғанда немесе өзгертілгенде, ол автоматты түрде жергілікті компьютермен үндестіріледі. Сонымен қатар, жергілікті машина автоматты түрде басқа машиналарды тарту үшін түйін ретінде қызмет етеді:

```bash
sync0 sub 10.0.0.1:9000 dataset ./local_mirror
```

### 4. Көп машиналық топтарды екі жақты синхрондау

Бір топ атына бірнеше машиналар қосылады және кез келген түйін каталогындағы өзгерістер топтағы басқа түйіндермен автоматты түрде синхрондалады:

```bash
sync0 group team-docs ./docs 10.0.0.1:9000,10.0.0.2:9000
```

### 5. Түйіннің жеке куәлігі және жеке визит картасы

Әрбір түйін пайдаланушы атын, қаланы, электрондық поштаны, веб-сайтты және жеке қолтаңбаны (ең көбі 256 таңба) орнатуды қолдайды және жергілікті жеке кілт қолтаңбасының аутентификациясынан өтеді:

```bash
# Жергілікті жалпы кілт идентификаторын көру (кілтті сақтау үшін конфигурация каталогын көрсетіңіз)
sync0 id -c ~/.config/sync0

# Жекелендірілген қолтаңбалары бар түйін визиткаларын жасаңыз және көрсетіңіз
sync0 profile -c ~/.config/sync0 \
  -u alice \
  --region SHA \
  --email alice@example.com \
  --url https://example.com \
  -b "Shanghai backup node"
```

`share`, `pull`, `sub`, `group` осы профиль параметрлерімен де іске қосылуы мүмкін:

```bash
sync0 share dataset ./data -c ~/.config/sync0 -u alice --region SHA -b "Shanghai backup node"
```

### 6. Көп тілді ауыстыру

`sync0` 75 тілді қолдайды. Әдепкі бойынша пәрмен жолы анықтамасы мен сәйкес тілдегі сұраулар операциялық жүйенің тілдік ортасына сәйкес автоматты түрде көрсетіледі; егер жүйе тілі қолдау көрсетілетін тізімде болмаса, ағылшын тілі әдепкі бойынша пайдаланылады.

Тілді қолмен көрсету үшін, орта айнымалы мәнін `SYNC0_LANG` орнатыңыз:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
