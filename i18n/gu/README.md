# sync0

`sync0` એ પીઅર-ટુ-પીઅર (P2P) ફાઇલ શેરિંગ અને મલ્ટિ-મશીન સિંક્રોનાઇઝેશન ટૂલ છે જે Resilio Sync સાથે સ્પર્ધા કરે છે.

દરેક મશીન સર્વર અને ક્લાયન્ટ બંને છે: કોઈપણ નોડ બહુવિધ ફાઇલ શેરિંગ જૂથો પ્રકાશિત કરી શકે છે. અન્ય ગાંઠો જોડાયા પછી, તેઓ પીઅર સર્વરમાંથી આપમેળે ઉપલબ્ધ બીજ ગાંઠો મેળવી શકે છે અને બહુવિધ સ્ત્રોતોમાંથી એકસાથે ખેંચી શકે છે. સિંક્રનાઇઝેશન પૂર્ણ થયા પછી, ડાઉનલોડને વેગ આપવા માટે વધુ નોડ માટે બીજ આપમેળે બનાવવામાં આવશે.

## કોર હાઇલાઇટ્સ

- **દરેક વ્યક્તિ સર્વર અને ક્લાયંટ બંને છે**: રેસિલિયો સિંક સાથે તુલનાત્મક, કોઈ કેન્દ્રીય સર્વર નિર્ભરતા નથી. કોઈપણ નોડ બહુવિધ ફાઇલ શેરિંગ જૂથો બનાવી શકે છે, અને અન્ય લોકોના શેરિંગ જૂથોમાં પણ જોડાઈ શકે છે; ગાંઠો આપમેળે વિનિમય કરે છે અને ઉપલબ્ધ સીડ ગાંઠો મેળવે છે જેથી બહુવિધ મશીનોના સહવર્તી પુલિંગ અને રીઅલ-ટાઇમ સિંક્રનાઇઝેશન પ્રાપ્ત થાય.
- **IP-ફ્રી નોડ સરનામું**: મૂળભૂત રીતે, નોડ કી અને `base64url` એન્કોડ કરેલ `iroh` સરનામું આપમેળે `~/.config/sync0` માં જનરેટ થાય છે.
- **મલ્ટિ-સિલેક્ટ સિંક્રનાઇઝેશન ઓન ડિમાન્ડ**: સમગ્ર શેરિંગ ગ્રૂપના સિંક્રોનાઇઝેશનને સપોર્ટ કરે છે અને એક જ સમયે બહુવિધ ફાઇલો અથવા સબડિરેક્ટરીઝ પસંદ કરીને ડિમાન્ડ પર સિંક્રનાઇઝેશનને પણ સપોર્ટ કરે છે.
- **જૂથ સભ્ય અધિક્રમિક પરવાનગીઓ અને અપલોડ ડિરેક્ટરી નિયંત્રણ**: ફક્ત વાંચવા માટે (`ro`), વાંચવા-લખવા અપલોડ (`rw`), અને સંચાલન (`admin`) પરવાનગીઓને સમર્થન આપે છે, અને દરેક સભ્યને અપલોડ કરવાની મંજૂરી હોય તે પાથ ઉપસર્ગને વ્યક્તિગત રીતે નિર્દિષ્ટ કરી શકે છે (ડિફૉલ્ટ રૂપે, શેર ડાયરેક્ટરી અપલોડ કરવા માટે મંજૂર છે).
- **નેટવર્ક પર પૂર્ણ-સ્પીડ અને ઇન્ક્રીમેન્ટલ સિંક્રનાઇઝેશન**: મોટી ફાઇલોનું સહવર્તી ટ્રાન્સમિશન, મેમરીમાં મોટી નાની ફાઇલોનું એકત્રીકરણ, અને જ્યારે ફાઇલોને આંશિક રીતે સંશોધિત કરવામાં આવે ત્યારે જ સિંક્રનાઇઝ્ડ ડેટા બ્લોક્સ.

## ઇન્સ્ટોલ કરો

### પદ્ધતિ 1: કાર્ગો દ્વારા ઇન્સ્ટોલ કરો

```bash
cargo install sync0
```

### પદ્ધતિ 2: પૂર્વસંકલિત દ્વિસંગી ડાઉનલોડ કરો

અનુરૂપ સિસ્ટમ (Linux, macOS, Windows, Android, FreeBSD, NetBSD ને સપોર્ટ કરે છે) માટે `.tar.xz` સંકુચિત પેકેજ ડાઉનલોડ કરવા [GitHub Releases](https://github.com/webc-site/sync0/releases) પર જાઓ, અનઝિપ કરો અને તેને `PATH` ડિરેક્ટરીમાં મૂકો:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## ઝડપથી શરૂ કરો

`sync0` ડિફૉલ્ટ રૂપે રૂપરેખાંકન નિર્દેશિકા તરીકે `~/.config/sync0` નો ઉપયોગ કરે છે (જો તમારે અન્ય ડિરેક્ટરીઓ પર સ્વિચ કરવાની જરૂર હોય, તો તમે `-c <directory>` ઉમેરી શકો છો).

### 1. સ્થાનિક નોડ સરનામું અને સેટિંગ બિઝનેસ કાર્ડ જુઓ

```bash
# સ્થાનિક નોડ સરનામું જુઓ (કી પ્રથમ વખત ~/.config/sync0 માં આપમેળે જનરેટ થાય છે)
sync0 id

# પર્સનલ નોડ બિઝનેસ કાર્ડ જનરેટ કરો (વપરાશકર્તાના નામ, શહેર, ઈમેલ, વેબસાઈટ અને 256 શબ્દોની અંદર સહીને સપોર્ટ કરે છે)
sync0 profile -u alice --region SHA --email alice@example.com --url https://example.com -b "Shanghai node"
```

### 2. બહુવિધ ફાઇલ શેરિંગ જૂથો પ્રકાશિત કરો અને જૂથ સભ્ય પરવાનગીઓ સેટ કરો (`.nt` ગોઠવણી)

`sync0` [NestedText](https://nestedtext.org) (`.nt`) ફોર્મેટમાં ગોઠવેલ છે. દરેક વપરાશકર્તા પાસે અલગ `.nt` ગોઠવણી ફાઇલ હોય છે. તમે `config.nt` માં `users_dir` દ્વારા વપરાશકર્તા પ્રોફાઇલ ડિરેક્ટરીનો ઉલ્લેખ કરી શકો છો (જે આ ડિરેક્ટરીમાંની બધી `.nt` ફાઇલોને આપમેળે સમાવે છે). અપલોડ કરવા માટે માન્ય વપરાશકર્તા અને પાથ ઉપસર્ગ બંને અક્રમાંકિત સૂચિ (`-`) નો ઉપયોગ કરે છે. **જ્યારે અપલોડ પાથ ઉપસર્ગ ભરાયેલો ન હોય, ત્યારે શેરની રૂટ ડાયરેક્ટરી પર અપલોડ કરવાની ડિફોલ્ટ રૂપે મંજૂરી છે**.

1. `~/.config/sync0/users/` ડિરેક્ટરીમાં દરેક સભ્ય માટે અલગ `.nt` રૂપરેખાંકન ફાઇલો બનાવો:

`~/.config/sync0/users/alice.nt` (ફક્ત વાંચવા માટેના સભ્ય, દર મર્યાદિત `80MB`, `rate` `GB`, `MB`, `KB` એકમોને સપોર્ટ કરે છે):

```yaml
id: 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c
perm: ro
rate: 80MB
```

`~/.config/sync0/users/bob.nt` (પ્રતિબંધિત અપલોડ સભ્યો: માત્ર `uploads/bob` અને `shared/common` ડિરેક્ટરીઓ પર અપલોડ કરવાની મંજૂરી છે):

```yaml
id: 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f
perm: rw
write_prefix:
  - uploads/bob
  - shared/common
```

`~/.config/sync0/users/charlie.nt` (ડિફૉલ્ટ સભ્ય અપલોડ: જ્યારે `write_prefix` અવગણવામાં આવે છે, ત્યારે ડિફૉલ્ટ રૂપે શેરની રૂટ ડિરેક્ટરીમાં અપલોડ કરવાની મંજૂરી છે):

```yaml
id: 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
perm: rw
```

2. `~/.config/sync0/config.nt`માં વપરાશકર્તા નિર્દેશિકા અને બહુવિધ ફાઇલ શેરિંગ જૂથોને ગોઠવો:

```yaml
users_dir: ./users

groups:
  dataset:
    path: ./data
    auth: false
    perm: ro
    rate: 50MB

  models:
    path: ./models
    auth: false
    perm: ro
    rate: 1GB

  team-vault:
    path: ./vault
    auth: true
    perm: ro
    rate: 512KB
    users:
      - alice
      - bob
      - charlie
```

શેરિંગ સેવા શરૂ કરો:

```bash
# ડાયરેક્ટ સ્ટાર્ટઅપ (~/.config/sync0/config.nt અને user_dir ડિરેક્ટરીઓમાં તમામ .nt વપરાશકર્તા રૂપરેખાંકનો આપમેળે લોડ થાય છે)
sync0 share --region SHA

# અથવા બહુવિધ શેરિંગ જૂથોને ઝડપથી પ્રકાશિત કરો અને જૂથના સભ્યોને સીધા આદેશ વાક્ય દ્વારા અધિકૃત કરો
sync0 share dataset:./data team-vault:./vault \
  --auth \
  --allow-ro 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c \
  --allow-rw 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f:uploads/bob,shared/common \
  --allow-rw 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
```

### 3. બધી સામગ્રી ખેંચો અથવા બહુવિધ ફાઇલો અને ડિરેક્ટરીઓ પસંદ કરો (`sync0 pull`)

શેરિંગ જૂથમાં તમામ ઉપલબ્ધ બીજ ગાંઠો આપમેળે મેળવવા માટે કોઈપણ પીઅર નોડ સાથે કનેક્ટ કરો અને એકસાથે બહુવિધ બીજ ગાંઠોમાંથી ખેંચો:

```bash
# સમગ્ર ડેટાસેટ શેરિંગ જૂથને સ્થાનિક ./local_data પર ખેંચો
sync0 પુલ ડેટાસેટ:// ./local_data -p <નોડ સરનામું>

# મલ્ટિ-સિલેક્ટ સિંક્રોનાઇઝેશન: એક સાથે એક ફાઇલ docs/readme.md અને સબડિરેક્ટરીઝ એસેટ/આઇકન્સ, src/core ખેંચો
sync0 પુલ ડેટાસેટ://docs/readme.md,assets/icons,src/core ./local_data -p <નોડ સરનામું>
```

### 4. શેરિંગ જૂથ (`sync0 push`) પર ફાઇલ અથવા ડિરેક્ટરી અપલોડ કરો

અપલોડ પરવાનગીઓ (`rw` અથવા `admin`) ધરાવતા સભ્યો રિમોટ શેરિંગ જૂથોમાં સ્થાનિક ફાઇલો અથવા ડિરેક્ટરીઓ અપલોડ કરી શકે છે:

```bash
# રૂટ ડાયરેક્ટરી અપલોડ કરવાની પરવાનગી ધરાવતા સભ્યો: શેર કરેલી રૂટ ડિરેક્ટરીમાં સીધા જ અપલોડ કરો
sync0 push team-vault:// ./new_release -p <નોડ સરનામું>

# ચોક્કસ ઉપસર્ગ (જેમ કે અપલોડ્સ/બોબ) માટે અધિકૃત સભ્યો જ: માન્ય પાથ ઉપસર્ગ પર અપલોડ કરો
sync0 push team-vault://uploads/bob/report.pdf ./report.pdf -p <નોડ સરનામું>
```

### 5. સ્વચાલિત સમન્વયન અને સીડીંગ માટે સબ્સ્ક્રાઇબ કરો (`sync0 sub`)

ચોક્કસ નોડના શેરિંગ જૂથમાં સબ્સ્ક્રાઇબ કર્યા પછી, સ્થાનિક સર્વર પ્રાપ્ત કરનાર ક્લાયન્ટ અને નવું સીડિંગ સર્વર બંને છે; જ્યારે સ્ત્રોત નોડ ફાઈલ અપડેટ થાય છે, ત્યારે તે આપમેળે સમન્વયિત થાય છે અને અન્ય નોડ્સ માટે ચંક્ડ ડાઉનલોડ્સ પ્રદાન કરે છે:

```bash
# સમગ્ર શેરિંગ જૂથમાં સબ્સ્ક્રાઇબ કરો અને આપમેળે બીજ આપો
sync0 સબ ડેટાસેટ:// ./local_mirror -p <નોડ સરનામું>

# ઉલ્લેખિત ફાઇલો અને સબડિરેક્ટરીઝમાં સબ્સ્ક્રાઇબ કરવા માટે માત્ર બહુ-પસંદ કરો અને તેમને સીડ કરો
sync0 સબ ડેટાસેટ://models/llama.onnx,configs ./local_mirror -p <નોડ સરનામું>
```

### 6. મલ્ટિ-મશીન ગ્રૂપ પીઅર સિંક્રોનાઇઝેશન (`sync0 group`)

બહુવિધ મશીનો સમાન શેરિંગ જૂથમાં જોડાય છે, એકબીજાને આપમેળે ઉપલબ્ધ બીજ ગાંઠો શોધે છે અને દ્વિ-માર્ગીય સિંક્રનાઇઝેશન જાળવે છે (સંપૂર્ણ સિંક્રનાઇઝેશન અથવા ફાઇલો અને ડિરેક્ટરીઓની બહુવિધ પસંદગીને સમર્થન આપે છે):

```bash
# જૂથ અને દ્વિ-માર્ગીય સુમેળમાં સંપૂર્ણપણે જોડાઓ
sync0 group team-docs:// ./docs -p <node address>

# મલ્ટિ-સિલેક્ટ સિંક્રોનાઇઝેશન જૂથમાં ફક્ત wal ડિરેક્ટરી અને meta.json ફાઇલ
sync0 જૂથ ટીમ-docs://wal,meta.json ./docs -p <નોડ સરનામું>
```

### 7. બે મશીનો વચ્ચે પોઇન્ટ-ટુ-પોઇન્ટ ડાયરેક્ટ ટ્રાન્સમિશન (`send` / `recv`)

જૂથને પૂર્વ-રૂપરેખાંકિત કરવાની કોઈ જરૂર નથી, અને તમે અસ્થાયી રૂપે ફાઇલો અથવા ડિરેક્ટરીઓ સીધા બે મશીનો વચ્ચે સ્થાનાંતરિત કરી શકો છો:

```bash
# રીસીવર મોનીટરીંગ
sync0 recv 0.0.0.0:9000 ./backup

# મોકલવાનો અંત સીધો ફાઇલો અથવા ડિરેક્ટરીઓ સ્થાનાંતરિત કરે છે (વૈકલ્પિક --વધારાની ફાઇલોને સાફ કરવા માટે મિરર કાઢી નાખો, --રેટ ઝડપ મર્યાદા)
sync0 send ./project 192.168.1.10:9000
```

### 8. બહુ-ભાષા સ્વિચિંગ

`sync0` 75 ભાષાઓને સપોર્ટ કરે છે, અને મૂળભૂત રીતે સિસ્ટમ ભાષા પર્યાવરણ અનુસાર આપમેળે સ્વિચ થાય છે; તે `SYNC0_LANG` દ્વારા મેન્યુઅલી પણ સ્પષ્ટ કરી શકાય છે:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
