# sync0

`sync0` એ સમગ્ર નેટવર્કમાં ફાઇલોને સ્થાનાંતરિત કરવા, ડાયરેક્ટરીઝને સતત સિંક્રનાઇઝ કરવા અને એકસાથે બહુવિધ મશીનો પર ડેટા વિતરિત કરવા માટેનું કમાન્ડ લાઇન સાધન છે.

## મૂળ ડિઝાઇન હેતુ

ક્રોસ-મશીન રૂમ, દેશો અથવા નેટવર્કમાં વિલંબ અને પેકેટ નુકશાન સાથેના વાતાવરણમાં, `rsync` અને `scp` જેવા સાધનો સિંગલ કનેક્શન સિક્વન્સ કન્ફર્મેશન પર આધારિત છે, જે બેન્ડવિડ્થના ઉપયોગને મર્યાદિત કરે છે; જ્યારે બહુવિધ મશીનો એક જ સર્વરમાંથી એક જ સમયે ડેટા ખેંચે છે, ત્યારે સોર્સ સર્વર નેટવર્ક કાર્ડ સરળતાથી અવરોધ બની શકે છે.

`sync0`નો ધ્યેય બે સમસ્યાઓ હલ કરવાનો છે:

1. બે મશીનો વચ્ચેની ફાઇલ અને ડિરેક્ટરી સિંક્રનાઇઝેશનને સંપૂર્ણ ભૌતિક બેન્ડવિડ્થ ચલાવવા દો, અને જ્યારે ફાઇલ આંશિક રીતે સંશોધિત થાય ત્યારે જ બદલાયેલ ભાગને સ્થાનાંતરિત કરો.
2. એક જ ડાયરેક્ટરી સિંક્રનાઇઝ કરતી વખતે બહુવિધ મશીનો ડેટા બ્લોક્સને એકબીજામાં ટ્રાન્સફર કરી શકે છે, સ્ત્રોત સર્વર પરનો ભાર ઘટાડે છે અને એકંદર સિંક્રનાઇઝેશન સમય ટૂંકાવે છે.

## rsync સાથે ઝડપની સરખામણી

પરીક્ષણ પર્યાવરણ: યુરોપિયન નોડ $\leftrightarrow$ નોર્થ અમેરિકન નોડ, રાઉન્ડ-ટ્રીપ વિલંબ 86 ms, ડાયરેક્ટરી સ્કેનિંગ, ડિડુપ્લિકેશન સરખામણી, નેટવર્ક ટ્રાન્સમિશન અને ડિસ્ક પ્લેસમેન્ટ વેરિફિકેશન સહિત સંપૂર્ણ સમય-વપરાશનું માપન:

| ટ્રાન્સમિશન દૃશ્ય | ડેટાનું કદ | `sync0` | `rsync` | બહુવિધ |
| :--- | :---: | :---: | :---: | :---: |
| 10,000 નાની ફાઇલો | 77.6 MB | 0.90 s (688 Mbps) | 4.86 s (128 Mbps) | 5.4x |
| કોડ અને આર્કાઇવ પેકેજો (`.tar`) | 512 MB | 1.94 s (2111 Mbps) | 9.36 s (438 Mbps) | 4.8x |
| વિડિઓ ફાઇલ (`.mp4`) | 512 MB | 7.36 s (556 Mbps) | 12.11 s (338 Mbps) | 1.6x |
| ઇન્ક્રીમેન્ટલ સિંક્રોનાઇઝેશન (1% સામગ્રી સંશોધિત કરો) | 512 MB | 0.12 s | 1.85 s | 15.4x |

## પ્રદર્શન સુધારણા પદ્ધતિઓ

- **UDP સમવર્તી ટ્રાન્સમિશન**: UDP દ્વારા ડેટા બ્લોક્સ મોકલો, અને પછીના ફાઇલ ટ્રાન્સફરને અવરોધિત કરતી એક પેકેટની ખોટને ટાળવા માટે માત્ર ખોવાયેલા ટુકડાઓને ફરીથી ટ્રાન્સમિટ કરો.
- **કન્ટેન્ટ સેગ્મેન્ટેશન અને ડીડુપ્લિકેશન**: ફાઇલને સામગ્રી અનુસાર ડેટા બ્લોક્સમાં વિભાજિત કરો અને ચેક મૂલ્યની ગણતરી કરો. પ્રાપ્તિના છેડે પહેલેથી જ સમાન સામગ્રી નેટવર્કની નકલ કર્યા વિના સીધા સ્થાનિક રીતે ફરીથી ઉપયોગમાં લેવાય છે.
- **નેટવર્ક સ્પીડ અનુસાર કમ્પ્રેશનને આપમેળે સમાયોજિત કરો**: સંકુચિત સામગ્રી જેમ કે ટેક્સ્ટ અને કોડ માટે કમ્પ્રેશન ચાલુ કરો; CPU વપરાશ ઘટાડવા માટે વિડિઓઝ, ચિત્રો, સંકુચિત પેકેજો અથવા હાઇ-સ્પીડ LAN હેઠળ આપમેળે કમ્પ્રેશન છોડો.
- **મલ્ટિ-નોડ નજીકના પુલિંગ**: જ્યારે બહુવિધ મશીનો એક જ ડિરેક્ટરી ખેંચે છે, ત્યારે ડેટા બ્લોક્સ એક જ શહેરમાં અથવા ઓછી વિલંબિતતા સાથે ડાઉનલોડ કરેલા નોડ્સમાંથી એકસાથે ખેંચવામાં આવશે.

## ઇન્સ્ટોલ કરો

### પદ્ધતિ 1: કાર્ગો દ્વારા ઇન્સ્ટોલ કરો

```bash
cargo install sync0
```

### પદ્ધતિ 2: પૂર્વસંકલિત દ્વિસંગી ડાઉનલોડ કરો

અનુરૂપ સિસ્ટમ માટે `.tar.xz` સંકુચિત પેકેજ ડાઉનલોડ કરવા માટે [GitHub Releases](https://github.com/webc-site/sync0/releases) પર જાઓ (Linux x86_64/ARM64, macOS Apple Silicon/Intel, Windows x64/ARM64, Android ARM64/x86_64, FreeBSD, NetBSD સપોર્ટ કરે છે). અનઝિપ કર્યા પછી, `sync0`ને `PATH` ડિરેક્ટરીમાં મૂકો:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## વપરાશકર્તા માર્ગદર્શિકા

### 1. બે મશીનો વચ્ચે સીધી ફાઇલો અથવા ડિરેક્ટરીઓ સ્થાનાંતરિત કરો

રીસીવિંગ મશીન પર મોનીટરીંગ શરૂ કરો અને રીસીવિંગ અને સેવિંગ પાથનો ઉલ્લેખ કરો:

```bash
sync0 recv 0.0.0.0:9000 ./backup
```

મોકલવાના મશીનમાંથી એક ફાઇલ અથવા સંપૂર્ણ ડિરેક્ટરી મોકલો:

```bash
sync0 send ./project 192.168.1.10:9000
```

સામાન્ય રીતે ઉપયોગમાં લેવાતા પરિમાણો:

```bash
# રીડન્ડન્ટ ફાઇલો કાઢી નાખો કે જે પ્રાપ્ત કરવાના છેડે અસ્તિત્વમાં છે પરંતુ મોકલવાના છેડે નહીં (મિરર સિંક્રનાઇઝેશન)
sync0 send ./project 192.168.1.10:9000 --delete

# મોકલવાનો દર મર્યાદિત કરો (એકમ: બાઇટ્સ/સેકન્ડ, ઉદાહરણ તરીકે 50 MB/s)
sync0 send ./project 192.168.1.10:9000 --rate 50000000

# સાયલન્ટ મોડ (કોઈ પ્રોગ્રેસ બાર બતાવેલ નથી)
sync0 send ./project 192.168.1.10:9000 -q
```

### 2. વહેંચાયેલ ડિરેક્ટરીઓ પ્રકાશિત કરવી અને બહુવિધ નોડ્સમાંથી ખેંચવું

ઑરિજિન સર્વર પર શેર કરેલી ડિરેક્ટરી (`dataset` નામની) પ્રકાશિત કરો:

```bash
sync0 share dataset ./data --region SHA
```

અન્ય મશીનો પર વહેંચાયેલ નિર્દેશિકાને ખેંચો (તમે એક જ સમયે બહુવિધ નોડ સરનામાંઓ ભરી શકો છો, એકસાથે ખેંચવા માટે અલ્પવિરામ દ્વારા અલગ કરી શકો છો):

```bash
sync0 pull 10.0.0.1:9000,10.0.0.2:9000 dataset ./local_data
```

શેર કરેલી ડિરેક્ટરીમાં માત્ર ચોક્કસ સબડિરેક્ટરી ખેંચો:

```bash
sync0 pull 10.0.0.1:9000 dataset ./local_data --subpath 2026/logs
```

સ્થાનિક ફેરફારોને રિમોટ શેર કરેલી ડિરેક્ટરીમાં પાછા દબાણ કરો:

```bash
sync0 push 10.0.0.1:9000 dataset ./local_data
```

### 3. કૅટેલોગ સ્વચાલિત અપડેટ્સ પર સબ્સ્ક્રાઇબ કરો

સ્ત્રોત નોડની વહેંચાયેલ ડિરેક્ટરીમાં સબ્સ્ક્રાઇબ કરો. જ્યારે સ્રોત નિર્દેશિકામાં ફાઇલ ઉમેરવામાં આવે છે અથવા સંશોધિત કરવામાં આવે છે, ત્યારે તે સ્થાનિક કમ્પ્યુટર પર આપમેળે સમન્વયિત થશે. તે જ સમયે, સ્થાનિક મશીન આપમેળે અન્ય મશીનોને ખેંચવા માટે નોડ તરીકે સેવા આપશે:

```bash
sync0 sub 10.0.0.1:9000 dataset ./local_mirror
```

### 4. મલ્ટિ-મશીન જૂથોનું દ્વિ-માર્ગીય સુમેળ

બહુવિધ મશીનો સમાન જૂથના નામમાં જોડાય છે, અને કોઈપણ નોડ ડિરેક્ટરીમાં ફેરફારો જૂથમાંના અન્ય નોડ્સ સાથે આપમેળે સમન્વયિત થશે:

```bash
sync0 group team-docs ./docs 10.0.0.1:9000,10.0.0.2:9000
```

### 5. નોડ ઓળખ અને વ્યક્તિગત બિઝનેસ કાર્ડ

દરેક નોડ વપરાશકર્તા નામ, શહેર, ઇમેઇલ, વેબસાઇટ અને વ્યક્તિગત હસ્તાક્ષર (મહત્તમ 256 અક્ષરો) સેટ કરવાનું સમર્થન કરે છે અને સ્થાનિક ખાનગી કી હસ્તાક્ષર પ્રમાણીકરણ પસાર કરે છે:

```bash
# સ્થાનિક સાર્વજનિક કી ID જુઓ (કી ચાલુ રાખવા માટે રૂપરેખાંકન નિર્દેશિકાનો ઉલ્લેખ કરો)
sync0 id -c ~/.config/sync0

# વ્યક્તિગત હસ્તાક્ષરો સાથે નોડ બિઝનેસ કાર્ડ્સ બનાવો અને પ્રદર્શિત કરો
sync0 profile -c ~/.config/sync0 \
  -u alice \
  --region SHA \
  --email alice@example.com \
  --url https://example.com \
  -b "Shanghai backup node"
```

`share`, `pull`, `sub`, `group` આ પ્રોફાઇલ પરિમાણો સાથે પણ લોંચ કરી શકાય છે:

```bash
sync0 share dataset ./data -c ~/.config/sync0 -u alice --region SHA -b "Shanghai backup node"
```

### 6. બહુ-ભાષા સ્વિચિંગ

`sync0` 75 ભાષાઓને સપોર્ટ કરે છે. મૂળભૂત રીતે, કમાન્ડ લાઇન મદદ અને અનુરૂપ ભાષામાં પ્રોમ્પ્ટ ઓપરેટિંગ સિસ્ટમના ભાષા પર્યાવરણ અનુસાર આપમેળે પ્રદર્શિત થાય છે; જો સિસ્ટમ ભાષા સમર્થિત સૂચિમાં નથી, તો અંગ્રેજી મૂળભૂત રીતે વપરાય છે.

ભાષાને મેન્યુઅલી સ્પષ્ટ કરવા માટે, પર્યાવરણ ચલ સેટ કરો `SYNC0_LANG`:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
