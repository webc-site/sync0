# sync0

`sync0` என்பது பிணையங்கள் முழுவதும் கோப்புகளை மாற்றுவதற்கும், கோப்பகங்களை அதிகப்படியாக ஒத்திசைப்பதற்கும் மற்றும் பல இயந்திரங்களுக்கு ஒரே நேரத்தில் தரவை விநியோகிப்பதற்குமான கட்டளை வரி கருவியாகும்.

## அசல் வடிவமைப்பு நோக்கம்

குறுக்கு இயந்திர அறைகள், நாடுகள் அல்லது சூழல்களில் நெட்வொர்க் தாமதங்கள் மற்றும் பாக்கெட் இழப்புடன், `rsync` மற்றும் `scp` போன்ற கருவிகள் ஒற்றை இணைப்பு வரிசை உறுதிப்படுத்தலை அடிப்படையாகக் கொண்டவை, இது அலைவரிசை பயன்பாட்டைக் கட்டுப்படுத்துகிறது; ஒரே நேரத்தில் ஒரே சர்வரில் இருந்து பல இயந்திரங்கள் தரவை இழுக்கும் போது, ​​மூல சர்வர் நெட்வொர்க் கார்டு எளிதாக ஒரு தடையாக மாறும்.

இரண்டு சிக்கல்களைத் தீர்ப்பதே `sync0`ன் குறிக்கோள்:

1. இரண்டு இயந்திரங்களுக்கிடையில் கோப்பு மற்றும் அடைவு ஒத்திசைவு முழு இயற்பியல் அலைவரிசையில் இயங்கட்டும், மேலும் கோப்பு பகுதியளவு மாற்றியமைக்கப்படும் போது மட்டுமே மாற்றப்பட்ட பகுதியை மாற்றவும்.
2. ஒரே கோப்பகத்தை ஒத்திசைக்கும்போது, ​​மூல சர்வரில் சுமையைக் குறைக்கும் மற்றும் ஒட்டுமொத்த ஒத்திசைவு நேரத்தைக் குறைக்கும் போது பல இயந்திரங்கள் தரவுத் தொகுதிகளை ஒன்றோடொன்று மாற்றிக்கொள்ளலாம்.

## rsync உடன் வேக ஒப்பீடு

சோதனை சூழல்: ஐரோப்பிய முனை $\leftrightarrow$ வட அமெரிக்க முனை, சுற்று-பயண தாமதம் 86 ms, டைரக்டரி ஸ்கேனிங், டியூப்ளிகேஷன் ஒப்பீடு, நெட்வொர்க் டிரான்ஸ்மிஷன் மற்றும் டிஸ்க் பிளேஸ்மென்ட் சரிபார்ப்பு உட்பட முழு நேரத்தையும் அளவிடுகிறது:

| பரிமாற்ற காட்சி | தரவு அளவு | `sync0` | `rsync` | பல |
| :--- | :---: | :---: | :---: | :---: |
| 10,000 சிறிய கோப்புகள் | 77.6 MB | 0.90 s (688 Mbps) | 4.86 s (128 Mbps) | 5.4x |
| குறியீடு மற்றும் காப்பக தொகுப்புகள் (`.tar`) | 512 MB | 1.94 s (2111 Mbps) | 9.36 s (438 Mbps) | 4.8x |
| வீடியோ கோப்பு (`.mp4`) | 512 MB | 7.36 s (556 Mbps) | 12.11 s (338 Mbps) | 1.6x |
| அதிகரிக்கும் ஒத்திசைவு (1% உள்ளடக்கத்தை மாற்றவும்) | 512 MB | 0.12 s | 1.85 s | 15.4x |

## செயல்திறனை மேம்படுத்தும் முறைகள்

- **UDP concurrent transmission**: UDP மூலம் தரவுத் தொகுதிகளை அனுப்பவும், அடுத்தடுத்த கோப்புப் பரிமாற்றங்களைத் தடுக்கும் ஒரு பாக்கெட் இழப்பைத் தவிர்க்க, இழந்த துண்டுகளை மட்டும் மீண்டும் அனுப்பவும்.
- **உள்ளடக்கப் பிரிவு மற்றும் குறைப்பு**: உள்ளடக்கத்தின்படி கோப்பை தரவுத் தொகுதிகளாகப் பிரித்து சரிபார்ப்பு மதிப்பைக் கணக்கிடவும். ஏற்கனவே பெறப்பட்ட அதே உள்ளடக்கம் நெட்வொர்க்கை நகலெடுக்காமல் நேரடியாக உள்நாட்டில் மீண்டும் பயன்படுத்தப்படுகிறது.
- **நெட்வொர்க் வேகத்திற்கு ஏற்ப சுருக்கத்தை தானாக சரிசெய்தல்**: உரை மற்றும் குறியீடு போன்ற சுருக்கக்கூடிய உள்ளடக்கத்திற்கான சுருக்கத்தை இயக்கவும்; CPU நுகர்வு குறைக்க வீடியோக்கள், படங்கள், சுருக்கப்பட்ட தொகுப்புகள் அல்லது அதிவேக LAN இன் கீழ் சுருக்கத்தை தானாகவே தவிர்க்கவும்.
- **மல்டி-நோட் அருகிலுள்ள இழுத்தல்**: பல இயந்திரங்கள் ஒரே கோப்பகத்தை இழுக்கும்போது, ​​அதே நகரத்தில் பதிவிறக்கம் செய்யப்பட்ட முனைகளிலிருந்து அல்லது குறைந்த தாமதத்துடன் தரவுத் தொகுதிகள் ஒரே நேரத்தில் இழுக்கப்படும்.

## நிறுவவும்

### முறை 1: சரக்கு வழியாக நிறுவவும்

```bash
cargo install sync0
```

### முறை 2: முன்தொகுக்கப்பட்ட பைனரிகளைப் பதிவிறக்கவும்

தொடர்புடைய சிஸ்டத்திற்கான `.tar.xz` சுருக்கப்பட்ட தொகுப்பைப் பதிவிறக்க, [GitHub Releases](https://github.com/webc-site/sync0/releases) க்குச் செல்லவும் (Linux x86_64/ARM64, macOS Apple Silicon/Intel, Windows x64/ARM64, Android ARM64/x86_64, NetBSD, SDBSD ஆகியவற்றை ஆதரிக்கிறது). அன்ஜிப் செய்த பிறகு, `sync0`ஐ `PATH` கோப்பகத்தில் வைக்கவும்:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## பயனர் வழிகாட்டி

### 1. இரண்டு இயந்திரங்களுக்கு இடையில் கோப்புகள் அல்லது கோப்பகங்களை நேரடியாக மாற்றவும்

பெறும் இயந்திரத்தில் கண்காணிப்பைத் தொடங்கி, பெறும் மற்றும் சேமிக்கும் பாதையைக் குறிப்பிடவும்:

```bash
sync0 recv 0.0.0.0:9000 ./backup
```

அனுப்பும் இயந்திரத்திலிருந்து ஒரு கோப்பு அல்லது முழு கோப்பகத்தையும் அனுப்பவும்:

```bash
sync0 send ./project 192.168.1.10:9000
```

பொதுவாக பயன்படுத்தப்படும் அளவுருக்கள்:

```bash
# பெறும் முனையில் இருக்கும் ஆனால் அனுப்பும் முனையில் இல்லாத தேவையற்ற கோப்புகளை நீக்கவும் (கண்ணாடி ஒத்திசைவு)
sync0 send ./project 192.168.1.10:9000 --delete

# அனுப்பும் வீதத்தை வரம்பிடவும் (அலகு: பைட்டுகள்/வினாடி, எடுத்துக்காட்டாக 50 எம்பி/வி)
sync0 send ./project 192.168.1.10:9000 --rate 50000000

# அமைதியான பயன்முறை (முன்னேற்றப் பட்டி எதுவும் காட்டப்படவில்லை)
sync0 send ./project 192.168.1.10:9000 -q
```

### 2. பகிரப்பட்ட கோப்பகங்களை வெளியிடுதல் மற்றும் பல முனைகளிலிருந்து இழுத்தல்

மூல சேவையகத்தில் பகிரப்பட்ட கோப்பகத்தை (`dataset` என்ற பெயரில் வெளியிடவும்:

```bash
sync0 share dataset ./data --region SHA
```

மற்ற கணினிகளில் பகிரப்பட்ட கோப்பகத்தை இழுக்கவும் (நீங்கள் ஒரே நேரத்தில் பல முனை முகவரிகளை நிரப்பலாம், ஒரே நேரத்தில் இழுக்க காற்புள்ளிகளால் பிரிக்கலாம்):

```bash
sync0 pull 10.0.0.1:9000,10.0.0.2:9000 dataset ./local_data
```

பகிரப்பட்ட கோப்பகத்தில் ஒரு குறிப்பிட்ட துணை அடைவை மட்டும் இழுக்கவும்:

```bash
sync0 pull 10.0.0.1:9000 dataset ./local_data --subpath 2026/logs
```

உள்ளூர் மாற்றங்களை ரிமோட் பகிரப்பட்ட கோப்பகத்திற்குத் தள்ளவும்:

```bash
sync0 push 10.0.0.1:9000 dataset ./local_data
```

### 3. பட்டியல் தானியங்கு புதுப்பிப்புகளுக்கு குழுசேரவும்

மூல முனையின் பகிரப்பட்ட கோப்பகத்திற்கு குழுசேரவும். மூல கோப்பகத்தில் ஒரு கோப்பு சேர்க்கப்படும்போது அல்லது மாற்றப்படும்போது, ​​அது தானாகவே உள்ளூர் கணினியுடன் ஒத்திசைக்கப்படும். அதே நேரத்தில், உள்ளூர் இயந்திரம் தானாகவே மற்ற இயந்திரங்களை இழுக்க ஒரு முனையாக செயல்படும்:

```bash
sync0 sub 10.0.0.1:9000 dataset ./local_mirror
```

### 4. பல இயந்திர குழுக்களின் இருவழி ஒத்திசைவு

ஒரே குழுவின் பெயரில் பல இயந்திரங்கள் இணைகின்றன, மேலும் எந்த முனை கோப்பகத்திலும் மாற்றங்கள் தானாகவே குழுவில் உள்ள மற்ற முனைகளுடன் ஒத்திசைக்கப்படும்:

```bash
sync0 group team-docs ./docs 10.0.0.1:9000,10.0.0.2:9000
```

### 5. முனை அடையாளம் மற்றும் தனிப்பட்ட வணிக அட்டை

ஒவ்வொரு முனையும் பயனர் பெயர், நகரம், மின்னஞ்சல், இணையதளம் மற்றும் தனிப்பயனாக்கப்பட்ட கையொப்பம் (அதிகபட்சம் 256 எழுத்துகள்) ஆகியவற்றை அமைப்பதை ஆதரிக்கிறது மற்றும் உள்ளூர் தனிப்பட்ட விசை கையொப்ப அங்கீகாரத்தை அனுப்புகிறது:

```bash
# உள்ளூர் பொது விசை ஐடியைப் பார்க்கவும் (விசையைத் தொடர உள்ளமைவு கோப்பகத்தைக் குறிப்பிடவும்)
sync0 id -c ~/.config/sync0

# தனிப்பயனாக்கப்பட்ட கையொப்பங்களுடன் முனை வணிக அட்டைகளை உருவாக்கி காட்சிப்படுத்தவும்
sync0 profile -c ~/.config/sync0 \
  -u alice \
  --region SHA \
  --email alice@example.com \
  --url https://example.com \
  -b "Shanghai backup node"
```

`share`, `pull`, `sub`, `group` ஆகியவற்றை இந்த சுயவிவர அளவுருக்களுடன் தொடங்கலாம்:

```bash
sync0 share dataset ./data -c ~/.config/sync0 -u alice --region SHA -b "Shanghai backup node"
```

### 6. பல மொழி மாறுதல்

`sync0` 75 மொழிகளை ஆதரிக்கிறது. முன்னிருப்பாக, இயக்க முறைமையின் மொழி சூழலுக்கு ஏற்ப, கட்டளை வரி உதவி மற்றும் தொடர்புடைய மொழியில் உள்ள அறிவுறுத்தல்கள் தானாகவே காட்டப்படும்; கணினி மொழி ஆதரிக்கப்படும் பட்டியலில் இல்லை என்றால், ஆங்கிலம் இயல்பாகவே பயன்படுத்தப்படும்.

மொழியை கைமுறையாகக் குறிப்பிட, சூழல் மாறியை `SYNC0_LANG` அமைக்கவும்:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
