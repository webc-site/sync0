# sync0

`sync0` என்பது ஒரு பரவலாக்கப்பட்ட P2P கோப்பு பகிர்வு, நிகழ்நேர ஒத்திசைவு மற்றும் பல-மூல விநியோக கருவி `rsync`க்கு பதிலாகப் பயன்படுத்தப்படுகிறது - கண்டம் தாண்டிய பரந்த பகுதி நெட்வொர்க்கின் அளவிடப்பட்ட வேகமானது `rsync` (ஒற்றை-புள்ளி P2P 2.0 வடிவியல் சராசரி வேகம் **6.95×** வரை இருக்கும். வேகம் **3.33×**), மற்றும் கடல் முழுவதும் பாரிய சிறிய கோப்புகளின் ஒத்திசைவு **7.19×** வேகமானது.

ஒவ்வொரு இயந்திரமும் ஒரு சேவையகம் மற்றும் கிளையன்ட் ஆகும்: மைய சேவையகம் அல்லது பொது நெட்வொர்க் முகவரி தேவையில்லை, தானியங்கி துளை குத்துதல் விநியோகிக்கப்பட்ட பிணைய பொது விசை முகவரியை அடிப்படையாகக் கொண்டது, மேலும் இது இரண்டு இயந்திரங்களுக்கு இடையே நேரடி பரிமாற்றத்தை ஆதரிக்கிறது, பல பகிர்வு குழு அனுமதி ஹோஸ்டிங், தேவைக்கேற்ப துணை அடைவுகளின் பல தேர்வு, மில்லி விநாடி-நிலை நிகழ்நேர பன்முக ஒத்திசைவு மற்றும் P.2P.

## நிறுவவும்

### முறை 1: சரக்கு நிறுவல்

```bash
cargo install sync0
```

### முறை 2: முன்தொகுக்கப்பட்ட பைனரிகளைப் பதிவிறக்கவும்

கணினியுடன் தொடர்புடைய `.tar.xz` சுருக்கப்பட்ட தொகுப்பைப் பதிவிறக்க [GitHub Releases](https://github.com/webc-site/sync0/releases) க்குச் செல்லவும் (Linux, macOS, Windows, Android, iOS, FreeBSD ஐ ஆதரிக்கிறது), அன்ஜிப் செய்து `PATH` இல் வைக்கவும்:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## விரைவில் தொடங்குங்கள்

### 1. இரண்டு இயந்திரங்களுக்கு இடையேயான பூஜ்ஜிய-கட்டமைப்பு நேரடி பரிமாற்றம் (`send` / `recv`)

பகிர்தல் குழுவை உள்ளமைக்க வேண்டிய அவசியமில்லை, இரண்டு இயந்திரங்களுக்கு இடையில் அதிக வேகத்தில் கோப்புகள் அல்லது கோப்பகங்களை நேரடியாக மாற்றவும்:

```bash
# பெறுதல் முனை போர்ட்டில் கேட்கிறது மற்றும் ./backup க்கு எழுதுகிறது
sync0 recv 0.0.0.0:9000 ./backup

# அனுப்புநரிடமிருந்து நேரடி பரிமாற்றம் (விரும்பினால் --அதிகப்படியான கோப்புகளை சுத்தம் செய்ய கண்ணாடியை நீக்கவும், --வீதம் 50MB வேக வரம்பு)
sync0 send ./project 192.168.1.10:9000
```

### 2. இடுகை பகிர்வு மற்றும் தேவைக்கேற்ப இழுத்தல்/பதிவேற்றம் (`share` / `pull` / `push`)

```bash
# சேவையகம்: பகிர்தல் குழுவை ஒரு வரி கட்டளையுடன் வெளியிடவும் (தொடக்கத்திற்குப் பிறகு IP-இலவச iroh முனை முகவரியை வெளியிடவும்)
sync0 share dataset:./data

# கிளையண்ட்: முழு தரவுத்தொகுப்பு பகிர்வு குழுவையும் உள்ளூர் ./local_data க்கு இழுக்கவும்
sync0 pull dataset:// ./local_data -p <node address>

# கிளையண்ட்: தேவைக்கேற்ப பல தேர்வுகளை இழுக்கவும் (குறிப்பிட்ட ஒற்றை கோப்புகள் மற்றும் துணை அடைவுகளை மட்டும் ஒத்திசைக்கவும்)
sync0 pull dataset://docs/readme.md,assets/icons,src/core ./local_data -p <node address>

# கிளையண்ட்: அங்கீகரிக்கப்பட்ட பகிர்வு குழுக்களுக்கு கோப்புகள் அல்லது கோப்பகங்களைப் பதிவேற்றவும்
sync0 push dataset://releases/v1 ./build_output -p <node address>
```

### 3. நிகழ்நேர சந்தா விதைப்பு மற்றும் பல இயந்திர இருவழி ஒத்திசைவு (`sub` / `group`)

நீண்ட இணைப்பை நிறுவிய பின், ரிமோட் முடிவில் ஏதேனும் கோப்பு ** சேர்த்தல், மாற்றுதல், நீக்குதல், மாற்றுதல் அல்லது மாற்றும் நேரம் நேரடியாக தொகுதிகள்):

- **`sync0 sub`(ஒரு வழி நிகழ்நேர பிரதிபலிப்பு + தானியங்கி விதைப்பு)**: உள்ளூர் நிகழ்நேரமானது பகிர்வு முடிவில் சேர்த்தல், நீக்குதல் மற்றும் மாற்றங்களைப் பின்பற்றுகிறது, மேலும் மற்ற இழுக்கும் முனைகளுக்கு ஒரே நேரத்தில் முடுக்கத்தை வழங்க P2P விதை ஆதாரமாக தானாகவே செயல்படுகிறது.
- **`sync0 group`(மல்டி-மெஷின் பியர்-டு-பியர் டூ-வே நிகழ்நேர ஒத்திசைவு)**: குழுவில் உள்ள ஏதேனும் ஒரு கணினியில் கோப்புகள் சேர்க்கப்பட்டால், நீக்கப்பட்டால் அல்லது மாற்றியமைக்கப்பட்டால், மற்ற அனைத்து ஆன்லைன் முனைகளும் நிகழ்நேரத்தில் ஒத்திசைவாக புதுப்பிக்கப்பட்டு, ஒன்றுக்கொன்று விதைகளாகச் செயல்படும்.

```bash
# முழு பகிர்வு குழுவிற்கும் குழுசேரவும்: தொலைநிலை சேர்த்தல்கள், நீக்குதல்கள் மற்றும் மாற்றங்கள் நிகழ்நேரத்தில் உள்ளூரில் ஒத்திசைக்கப்பட்டு தானாக விதைக்கப்படும்
sync0 sub dataset:// ./local_mirror -p <node address>

# ஆன்-டிமாண்ட் மல்டி-செலக்ட் சந்தா: குறிப்பிட்ட ஒற்றை கோப்புகள் மற்றும் துணை அடைவுகளை நிகழ்நேரத்தில் மட்டுமே ஒத்திசைத்து விதைக்கவும்
sync0 துணை தரவுத்தொகுப்பு://models/llama.onnx,configs ./local_mirror -p <node address>

# மல்டி-மெஷின் பியர் குழு இருவழி நிகழ்நேர ஒத்திசைவு (முழு அல்லது கமா பல-தேர்ந்தெடுக்கப்பட்ட பாதைகளையும் ஆதரிக்கிறது)
sync0 group team-docs:// ./docs -p <node address>
```

### 4. குழு பல பகிர்வு குழு மற்றும் உறுப்பினர் அனுமதி உள்ளமைவு (`.nt` உள்ளமைவு)

இயல்புநிலை உள்ளமைவு அடைவு `~/.config/sync0` (`-c <directory>` வழியாக மாறலாம்), குறைந்தபட்ச [NestedText](https://nestedtext.org) (`.nt`) வடிவமைப்பைப் பயன்படுத்தி:
- **பொது நெட்வொர்க் வாசிப்பைக் கட்டுப்படுத்துவதை ஆதரிக்கிறது (அங்கீகரிக்கப்பட்ட பயனர்கள் மட்டுமே படிக்க முடியும்)**: பகிர்தல் குழு ஒரு `users:` உறுப்பினர் பட்டியலுடன் கட்டமைக்கப்பட்டிருக்கும் வரை (அல்லது கட்டளை வரியானது `--allow-r` / `--allow-rw` / `--allow-w` / `--auth` என்பதை குறிப்பிடும் வரை, இது முற்றிலும் தனிப்பட்ட முறையில் இயங்கும் (தானியங்கி)`auth: true`)** மற்றும் பொது நெட்வொர்க்கின் அநாமதேய கணு கணக்கீடு அல்லது வாசிப்பை தடைசெய்கிறது, மேலும் P2P விதைப்பு முனைகளுக்கு சந்தா செலுத்துவதும் அனுமதிப்பட்டியலை ஒரே நேரத்தில் பெறுகிறது, இது அங்கீகரிக்கப்பட்ட பயனர்களை மட்டுமே படிக்க அனுமதிக்கிறது; `users` உடன் கட்டமைக்கப்படாத பகிர்தல் குழுக்கள் பொது மற்றும் இயல்புநிலையில் படிக்க மட்டுமே (பொதுவாகவும் படிக்க மட்டுமேயாகவும் மற்றும் குறிப்பிட்ட உறுப்பினர்களுக்கு மட்டுமே பதிவேற்றங்களைத் திறக்கவும் விரும்பினால், நீங்கள் வெளிப்படையாக `auth: false` அமைக்கலாம்).
- ** நுணுக்கமான வாசிப்பு-எழுதுதல் மற்றும் துணை அடைவு விநியோக அனுமதிகள்**: உறுப்பினர்கள் இயல்புநிலையில் படிக்க மட்டுமே (`r` வெளிப்படையாக எழுத வேண்டிய அவசியமில்லை), மேலும் `r` (படிக்க மட்டும்), `w` (துளி பெட்டியில் மட்டும் எழுதவும், <b id-4">ஐ ஆதரிக்கவும் (read-4) id="5"> (பதிவேற்ற அனுமதிக்கப்படும் துணை அடைவு முன்னொட்டை வரம்பிடவும்).

**உறுப்பினர் உள்ளமைவு உதாரணம் (`~/.config/sync0/users/`):**

```yaml
# ~/.config/sync0/users/alice.nt (இயல்புநிலை படிக்க மட்டும், வேக வரம்பு 80MB)
id: 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c
rate: 80MB
```

```yaml
# ~/.config/sync0/users/bob.nt (படிக்க மற்றும் எழுத அனுமதிகள், குறிப்பிட்ட துணை அடைவில் மட்டுமே பதிவேற்ற அனுமதிக்கப்படுகிறது)
id: 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f
perm: rw
write_prefix:
  - uploads/bob
  - shared/common
```

```yaml
# ~/.config/sync0/users/charlie.nt (டெலிவரி அனுமதியை மட்டும் எழுதுங்கள், வாசிப்பது தடைசெய்யப்பட்டுள்ளது)
id: 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
perm: w
```

**பகிர்தல் குழு கட்டமைப்பு உதாரணம் (`~/.config/sync0/config.nt`):**

```yaml
users_dir: ./users

groups:
  # உள்ளமைக்கப்படாத பயனர்கள்: இயல்புநிலை பொது நெட்வொர்க் படிக்க மட்டும்
  dataset:
    path: ./data
    rate: 50MB

  # கட்டமைக்கப்பட்ட பயனர்கள்: பொது நெட்வொர்க் வாசிப்பை தானாக கட்டுப்படுத்துங்கள் (ஆலிஸ் மற்றும் பாப் மட்டுமே படிக்க முடியும், சார்லி மட்டுமே டெலிவரி செய்து பதிவேற்ற முடியும்)
  team-vault:
    path: ./vault
    users:
      - alice
      - bob
      - charlie
```

சேவையைத் தொடங்கவும் (உள்ளமைவு கோப்பை ஏற்றவும் அல்லது பொது நெட்வொர்க் வாசிப்பை கட்டுப்படுத்தவும் உறுப்பினர்களை அங்கீகரிக்கவும் கட்டளை வரி அளவுருக்களை நேரடியாகப் பயன்படுத்தவும்):

```bash
# தொடங்குவதற்கு ~/.config/sync0/config.nt ஐ ஏற்றவும்
sync0 share --region SHA

# அல்லது தூய கட்டளை வரி மூலம் ஒரு தனிப்பட்ட பகிர்வு குழுவை வெளியிடவும் (பொது நெட்வொர்க் வாசிப்பை தானாக கட்டுப்படுத்த --allow-* குறிப்பிடவும் மற்றும் அங்கீகரிக்கப்பட்ட பயனர்கள் மட்டுமே அதை அணுக முடியும்)
sync0 share team-vault:./vault \
  --allow-r 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c \
  --allow-rw 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f:uploads/bob,shared/common \
  --allow-w 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
```

### 5. முனை முகவரி, வணிக அட்டை மற்றும் பல மொழி


### முக்கிய தயாரிப்பு அம்சங்கள்

- **பொது விசை முகவரி தானியங்கி துளை குத்துதல்**: மத்திய சேவையகம் மற்றும் பொது நெட்வொர்க் முகவரி தேவையில்லை, விநியோகிக்கப்பட்ட நெட்வொர்க் பொது விசை முகவரியின் அடிப்படையில் தானியங்கி NAT துளை குத்துதல்.
- **மில்லிசெகண்ட்-நிலை நிகழ்நேர ஒத்திசைவு மற்றும் மெட்டாடேட்டா விழிப்புணர்வு**: நேட்டிவ் கோப்பு நிகழ்வு கண்காணிப்பு அடிப்படையில் (`FSEvents` / `inotify` / `ReadDirectoryChangesW`), கோப்பு சேர்த்தல், நீக்குதல், POSIX அனுமதிகள் (`mode`) மற்றும் millisecond நேரம் (`mode`) மற்றும் millisecond); அனுமதிகள் அல்லது நேரம் மட்டும் மாற்றியமைக்கப்படும் போது, ​​பூஜ்ஜிய தரவு பரிமாற்றம்.
- **BT-பாணியில் ஒரே நேரத்தில் பதிவிறக்கம் மற்றும் பதிவேற்றம் மற்றும் பிராந்திய தொடர்பு திட்டமிடல்**: பதிவிறக்கும் முனை முழுத் தொகையையும் பதிவிறக்கம் செய்ய காத்திருக்க வேண்டியதில்லை. 128-பிட் ஹாஷ் காசோலையை கடந்துவிட்ட அனைத்து பிளாக் இடைவெளிகளும் (`Op::Have`) மற்ற முனைகள் ஒரே நேரத்தில் இழுக்க உடனடியாக நினைவகம்/தற்காலிகக் குளத்தில் பூட்டப்படும். டைனமிக் PEX முனை பரிமாற்றம் மற்றும் ஸ்லோ நோட் ஹாஃப் ப்ரீம்ப்ஷன் (வேலை-திருடுதல்) ஆகியவற்றுடன் சேர்ந்து, கிளஸ்டர் செயல்திறன் அதிகரிக்கப்படுகிறது.
- **தீங்கிழைக்கும் நோட் டேம்பரிங் மற்றும் க்ளஸ்டர் விஷனிங் நோய் எதிர்ப்பு சக்தி**: அதிகாரப்பூர்வ மூலப் பட்டியல் `root_hash` சுய-நிலையான பூட்டுதல் + கட்டாய வன்பொருள் முடுக்கம் `gxhash128` ஒவ்வொரு தொகுதியும் வட்டில் வைக்கப்பட்டு வெளிப்புறமாக விதைக்கப்படுவதற்கு முன்பு சரிபார்ப்பு; சிதைந்த தொகுதி கண்டறியப்பட்டால், மில்லி விநாடி-நிலை சர்க்யூட் பிரேக்கர் தீங்கிழைக்கும் முனையை இருட்டடிப்பு செய்து, நேர்மையான மூலத்திலிருந்து தானாகவே மீட்டெடுக்கும்.
- **FastCDC இன்-சிட்டு அதிகரிப்பு மற்றும் சிறிய கோப்பு திரட்டல்**: பெரிய கோப்புகளின் பகுதி மாற்றத்திற்காக வேறுபட்ட தொகுதிகள் மட்டுமே மாற்றப்பட்டு வட்டில் வைக்கப்படும்; பெரிய சிறிய கோப்பு நினைவக பேக்கேஜிங் மற்றும் முன்னொட்டு வேறுபட்ட சுருக்கமானது கோப்பு-மூலம்-கோப்பு சுற்று-பயண மேல்நிலையை நீக்குகிறது.
- **மின் தடைக்குப் பிறகு சுய-குணப்படுத்துதல் மற்றும் மறுதொடக்கம் செய்த பிறகு மீண்டும் தொடங்குதல்**: விதைப்பு நிலை மற்றும் கோப்புப் பட்டியலைத் தொடர Redis-போன்ற RDB + AOF ஹைப்ரிட் வடிவம் (`.s0_subs.bin`) பயன்படுத்தப்படுகிறது, தினசரி மாற்றங்கள் மைக்ரோ விநாடிகளில் சேர்க்கப்படும், மேலும் தானாகவே மீண்டும் எழுதப்பட்டு ஒழுங்கமைக்கப்படும். சேவையகம் மறுதொடக்கம் செய்யப்பட்ட பிறகு, ஆஃப்லைன் மாற்றங்கள் தானாகவே விதைப்பு முனைக்கு தள்ளப்படும்.
