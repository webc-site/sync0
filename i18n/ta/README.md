# sync0

`sync0` என்பது ஒரு பியர்-டு-பியர் (P2P) கோப்பு பகிர்வு மற்றும் Resilio Sync உடன் போட்டியிடும் பல இயந்திர ஒத்திசைவு கருவியாகும்.

ஒவ்வொரு இயந்திரமும் ஒரு சர்வர் மற்றும் கிளையன்ட் ஆகும்: எந்த முனையும் பல கோப்பு பகிர்வு குழுக்களை வெளியிடலாம். மற்ற முனைகள் இணைந்த பிறகு, அவை தானாகவே கிடைக்கக்கூடிய விதை முனைகளை பியர் சர்வரில் இருந்து பெறலாம் மற்றும் அவற்றை ஒரே நேரத்தில் பல ஆதாரங்களில் இருந்து இழுக்கலாம். ஒத்திசைவு முடிந்ததும், பதிவிறக்கங்களை விரைவுபடுத்த அதிக முனைகளுக்கு விதைகள் தானாகவே உருவாக்கப்படும்.

## முக்கிய சிறப்பம்சங்கள்

- **எல்லோரும் ஒரு சர்வர் மற்றும் கிளையன்ட் இருவரும்**: Resilio Sync உடன் ஒப்பிடலாம், மைய சர்வர் சார்பு இல்லை. எந்த முனையும் பல கோப்பு பகிர்வு குழுக்களை உருவாக்கலாம், மேலும் பிறரின் பகிர்வு குழுக்களிலும் சேரலாம்; பல இயந்திரங்களின் ஒரே நேரத்தில் இழுத்தல் மற்றும் நிகழ்நேர ஒத்திசைவு ஆகியவற்றை அடைய முனைகள் தானாகவே பரிமாற்றம் மற்றும் கிடைக்கக்கூடிய விதை முனைகளைப் பெறுகின்றன.
- **IP-இலவச முனை முகவரி**: முன்னிருப்பாக, முனை விசையும் `base64url` குறியிடப்பட்ட `iroh` முகவரியும் பொது ஐபியை நினைவில் கொள்ளவோ ​​அல்லது வெளிப்படுத்தவோ தேவையில்லாமல் தானாகவே `~/.config/sync0` இல் உருவாக்கப்படும்.
- ** தேவைக்கேற்ப பல-தேர்வு ஒத்திசைவு**: முழு பகிர்வு குழுவின் ஒத்திசைவை ஆதரிக்கிறது, மேலும் ஒரே நேரத்தில் பல கோப்புகள் அல்லது துணை அடைவுகளைத் தேர்ந்தெடுப்பதன் மூலம் தேவைக்கேற்ப ஒத்திசைவை ஆதரிக்கிறது.
- **குழு உறுப்பினர் படிநிலை அனுமதிகள் மற்றும் பதிவேற்ற அடைவுக் கட்டுப்பாடு**: படிக்க-மட்டும் (`ro`), படிக்க-எழுத பதிவேற்றம் (`rw`), மேலாண்மை (`admin`) அனுமதிகளை ஆதரிக்கிறது, மேலும் ஒவ்வொரு உறுப்பினரும் ரூட் பதிவேற்ற அனுமதிக்கப்படும் பாதை முன்னொட்டை தனித்தனியாக குறிப்பிடலாம் (இயல்புநிலை பதிவேற்றம் மூலம்).
- **நெட்வொர்க்குகள் முழுவதும் முழு-வேக மற்றும் அதிகரிக்கும் ஒத்திசைவு**: பெரிய கோப்புகளின் ஒரே நேரத்தில் பரிமாற்றம், நினைவகத்தில் பெரிய சிறிய கோப்புகளை ஒருங்கிணைத்தல் மற்றும் கோப்புகள் பகுதியளவு மாற்றியமைக்கப்படும் போது மட்டுமே ஒத்திசைக்கப்பட்ட தரவுத் தொகுதிகள்.

## நிறுவவும்

### முறை 1: சரக்கு வழியாக நிறுவவும்

```bash
cargo install sync0
```

### முறை 2: முன்தொகுக்கப்பட்ட பைனரிகளைப் பதிவிறக்கவும்

தொடர்புடைய கணினிக்கான `.tar.xz` சுருக்கப்பட்ட தொகுப்பைப் பதிவிறக்க, [GitHub Releases](https://github.com/webc-site/sync0/releases) க்குச் செல்லவும் (Linux, macOS, Windows, Android, FreeBSD, NetBSD ஐ ஆதரிக்கிறது), அன்ஜிப் செய்து `PATH` கோப்பகத்தில் வைக்கவும்:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## விரைவில் தொடங்குங்கள்

`sync0` இயல்புநிலையாக உள்ளமைவு கோப்பகமாக `~/.config/sync0` ஐப் பயன்படுத்துகிறது (நீங்கள் மற்ற கோப்பகங்களுக்கு மாற வேண்டுமானால், நீங்கள் `-c <directory>`ஐச் சேர்க்கலாம்).

### 1. உள்ளூர் முனை முகவரி மற்றும் வணிக அட்டையை அமைக்கவும்

```bash
# உள்ளூர் முனை முகவரியைக் காண்க (முதன்முறையாக விசை தானாகவே ~/.config/sync0 இல் உருவாக்கப்படும்)
sync0 id

# தனிப்பட்ட முனை வணிக அட்டையை உருவாக்கவும் (பயனர் பெயர், நகரம், மின்னஞ்சல், இணையதளம் மற்றும் கையொப்பத்தை 256 வார்த்தைகளுக்குள் ஆதரிக்கிறது)
sync0 profile -u alice --region SHA --email alice@example.com --url https://example.com -b "Shanghai node"
```

### 2. பல கோப்பு பகிர்வு குழுக்களை வெளியிடவும் மற்றும் குழு உறுப்பினர் அனுமதிகளை அமைக்கவும் (`.nt` கட்டமைப்பு)

`sync0` [NestedText](https://nestedtext.org) (`.nt`) வடிவத்தில் உள்ளமைக்கப்பட்டுள்ளது. ஒவ்வொரு பயனருக்கும் தனித்தனி `.nt` உள்ளமைவு கோப்பு உள்ளது. `config.nt` இல் உள்ள `users_dir` மூலம் பயனர் சுயவிவர கோப்பகத்தை நீங்கள் குறிப்பிடலாம் (இந்த கோப்பகத்தில் உள்ள அனைத்து `.nt` கோப்புகளும் தானாகவே அடங்கும்). பதிவேற்றம் செய்ய அனுமதிக்கப்பட்ட பயனர் மற்றும் பாதை முன்னொட்டு இரண்டும் வரிசைப்படுத்தப்படாத பட்டியலைப் பயன்படுத்துகின்றன (`-`). ** பதிவேற்ற பாதை முன்னொட்டு நிரப்பப்படாதபோது, ​​பகிர்வின் ரூட் கோப்பகத்தில் பதிவேற்றுவது இயல்பாக அனுமதிக்கப்படும்**.

1. `~/.config/sync0/users/` கோப்பகத்தில் ஒவ்வொரு உறுப்பினருக்கும் தனித்தனி `.nt` உள்ளமைவு கோப்புகளை உருவாக்கவும்:

`~/.config/sync0/users/alice.nt` (படிக்க மட்டும் உறுப்பினர், வரம்புக்குட்பட்ட `80MB`, `rate` ஆதரிக்கிறது `GB`, `MB`, `KB` அலகுகள்):

```yaml
id: 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c
perm: ro
rate: 80MB
```

`~/.config/sync0/users/bob.nt` (கட்டுப்படுத்தப்பட்ட பதிவேற்ற உறுப்பினர்கள்: `uploads/bob` மற்றும் `shared/common` கோப்பகங்களுக்கு மட்டுமே பதிவேற்ற அனுமதிக்கப்படுகிறது):

```yaml
id: 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f
perm: rw
write_prefix:
  - uploads/bob
  - shared/common
```

`~/.config/sync0/users/charlie.nt` (இயல்புநிலை உறுப்பினர் பதிவேற்றம்: `write_prefix` தவிர்க்கப்பட்டால், பகிர்வின் ரூட் கோப்பகத்தில் பதிவேற்றுவது இயல்பாக அனுமதிக்கப்படும்):

```yaml
id: 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
perm: rw
```

2. பயனர் கோப்பகம் மற்றும் பல கோப்பு பகிர்வு குழுக்களை `~/.config/sync0/config.nt` இல் உள்ளமைக்கவும்:

```yaml
users_dir: ./users

groups:
  dataset:
    path: ./data
    auth: false
    perm: ro
    rate: 50MB

  models:
    path: ./models
    auth: false
    perm: ro
    rate: 1GB

  team-vault:
    path: ./vault
    auth: true
    perm: ro
    rate: 512KB
    users:
      - alice
      - bob
      - charlie
```

பகிர்வு சேவையைத் தொடங்கவும்:

```bash
# நேரடி தொடக்கம் (~/.config/sync0/config.nt மற்றும் users_dir கோப்பகங்களில் அனைத்து .nt பயனர் உள்ளமைவுகளையும் தானாக ஏற்றுகிறது)
sync0 share --region SHA

# அல்லது பல பகிர்வு குழுக்களை விரைவாக வெளியிடவும் மற்றும் கட்டளை வரி மூலம் நேரடியாக குழு உறுப்பினர்களை அங்கீகரிக்கவும்
sync0 share dataset:./data team-vault:./vault \
  --auth \
  --allow-ro 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c \
  --allow-rw 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f:uploads/bob,shared/common \
  --allow-rw 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
```

### 3. எல்லா உள்ளடக்கத்தையும் இழுக்கவும் அல்லது பல கோப்புகள் மற்றும் கோப்பகங்களைத் தேர்ந்தெடுக்கவும் (`sync0 pull`)

பகிர்வுக் குழுவில் கிடைக்கும் அனைத்து விதை முனைகளையும் தானாகப் பெற எந்த பியர் முனையுடனும் இணைக்கவும், மேலும் ஒரே நேரத்தில் பல விதை முனைகளிலிருந்து இழுக்கவும்:

```bash
# முழு தரவுத்தொகுப்பு பகிர்வு குழுவையும் உள்ளூர் ./local_data க்கு இழுக்கவும்
sync0 pull dataset:// ./local_data -p <node address>

# பல-தேர்வு ஒத்திசைவு: ஒரே நேரத்தில் ஒற்றை கோப்பு docs/readme.md மற்றும் துணை அடைவுகள் சொத்துகள்/ஐகான்கள், src/core ஆகியவற்றை இழுக்கவும்
sync0 pull dataset://docs/readme.md,assets/icons,src/core ./local_data -p <node address>
```

### 4. பகிர்தல் குழுவில் கோப்பு அல்லது கோப்பகத்தைப் பதிவேற்றவும் (`sync0 push`)

பதிவேற்ற அனுமதிகளைக் கொண்ட உறுப்பினர்கள் (`rw` அல்லது `admin`) தொலைநிலைப் பகிர்வு குழுக்களுக்கு உள்ளூர் கோப்புகள் அல்லது கோப்பகங்களைப் பதிவேற்றலாம்:

```bash
# ரூட் கோப்பகத்தைப் பதிவேற்ற அனுமதி உள்ள உறுப்பினர்கள்: பகிரப்பட்ட ரூட் கோப்பகத்தில் நேரடியாகப் பதிவேற்றவும்
sync0 push team-vault:// ./new_release -p <node address>

# குறிப்பிட்ட முன்னொட்டுக்கு (பதிவேற்றங்கள்/பாப் போன்றவை) அங்கீகரிக்கப்பட்ட உறுப்பினர்கள் மட்டுமே: அனுமதிக்கப்பட்ட பாதை முன்னொட்டுக்குப் பதிவேற்றவும்
sync0 push team-vault://uploads/bob/report.pdf ./report.pdf -p <node address>
```

### 5. தானியங்கு ஒத்திசைவு மற்றும் விதைப்புக்கு குழுசேரவும் (`sync0 sub`)

ஒரு குறிப்பிட்ட முனையின் பகிர்வு குழுவிற்கு குழுசேர்ந்த பிறகு, உள்ளூர் சேவையகம் ஒரு பெறும் கிளையன்ட் மற்றும் ஒரு புதிய விதைப்பு சேவையகம் ஆகும்; மூல முனை கோப்பு புதுப்பிக்கப்படும் போது, ​​அது தானாகவே ஒத்திசைக்கப்படும் மற்றும் பிற முனைகளுக்கு துண்டிக்கப்பட்ட பதிவிறக்கங்களை வழங்குகிறது:

```bash
# முழு பகிர்வு குழுவிற்கும் குழுசேர்ந்து தானாகவே விதைக்கவும்
sync0 sub dataset:// ./local_mirror -p <node address>

# குறிப்பிட்ட கோப்புகள் மற்றும் துணை அடைவுகளுக்கு குழுசேர மற்றும் அவற்றை விதைப்பதற்கு பல தேர்ந்தெடுக்கப்பட்டவை மட்டுமே
sync0 துணை தரவுத்தொகுப்பு://models/llama.onnx,configs ./local_mirror -p <node address>
```

### 6. மல்டி-மெஷின் குழு பியர் ஒத்திசைவு (`sync0 group`)

பல இயந்திரங்கள் ஒரே பகிர்வுக் குழுவில் இணைகின்றன, ஒன்றுக்கொன்று தானாகவே கிடைக்கக்கூடிய விதை முனைகளைக் கண்டறிந்து இருவழி ஒத்திசைவை பராமரிக்கிறது (முழு ஒத்திசைவு அல்லது கோப்புகள் மற்றும் கோப்பகங்களின் பல தேர்வுகளை ஆதரிக்கிறது):

```bash
# குழுவில் முழுமையாக சேரவும் மற்றும் இருவழி ஒத்திசைவு
sync0 group team-docs:// ./docs -p <node address>

# பல தேர்ந்தெடுக்கப்பட்ட ஒத்திசைவு குழுவில் உள்ள வால் டைரக்டரி மற்றும் meta.json கோப்பு மட்டுமே
sync0 group team-docs://wal,meta.json ./docs -p <node address>
```

### 7. இரண்டு இயந்திரங்களுக்கு இடையே பாயிண்ட்-டு-பாயிண்ட் நேரடி பரிமாற்றம் (`send` / `recv`)

ஒரு குழுவை முன்-கட்டமைக்க வேண்டிய அவசியமில்லை, மேலும் நீங்கள் தற்காலிகமாக இரண்டு இயந்திரங்களுக்கு இடையில் நேரடியாக கோப்புகள் அல்லது கோப்பகங்களை மாற்றலாம்:

```bash
# ரிசீவர் கண்காணிப்பு
sync0 recv 0.0.0.0:9000 ./backup

# அனுப்பும் முடிவு நேரடியாக கோப்புகள் அல்லது கோப்பகங்களை மாற்றுகிறது (விரும்பினால் --அதிகப்படியான கோப்புகளை சுத்தம் செய்ய கண்ணாடியை நீக்கவும், --விகித வேக வரம்பு)
sync0 send ./project 192.168.1.10:9000
```

### 8. பல மொழி மாறுதல்

`sync0` 75 மொழிகளை ஆதரிக்கிறது மற்றும் முன்னிருப்பாக கணினி மொழி சூழலுக்கு ஏற்ப தானாகவே மாறுகிறது; அதை `SYNC0_LANG` மூலம் கைமுறையாகவும் குறிப்பிடலாம்:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
