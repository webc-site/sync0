# sync0

`sync0` هڪ پيئر-ٽو-پيئر (P2P) فائل شيئرنگ ۽ ملٽي مشين سنڪرونائيزيشن جو اوزار آهي جيڪو Resilio Sync سان مقابلو ڪري ٿو.

هر مشين هڪ سرور ۽ ڪلائنٽ آهي: ڪو به نوڊ ڪيترن ئي فائل شيئرنگ گروپن کي شايع ڪري سگهي ٿو. ٻيون نوڊس شامل ٿيڻ کان پوءِ، اھي پاڻمرادو دستياب سيڊ نوڊس کي پيئر سرور مان حاصل ڪري سگھن ٿا ۽ انھن کي گڏ ڪري گھڻن ذريعن کان گڏ ڪري سگھن ٿا. هم وقت سازي مڪمل ٿيڻ کان پوءِ، ڊائون لوڊ کي تيز ڪرڻ لاءِ وڌيڪ نوڊس لاءِ ٻج خود بخود ٺاهيا ويندا.

## بنيادي نمايان

- **هرڪو ٻئي سرور ۽ ڪلائنٽ آهي**: Resilio Sync جي مقابلي ۾، ڪو به مرڪزي سرور انحصار ناهي. ڪو به نوڊ ڪيترن ئي فائل شيئرنگ گروپن کي ٺاهي سگھي ٿو، ۽ پڻ ٻين ماڻھن جي شيئرنگ گروپن ۾ شامل ٿي سگھي ٿو؛ نوڊس پاڻمرادو مٽا سٽا ۽ دستياب ٻج نوڊس حاصل ڪن ٿا ته جيئن ڪيترن ئي مشينن جي هم وقتي ڇڪڻ ۽ حقيقي وقت جي هم وقت سازي حاصل ڪرڻ لاءِ.
- **IP فري نوڊ ايڊريس**: ڊفالٽ طور، نوڊ ڪي ۽ `base64url` انڪوڊ ٿيل `iroh` پتو خودڪار طور تي ٺاهيا ويندا آهن `~/.config/sync0` ۾ عوامي IP کي ياد ڪرڻ يا ظاهر ڪرڻ جي ضرورت کان سواءِ.
- **ملٽي سليڪٽ سنڪرونائيزيشن آن ڊيمانڊ**: پوري شيئرنگ گروپ جي هم وقت سازي کي سپورٽ ڪري ٿي، ۽ ساڳئي وقت ڪيترن ئي فائلن يا ذيلي ڊاريڪٽريز کي چونڊڻ سان مطالبن تي هم وقت سازي کي سپورٽ ڪري ٿي.
- **گروپ ميمبر جي درجه بندي اجازتون ۽ اپلوڊ ڊاريڪٽري ڪنٽرول**: سپورٽ ڪري ٿو صرف پڙهڻ لاءِ (`ro`)، پڙهڻ لاءِ اپلوڊ (`rw`)، ۽ انتظام (`admin`) اجازتون، ۽ انفرادي طور تي وضاحت ڪري سگھي ٿو رستو اڳياڙي جيڪو هر ميمبر کي اپلوڊ ڪرڻ جي اجازت آهي (ڊفالٽ طور، روٽ ڊاريڪٽري کي اپ لوڊ ڪرڻ جي اجازت آهي).
- **نيٽ ورڪن تي مڪمل رفتار ۽ وڌندڙ هم وقت سازي**: وڏي فائلن جي سمورو ٽرانسميشن، ميموري ۾ وڏين ننڍين فائلن جو مجموعو، ۽ صرف هم وقت ٿيل ڊيٽا بلاڪ جڏهن فائلون جزوي طور تبديل ڪيون وينديون آهن.

## انسٽال ڪريو

### طريقو 1: ڪارگو ذريعي انسٽال ڪريو

```bash
cargo install sync0
```

### طريقو 2: ڊائون لوڊ ڪريو اڳ ۾ ٺهيل بائنري

[GitHub Releases](https://github.com/webc-site/sync0/releases) ڏانهن وڃو `.tar.xz` لاڳاپيل سسٽم لاءِ ڪمپريس ٿيل پيڪيج (لينڪس، ميڪوس، ونڊوز، اينڊرائيڊ، فري بي ايس ڊي، نيٽ بي ايس ڊي کي سپورٽ ڪري ٿو)، ان زپ ڪريو ۽ ان کي `PATH` ڊاريڪٽري ۾ وجھو:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## جلدي شروع ڪريو

`sync0` استعمال ڪري ٿو `~/.config/sync0` ڊفالٽ جي ترتيب واري ڊاريڪٽري طور (جيڪڏهن توهان کي ٻين ڊاريڪٽري ڏانهن تبديل ڪرڻ جي ضرورت آهي، توهان شامل ڪري سگهو ٿا `-c <directory>`).

### 1. ڏسو مقامي نوڊ ايڊريس ۽ سيٽنگ ڪاروباري ڪارڊ

```bash
# مقامي نوڊ ايڊريس ڏسو (ڪجھه پهريون ڀيرو ~/.config/sync0 ۾ خودڪار طور تي ٺاهي وئي آهي)
sync0 id

# ھڪڙو ذاتي نوڊ ڪاروباري ڪارڊ ٺاھيو (استعمال ڪندڙ نالو، شھر، اي ميل، ويب سائيٽ ۽ دستخط 256 لفظن جي اندر)
sync0 profile -u alice --region SHA --email alice@example.com --url https://example.com -b "Shanghai node"
```

### 2. ڪيترن ئي فائل شيئرنگ گروپن کي شايع ڪريو ۽ گروپ ميمبرن جي اجازت مقرر ڪريو (`.nt` ترتيب)

`sync0` ترتيب ڏنل آهي [NestedText](https://nestedtext.org) (`.nt`) فارميٽ ۾. هر صارف وٽ هڪ الڳ آهي `.nt` ترتيب واري فائيل. توھان وضاحت ڪري سگھوٿا يوزر پروفائل ڊاريڪٽري ذريعي `users_dir` in `config.nt` (جنھن ۾ پاڻمرادو شامل آھن سڀ `.nt` فائلون ھن ڊاريڪٽري ۾). ٻئي استعمال ڪندڙ ۽ واٽ پريفڪس کي اپلوڊ ڪرڻ جي اجازت ڏني وئي غير ترتيب ڏنل فهرست (`-`). **جڏهن اپلوڊ رستو پريفڪس ڀريو نه ويو آهي، شيئر جي روٽ ڊاريڪٽري تي اپلوڊ ڪرڻ جي اجازت ڏني وئي آهي ڊفالٽ **.

1. ڊاريڪٽري ۾ هر ميمبر لاءِ الڳ `.nt` ٺاھڻ واريون فائلون ٺاھيو:

`~/.config/sync0/users/alice.nt` (صرف پڙهڻ لاءِ ميمبر، شرح محدود `80MB`، `rate` سپورٽ `GB`، `MB`، `KB` يونٽس):

```yaml
id: 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c
perm: ro
rate: 80MB
```

`~/.config/sync0/users/bob.nt` (محدود اپلوڊ ميمبر: صرف `uploads/bob` ۽ `shared/common` ڊائريڪٽرن تي اپلوڊ ڪرڻ جي اجازت آهي):

```yaml
id: 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f
perm: rw
write_prefix:
  - uploads/bob
  - shared/common
```

`~/.config/sync0/users/charlie.nt` (ڊفالٽ ميمبر اپ لوڊ: جڏهن `write_prefix` کي ختم ڪيو ويو آهي، شيئر جي روٽ ڊاريڪٽري تي اپلوڊ ڪرڻ جي اجازت هوندي آهي ڊفالٽ):

```yaml
id: 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
perm: rw
```

2. `~/.config/sync0/config.nt` ۾ يوزر ڊاريڪٽري ۽ گھڻن فائل شيئرنگ گروپن کي ترتيب ڏيو:

```yaml
users_dir: ./users

groups:
  dataset:
    path: ./data
    auth: false
    perm: ro
    rate: 50MB

  models:
    path: ./models
    auth: false
    perm: ro
    rate: 1GB

  team-vault:
    path: ./vault
    auth: true
    perm: ro
    rate: 512KB
    users:
      - alice
      - bob
      - charlie
```

شيئرنگ سروس شروع ڪريو:

```bash
# سڌو شروع ڪرڻ (خودڪار طور تي سڀني .nt استعمال ڪندڙ ترتيبن کي لوڊ ڪري ٿو ~/.config/sync0/config.nt ۽ user_dir ڊائريڪٽرن ۾)
sync0 share --region SHA

# يا جلدي ڪيترن ئي شيئرنگ گروپن کي شايع ڪريو ۽ گروپ جي ميمبرن کي سڌو سنئون ڪمانڊ لائن ذريعي اختيار ڪريو
sync0 share dataset:./data team-vault:./vault \
  --auth \
  --allow-ro 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c \
  --allow-rw 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f:uploads/bob,shared/common \
  --allow-rw 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
```

### 3. سڀ مواد ڪڍو يا گھڻن فائلن ۽ ڊائريڪٽرن کي چونڊيو (`sync0 pull`)

شيئرنگ گروپ ۾ موجود سڀ موجود ٻج نوڊس پاڻمرادو حاصل ڪرڻ لاءِ ڪنهن به پير نوڊ سان ڳنڍيو، ۽ ڪيترن ئي ٻج جي نوڊس کي گڏ ڪريو:

```bash
# سڄي ڊيٽا سيٽ شيئرنگ گروپ کي مقامي ./local_data ڏانهن ڇڪيو
sync0 pull dataset:// ./local_data -p <node address>

# ملٽي-منتخب هم وقت سازي: هڪ ئي وقت هڪ فائل کي ڇڪيو docs/readme.md ۽ ذيلي ڊائريڪٽري اثاثن/آئڪن، src/core
sync0 pull dataset://docs/readme.md,assets/icons,src/core ./local_data -p <node address>
```

### 4. شيئرنگ گروپ ۾ فائل يا ڊاريڪٽري اپ لوڊ ڪريو (`sync0 push`)

اپلوڊ جي اجازتن سان گڏ ميمبر (`rw` يا `admin`) مقامي فائلون يا ڊائريڪٽريون اپلوڊ ڪري سگھن ٿا ريموٽ شيئرنگ گروپن ۾:

```bash
# ميمبر روٽ ڊاريڪٽري اپلوڊ جي اجازت سان: سڌي طرح حصيداري روٽ ڊاريڪٽري تي اپ لوڊ ڪريو
sync0 push team-vault:// ./new_release -p <node address>

# صرف ميمبرن کي مخصوص پريفڪس (جهڙوڪ اپلوڊ/بوب) جي اجازت ڏني وئي آهي: اجازت ڏنل رستي جي اڳياڙي تي اپ لوڊ ڪريو
sync0 push team-vault://uploads/bob/report.pdf ./report.pdf -p <node address>
```

### 5. رڪنيت حاصل ڪريو خودڪار هم وقت سازي ۽ سيڊنگ (`sync0 sub`)

ھڪڙي خاص نوڊ جي شيئرنگ گروپ جي رڪنيت حاصل ڪرڻ کان پوء، مقامي سرور ٻئي وصول ڪندڙ ڪلائنٽ ۽ ھڪڙو نئون سيڊنگ سرور آھي؛ جڏهن ماخذ نوڊ فائل کي اپڊيٽ ڪيو ويندو آهي، اهو خودڪار طور تي هم وقت سازي ڪيو ويندو آهي ۽ ٻين نوڊس لاء chunked ڊائون لوڊ مهيا ڪري:

```bash
# سڄي شيئرنگ گروپ ۾ رڪنيت حاصل ڪريو ۽ خودڪار طور تي ٻج
sync0 sub dataset:// ./local_mirror -p <node address>

# مخصوص فائلن ۽ سب ڊاريڪٽريز جي رڪنيت حاصل ڪرڻ لاءِ صرف گھڻن کي منتخب ڪريو ۽ انھن کي سيڊ ڪريو
sync0 sub dataset://models/llama.onnx,configs ./local_mirror -p <node address>
```

### 6. ملٽي مشين گروپ پير هم وقت سازي (`sync0 group`)

ڪيتريون ئي مشينون هڪ ئي شيئرنگ گروپ ۾ شامل ٿين ٿيون، هڪ ٻئي خودڪار طريقي سان دستياب ٿيل ٻج نوڊس کي ڳولي ٿو ۽ ٻه طرفي هم وقت سازي کي برقرار رکي ٿو (مڪمل هم وقت سازي يا فائلن ۽ ڊائريڪٽرن جي گهڻن چونڊ کي سپورٽ ڪري ٿو):

```bash
# مڪمل طور تي گروپ ۾ شامل ٿيو ۽ ٻه طرفي هم وقت سازي
sync0 group team-docs:// ./docs -p <node address>

# صرف wal ڊاريڪٽري ۽ meta.json فائل ملٽي-منتخب هم وقت سازي گروپ ۾
sync0 group team-docs://wal,meta.json ./docs -p <node address>
```

### 7. پوائنٽ کان پوائنٽ سڌو ٽرانسميشن ٻن مشينن جي وچ ۾ (`send` / `recv`)

ڪنهن گروپ کي اڳ ۾ ترتيب ڏيڻ جي ڪا ضرورت ناهي، ۽ توهان عارضي طور تي فائلون يا ڊائريڪٽريون سڌو سنئون ٻن مشينن جي وچ ۾ منتقل ڪري سگهو ٿا:

```bash
# وصول ڪندڙ جي نگراني
sync0 recv 0.0.0.0:9000 ./backup

# موڪلڻ واري پڇاڙي سڌي طرح فائلن يا ڊائريڪٽرن کي منتقل ڪري ٿي (اختياري - اضافي فائلن کي صاف ڪرڻ لاء آئيني کي حذف ڪريو، رفتار جي رفتار جي حد)
sync0 send ./project 192.168.1.10:9000
```

### 8. گھڻن ٻولين جي سوئچنگ

`sync0` 75 ٻولين کي سپورٽ ڪري ٿو، ۽ خود بخود سسٽم ٻولي ماحول جي مطابق ڊفالٽ طور تبديل ڪري ٿو؛ اهو پڻ دستي طور تي بيان ڪري سگهجي ٿو `SYNC0_LANG`:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
