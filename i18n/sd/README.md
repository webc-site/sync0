# sync0

`sync0` ھڪ ڪمانڊ لائن ٽول آھي فائلن کي نيٽ ورڪن ۾ منتقل ڪرڻ لاءِ، ڊاريڪٽري کي وڌ ۾ وڌ هم وقت سازي ڪرڻ، ۽ گڏوگڏ ڊيٽا ڪيترن ئي مشينن ۾ ورهائڻ لاءِ.

## اصل ڊيزائن جو ارادو

ڪراس مشين ڪمرن، ملڪن، يا ماحول ۾ نيٽ ورڪ جي دير ۽ پيڪٽ جي نقصان سان، اوزار جهڙوڪ `rsync` ۽ `scp` سنگل ڪنيڪشن جي تسلسل جي تصديق تي ٻڌل آهن، جيڪي بينڊوڊٿ جي استعمال کي محدود ڪن ٿا؛ جڏهن هڪ ئي وقت هڪ ئي سرور مان گھڻا مشينون ڊيٽا ڪڍن ٿيون، سورس سرور نيٽ ورڪ ڪارڊ آساني سان هڪ رڪاوٽ بڻجي سگهي ٿو.

`sync0` جو مقصد ٻه مسئلا حل ڪرڻ آهي:

1. ٻن مشينن جي وچ ۾ فائل ۽ ڊاريڪٽري جي هم وقت سازي کي مڪمل جسماني بينڊوڊٿ هلائڻ ڏيو، ۽ صرف تبديل ٿيل حصو کي منتقل ڪريو جڏھن فائل جزوي طور تي تبديل ٿيل آھي.
2. ڪيتريون ئي مشينون ڊيٽا بلاڪ کي هڪ ٻئي ڏانهن منتقل ڪري سگهن ٿيون جڏهن ساڳئي ڊاريڪٽري کي هم وقت سازي ڪندي، سورس سرور تي لوڊ کي گهٽائڻ ۽ مجموعي هم وقت سازي جي وقت کي مختصر ڪندي.

## رفتار جو مقابلو rsync سان

ٽيسٽ ماحول: يورپي نوڊ $\leftrightarrow$ اتر آمريڪي نوڊ، راؤنڈ ٽرپ دير 86 ms، ماپڻ مڪمل وقت خرچ ڪرڻ سميت ڊاريڪٽري اسڪيننگ، ڊيڊپليڪيشن موازن، نيٽ ورڪ ٽرانسميشن ۽ ڊسڪ پليسمينٽ جي تصديق:

| ٽرانسميشن منظر | ڊيٽا جي ماپ | `sync0` | `rsync` | گھڻا |
| :--- | :---: | :---: | :---: | :---: |
| 10,000 ننڍيون فائلون | 77.6 MB | 0.90 s (688 Mbps) | 4.86 s (128 Mbps) | 5.4x |
| ڪوڊ ۽ آرڪائيو پيڪيجز (`.tar`) | 512 MB | 1.94 s (2111 Mbps) | 9.36 s (438 Mbps) | 4.8x |
| وڊيو فائيل (`.mp4`) | 512 MB | 7.36 s (556 Mbps) | 12.11 s (338 Mbps) | 1.6x |
| وڌندڙ هم وقت سازي (1٪ مواد تبديل ڪريو) | 512 MB | 0.12 s | 1.85 s | 15.4x |

## ڪارڪردگي بهتر ڪرڻ جا طريقا

- **UDP سمورو ٽرانسميشن**: UDP ذريعي ڊيٽا بلاڪ موڪليو، ۽ صرف هڪ پيڪٽ جي نقصان کان بچڻ لاءِ گم ٿيل ٽڪڙن کي ٻيهر منتقل ڪريو بعد ۾ فائلن جي منتقلي کي بلاڪ ڪرڻ.
- ** مواد جي ڀاڱيداري ۽ نقل ڪرڻ **: فائل کي ورهايو ڊيٽا بلاڪ ۾ مواد جي مطابق ۽ حساب ڪريو چيڪ جي قيمت. ساڳيو مواد اڳ ۾ ئي وصول ڪرڻ واري آخر تي آهي نيٽ ورڪ کي نقل ڪرڻ کان سواءِ سڌو مقامي طور تي ٻيهر استعمال ڪيو ويندو آهي.
- ** نيٽ ورڪ جي رفتار جي مطابق ڪمپريشن کي پاڻمرادو ترتيب ڏيو**: دٻائڻ واري مواد لاءِ ڪمپريشن آن ڪريو جيئن ٽيڪسٽ ۽ ڪوڊ؛ سي پي يو جي استعمال کي گھٽائڻ لاءِ وڊيوز، تصويرن، ڪمپريس ٿيل پيڪيجز يا تيز رفتار LAN لاءِ خود بخود ڪمپريشن کي ڇڏي ڏيو.
- **ملٽي نوڊ ويجھي ڇڪڻ**: جڏھن گھڻا مشينون ھڪڙي ڊاريڪٽري کي ڇڪيندا آھن، ڊيٽا بلاڪ ساڳئي شھر ۾ ڊائون لوڊ ٿيل نوڊس مان يا گھٽ دير سان گڏ ڪيا ويندا.

## انسٽال ڪريو

### طريقو 1: ڪارگو ذريعي انسٽال ڪريو

```bash
cargo install sync0
```

### طريقو 2: ڊائون لوڊ ڪريو اڳ ۾ ٺهيل بائنري

[GitHub Releases](https://github.com/webc-site/sync0/releases) ڏانهن وڃو ڊائون لوڊ ڪرڻ لاءِ `.tar.xz` لاڳاپيل سسٽم لاءِ ڪمپريس ٿيل پيڪيج (سپورٽ ڪري ٿو Linux x86_64/ARM64, macOS Apple Silicon/Intel, Windows x64/ARM64, Android ARM64/x86_64, FreeBSD, NetBSD). ان زپ ڪرڻ کان پوء، `sync0` کي `PATH` ڊاريڪٽري ۾ رکو:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## استعمال ڪندڙ ھدايت

### 1. سڌو سنئون فائلون يا ڊائريڪٽريون ٻن مشينن جي وچ ۾ منتقل ڪريو

وصول ڪرڻ واري مشين تي مانيٽرنگ شروع ڪريو ۽ وصول ڪرڻ ۽ بچائڻ جو رستو بيان ڪريو:

```bash
sync0 recv 0.0.0.0:9000 ./backup
```

موڪلڻ واري مشين مان ھڪڙي فائل يا پوري ڊاريڪٽري موڪليو:

```bash
sync0 send ./project 192.168.1.10:9000
```

عام طور تي استعمال ٿيل پيٽرولر:

```bash
# بيڪار فائلن کي حذف ڪريو جيڪي حاصل ڪرڻ واري آخر ۾ موجود آهن پر موڪلڻ واري آخر تي نه (عصري هم وقت سازي)
sync0 send ./project 192.168.1.10:9000 --delete

# حد موڪلڻ جي شرح (يونٽ: بائيٽ/سيڪنڊ، مثال طور 50 MB/s)
sync0 send ./project 192.168.1.10:9000 --rate 50000000

# خاموش موڊ (ڪو به ترقي وارو بار نه ڏيکاريل آهي)
sync0 send ./project 192.168.1.10:9000 -q
```

### 2. گڏيل ڊائريڪٽري شايع ڪرڻ ۽ ڪيترن ئي نوڊس مان ڪڍڻ

ھڪڙي حصيداري ڊاريڪٽري (نالي `dataset`) شايع ڪريو اصل سرور تي:

```bash
sync0 share dataset ./data --region SHA
```

شيئر ڪيل ڊاريڪٽري کي ٻين مشينن تي ڇڪيو (توهان هڪ ئي وقت ڪيترن ئي نوڊ ايڊريس ڀري سگهو ٿا، هڪ ئي وقت ڪڍڻ لاءِ ڪاما سان الڳ ٿيل):

```bash
sync0 pull 10.0.0.1:9000,10.0.0.2:9000 dataset ./local_data
```

حصيداري ڊاريڪٽري ۾ صرف هڪ خاص ذيلي ڊائريڪٽري کي ڇڪيو:

```bash
sync0 pull 10.0.0.1:9000 dataset ./local_data --subpath 2026/logs
```

مقامي تبديلين کي واپس ريموٽ شيئر ڊاريڪٽري ڏانهن ڇڪيو:

```bash
sync0 push 10.0.0.1:9000 dataset ./local_data
```

### 3. رڪنيت حاصل ڪريو فهرست خودڪار تازه ڪاريون

ماخذ نوڊ جي گڏيل ڊاريڪٽري ۾ رڪنيت حاصل ڪريو. جڏهن هڪ فائل شامل ڪئي ويندي آهي يا ماخذ ڊاريڪٽري ۾ تبديل ٿي ويندي آهي، اهو خودڪار طريقي سان مقامي ڪمپيوٽر ڏانهن هم وقت سازي ڪئي ويندي. ساڳئي وقت، مقامي مشين خودڪار طريقي سان ٻين مشينن کي ڇڪڻ لاء نوڊ طور ڪم ڪندو:

```bash
sync0 sub 10.0.0.1:9000 dataset ./local_mirror
```

### 4. ملٽي مشين گروپن جي ٻه طرفي هم وقت سازي

ڪيتريون ئي مشينون ساڳئي گروپ جي نالي سان شامل ٿين ٿيون، ۽ ڪنهن به نوڊ ڊاريڪٽري ۾ تبديليون پاڻمرادو گروپ ۾ ٻين نوڊس سان هم وقت ٿي وينديون آهن:

```bash
sync0 group team-docs ./docs 10.0.0.1:9000,10.0.0.2:9000
```

### 5. نوڊ جي سڃاڻپ ۽ ذاتي ڪاروباري ڪارڊ

هر نوڊ صارف جو نالو، شهر، اي ميل، ويب سائيٽ ۽ ذاتي دستخط (وڌ ۾ وڌ 256 اکرن) کي ترتيب ڏيڻ جي حمايت ڪري ٿو، ۽ مقامي نجي اهم دستخط جي تصديق کي پاس ڪري ٿو:

```bash
# مقامي عوامي ڪيئي ID ڏسو (ڪي کي جاري رکڻ لاءِ ترتيب واري ڊاريڪٽري جي وضاحت ڪريو)
sync0 id -c ~/.config/sync0

# ذاتي ٿيل دستخط سان نوڊ ڪاروباري ڪارڊ ٺاهي ۽ ڊسپلي ڪريو
sync0 profile -c ~/.config/sync0 \
  -u alice \
  --region SHA \
  --email alice@example.com \
  --url https://example.com \
  -b "Shanghai backup node"
```

`share`، `pull`، `sub`، `group` پڻ شروع ڪري سگھجن ٿا انهن پروفائل پيرا ميٽرن سان:

```bash
sync0 share dataset ./data -c ~/.config/sync0 -u alice --region SHA -b "Shanghai backup node"
```

### 6. گھڻن ٻولين جي سوئچنگ

`sync0` 75 ٻولين کي سپورٽ ڪري ٿو. ڊفالٽ طور، ڪمانڊ لائن مدد ۽ لاڳاپيل ٻولي ۾ اشارا خودڪار طريقي سان ڏيکاريا ويندا آھن آپريٽنگ سسٽم جي ٻولي ماحول جي مطابق؛ جيڪڏهن سسٽم ٻولي سپورٽ لسٽ ۾ نه آهي، انگريزي ڊفالٽ طور استعمال ڪيو ويندو آهي.

ٻولي کي دستي طور بيان ڪرڻ لاءِ، ماحوليات جي متغير کي سيٽ ڪريو `SYNC0_LANG`:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
