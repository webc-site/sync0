# sync0

`sync0` ایک کمانڈ لائن ٹول ہے جو تمام نیٹ ورکس میں فائلوں کو منتقل کرنے، ڈائرکٹریوں کو بتدریج ہم آہنگ کرنے، اور بیک وقت متعدد مشینوں میں ڈیٹا کی تقسیم کے لیے ہے۔

## اصل ڈیزائن کا ارادہ

کراس مشین رومز، ممالک، یا نیٹ ورک میں تاخیر اور پیکٹ کے نقصان والے ماحول میں، ٹولز جیسے `rsync` اور `scp` سنگل کنکشن کی ترتیب کی تصدیق پر مبنی ہیں، جو بینڈوڈتھ کے استعمال کو محدود کرتا ہے۔ جب متعدد مشینیں ایک ہی وقت میں ایک ہی سرور سے ڈیٹا کھینچتی ہیں، تو سورس سرور نیٹ ورک کارڈ آسانی سے رکاوٹ بن سکتا ہے۔

`sync0` کا مقصد دو مسائل کو حل کرنا ہے:

1. دو مشینوں کے درمیان فائل اور ڈائرکٹری کی مطابقت پذیری کو مکمل فزیکل بینڈوڈتھ چلانے دیں، اور فائل میں جزوی طور پر ترمیم ہونے پر ہی تبدیل شدہ حصے کو منتقل کریں۔
2. ایک ہی ڈائرکٹری کو سنکرونائز کرتے وقت متعدد مشینیں ڈیٹا بلاکس کو ایک دوسرے کو منتقل کر سکتی ہیں، سورس سرور پر بوجھ کو کم کرتی ہیں اور مجموعی مطابقت پذیری کے وقت کو مختصر کرتی ہیں۔

## rsync کے ساتھ رفتار کا موازنہ

ٹیسٹ ماحول: یورپی نوڈ $\leftrightarrow$ نارتھ امریکن نوڈ، راؤنڈ ٹرپ میں تاخیر 86 ms، جس میں ڈائرکٹری اسکیننگ، ڈپلیکیشن موازنہ، نیٹ ورک ٹرانسمیشن اور ڈسک پلیسمنٹ کی تصدیق سمیت مکمل وقت کی پیمائش:

| ٹرانسمیشن کا منظر نامہ | ڈیٹا کا سائز | `sync0` | `rsync` | متعدد |
| :--- | :---: | :---: | :---: | :---: |
| 10,000 چھوٹی فائلیں۔ | 77.6 MB | 0.90 s (688 Mbps) | 4.86 s (128 Mbps) | 5.4x |
| کوڈ اور آرکائیو پیکجز (`.tar`) | 512 MB | 1.94 s (2111 Mbps) | 9.36 s (438 Mbps) | 4.8x |
| ویڈیو فائل (`.mp4`) | 512 MB | 7.36 s (556 Mbps) | 12.11 s (338 Mbps) | 1.6x |
| اضافی مطابقت پذیری (1% مواد میں ترمیم کریں) | 512 MB | 0.12 s | 1.85 s | 15.4x |

## کارکردگی میں بہتری کے طریقے

- **UDP کنکرنٹ ٹرانسمیشن**: UDP کے ذریعے ڈیٹا بلاکس بھیجیں، اور صرف کھوئے ہوئے ٹکڑوں کو دوبارہ منتقل کریں تاکہ ایک پیکٹ کے نقصان سے بچنے کے لیے فائل کی منتقلی کو روکا جا سکے۔
- **مواد کی تقسیم اور ڈپلیکیشن**: فائل کو مواد کے مطابق ڈیٹا بلاکس میں تقسیم کریں اور چیک ویلیو کا حساب لگائیں۔ وہی مواد جو پہلے سے موصول ہونے والے سرے پر ہے نیٹ ورک کو نقل کیے بغیر براہ راست مقامی طور پر دوبارہ استعمال کیا جاتا ہے۔
- **نیٹ ورک کی رفتار کے مطابق خودکار طور پر کمپریشن کو ایڈجسٹ کریں**: کمپریس ایبل مواد جیسے ٹیکسٹ اور کوڈ کے لیے کمپریشن آن کریں۔ CPU کی کھپت کو کم کرنے کے لیے خود بخود ویڈیوز، تصاویر، کمپریسڈ پیکجز یا ہائی سپیڈ LAN کے لیے کمپریشن کو چھوڑ دیں۔
- **ملٹی نوڈ قریبی پلنگ**: جب ایک سے زیادہ مشینیں ایک ہی ڈائرکٹری کو کھینچتی ہیں، تو ڈیٹا بلاکس کو ایک ہی شہر میں یا کم تاخیر کے ساتھ ڈاؤن لوڈ کیے گئے نوڈس سے بیک وقت کھینچا جائے گا۔

## انسٹال کریں۔

### طریقہ 1: کارگو کے ذریعے انسٹال کریں۔

```bash
cargo install sync0
```

### طریقہ 2: پہلے سے مرتب شدہ بائنریز ڈاؤن لوڈ کریں۔

متعلقہ سسٹم کے لیے `.tar.xz` کمپریسڈ پیکج ڈاؤن لوڈ کرنے کے لیے [GitHub Releases](https://github.com/webc-site/sync0/releases) پر جائیں (Linux x86_64/ARM64, macOS Apple Silicon/Intel, Windows x64/ARM64, Android ARM64/x86_64, FreeBSD, NetBSD کو سپورٹ کرتا ہے)۔ ان زپ کرنے کے بعد، `sync0` کو `PATH` ڈائریکٹری میں رکھیں:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## یوزر گائیڈ

### 1. دو مشینوں کے درمیان فائلوں یا ڈائریکٹریوں کو براہ راست منتقل کریں۔

وصول کرنے والی مشین پر نگرانی شروع کریں اور وصول کرنے اور بچانے کے راستے کی وضاحت کریں:

```bash
sync0 recv 0.0.0.0:9000 ./backup
```

بھیجنے والی مشین سے ایک فائل یا پوری ڈائرکٹری بھیجیں:

```bash
sync0 send ./project 192.168.1.10:9000
```

عام طور پر استعمال ہونے والے پیرامیٹرز:

```bash
# فالتو فائلوں کو حذف کریں جو موصول ہونے والے سرے پر موجود ہیں لیکن بھیجنے والے سرے پر نہیں (آئینے کی مطابقت پذیری)
sync0 send ./project 192.168.1.10:9000 --delete

# بھیجنے کی شرح کو محدود کریں (یونٹ: بائٹس/سیکنڈ، مثال کے طور پر 50 MB/s)
sync0 send ./project 192.168.1.10:9000 --rate 50000000

# خاموش موڈ (کوئی پروگریس بار نہیں دکھایا گیا)
sync0 send ./project 192.168.1.10:9000 -q
```

### 2. مشترکہ ڈائریکٹریز شائع کرنا اور متعدد نوڈس سے کھینچنا

ایک مشترکہ ڈائریکٹری شائع کریں (جس کا نام `dataset` ہے) اوریجن سرور پر:

```bash
sync0 share dataset ./data --region SHA
```

مشترکہ ڈائرکٹری کو دوسری مشینوں پر کھینچیں (آپ بیک وقت متعدد نوڈ ایڈریس کو بھر سکتے ہیں، بیک وقت کھینچنے کے لیے کوما سے الگ کیا گیا ہے):

```bash
sync0 pull 10.0.0.1:9000,10.0.0.2:9000 dataset ./local_data
```

مشترکہ ڈائریکٹری میں صرف ایک مخصوص ذیلی ڈائرکٹری کو کھینچیں:

```bash
sync0 pull 10.0.0.1:9000 dataset ./local_data --subpath 2026/logs
```

مقامی تبدیلیوں کو ریموٹ مشترکہ ڈائریکٹری میں واپس دھکیلیں:

```bash
sync0 push 10.0.0.1:9000 dataset ./local_data
```

### 3. کیٹلاگ خودکار اپ ڈیٹس کو سبسکرائب کریں۔

سورس نوڈ کی مشترکہ ڈائریکٹری کو سبسکرائب کریں۔ جب کوئی فائل سورس ڈائرکٹری میں شامل یا ترمیم کی جاتی ہے، تو یہ خود بخود مقامی کمپیوٹر کے ساتھ مطابقت پذیر ہو جائے گی۔ ایک ہی وقت میں، مقامی مشین خود بخود دوسری مشینوں کو کھینچنے کے لیے ایک نوڈ کے طور پر کام کرے گی:

```bash
sync0 sub 10.0.0.1:9000 dataset ./local_mirror
```

### 4. ملٹی مشین گروپس کی دو طرفہ ہم آہنگی۔

ایک سے زیادہ مشینیں ایک ہی گروپ کے نام میں شامل ہوتی ہیں، اور کسی بھی نوڈ ڈائرکٹری میں ہونے والی تبدیلیاں خود بخود گروپ کے دوسرے نوڈس کے ساتھ مطابقت پذیر ہو جائیں گی۔

```bash
sync0 group team-docs ./docs 10.0.0.1:9000,10.0.0.2:9000
```

### 5. نوڈ شناخت اور ذاتی کاروباری کارڈ

ہر نوڈ صارف کا نام، شہر، ای میل، ویب سائٹ اور ذاتی دستخط (زیادہ سے زیادہ 256 حروف) ترتیب دینے میں معاونت کرتا ہے، اور مقامی نجی کلیدی دستخط کی توثیق کو پاس کرتا ہے:

```bash
# مقامی عوامی کلید کی ID دیکھیں (کی کو برقرار رکھنے کے لیے کنفیگریشن ڈائرکٹری کی وضاحت کریں)
sync0 id -c ~/.config/sync0

# ذاتی دستخطوں کے ساتھ نوڈ بزنس کارڈ بنائیں اور ڈسپلے کریں۔
sync0 profile -c ~/.config/sync0 \
  -u alice \
  --region SHA \
  --email alice@example.com \
  --url https://example.com \
  -b "Shanghai backup node"
```

`share`، `pull`، `sub`، `group` ان پروفائل پیرامیٹرز کے ساتھ بھی لانچ کیا جا سکتا ہے:

```bash
sync0 share dataset ./data -c ~/.config/sync0 -u alice --region SHA -b "Shanghai backup node"
```

### 6. ملٹی لینگویج سوئچنگ

`sync0` 75 زبانوں کو سپورٹ کرتا ہے۔ پہلے سے طے شدہ طور پر، متعلقہ زبان میں کمانڈ لائن ہیلپ اور پرامپٹس آپریٹنگ سسٹم کے زبان کے ماحول کے مطابق خود بخود ظاہر ہوتے ہیں۔ اگر سسٹم کی زبان معاون فہرست میں نہیں ہے تو، انگریزی بطور ڈیفالٹ استعمال ہوتی ہے۔

زبان کو دستی طور پر بتانے کے لیے، ماحولیاتی متغیر سیٹ کریں `SYNC0_LANG`:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
