# sync0

`sync0` ເປັນ​ການ​ແບ່ງ​ປັນ​ໄຟລ​໌ peer-to-peer (P2P) ແລະ​ເຄື່ອງ​ມື synchronization ຫຼາຍ​ເຄື່ອງ​ທີ່​ແຂ່ງ​ຂັນ​ກັບ Resilio Sync​.

ແຕ່ລະເຄື່ອງແມ່ນທັງເຊີບເວີແລະລູກຄ້າ: ໂນດໃດສາມາດເຜີຍແຜ່ຫຼາຍກຸ່ມແບ່ງປັນໄຟລ໌. ຫຼັງຈາກ nodes ອື່ນໆເຂົ້າຮ່ວມ, ພວກເຂົາສາມາດໄດ້ຮັບ nodes ເມັດທີ່ມີຢູ່ໂດຍອັດຕະໂນມັດຈາກເຄື່ອງແມ່ຂ່າຍຂອງ peer ແລະດຶງພວກມັນພ້ອມກັນຈາກຫຼາຍແຫຼ່ງ. ຫຼັງຈາກ synchronization ສໍາເລັດ, ເມັດຈະຖືກສ້າງຂື້ນໂດຍອັດຕະໂນມັດສໍາລັບ nodes ເພີ່ມເຕີມເພື່ອເລັ່ງການດາວໂຫຼດ.

## ຈຸດເດັ່ນຫຼັກ

- **ທຸກຄົນເປັນທັງເຊີບເວີ ແລະລູກຄ້າ**: ປຽບທຽບກັບ Resilio Sync, ບໍ່ມີການຂຶ້ນກັບເຊີບເວີສູນກາງ. node ໃດສາມາດສ້າງກຸ່ມແບ່ງປັນໄຟລ໌ຫຼາຍ, ແລະຍັງສາມາດເຂົ້າຮ່ວມກຸ່ມແບ່ງປັນຂອງຄົນອື່ນ; nodes ອັດຕະໂນມັດແລກປ່ຽນແລະໄດ້ຮັບ nodes ແກ່ນທີ່ມີຢູ່ເພື່ອບັນລຸການດຶງພ້ອມກັນແລະ synchronization ໃນເວລາທີ່ແທ້ຈິງຂອງເຄື່ອງຈັກຫຼາຍ.
- **ທີ່ຢູ່ node ທີ່ບໍ່ມີ IP**: ຕາມຄ່າເລີ່ມຕົ້ນ, node key ແລະ `base64url`ທີ່ເຂົ້າລະຫັດ `iroh`ທີ່ຢູ່ ຈະຖືກສ້າງໂດຍອັດຕະໂນມັດໃນ `~/.config/sync0` ໂດຍບໍ່ຈໍາເປັນຕ້ອງຈື່ ຫຼືເປີດເຜີຍ IP ສາທາລະນະ.
- **ເລືອກ synchronization ຫຼາຍຕາມຄວາມຕ້ອງການ**: ສະຫນັບສະຫນູນ synchronization ຂອງກຸ່ມແບ່ງປັນທັງຫມົດ, ແລະຍັງສະຫນັບສະຫນູນ synchronization ຕາມຄວາມຕ້ອງການໂດຍການເລືອກຫຼາຍໄຟລ໌ຫຼື subdirectories ໃນເວລາດຽວກັນ.
- **ການອະນຸຍາດຕາມລຳດັບຂອງສະມາຊິກກຸ່ມ ແລະການຄວບຄຸມການອັບໂຫລດໄຟລ໌**: ຮອງຮັບການອ່ານແບບອ່ານເທົ່ານັ້ນ (`ro`), ອ່ານຂຽນການອັບໂຫລດ (`rw`), ແລະການຈັດການ (`admin`) ການອະນຸຍາດ, ແລະສາມາດລະບຸຕົວນຳໜ້າເສັ້ນທາງທີ່ສະມາຊິກແຕ່ລະຄົນອະນຸຍາດໃຫ້ອັບໂຫລດໄດ້ (ໂດຍຄ່າເລີ່ມຕົ້ນ, ການອັບໂຫລດໄປຍັງລະບົບຮາກຂອງການແບ່ງປັນແມ່ນອະນຸຍາດ).
- **ການ​ຊິງ​ໂຄຣ​ໄນ​ແບບ​ເຕັມ​ຄວາມ​ໄວ​ແລະ​ເພີ່ມ​ຂຶ້ນ​ໃນ​ທົ່ວ​ເຄືອ​ຂ່າຍ**​: ການ​ສົ່ງ​ຕໍ່​ຂອງ​ໄຟລ​໌​ຂະ​ຫນາດ​ໃຫຍ່​, ການ​ຮວບ​ຮວມ​ຂອງ​ໄຟລ​໌​ຂະ​ຫນາດ​ນ້ອຍ​ຂະ​ຫນາດ​ໃຫຍ່​ໃນ​ຫນ່ວຍ​ຄວາມ​ຈໍາ​, ແລະ​ພຽງ​ແຕ່ synchronized ຂໍ້​ມູນ​ທີ່​ໄຟລ​໌​ໄດ້​ຖືກ​ດັດ​ແກ້​ບາງ​ສ່ວນ​.

## ຕິດຕັ້ງ

### ວິທີທີ່ 1: ຕິດຕັ້ງຜ່ານ Cargo

```bash
cargo install sync0
```

### ວິທີທີ່ 2: ດາວໂຫລດ binary precompiled

ໄປ​ທີ່ [GitHub Releases](https://github.com/webc-site/sync0/releases) ເພື່ອ​ດາວ​ໂຫລດ `.tar.xz`ແພັກ​ເກດ​ບີບ​ອັດ​ສໍາ​ລັບ​ລະ​ບົບ​ທີ່​ສອດ​ຄ້ອງ​ກັນ (ສະ​ຫນັບ​ສະ​ຫນູນ Linux, macOS, Windows, Android, FreeBSD, NetBSD), unzip ແລະ​ເອົາ​ໃສ່​ໃນ `PATH`ລະ​ບົບ:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## ເລີ່ມຕົ້ນໄວ

`sync0` ໃຊ້ `~/.config/sync0` ເປັນໄດເຣັກທໍຣີການຕັ້ງຄ່າຕາມຄ່າເລີ່ມຕົ້ນ (ຖ້າທ່ານຕ້ອງການປ່ຽນເປັນໄດເຣັກທໍຣີອື່ນ, ທ່ານສາມາດເພີ່ມ `-c <directory>` ໄດ້).

### 1. ເບິ່ງທີ່ຢູ່ node ທ້ອງຖິ່ນແລະການຕັ້ງຄ່ານາມບັດ

```bash
# ເບິ່ງທີ່ຢູ່ຂອງ node ທ້ອງຖິ່ນ (ລະຫັດຈະຖືກສ້າງໂດຍອັດຕະໂນມັດໃນ ~/.config/sync0 ເປັນຄັ້ງທຳອິດ)
sync0 id

# ສ້າງນາມບັດສ່ວນບຸກຄົນ (ສະຫນັບສະຫນູນຊື່ຜູ້ໃຊ້, ເມືອງ, ອີເມວ, ເວັບໄຊທ໌ແລະລາຍເຊັນພາຍໃນ 256 ຄໍາ)
sync0 profile -u alice --region SHA --email alice@example.com --url https://example.com -b "Shanghai node"
```

### 2. ເຜີຍ​ແຜ່​ຫຼາຍ​ກຸ່ມ​ແບ່ງ​ປັນ​ໄຟລ​໌​ແລະ​ກໍາ​ນົດ​ການ​ອະ​ນຸ​ຍາດ​ສະ​ມາ​ຊິກ​ກຸ່ມ (`.nt`​ການ​ຕັ້ງ​ຄ່າ​)

`sync0`ຖືກກຳນົດຄ່າໃນຮູບແບບ [NestedText](https://nestedtext.org) (`.nt`). ຜູ້ໃຊ້ແຕ່ລະຄົນມີໄຟລ໌ການຕັ້ງຄ່າແຍກຕ່າງຫາກ `.nt`. ທ່ານສາມາດລະບຸໄດເລກະທໍລີໂປຣໄຟລ໌ຜູ້ໃຊ້ຜ່ານ `users_dir`ໃນ `config.nt` (ເຊິ່ງລວມມີໄຟລ໌ `.nt`ທັງໝົດໃນໄດເລກະທໍລີນີ້ໂດຍອັດຕະໂນມັດ). ທັງ​ຜູ້​ໃຊ້​ແລະ​ຄໍາ​ນໍາ​ຫນ້າ​ເສັ້ນ​ທາງ​ອະ​ນຸ​ຍາດ​ໃຫ້​ໄດ້​ຮັບ​ການ​ອັບ​ໂຫລດ​ນໍາ​ໃຊ້​ບັນ​ຊີ​ລາຍ​ການ​ທີ່​ບໍ່​ໄດ້​ຈັດ​ລໍາ​ດັບ (`-`). ** ເມື່ອ​ຄໍາ​ນໍາ​ຫນ້າ​ເສັ້ນ​ທາງ​ການ​ອັບ​ໂຫລດ​ບໍ່​ໄດ້​ຕື່ມ​ຂໍ້​ມູນ​ໃສ່​ໃນ​, ການ​ອັບ​ໂຫລດ​ໃນ​ລະ​ບົບ​ຮາກ​ຂອງ​ການ​ແບ່ງ​ປັນ​ແມ່ນ​ອະ​ນຸ​ຍາດ​ໃຫ້​ເປັນ​ຄ່າ​ເລີ່ມ​ຕົ້ນ **​.

1. ສ້າງໄຟລ໌ການຕັ້ງຄ່າແຍກຕ່າງຫາກສໍາລັບແຕ່ລະສະມາຊິກໃນ `~/.config/sync0/users/`ໄດເລກະທໍລີ:

`~/.config/sync0/users/alice.nt` (ສະມາຊິກອ່ານຢ່າງດຽວ, ອັດຕາຈຳກັດ `80MB`, `rate`ຮອງຮັບ `GB`, `MB`, `KB`ໜ່ວຍ):

```yaml
id: 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c
perm: ro
rate: 80MB
```

`~/.config/sync0/users/bob.nt` (ສະມາຊິກ​ການ​ອັບ​ໂຫຼດ​ຖືກ​ຈຳ​ກັດ: ອະ​ນຸ​ຍາດ​ໃຫ້​ອັບ​ໂຫລດ​ໃສ່ `uploads/bob` ແລະ `shared/common` ລາຍ​ການ​ເທົ່າ​ນັ້ນ):

```yaml
id: 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f
perm: rw
write_prefix:
  - uploads/bob
  - shared/common
```

`~/.config/sync0/users/charlie.nt` (ການອັບໂຫລດສະມາຊິກເລີ່ມຕົ້ນ: ເມື່ອ `write_prefix`ຖືກລະເວັ້ນ, ການອັບໂຫລດໄປຍັງໄດເລກະທໍລີຮາກຂອງການແບ່ງປັນແມ່ນອະນຸຍາດຕາມຄ່າເລີ່ມຕົ້ນ):

```yaml
id: 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
perm: rw
```

2. ກຳນົດຄ່າໄດເຣັກທໍຣີຜູ້ໃຊ້ ແລະຫຼາຍກຸ່ມການແບ່ງປັນໄຟລ໌ໃນ `~/.config/sync0/config.nt`:

```yaml
users_dir: ./users

groups:
  dataset:
    path: ./data
    auth: false
    perm: ro
    rate: 50MB

  models:
    path: ./models
    auth: false
    perm: ro
    rate: 1GB

  team-vault:
    path: ./vault
    auth: true
    perm: ro
    rate: 512KB
    users:
      - alice
      - bob
      - charlie
```

ເລີ່ມການບໍລິການແບ່ງປັນ:

```bash
# ການເລີ່ມຕົ້ນໂດຍກົງ (ໂຫຼດການຕັ້ງຄ່າຜູ້ໃຊ້ .nt ທັງໝົດໂດຍອັດຕະໂນມັດໃນລາຍການ ~/.config/sync0/config.nt ແລະ user_dir)
sync0 share --region SHA

# ຫຼືເຜີຍແຜ່ຫຼາຍກຸ່ມແບ່ງປັນຢ່າງໄວວາ ແລະອະນຸຍາດໃຫ້ສະມາຊິກກຸ່ມໂດຍກົງຜ່ານເສັ້ນຄຳສັ່ງ
sync0 share dataset:./data team-vault:./vault \
  --auth \
  --allow-ro 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c \
  --allow-rw 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f:uploads/bob,shared/common \
  --allow-rw 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
```

### 3. ດຶງເນື້ອຫາທັງໝົດ ຫຼືເລືອກຫຼາຍໄຟລ໌ ແລະໄດເລກະທໍລີ (`sync0 pull`)

ເຊື່ອມຕໍ່ຫາ peer node ໃດນຶ່ງເພື່ອຮັບເອົາ seed nodes ທັງໝົດທີ່ມີຢູ່ໂດຍອັດຕະໂນມັດໃນກຸ່ມແບ່ງປັນ, ແລະດຶງຈາກ seed nodes ຫຼາຍອັນພ້ອມກັນ:

```bash
# ດຶງກຸ່ມແບ່ງປັນຊຸດຂໍ້ມູນທັງໝົດໄປທີ່ ./local_data
sync0 pull dataset:// ./local_data -p <node address>

# ການຊິ້ງຂໍ້ມູນຫຼາຍອັນ: ພ້ອມກັນດຶງໄຟລ໌ດຽວ docs/readme.md ແລະຊັບສິນຍ່ອຍ/ໄອຄອນ, src/core
sync0 pull dataset://docs/readme.md,assets/icons,src/core ./local_data -p <node address>
```

### 4. ອັບໂຫລດໄຟລ໌ ຫຼືໄດເລກະທໍລີໃສ່ກຸ່ມແບ່ງປັນ (`sync0 push`)

ສະ​ມາ​ຊິກ​ທີ່​ມີ​ການ​ອະ​ນຸ​ຍາດ​ອັບ​ໂຫລດ (`rw` ຫຼື `admin`) ສາ​ມາດ​ອັບ​ໂຫລດ​ໄຟລ​໌​ໃນ​ທ້ອງ​ຖິ່ນ​ຫຼື​ບັນ​ຊີ​ຫາ​ກຸ່ມ​ການ​ແບ່ງ​ປັນ​ທາງ​ໄກ​:

```bash
# ສະມາຊິກທີ່ມີການອະນຸຍາດອັບໂຫລດໄດເລກະທໍລີຮາກ: ອັບໂຫລດໂດຍກົງໃສ່ໄດເລກະທໍລີຮາກທີ່ແບ່ງປັນ
sync0 push team-vault:// ./new_release -p <node address>

# ສະເພາະສະມາຊິກທີ່ໄດ້ຮັບອະນຸຍາດເປັນຄຳນຳໜ້າສະເພາະ (ເຊັ່ນ: ອັບໂຫຼດ/bob): ອັບໂຫຼດໃສ່ຄຳນຳໜ້າເສັ້ນທາງທີ່ອະນຸຍາດ.
sync0 push team-vault://uploads/bob/report.pdf ./report.pdf -p <node address>
```

### 5. ສະໝັກໃຊ້ການຊິງຄ໌ອັດຕະໂນມັດ ແລະແກ່ນພັນ (`sync0 sub`)

ຫຼັງຈາກການລົງທະບຽນກັບກຸ່ມການແບ່ງປັນຂອງ node ທີ່ແນ່ນອນ, ເຄື່ອງແມ່ຂ່າຍທ້ອງຖິ່ນແມ່ນທັງລູກຄ້າທີ່ໄດ້ຮັບແລະເຄື່ອງແມ່ຂ່າຍ seeding ໃຫມ່; ເມື່ອໄຟລ໌ node ແຫຼ່ງຖືກປັບປຸງ, ມັນຈະຖືກ synchronized ໂດຍອັດຕະໂນມັດແລະສະຫນອງການດາວໂຫຼດ chunked ສໍາລັບ nodes ອື່ນໆ:

```bash
# ຈອງກຸ່ມແບ່ງປັນທັງຫມົດແລະອັດຕະໂນມັດແກ່ນ
sync0 sub dataset:// ./local_mirror -p <node address>

# ພຽງແຕ່ເລືອກຫຼາຍອັນເພື່ອສະໝັກໃຊ້ໄຟລ໌ທີ່ລະບຸໄວ້ ແລະໄດເລກະທໍລີຍ່ອຍ ແລະແກ່ນພວກມັນ
sync0 sub dataset://models/llama.onnx,config ./local_mirror -p <node address>
```

### 6. ການຊິ້ງຂໍ້ມູນກຸ່ມຫຼາຍເຄື່ອງ (`sync0 group`)

ເຄື່ອງຈັກຫຼາຍເຄື່ອງເຂົ້າຮ່ວມກຸ່ມແບ່ງປັນດຽວກັນ, ເຊິ່ງກັນແລະກັນອັດຕະໂນມັດຄົ້ນພົບຂໍ້ເມັດພັນທີ່ມີຢູ່ ແລະຮັກສາການຊິງໂຄຣໄນແບບສອງທາງ (ຮອງຮັບການຊິງໂຄຣໄນເຕັມຮູບແບບ ຫຼືເລືອກຫຼາຍໄຟລ໌ ແລະໄດເລກະທໍລີ):

```bash
# ເຂົ້າຮ່ວມກຸ່ມຢ່າງເຕັມສ່ວນແລະ synchronization ສອງທາງ
sync0 ກຸ່ມ team-docs:// ./docs -p <node address>

# ມີພຽງແຕ່ໄດເລກະທໍລີ wal ແລະໄຟລ໌ meta.json ໃນກຸ່ມ synchronization ຫຼາຍທາງເລືອກ
sync0 ກຸ່ມ team-docs://wal,meta.json ./docs -p <node address>
```

### 7. ການສົ່ງໂດຍກົງຈາກຈຸດຫາຈຸດລະຫວ່າງສອງເຄື່ອງຈັກ (`send` / `recv`)

ບໍ່​ຈໍາ​ເປັນ​ຕ້ອງ​ກໍາ​ນົດ​ຄ່າ​ກຸ່ມ​ໄວ້​ລ່ວງ​ຫນ້າ​, ແລະ​ທ່ານ​ສາ​ມາດ​ຊົ່ວ​ຄາວ​ການ​ໂອນ​ໄຟລ​໌​ຫຼື​ລາຍ​ການ​ໂດຍ​ກົງ​ລະ​ຫວ່າງ​ສອງ​ເຄື່ອງ​ຈັກ​:

```bash
# ການຕິດຕາມຜູ້ຮັບ
sync0 recv 0.0.0.0:9000 ./backup

# ການ​ສົ່ງ​ທ້າຍ​ໂດຍ​ກົງ​ໂອນ​ໄຟລ​໌​ຫຼື​ບັນ​ຊີ​ລາຍ​ການ (ທາງ​ເລືອກ --delete mirror ເພື່ອ​ທໍາ​ຄວາມ​ສະ​ອາດ​ໄຟລ​໌​ເກີນ​, --rate ຄວາມ​ໄວ​ຈໍາ​ກັດ​)
sync0 send ./project 192.168.1.10:9000
```

### 8. ສະຫຼັບຫຼາຍພາສາ

`sync0` ຮອງຮັບ 75 ພາສາ, ແລະປ່ຽນອັດຕະໂນມັດຕາມສະພາບແວດລ້ອມພາສາລະບົບໂດຍຄ່າເລີ່ມຕົ້ນ; ມັນຍັງສາມາດຖືກກໍານົດດ້ວຍຕົນເອງໂດຍຜ່ານ `SYNC0_LANG`:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
