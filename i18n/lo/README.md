# sync0

`sync0` ເປັນ​ເຄື່ອງ​ມື​ບັນ​ຊີ​ຄໍາ​ສັ່ງ​ສໍາ​ລັບ​ການ​ໂອນ​ໄຟລ​໌​ໃນ​ເຄືອ​ຂ່າຍ​, incrementally synchronizing directory​, ແລະ​ການ​ກະ​ຈາຍ​ຂໍ້​ມູນ​ພ້ອມ​ກັນ​ກັບ​ຫຼາຍ​ເຄື່ອງ​.

## ຄວາມຕັ້ງໃຈໃນການອອກແບບຕົ້ນສະບັບ

ຢູ່ໃນຫ້ອງຂ້າມເຄື່ອງ, ປະເທດ, ຫຼືສະພາບແວດລ້ອມທີ່ມີເຄືອຂ່າຍຊັກຊ້າ ແລະການສູນເສຍແພັກເກັດ, ເຄື່ອງມືເຊັ່ນ `rsync` ແລະ `scp` ແມ່ນອີງໃສ່ການຢືນຢັນລໍາດັບການເຊື່ອມຕໍ່ດຽວ, ເຊິ່ງຈໍາກັດການໃຊ້ແບນວິດ; ເມື່ອຫຼາຍເຄື່ອງດຶງຂໍ້ມູນຈາກເຄື່ອງແມ່ຂ່າຍດຽວກັນໃນເວລາດຽວກັນ, ບັດເຄືອຂ່າຍເຄື່ອງແມ່ຂ່າຍແຫຼ່ງສາມາດກາຍເປັນຄໍຂວດໄດ້ຢ່າງງ່າຍດາຍ.

ເປົ້າໝາຍຂອງ `sync0`ແມ່ນເພື່ອແກ້ໄຂບັນຫາສອງຢ່າງ:

1. ໃຫ້ໄຟລ໌ແລະໄດເລກະທໍລີ synchronization ລະຫວ່າງສອງເຄື່ອງແລ່ນແບນວິດທາງດ້ານຮ່າງກາຍຢ່າງເຕັມທີ່, ແລະພຽງແຕ່ໂອນສ່ວນທີ່ມີການປ່ຽນແປງເມື່ອໄຟລ໌ຖືກດັດແກ້ບາງສ່ວນ.
2. ເຄື່ອງຈັກຫຼາຍເຄື່ອງສາມາດໂອນຂໍ້ມູນບລັອກໄປຫາກັນແລະກັນໃນເວລາທີ່ synchronizing ໄດເລກະທໍລີດຽວກັນ, ຫຼຸດຜ່ອນການໂຫຼດໃນເຄື່ອງແມ່ຂ່າຍແຫຼ່ງແລະຫຍໍ້ເວລາ synchronization ໂດຍລວມ.

## ການປຽບທຽບຄວາມໄວກັບ rsync

ສະພາບແວດລ້ອມການທົດສອບ: ໂນດຢູໂຣບ $\leftrightarrow$ ໂນດອາເມລິກາເໜືອ, ຄວາມລ່າຊ້າໄປກັບ 86 ms, ການວັດແທກການໃຊ້ເວລາເຕັມທີ່ລວມທັງການສະແກນໄດເລກະທໍລີ, ການປຽບທຽບການຫັກອອກ, ການສົ່ງຕໍ່ເຄືອຂ່າຍ ແລະການກວດສອບການຈັດວາງແຜ່ນ:

| ສະຖານະການສົ່ງ | ຂະໜາດຂໍ້ມູນ | `sync0` | `rsync` | ຫຼາຍ |
| :--- | :---: | :---: | :---: | :---: |
| 10,000 ໄຟລ໌ຂະຫນາດນ້ອຍ | 77.6 MB | 0.90 s (688 Mbps) | 4.86 s (128 Mbps) | 5.4x |
| ຊຸດລະຫັດ ແລະເກັບຂໍ້ມູນ (`.tar`) | 512 MB | 1.94 s (2111 Mbps) | 9.36 s (438 Mbps) | 4.8x |
| ໄຟລ໌ວິດີໂອ (`.mp4`) | 512 MB | 7.36 s (556 Mbps) | 12.11 s (338 Mbps) | 1.6x |
| ການຊິ້ງຂໍ້ມູນທີ່ເພີ່ມຂຶ້ນ (ແກ້ໄຂເນື້ອຫາ 1%) | 512 MB | 0.12 s | 1.85 s | 15.4x |

## ວິທີການປັບປຸງປະສິດທິພາບ

- **ການສົ່ງຂໍ້ມູນ UDP ພ້ອມກັນ**: ສົ່ງບລັອກຂໍ້ມູນຜ່ານ UDP, ແລະພຽງແຕ່ສົ່ງຊິ້ນສ່ວນທີ່ເສຍໄປຄືນໃໝ່ເພື່ອຫຼີກເວັ້ນການສູນເສຍແພັກເກັດດຽວທີ່ຂັດຂວາງການໂອນໄຟລ໌ຕໍ່ໄປ.
- **ການແບ່ງສ່ວນເນື້ອຫາແລະການຊໍ້າຊ້ອນ**: ແຍກໄຟລ໌ອອກເປັນບລັອກຂໍ້ມູນຕາມເນື້ອຫາ ແລະຄິດໄລ່ມູນຄ່າການກວດສອບ. ເນື້ອໃນດຽວກັນຢູ່ໃນຕອນຮັບແມ່ນຖືກນໍາໃຊ້ຄືນໃຫມ່ໂດຍກົງໂດຍບໍ່ໄດ້ເຮັດຊ້ໍາເຄືອຂ່າຍ.
- ** ປັບ​ອັດ​ຕະ​ໂນ​ມັດ​ການ​ບີບ​ອັດ​ຕາມ​ຄວາມ​ໄວ​ເຄືອ​ຂ່າຍ **​: ເປີດ​ການ​ບີບ​ອັດ​ສໍາ​ລັບ​ເນື້ອ​ໃນ​ທີ່​ບີບ​ອັດ​ເຊັ່ນ​: ຂໍ້​ຄວາມ​ແລະ​ລະ​ຫັດ​; ຂ້າມການບີບອັດອັດຕະໂນມັດສຳລັບວິດີໂອ, ຮູບພາບ, ແພັກເກັດທີ່ຖືກບີບອັດ ຫຼືພາຍໃຕ້ LAN ຄວາມໄວສູງເພື່ອຫຼຸດຜ່ອນການໃຊ້ CPU.
- **ການດຶງຫຼາຍໂຫນດໃກ້ຄຽງ**: ເມື່ອຫຼາຍເຄື່ອງດຶງໄດເລກະທໍລີດຽວກັນ, ບລັອກຂໍ້ມູນຈະຖືກດຶງພ້ອມກັນຈາກໂຫນດທີ່ດາວໂຫຼດຢູ່ໃນເມືອງດຽວກັນ ຫຼືມີເວລາແພັກເກັດໜ້ອຍລົງ.

## ຕິດຕັ້ງ

### ວິທີທີ່ 1: ຕິດຕັ້ງຜ່ານ Cargo

```bash
cargo install sync0
```

### ວິທີທີ່ 2: ດາວໂຫລດ binary precompiled

ໄປທີ່ [GitHub Releases](https://github.com/webc-site/sync0/releases) ເພື່ອດາວໂຫລດ `.tar.xz`ແພັກເກັດບີບອັດສໍາລັບລະບົບທີ່ສອດຄ້ອງກັນ (ຮອງຮັບ Linux x86_64/ARM64, macOS Apple Silicon/Intel, Windows x64/ARM64, Android ARM64/x86_64, FreeBSD, NetBSD). ຫຼັງ​ຈາກ unzipping​, ວາງ `sync0` ເຂົ້າ​ໄປ​ໃນ `PATH` ລະ​ບົບ:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## ຄູ່ມືຜູ້ໃຊ້

### 1. ໂອນໄຟລ໌ຫຼືໄດເລກະທໍລີໂດຍກົງລະຫວ່າງສອງເຄື່ອງ

ເລີ່ມ​ຕົ້ນ​ການ​ຕິດ​ຕາມ​ກວດ​ກາ​ໃນ​ເຄື່ອງ​ຮັບ​ແລະ​ລະ​ບຸ​ເສັ້ນ​ທາງ​ການ​ຮັບ​ແລະ​ການ​ປະ​ຢັດ​:

```bash
sync0 recv 0.0.0.0:9000 ./backup
```

ສົ່ງໄຟລ໌ດຽວ ຫຼືໄດເລກະທໍລີທັງໝົດຈາກເຄື່ອງສົ່ງ:

```bash
sync0 send ./project 192.168.1.10:9000
```

ພາລາມິເຕີທີ່ໃຊ້ທົ່ວໄປ:

```bash
# ລຶບໄຟລ໌ທີ່ຊໍ້າຊ້ອນທີ່ມີຢູ່ໃນຈຸດຮັບແຕ່ບໍ່ແມ່ນຢູ່ໃນຕອນທ້າຍສົ່ງ (ການຊິງຄ໌ແວ່ນ)
sync0 send ./project 192.168.1.10:9000 --delete

# ຈຳກັດອັດຕາການສົ່ງ (ຫົວໜ່ວຍ: bytes/ວິນາທີ, ຕົວຢ່າງ 50 MB/s)
sync0 send ./project 192.168.1.10:9000 --rate 50000000

# ໂໝດງຽບ (ບໍ່ສະແດງແຖບຄວາມຄືບໜ້າ)
sync0 send ./project 192.168.1.10:9000 -q
```

### 2. ການເຜີຍແພ່ໄດເລກະທໍລີທີ່ແບ່ງປັນແລະດຶງອອກຈາກຫຼາຍໂຫນດ

ເຜີຍແຜ່ໄດເຣັກທໍຣີທີ່ໃຊ້ຮ່ວມກັນ (ຊື່ `dataset`) ໃນເຊີບເວີຕົ້ນກຳເນີດ:

```bash
sync0 share dataset ./data --region SHA
```

ດຶງໄດເລກະທໍລີທີ່ໃຊ້ຮ່ວມກັນໃນເຄື່ອງອື່ນໆ (ທ່ານສາມາດຕື່ມຂໍ້ມູນໃສ່ໃນຫຼາຍ node ໃນເວລາດຽວກັນ, ແຍກດ້ວຍເຄື່ອງໝາຍຈຸດເພື່ອດຶງພ້ອມກັນ):

```bash
sync0 pull 10.0.0.1:9000,10.0.0.2:9000 dataset ./local_data
```

ດຶງພຽງແຕ່ໄດເລກະທໍລີຍ່ອຍສະເພາະໃນໄດເລກະທໍລີທີ່ແບ່ງປັນ:

```bash
sync0 pull 10.0.0.1:9000 dataset ./local_data --subpath 2026/logs
```

ຊຸກ​ດັນ​ໃຫ້​ການ​ປ່ຽນ​ແປງ​ໃນ​ທ້ອງ​ຖິ່ນ​ກັບ​ຄືນ​ໄປ​ບ່ອນ​ການ​ແບ່ງ​ປັນ​ທາງ​ໄກ​:

```bash
sync0 push 10.0.0.1:9000 dataset ./local_data
```

### 3. ສະໝັກໃຊ້ລາຍການອັບເດດອັດຕະໂນມັດ

ຈອງກັບໄດເລກະທໍລີທີ່ແບ່ງປັນຂອງ node ແຫຼ່ງ. ເມື່ອໄຟລ໌ໃດນຶ່ງຖືກເພີ່ມ ຫຼືແກ້ໄຂໃນໄດເລກະທໍລີແຫຼ່ງທີ່ມາ, ມັນຈະຖືກ synchronized ໂດຍອັດຕະໂນມັດກັບຄອມພິວເຕີທ້ອງຖິ່ນ. ໃນເວລາດຽວກັນ, ເຄື່ອງທ້ອງຖິ່ນອັດຕະໂນມັດຈະເຮັດຫນ້າທີ່ເປັນ node ສໍາລັບເຄື່ອງຈັກອື່ນໆທີ່ຈະດຶງ:

```bash
sync0 sub 10.0.0.1:9000 dataset ./local_mirror
```

### 4. synchronization ສອງທາງຂອງກຸ່ມຫຼາຍເຄື່ອງຈັກ

ເຄື່ອງຈັກຫຼາຍເຄື່ອງເຂົ້າຮ່ວມຊື່ກຸ່ມດຽວກັນ, ແລະການປ່ຽນແປງໃນໄດເລກະທໍລີ node ໃດຈະຖືກ synchronized ອັດຕະໂນມັດກັບ nodes ອື່ນໆໃນກຸ່ມ:

```bash
sync0 group team-docs ./docs 10.0.0.1:9000,10.0.0.2:9000
```

### 5. ຕົວຕົນຂອງໂນດ ແລະນາມບັດສ່ວນຕົວ

ແຕ່ລະ node ສະຫນັບສະຫນູນການຕັ້ງຊື່ຜູ້ໃຊ້, ເມືອງ, ອີເມວ, ເວັບໄຊທ໌ແລະລາຍເຊັນສ່ວນບຸກຄົນ (ສູງສຸດ 256 ຕົວອັກສອນ), ແລະຜ່ານການກວດສອບລາຍເຊັນເອກະຊົນທ້ອງຖິ່ນ:

```bash
# ເບິ່ງ ID ລະຫັດສາທາລະນະໃນທ້ອງຖິ່ນ (ລະບຸໄດເລກະທໍລີການຕັ້ງຄ່າເພື່ອສືບຕໍ່ລະຫັດ)
sync0 id -c ~/.config/sync0

# ສ້າງແລະສະແດງນາມບັດ node ທີ່ມີລາຍເຊັນສ່ວນບຸກຄົນ
sync0 profile -c ~/.config/sync0 \
  -u alice \
  --region SHA \
  --email alice@example.com \
  --url https://example.com \
  -b "Shanghai backup node"
```

`share`, `pull`, `sub`, `group`ຍັງສາມາດຖືກເປີດໃຊ້ດ້ວຍຕົວກໍານົດໂປຣໄຟລ໌ເຫຼົ່ານີ້:

```bash
sync0 share dataset ./data -c ~/.config/sync0 -u alice --region SHA -b "Shanghai backup node"
```

### 6. ສະຫຼັບຫຼາຍພາສາ

`sync0` ຮອງຮັບ 75 ພາສາ. ໂດຍຄ່າເລີ່ມຕົ້ນ, ເສັ້ນຄໍາສັ່ງຊ່ວຍເຫຼືອແລະ prompts ໃນພາສາທີ່ສອດຄ້ອງກັນຈະສະແດງອັດຕະໂນມັດຕາມສະພາບແວດລ້ອມພາສາຂອງລະບົບປະຕິບັດການ; ຖ້າພາສາລະບົບບໍ່ຢູ່ໃນລາຍການທີ່ຮອງຮັບ, ພາສາອັງກິດຈະຖືກໃຊ້ໂດຍຄ່າເລີ່ມຕົ້ນ.

ເພື່ອລະບຸພາສາດ້ວຍຕົນເອງ, ຕັ້ງຄ່າຕົວແປສະພາບແວດລ້ອມ `SYNC0_LANG`:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
