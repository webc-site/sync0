# sync0

`sync0`-ը հավասարազոր (P2P) ֆայլերի փոխանակման և բազմամեքենայի համաժամացման գործիք է, որը մրցում է Resilio Sync-ի հետ:

Յուրաքանչյուր մեքենա և՛ սերվեր է, և՛ հաճախորդ. ցանկացած հանգույց կարող է հրապարակել բազմաթիվ ֆայլերի փոխանակման խմբեր: Մյուս հանգույցները միանալուց հետո նրանք կարող են ավտոմատ կերպով ձեռք բերել հասանելի սերմային հանգույցներ գործընկեր սերվերից և դրանք միաժամանակ քաշել բազմաթիվ աղբյուրներից: Համաժամացման ավարտից հետո սերմերն ավտոմատ կերպով կստեղծվեն ավելի շատ հանգույցների համար՝ ներբեռնումները արագացնելու համար:

## Հիմնական շեշտադրումներ

- **Բոլորը և՛ սերվեր են, և՛ հաճախորդ**. համեմատելի է Resilio Sync-ի հետ, առանց կենտրոնական սերվերի կախվածության: Ցանկացած հանգույց կարող է ստեղծել բազմաթիվ ֆայլերի փոխանակման խմբեր, ինչպես նաև կարող է միանալ այլ մարդկանց փոխանակման խմբերին. հանգույցները ավտոմատ կերպով փոխանակվում և ձեռք են բերում հասանելի սերմային հանգույցներ՝ մի քանի մեքենաների միաժամանակ ձգման և իրական ժամանակում համաժամացման հասնելու համար:
- **IP առանց հանգույցի հասցե**. Լռելյայնորեն, հանգույցի բանալին և `base64url` կոդավորված `iroh` հասցեն ավտոմատ կերպով ստեղծվում են `~/.config/sync0`-ում` առանց հանրային IP-ն հիշելու կամ բացահայտելու անհրաժեշտության:
- **Բազմակի ընտրությամբ համաժամացում ըստ պահանջի**. Աջակցում է համաժամացման ամբողջ համօգտագործման խմբին, ինչպես նաև աջակցում է համաժամացմանը ըստ պահանջի` միաժամանակ ընտրելով բազմաթիվ ֆայլեր կամ ենթագրքեր:
- **Խմբի անդամների հիերարխիկ թույլտվություններ և վերբեռնման գրացուցակի կառավարում**. Աջակցում է միայն կարդալու (`ro`), կարդալու-գրելու վերբեռնման (`rw`) և կառավարման (`admin`) թույլտվություններին և կարող է առանձին նշել ուղու նախածանցը, որը յուրաքանչյուր անդամին թույլատրվում է վերբեռնել (լռելյայն, բաժնետոմսերի վերբեռնումը արմատական ​​գրացուցակ է):
- **Լրիվ արագությամբ և աստիճանական համաժամացում ցանցերում**. մեծ ֆայլերի միաժամանակյա փոխանցում, զանգվածային փոքր ֆայլերի կուտակում հիշողության մեջ և միայն համաժամեցված տվյալների բլոկներ, երբ ֆայլերը մասամբ փոփոխվում են:

## Տեղադրեք

### Մեթոդ 1. Տեղադրեք Cargo-ի միջոցով

```bash
cargo install sync0
```

### Մեթոդ 2. Ներբեռնեք նախապես կազմված երկուականները

Գնացեք [GitHub Releases](https://github.com/webc-site/sync0/releases)՝ ներբեռնելու `.tar.xz` սեղմված փաթեթը համապատասխան համակարգի համար (աջակցում է Linux, macOS, Windows, Android, FreeBSD, NetBSD), ապակպեք և դրեք այն `PATH` գրացուցակում.

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## Շտապեք սկսել

`sync0`-ը լռելյայն օգտագործում է `~/.config/sync0` որպես կազմաձևման գրացուցակ (եթե անհրաժեշտ է անցնել այլ դիրեկտորիաների, կարող եք ավելացնել `-c <directory>`):

### 1. Դիտեք տեղական հանգույցի հասցեն և կարգավորումների այցեքարտը

```bash
# Դիտեք տեղական հանգույցի հասցեն (բանալին առաջին անգամ ավտոմատ կերպով ստեղծվում է ~/.config/sync0-ում)
sync0 id

# Ստեղծեք անհատական ​​հանգույցի այցեքարտ (աջակցում է օգտվողի անունը, քաղաքը, էլ.փոստը, կայքը և ստորագրությունը 256 բառի սահմաններում)
sync0 profile -u alice --region SHA --email alice@example.com --url https://example.com -b "Shanghai node"
```

### 2. Հրապարակեք բազմաթիվ ֆայլերի փոխանակման խմբեր և սահմանեք խմբի անդամների թույլտվությունները (`.nt` Կազմաձևում)

`sync0`-ը կազմաձևված է [NestedText](https://nestedtext.org) (`.nt`) ձևաչափով: Յուրաքանչյուր օգտվող ունի առանձին `.nt` կազմաձևման ֆայլ: Դուք կարող եք նշել օգտվողի պրոֆիլի գրացուցակը `users_dir`-ի միջոցով `config.nt`-ում (որն ավտոմատ կերպով ներառում է այս գրացուցակի բոլոր `.nt` ֆայլերը): Ե՛վ օգտագործողը, և՛ ուղու նախածանցը, որը թույլատրվում է վերբեռնել, օգտագործում են չդասավորված ցուցակ (`-`): **Երբ վերբեռնման ուղու նախածանցը լրացված չէ, բաժնետոմսի արմատային գրացուցակում վերբեռնումը լռելյայն թույլատրվում է**:

1. Ստեղծեք առանձին `.nt` կազմաձևման ֆայլեր յուրաքանչյուր անդամի համար `~/.config/sync0/users/` գրացուցակում.

`~/.config/sync0/users/alice.nt` (միայն կարդալու անդամ, տոկոսադրույքը սահմանափակ `80MB`, `rate` աջակցում է `GB`, `MB`, `KB` միավորները):

```yaml
id: 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c
perm: ro
rate: 80MB
```

`~/.config/sync0/users/bob.nt` (սահմանափակված վերբեռնման անդամներ. թույլատրվում է վերբեռնել միայն `uploads/bob` և `shared/common` գրացուցակներում):

```yaml
id: 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f
perm: rw
write_prefix:
  - uploads/bob
  - shared/common
```

`~/.config/sync0/users/charlie.nt` (Անդամների կանխադրված վերբեռնում. Երբ `write_prefix`-ը բաց է թողնվում, բաժնետոմսի արմատային գրացուցակում վերբեռնումը լռելյայն թույլատրվում է):

```yaml
id: 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
perm: rw
```

2. Կարգավորեք օգտվողի գրացուցակը և բազմաթիվ ֆայլերի փոխանակման խմբերը `~/.config/sync0/config.nt`-ում:

```yaml
users_dir: ./users

groups:
  dataset:
    path: ./data
    auth: false
    perm: ro
    rate: 50MB

  models:
    path: ./models
    auth: false
    perm: ro
    rate: 1GB

  team-vault:
    path: ./vault
    auth: true
    perm: ro
    rate: 512KB
    users:
      - alice
      - bob
      - charlie
```

Սկսեք համօգտագործման ծառայությունը.

```bash
# Ուղղակի գործարկում (ավտոմատ կերպով բեռնում է .nt օգտվողի բոլոր կոնֆիգուրացիաները ~/.config/sync0/config.nt և users_dir դիրեկտորիաներում)
sync0 share --region SHA

# Կամ արագ հրապարակեք մի քանի փոխանակման խմբեր և թույլատրեք խմբի անդամներին ուղղակիորեն հրամանի տողի միջոցով
sync0 share dataset:./data team-vault:./vault \
  --auth \
  --allow-ro 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c \
  --allow-rw 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f:uploads/bob,shared/common \
  --allow-rw 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
```

### 3. Քաշեք ամբողջ բովանդակությունը կամ ընտրեք բազմաթիվ ֆայլեր և գրացուցակներ (`sync0 pull`)

Միացեք ցանկացած հասակակից հանգույցին, որպեսզի ավտոմատ կերպով ձեռք բերեք բոլոր հասանելի սերմային հանգույցները համօգտագործման խմբում և միաժամանակ քաշեք մի քանի սերմային հանգույցներից.

```bash
# Քաշեք տվյալների համօգտագործման ամբողջ խումբը դեպի տեղական ./local_data
sync0 pull database:// ./local_data -p <հանգույցի հասցե>

# Բազմակի ընտրությամբ համաժամացում. միաժամանակ քաշեք մեկ ֆայլ docs/readme.md և ենթագրքեր ակտիվներ/պատկերակներ, src/core
sync0 pull տվյալների հավաքածու://docs/readme.md,assets/icons,src/core ./local_data -p <հանգույցի հասցե>
```

### 4. Վերբեռնեք ֆայլ կամ գրացուցակ համօգտագործման խմբի մեջ (`sync0 push`)

Վերբեռնման թույլտվություններ ունեցող անդամները (`rw` կամ `admin`) կարող են տեղական ֆայլեր կամ գրացուցակներ վերբեռնել հեռավոր համօգտագործման խմբերում՝

```bash
# Արմատային գրացուցակի վերբեռնման թույլտվություն ունեցող անդամներ. վերբեռնեք անմիջապես ընդհանուր արմատային գրացուցակում
sync0 push team-vault:// ./new_release -p <հանգույցի հասցե>

# Միայն որոշակի նախածանցով լիազորված անդամներ (օրինակ՝ վերբեռնումներ/բոբ). վերբեռնեք թույլատրված ճանապարհի նախածանցին
sync0 push team-vault://uploads/bob/report.pdf ./report.pdf -p <հանգույցի հասցե>
```

### 5. Բաժանորդագրվեք ավտոմատ համաժամացման և սերմանման (`sync0 sub`)

Որոշակի հանգույցի համօգտագործման խմբին բաժանորդագրվելուց հետո տեղական սերվերը և՛ ընդունող հաճախորդ է, և՛ նոր սերմացու սերվեր; երբ սկզբնաղբյուր հանգույցի ֆայլը թարմացվում է, այն ինքնաբերաբար համաժամացվում է և ապահովում է ներբեռնումներ այլ հանգույցների համար.

```bash
# Բաժանորդագրվեք համօգտագործման ողջ խմբին և ավտոմատ կերպով տեղադրեք
sync0 sub databas:// ./local_mirror -p <հանգույցի հասցե>

# Միայն բազմակի ընտրեք՝ նշված ֆայլերին և ենթագրքերներին բաժանորդագրվելու և դրանք սերմացնելու համար
sync0 ենթախմբի տվյալների հավաքագրում://models/llama.onnx,configs ./local_mirror -p <հանգույցի հասցե>
```

### 6. Բազմամեքենաների խմբի հասակակիցների համաժամացում (`sync0 group`)

Բազմաթիվ մեքենաներ միանում են նույն համօգտագործման խմբին, միմյանց ինքնաբերաբար հայտնաբերում են հասանելի սերմերի հանգույցները և պահպանում են երկկողմանի համաժամացումը (աջակցում է ամբողջական համաժամացմանը կամ ֆայլերի և գրացուցակների բազմակի ընտրությանը).

```bash
# Լիովին միանալ խմբին և երկկողմանի համաժամացման
sync0 group team-docs:// ./docs -p <հանգույցի հասցե>

# Միայն wal գրացուցակը և meta.json ֆայլը բազմաբնույթ համաժամացման խմբում
sync0 group team-docs://wal,meta.json ./docs -p <հանգույցի հասցե>
```

### 7. Կետ առ կետ ուղիղ փոխանցում երկու մեքենաների միջև (`send` / `recv`)

Խումբը նախապես կազմաձևելու կարիք չկա, և դուք կարող եք ժամանակավորապես փոխանցել ֆայլերը կամ գրացուցակները անմիջապես երկու մեքենաների միջև.

```bash
# Ընդունիչի մոնիտորինգ
sync0 recv 0.0.0.0:9000 ./backup

# Ուղարկող վերջն ուղղակիորեն փոխանցում է ֆայլերը կամ գրացուցակները (ըստ ցանկության - ջնջել հայելին ավելորդ ֆայլերը մաքրելու համար, - արագության սահմանաչափ)
sync0 send ./project 192.168.1.10:9000
```

### 8. Բազմալեզու փոխարկում

`sync0` աջակցում է 75 լեզու և ինքնաբերաբար փոխվում է ըստ համակարգի լեզվական միջավայրի լռելյայն. այն կարելի է նաև ձեռքով նշել `SYNC0_LANG`-ի միջոցով.

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
