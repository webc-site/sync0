# sync0

`sync0`-ը հրամանի տող գործիք է ցանցերում ֆայլեր փոխանցելու, դիրեկտորիաների աստիճանաբար համաժամացման և մի քանի մեքենաների վրա տվյալները միաժամանակ բաշխելու համար:

## Բնօրինակ դիզայնի մտադրություն

Խաչմերուկային մեքենայական սենյակներում, երկրներում կամ միջավայրերում, որտեղ ցանցի ուշացումներն ու փաթեթների կորուստը կան, այնպիսի գործիքներ, ինչպիսիք են `rsync` և `scp`-ը հիմնված են կապի մեկ հաջորդականության հաստատման վրա, որը սահմանափակում է թողունակության օգտագործումը. երբ մի քանի մեքենաներ միաժամանակ տվյալներ են վերցնում նույն սերվերից, աղբյուր սերվերի ցանցային քարտը կարող է հեշտությամբ դառնալ խցան:

`sync0`-ի նպատակն է լուծել երկու խնդիր.

1. Թույլ տվեք, որ ֆայլի և գրացուցակի համաժամացումը երկու մեքենաների միջև գործարկվի ամբողջ ֆիզիկական թողունակությամբ, և միայն փոխադրեք փոխված մասը, երբ ֆայլը մասամբ փոփոխված է:
2. Բազմաթիվ մեքենաներ կարող են տվյալների բլոկներ փոխանցել միմյանց՝ նույն գրացուցակը համաժամեցնելիս՝ նվազեցնելով աղբյուրի սերվերի բեռը և կրճատելով համաժամացման ընդհանուր ժամանակը:

## Արագության համեմատություն rsync-ի հետ

Փորձարկման միջավայր. Եվրոպական հանգույց $\ձախ աջ նետ$ Հյուսիսամերիկյան հանգույց, 86 մվ հետաձգում հետադարձ, չափում է ամբողջական ժամանակատար, ներառյալ գրացուցակի սկանավորումը, կրկնօրինակման համեմատությունը, ցանցի փոխանցումը և սկավառակի տեղադրման ստուգումը.

| Փոխանցման սցենար | Տվյալների չափը | `sync0` | `rsync` | բազմակի |
| :--- | :---: | :---: | :---: | :---: |
| 10,000 փոքր ֆայլեր | 77.6 MB | 0.90 s (688 Mbps) | 4.86 s (128 Mbps) | 5.4x |
| Կոդի և արխիվային փաթեթներ (`.tar`) | 512 MB | 1.94 s (2111 Mbps) | 9.36 s (438 Mbps) | 4.8x |
| Վիդեո ֆայլ (`.mp4`) | 512 MB | 7.36 s (556 Mbps) | 12.11 s (338 Mbps) | 1.6x |
| Աճող համաժամացում (փոփոխել 1% բովանդակությունը) | 512 MB | 0.12 s | 1.85 s | 15.4x |

## Արդյունավետության բարելավման մեթոդներ

- **UDP միաժամանակյա փոխանցում**. Ուղարկեք տվյալների բլոկներ UDP-ի միջոցով և վերահղեք միայն կորցրած հատվածները՝ խուսափելու համար մեկ փաթեթի կորուստից, որը արգելափակում է ֆայլերի հետագա փոխանցումները:
- **Բովանդակության հատվածավորում և կրկնօրինակում**. ֆայլը բաժանեք տվյալների բլոկների` ըստ բովանդակության և հաշվարկեք ստուգման արժեքը: Նույն բովանդակությունը, որն արդեն գտնվում է ստացողի վրա, վերաօգտագործվում է անմիջապես տեղում՝ առանց ցանցի կրկնօրինակման:
- **Ավտոմատ կերպով կարգավորել սեղմումը ըստ ցանցի արագության**. Միացնել սեղմումը սեղմվող բովանդակության համար, ինչպիսիք են տեքստը և կոդը; ավտոմատ կերպով բաց թողեք սեղմումը տեսանյութերի, նկարների, սեղմված փաթեթների կամ գերարագ LAN-ի տակ՝ պրոցեսորի սպառումը նվազեցնելու համար:
- **Մոտակա բազմաթիվ հանգույցների ձգում**. Երբ մի քանի մեքենաներ քաշում են նույն գրացուցակը, տվյալների բլոկները միաժամանակ կհանվեն նույն քաղաքի ներբեռնված հանգույցներից կամ ավելի ցածր ուշացումով:

## Տեղադրեք

### Մեթոդ 1. Տեղադրեք Cargo-ի միջոցով

```bash
cargo install sync0
```

### Մեթոդ 2. Ներբեռնեք նախապես կազմված երկուականները

Անցեք [GitHub Releases](https://github.com/webc-site/sync0/releases)՝ ներբեռնելու `.tar.xz` սեղմված փաթեթը համապատասխան համակարգի համար (աջակցում է Linux x86_64/ARM64, macOS Apple Silicon/Intel, Windows x64/ARM64, Android ARM64/x86_64, FreeBSD, NetBSD): Ապազիփելուց հետո տեղադրեք `sync0` `PATH` գրացուցակում.

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## Օգտագործողի ուղեցույց

### 1. Անմիջապես փոխանցեք ֆայլերը կամ գրացուցակները երկու մեքենաների միջև

Սկսեք մոնիտորինգը ստացող մեքենայի վրա և նշեք ստացման և պահպանման ուղին.

```bash
sync0 recv 0.0.0.0:9000 ./backup
```

Ուղարկեք մեկ ֆայլ կամ մի ամբողջ գրացուցակ ուղարկող մեքենայից.

```bash
sync0 send ./project 192.168.1.10:9000
```

Սովորաբար օգտագործվող պարամետրերը.

```bash
# Ջնջել ավելորդ ֆայլերը, որոնք առկա են ստացող, բայց ոչ ուղարկող վերջում (հայելային համաժամացում)
sync0 send ./project 192.168.1.10:9000 --delete

# Սահմանափակել ուղարկման արագությունը (միավոր՝ բայթ/վրկ, օրինակ՝ 50 ՄԲ/վ)
sync0 send ./project 192.168.1.10:9000 --rate 50000000

# Լուռ ռեժիմ (առաջընթացի տող չկա)
sync0 send ./project 192.168.1.10:9000 -q
```

### 2. Համօգտագործվող դիրեկտորիաների հրապարակում և մի քանի հանգույցներից քաշում

Հրապարակեք ընդհանուր գրացուցակ (`dataset` անունով) սկզբնաղբյուր սերվերի վրա.

```bash
sync0 share dataset ./data --region SHA
```

Քաշեք ընդհանուր գրացուցակը այլ մեքենաների վրա (կարող եք միաժամանակ լրացնել մի քանի հանգույցի հասցեներ՝ բաժանված ստորակետերով՝ միաժամանակ քաշելու համար).

```bash
sync0 pull 10.0.0.1:9000,10.0.0.2:9000 dataset ./local_data
```

Քաշեք միայն որոշակի ենթատեղեկատու ընդհանուր գրացուցակում.

```bash
sync0 pull 10.0.0.1:9000 dataset ./local_data --subpath 2026/logs
```

Տեղական փոփոխությունները հետ մղեք հեռավոր ընդհանուր գրացուցակ.

```bash
sync0 push 10.0.0.1:9000 dataset ./local_data
```

### 3. Բաժանորդագրվեք կատալոգի ավտոմատ թարմացումներին

Բաժանորդագրվեք աղբյուրի հանգույցի ընդհանուր գրացուցակին: Երբ ֆայլը ավելացվում կամ փոփոխվում է սկզբնաղբյուրի գրացուցակում, այն ինքնաբերաբար կհամաժամեցվի տեղական համակարգչի հետ: Միևնույն ժամանակ, տեղական մեքենան ավտոմատ կերպով կծառայի որպես հանգույց այլ մեքենաների համար՝ քաշելու համար.

```bash
sync0 sub 10.0.0.1:9000 dataset ./local_mirror
```

### 4. Բազմամեքենաների խմբերի երկկողմանի համաժամացում

Բազմաթիվ մեքենաներ միանում են նույն խմբի անունով, և ցանկացած հանգույցի գրացուցակի փոփոխություններն ավտոմատ կերպով կհամաժամանակացվեն խմբի այլ հանգույցների հետ.

```bash
sync0 group team-docs ./docs 10.0.0.1:9000,10.0.0.2:9000
```

### 5. Հանգույցի ինքնությունը և անձնական այցեքարտը

Յուրաքանչյուր հանգույց աջակցում է օգտատիրոջ անունը, քաղաքը, էլ.փոստը, կայքը և անհատականացված ստորագրությունը (առավելագույնը 256 նիշ) սահմանելը և փոխանցում է տեղական մասնավոր բանալին ստորագրության նույնականացումը.

```bash
# Դիտեք տեղական հանրային բանալու ID-ն (նշեք կազմաձևման գրացուցակը՝ բանալին պահպանելու համար)
sync0 id -c ~/.config/sync0

# Ստեղծեք և ցուցադրեք հանգույցների այցեքարտեր անհատականացված ստորագրություններով
sync0 profile -c ~/.config/sync0 \
  -u alice \
  --region SHA \
  --email alice@example.com \
  --url https://example.com \
  -b "Shanghai backup node"
```

`share`, `pull`, `sub`, `group` կարող են գործարկվել նաև այս պրոֆիլի պարամետրերով.

```bash
sync0 share dataset ./data -c ~/.config/sync0 -u alice --region SHA -b "Shanghai backup node"
```

### 6. Բազմալեզու փոխարկում

`sync0` Աջակցում է 75 լեզու: Լռելյայնորեն, հրամանի տողի օգնությունը և համապատասխան լեզվով հուշումները ավտոմատ կերպով ցուցադրվում են ըստ օպերացիոն համակարգի լեզվական միջավայրի. եթե համակարգի լեզուն աջակցվող ցանկում չէ, անգլերենն օգտագործվում է լռելյայն:

Լեզուն ձեռքով նշելու համար սահմանեք միջավայրի փոփոխական `SYNC0_LANG`:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
