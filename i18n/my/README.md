# sync0

`sync0` သည် Resilio Sync နှင့် ယှဉ်ပြိုင်နိုင်သော peer-to-peer (P2P) ဖိုင်မျှဝေခြင်းနှင့် စက်ပေါင်းများစွာ ထပ်တူပြုခြင်း တူးလ်တစ်ခုဖြစ်သည်။

စက်တစ်ခုစီသည် ဆာဗာနှင့် ဖောက်သည် နှစ်ခုလုံးဖြစ်သည်- မည်သည့် node မဆို ဖိုင်မျှဝေခြင်းအုပ်စုများစွာကို ထုတ်ဝေနိုင်ပါသည်။ အခြား node များ ချိတ်ဆက်ပြီးနောက်၊ ၎င်းတို့သည် ရရှိနိုင်သော မျိုးစေ့ node များကို မျိုးတူဆာဗာမှ အလိုအလျောက် ရယူနိုင်ပြီး အရင်းအမြစ်များစွာမှ ၎င်းတို့ကို တစ်ပြိုင်နက် ဆွဲထုတ်နိုင်သည်။ ထပ်တူပြုခြင်းပြီးဆုံးပြီးနောက်၊ ဒေါင်းလုဒ်များကို အရှိန်မြှင့်ရန် နောက်ထပ် node အတွက် မျိုးစေ့များကို အလိုအလျောက် ဖန်တီးပေးပါမည်။

## အဓိကအချက်များ

- **လူတိုင်းသည် ဆာဗာနှင့် ဖောက်သည် နှစ်မျိုးလုံးဖြစ်သည်**- Resilio Sync နှင့် နှိုင်းယှဉ်နိုင်သော၊ ဗဟိုဆာဗာ မှီခိုမှုမရှိပါ။ မည်သည့် node မဆို ဖိုင်ခွဲဝေမှုအဖွဲ့များစွာကို ဖန်တီးနိုင်ပြီး အခြားသူများ၏ မျှဝေသည့်အဖွဲ့များလည်း ပါဝင်နိုင်သည်။ စက်များစွာ၏ တစ်ပြိုင်နက်ဆွဲခြင်းနှင့် အချိန်နှင့်တစ်ပြေးညီ ထပ်တူပြုခြင်းရရှိရန် node များ အလိုအလျောက် လဲလှယ်ပြီး ရရှိနိုင်သော မျိုးစေ့ node များကို ရယူပါ။
- **IP-free node လိပ်စာ**- ပုံမှန်အားဖြင့်၊ node သော့နှင့် `base64url`ကုဒ်လုပ်ထားသော `iroh`လိပ်စာကို အများသူငှာ IP ကို ​​မှတ်မိရန် သို့မဟုတ် ဖော်ထုတ်ရန် မလိုအပ်ဘဲ `~/.config/sync0` အလိုအလျောက် ထုတ်ပေးပါသည်။
- **ဝယ်လိုအားတွင် မျိုးစုံသော ထပ်တူပြုခြင်း**- မျှဝေမှုအုပ်စုတစ်ခုလုံး၏ ထပ်တူပြုမှုကို ပံ့ပိုးပေးသည့်အပြင် ဖိုင်များစွာ သို့မဟုတ် လမ်းညွှန်ခွဲများကို တစ်ပြိုင်နက်ရွေးချယ်ခြင်းဖြင့် တောင်းဆိုမှုအပေါ် ထပ်တူပြုခြင်းကိုလည်း ပံ့ပိုးပေးပါသည်။
- **အုပ်စုအဖွဲ့ဝင်၏ အထက်အောက်ခွင့်ပြုချက်များနှင့် အပ်လုဒ်လမ်းညွှန်ထိန်းချုပ်မှု**- ဖတ်ရှုရန်-သီးသန့် (`ro`)၊ ဖတ်ရန်-ရေးတင် အပ်လုဒ် (`rw`)၊ နှင့် စီမံခန့်ခွဲမှု (`admin`) ခွင့်ပြုချက်များနှင့် အဖွဲ့ဝင်တစ်ဦးစီအား အပ်လုဒ်လုပ်ခွင့်ပြုသည့် လမ်းကြောင်းရှေ့ဆက်ကို သီးခြားသတ်မှတ်နိုင်သည် (ပုံမှန်အားဖြင့်၊ မျှဝေမှု၏ အမြစ်လမ်းညွှန်သို့ အပ်လုဒ်တင်ခြင်းကို ခွင့်ပြုသည်)။
- **ကွန်ရက်များတစ်လျှောက် မြန်နှုန်းအပြည့်နှင့် တိုးမြှင့်ထပ်တူပြုခြင်း**- ကြီးမားသောဖိုင်များကို တစ်ပြိုင်နက်ထုတ်လွှင့်ခြင်း၊ မမ်မိုရီအတွင်းရှိ ကြီးမားသောဖိုင်ငယ်များကို စုစည်းခြင်းနှင့် ဖိုင်များကို တစ်စိတ်တစ်ပိုင်းမွမ်းမံသည့်အခါတွင်သာ တစ်စိတ်တစ်ပိုင်းမွမ်းမံထားသော ဒေတာပိတ်ဆို့ခြင်းများ။

## တပ်ဆင်ပါ။

### နည်းလမ်း 1- Cargo မှတစ်ဆင့် ထည့်သွင်းပါ။

```bash
cargo install sync0
```

### နည်းလမ်း 2- precompiled binaries ကို ဒေါင်းလုဒ်လုပ်ပါ။

သက်ဆိုင်ရာစနစ်အတွက် `.tar.xz`ချုံ့ထားသောပက်ကေ့ဂျ်ကိုဒေါင်းလုဒ်လုပ်ရန် [GitHub ထုတ်ဝေမှုများ](https://github.com/webc-site/sync0/releases) သို့သွားပါ (Linux၊ macOS၊ Windows၊ Android၊ FreeBSD၊ NetBSD) ကို ဇစ်ဖွင့်ပြီး `PATH`လမ်းညွှန်ထဲသို့ ထည့်ပါ-

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## အမြန်စတင်လိုက်ပါ။

`sync0` သည် ပုံမှန်အားဖြင့် `~/.config/sync0`ကို ဖွဲ့စည်းမှုလမ်းညွှန်အဖြစ် အသုံးပြုသည် (အခြားလမ်းညွှန်များသို့ ပြောင်းရန် လိုအပ်ပါက၊ သင်သည် `-c <directory>` ကို ထည့်နိုင်သည်။

### 1. ဒေသတွင်း node လိပ်စာကို ကြည့်ရှုပြီး လုပ်ငန်းကတ်ဆက်တင်ကို ကြည့်ရှုပါ။

```bash
# ဒေသတွင်း node လိပ်စာကိုကြည့်ပါ (သော့ကို ~/.config/sync0 တွင် ပထမဆုံးအကြိမ်အဖြစ် အလိုအလျောက်ထုတ်ပေးသည်)
sync0 id

# ကိုယ်ပိုင် node လုပ်ငန်းကတ်တစ်ခု ဖန်တီးပါ (အသုံးပြုသူအမည်၊ မြို့၊ အီးမေးလ်၊ ဝဘ်ဆိုက်နှင့် လက်မှတ်ကို စကားလုံး 256 လုံးအတွင်း ပံ့ပိုးပေးသည်)
sync0 profile -u alice --region SHA --email alice@example.com --url https://example.com -b "Shanghai node"
```

### 2. ဖိုင်မျှဝေခြင်းအဖွဲ့များစွာကို ထုတ်ဝေပြီး အဖွဲ့အဖွဲ့ဝင်ခွင့်ပြုချက်များကို သတ်မှတ်ပါ (`.nt`ဖွဲ့စည်းမှု)

`sync0`ကို [NestedText](https://nestedtext.org) (`.nt`) ဖော်မက်ဖြင့် စီစဉ်သတ်မှတ်ထားသည်။ အသုံးပြုသူတစ်ဦးစီတွင် သီးခြား `.nt` ဖွဲ့စည်းမှုပုံစံဖိုင်တစ်ခု ရှိသည်။ သင်သည် `users_dir` မှတဆင့် `config.nt` (ဤလမ်းညွှန်တွင် `.nt` ဖိုင်များအားလုံး အလိုအလျောက် ပါ၀င်သည်) မှတဆင့် သင်သည် အသုံးပြုသူပရိုဖိုင်လမ်းညွှန်ကို သတ်မှတ်နိုင်ပါသည်။ အသုံးပြုသူနှင့် လမ်းကြောင်းရှေ့ဆက်ကို အပ်လုဒ်တင်ရန် ခွင့်ပြုထားသော နှစ်ခုလုံးသည် အစီအစဥ်မထားသောစာရင်း (`-`) ကို အသုံးပြုပါ။ ** အပ်လုဒ်လမ်းကြောင်းရှေ့ဆက်ကို မဖြည့်ပါက၊ မျှဝေမှု၏ အမြစ်လမ်းညွှန်သို့ အပ်လုဒ်တင်ခြင်းကို မူရင်းအတိုင်း ခွင့်ပြုသည်**။

1. အဖွဲ့ဝင်တစ်ဦးစီအတွက် သီးခြား `.nt`ဖွဲ့စည်းမှုဖိုင်များကို `~/.config/sync0/users/`လမ်းညွှန်တွင် ဖန်တီးပါ-

`~/.config/sync0/users/alice.nt` (ဖတ်ရန်သီးသန့်အဖွဲ့ဝင်၊ အဆင့်ကန့်သတ်ချက် `80MB`၊ `rate` `GB`၊ `MB`၊ `KB` ယူနစ်များကို ပံ့ပိုးသည်)

```yaml
id: 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c
perm: ro
rate: 80MB
```

`~/.config/sync0/users/bob.nt` (ကန့်သတ်ထားသော အပ်လုဒ်အဖွဲ့ဝင်များ- `uploads/bob` နှင့် `shared/common` လမ်းညွှန်များသို့သာ အပ်လုဒ်လုပ်ခွင့်ပြုသည်-

```yaml
id: 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f
perm: rw
write_prefix:
  - uploads/bob
  - shared/common
```

`~/.config/sync0/users/charlie.nt` (မူရင်းအဖွဲ့ဝင် အပ်လုဒ်- `write_prefix` ချန်လှပ်ထားသည့်အခါ၊ မျှဝေမှု၏ အမြစ်လမ်းညွှန်သို့ အပ်လုဒ်တင်ခြင်းကို မူရင်းအားဖြင့် ခွင့်ပြုသည်-

```yaml
id: 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
perm: rw
```

2. `~/.config/sync0/config.nt`တွင် အသုံးပြုသူလမ်းညွှန်နှင့် ဖိုင်မျှဝေမှုအုပ်စုများစွာကို ပြင်ဆင်သတ်မှတ်ပါ-

```yaml
users_dir: ./users

groups:
  dataset:
    path: ./data
    auth: false
    perm: ro
    rate: 50MB

  models:
    path: ./models
    auth: false
    perm: ro
    rate: 1GB

  team-vault:
    path: ./vault
    auth: true
    perm: ro
    rate: 512KB
    users:
      - alice
      - bob
      - charlie
```

မျှဝေခြင်းဝန်ဆောင်မှုကို စတင်ပါ-

```bash
# တိုက်ရိုက်စတင်ခြင်း (~/.config/sync0/config.nt နှင့် users_dir လမ်းညွှန်များတွင် .nt အသုံးပြုသူဖွဲ့စည်းပုံများကို အလိုအလျောက်တင်သည်)
sync0 share --region SHA

# သို့မဟုတ် မျှဝေမှုအုပ်စုများစွာကို လျင်မြန်စွာထုတ်ဝေပြီး အဖွဲ့၀င်များကို အမိန့်ပေးစာကြောင်းမှတစ်ဆင့် တိုက်ရိုက်ခွင့်ပြုပါ။
sync0 share dataset:./data team-vault:./vault \
  --auth \
  --allow-ro 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c \
  --allow-rw 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f:uploads/bob,shared/common \
  --allow-rw 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
```

### 3. အကြောင်းအရာအားလုံးကို ဆွဲထုတ်ပါ သို့မဟုတ် ဖိုင်အများအပြားနှင့် လမ်းညွှန်များကို ရွေးပါ (`sync0 pull`)

မျှဝေမှုအုပ်စုရှိ ရနိုင်သောမျိုးစေ့များအားလုံးကို အလိုအလျောက်ရရှိရန် မည်သည့်မျိုးစပ် node နှင့်မဆို ချိတ်ဆက်ပြီး မျိုးစေ့ node အများအပြားမှ တစ်ပြိုင်နက် ဆွဲထုတ်ပါ-

```bash
# ဒေတာအစုံမျှဝေသည့်အဖွဲ့တစ်ခုလုံးကို ဒေသတွင်း ./local_data သို့ ဆွဲထုတ်ပါ။
sync0 pull dataset:// ./local_data -p <node address>

# မျိုးစုံရွေးချယ်သော ထပ်တူပြုခြင်း- တစ်ခုတည်းသော ဖိုင် docs/readme.md နှင့် လမ်းကြောင်းခွဲများ ပိုင်ဆိုင်မှု/အိုင်ကွန်များ၊ src/core ကို တစ်ပြိုင်နက် ဆွဲထုတ်ပါ
ထပ်တူပြုခြင်း0 ဆွဲယူဒေတာအတွဲ://docs/readme.md၊assets/icons,src/core ./local_data -p <node လိပ်စာ>
```

### 4. မျှဝေသည့်အဖွဲ့သို့ ဖိုင် သို့မဟုတ် လမ်းညွှန်ကို အပ်လုဒ်လုပ်ပါ (`sync0 push`)

အပ်လုဒ်လုပ်ပိုင်ခွင့်များရှိသည့် အဖွဲ့ဝင်များ (`rw` သို့မဟုတ် `admin`) သည် အဝေးထိန်း မျှဝေသည့်အဖွဲ့များသို့ ဒေသတွင်း ဖိုင်များ သို့မဟုတ် လမ်းညွှန်များကို အပ်လုဒ်လုပ်နိုင်ပါသည်။

```bash
# root directory အပ်လုဒ်ခွင့်ပြုချက်ရှိသော အဖွဲ့ဝင်များ- မျှဝေထားသော root directory သို့ တိုက်ရိုက် အပ်လုဒ်လုပ်ပါ။
sync0 push team-vault:// ./new_release -p <node address>

# သတ်သတ်မှတ်မှတ်ရှေ့ဆက် (ဥပမာ အပ်လုဒ်များ/ bob ကဲ့သို့သော) အဖွဲ့ဝင်များကိုသာ ခွင့်ပြုထားသည်- ခွင့်ပြုထားသောလမ်းကြောင်းရှေ့ဆက်သို့ အပ်လုဒ်လုပ်ပါ
sync0 push team-vault://uploads/bob/report.pdf ./report.pdf -p <node address>
```

### 5. အလိုအလျောက် ထပ်တူကျပြီး မျိုးစေ့ချရန် စာရင်းသွင်းပါ (`sync0 sub`)

အချို့သော node တစ်ခု၏ မျှဝေမှုအုပ်စုကို စာရင်းသွင်းပြီးနောက်၊ ဒေသဆိုင်ရာ ဆာဗာသည် လက်ခံသည့် ကလိုင်းယင့်နှင့် မျိုးစေ့ဆာဗာအသစ် နှစ်ခုလုံးဖြစ်သည်။ အရင်းအမြစ် node ဖိုင်ကို အပ်ဒိတ်လုပ်သောအခါ၊ ၎င်းသည် အလိုအလျောက် ထပ်တူပြုပြီး အခြား node များအတွက် အတုံးလိုက်ဒေါင်းလုပ်များကို ပံ့ပိုးပေးသည်-

```bash
# မျှဝေမှုအုပ်စုတစ်ခုလုံးကို စာရင်းသွင်းပြီး အလိုအလျောက် မျိုးစေ့ချပါ။
sync0 sub dataset:// ./local_mirror -p <node address>

# သတ်မှတ်ထားသောဖိုင်များနှင့် လမ်းကြောင်းခွဲများသို့ စာရင်းသွင်းရန်နှင့် ၎င်းတို့ကို မျိုးစေ့ချရန် အများအပြားကိုသာ ရွေးချယ်ပါ။
ထပ်တူပြုခြင်း0 ခွဲဒေတာအတွဲ://models/llama.onnx၊configs ./local_mirror -p <node လိပ်စာ>
```

### 6. စက်ပေါင်းစုံအဖွဲ့မှ သက်တူရွယ်တူ ထပ်တူပြုခြင်း (`sync0 group`)

စက်များစွာသည် တူညီသောမျှဝေမှုအုပ်စုတွင် ပါဝင်ကြပြီး၊ အချင်းချင်းသည် ရနိုင်သောမျိုးစေ့များဆုံမှတ်များကို အလိုအလျောက်ရှာဖွေတွေ့ရှိပြီး နှစ်လမ်းသွားတစ်ပြိုင်တည်းချိန်ကိုက်မှုကို ထိန်းသိမ်းပေးသည် (အပြည့်အဝထပ်တူကူးခြင်း သို့မဟုတ် ဖိုင်များနှင့်လမ်းညွှန်အများအပြားရွေးချယ်မှုကို ပံ့ပိုးသည်-

```bash
# အဖွဲ့တွင် အပြည့်အဝပါဝင်ပြီး နှစ်လမ်းသွား ထပ်တူပြုခြင်း။
sync0 အဖွဲ့ team-docs:// ./docs -p <node address>

# အများအပြားရွေးချယ်ထားသော ထပ်တူပြုခြင်းအုပ်စုရှိ wal လမ်းညွှန်နှင့် meta.json ဖိုင်သာလျှင်
sync0 အဖွဲ့ team-docs://wal,meta.json ./docs -p <node address>
```

### 7. စက်နှစ်လုံးကြား ပွိုင့်မှ ပွိုင့် တိုက်ရိုက် ထုတ်လွှင့်ခြင်း (`send` / `recv`)

အဖွဲ့တစ်ခုကို ကြိုတင်ပြင်ဆင်ရန် မလိုအပ်ဘဲ စက်နှစ်လုံးကြားတွင် ဖိုင်များ သို့မဟုတ် လမ်းညွှန်များကို ယာယီလွှဲပြောင်းနိုင်သည်-

```bash
# လက်ခံသူစောင့်ကြည့်ခြင်း။
sync0 recv 0.0.0.0:9000 ./backup

# ပေးပို့ခြင်းအဆုံးသည် ဖိုင်များ သို့မဟုတ် လမ်းညွှန်များကို တိုက်ရိုက်လွှဲပြောင်းပေးသည် (ချန်လှပ်ထားနိုင်သော --ဖိုင်များကို ရှင်းရန် မှန်ကိုဖျက်ပါ၊ --အမြန်နှုန်းကန့်သတ်မှုနှုန်း)
sync0 send ./project 192.168.1.10:9000
```

### 8. ဘာသာစကားမျိုးစုံ ကူးပြောင်းခြင်း။

`sync0` သည် ဘာသာစကား 75 ခုကို ပံ့ပိုးပေးကာ မူရင်းစနစ်ဘာသာစကားပတ်ဝန်းကျင်အတိုင်း အလိုအလျောက်ပြောင်းသည်။ ၎င်းကို `SYNC0_LANG`မှတဆင့် ကိုယ်တိုင်သတ်မှတ်နိုင်သည်-

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
