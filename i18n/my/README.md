# sync0

`sync0` သည် ကွန်ရက်များပေါ်တွင် ဖိုင်များ လွှဲပြောင်းခြင်း၊ လမ်းကြောင်းများကို တိုးမြင့်စွာ တစ်ပြိုင်တည်း ဆောင်ရွက်ခြင်း နှင့် စက်များစွာသို့ ဒေတာ ဖြန့်ဝေခြင်းအတွက် အမိန့်ပေးစာကြောင်း ကိရိယာတစ်ခု ဖြစ်သည်။

## မူရင်းဒီဇိုင်း ရည်ရွယ်ချက်

ကွန်ရက်နှောင့်နှေးမှုများနှင့် ပက်ကက်ပျောက်ဆုံးမှုများရှိသည့် စက်ဖြတ်ကျော်စက်ခန်းများ၊ နိုင်ငံများ သို့မဟုတ် ပတ်ဝန်းကျင်တွင်၊ `rsync` နှင့် `scp`ကဲ့သို့သော ကိရိယာများသည် ကြိုးမဲ့အသုံးပြုမှုကို ကန့်သတ်ထားသည့် တစ်ခုတည်းသောချိတ်ဆက်မှုအစီအစဉ်အတည်ပြုချက်အပေါ် အခြေခံထားသည်။ စက်များစွာသည် တူညီသောဆာဗာတစ်ခုမှဒေတာများကို တစ်ပြိုင်နက်တည်းဆွဲယူသောအခါ၊ အရင်းအမြစ်ဆာဗာကွန်ရက်ကတ်သည် အလွယ်တကူတစ်ဆို့သွားနိုင်သည်။

`sync0` ၏ပန်းတိုင်မှာ ပြဿနာနှစ်ခုကို ဖြေရှင်းရန်ဖြစ်သည်-

1. စက်နှစ်ခုကြားရှိ ဖိုင်နှင့် လမ်းညွှန်ကို ထပ်တူပြုခြင်းအား ရုပ်ပိုင်းဆိုင်ရာ လှိုင်းနှုန်းအပြည့်ဖြင့် လုပ်ဆောင်ခွင့်ပေးပြီး ဖိုင်ကို တစ်စိတ်တစ်ပိုင်း ပြုပြင်ထားသည့်အခါတွင်သာ ပြောင်းလဲထားသော အပိုင်းကို လွှဲပြောင်းပါ။
2. စက်များစွာသည် တူညီသောလမ်းညွှန်ကို တစ်ပြိုင်တည်းလုပ်ဆောင်သောအခါ၊ အရင်းအမြစ်ဆာဗာတွင် ဝန်ကိုလျှော့ချပြီး အလုံးစုံထပ်တူကူးရန်အချိန်ကိုတိုစေသောအခါတွင် စက်များစွာသည် ဒေတာပိတ်ဆို့မှုများကို လွှဲပြောင်းပေးနိုင်သည်။

## rsync နှင့် မြန်နှုန်း နှိုင်းယှဉ်ခြင်း။

စမ်းသပ်မှုပတ်ဝန်းကျင်- European node $\leftrightarrow$ မြောက်အမေရိက ကုဒ်၊ အသွားအပြန် နှောင့်နှေးမှု 86 ms၊ လမ်းညွှန်စကင်န်ဖတ်ခြင်း၊ ပုံတူပွားခြင်း နှိုင်းယှဉ်ခြင်း၊ ကွန်ရက်ထုတ်လွှင့်ခြင်းနှင့် ဒစ်ခ်နေရာချထားခြင်း အတည်ပြုခြင်းအပါအဝင် ပြီးပြည့်စုံသော အချိန်ကုန်ခြင်းကို တိုင်းတာခြင်း-

| ဂီယာအခြေအနေ | ဒေတာအရွယ်အစား | `sync0` | `rsync` | မျိုးစုံ |
| :--- | :---: | :---: | :---: | :---: |
| ဖိုင်အသေး ၁၀၀၀၀ | 77.6 MB | 0.90 s (688 Mbps) | 4.86 s (128 Mbps) | 5.4x |
| ကုဒ်နှင့် သိမ်းဆည်းမှု ပက်ကေ့ဂျ်များ (`.tar`) | 512 MB | 1.94 s (2111 Mbps) | 9.36 s (438 Mbps) | 4.8x |
| ဗီဒီယိုဖိုင် (`.mp4`) | 512 MB | 7.36 s (556 Mbps) | 12.11 s (338 Mbps) | 1.6x |
| တိုးမြင့်ထပ်တူပြုခြင်း (အကြောင်းအရာ 1% ကို မွမ်းမံပါ) | 512 MB | 0.12 s | 1.85 s | 15.4x |

## စွမ်းဆောင်ရည်မြှင့်တင်ရေးနည်းလမ်းများ

- **UDP တစ်ပြိုင်တည်းထုတ်လွှင့်ခြင်း**- UDP မှတစ်ဆင့် ဒေတာပိတ်ဆို့မှုများကို ပေးပို့ကာ ပျောက်ဆုံးသွားသော အပိုင်းအစများကိုသာ နောက်ဆက်တွဲ ဖိုင်လွှဲပြောင်းမှုများကို ပိတ်ဆို့တားဆီးခြင်း တစ်ခုတည်းသော packet ဆုံးရှုံးမှုကို ရှောင်ရှားပါ။
- ** အကြောင်းအရာ အပိုင်းခွဲခြင်းနှင့် ခွဲထုတ်ခြင်း**- ဖိုင်ကို အကြောင်းအရာအလိုက် ဒေတာဘလောက်များအဖြစ် ခွဲပြီး စစ်ဆေးမှုတန်ဖိုးကို တွက်ချက်ပါ။ လက်ခံရေးအဆုံးတွင် ရှိနှင့်ပြီးသား တူညီသောအကြောင်းအရာကို ကွန်ရက်ကို ပွားခြင်းမပြုဘဲ စက်တွင်း တိုက်ရိုက်ပြန်သုံးပါသည်။
- ** ကွန်ရက်အမြန်နှုန်းအရ ချုံ့ချဲ့မှုကို အလိုအလျောက်ချိန်ညှိပါ**- စာသားနှင့် ကုဒ်ကဲ့သို့သော ချုံ့နိုင်သောအကြောင်းအရာအတွက် ဖိသိပ်မှုကိုဖွင့်ပါ။ CPU သုံးစွဲမှုကို လျှော့ချရန် ဗီဒီယိုများ၊ ရုပ်ပုံများ၊ ချုံ့ထားသော ပက်ကေ့ဂျ်များ သို့မဟုတ် CPU သုံးစွဲမှုကို လျှော့ချရန် မြန်နှုန်းမြင့် LAN အောက်တွင် ဖိသိပ်မှုကို အလိုအလျောက် ကျော်သွားပါ။
- ** အနီးနားရှိ Multi-node များကိုဆွဲခြင်း**- စက်များစွာသည် တူညီသောလမ်းညွှန်ကိုဆွဲယူသောအခါ၊ တူညီသောမြို့တစ်မြို့ရှိဒေါင်းလုဒ်လုပ်ထားသော node များမှဒေတာပိတ်ဆို့ခြင်းကို တစ်ပြိုင်နက်တည်း သို့မဟုတ် latency ပိုနည်းသောစက်များမှ ဆွဲထုတ်မည်ဖြစ်သည်။

## တပ်ဆင်ပါ။

### နည်းလမ်း 1- Cargo မှတစ်ဆင့် ထည့်သွင်းပါ။

```bash
cargo install sync0
```

### နည်းလမ်း 2- precompiled binaries ကို ဒေါင်းလုဒ်လုပ်ပါ။

သက်ဆိုင်ရာစနစ်အတွက် `.tar.xz`ချုံ့ထားသော ပက်ကေ့ဂျ်ကို ဒေါင်းလုဒ်လုပ်ရန် [GitHub Releases](https://github.com/webc-site/sync0/releases) သို့ သွားပါ (Linux x86_64/ARM64၊ macOS Apple Silicon/Intel၊ Windows x64/ARM64၊ Android ARM64/x86_64၊ FreeBSD၊ NetBSD)။ ဇစ်ဖွင့်ပြီးနောက်၊ `sync0` `PATH` လမ်းညွှန်ထဲသို့ ထားလိုက်ပါ-

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## အသုံးပြုသူလမ်းညွှန်

### 1. စက်နှစ်လုံးကြားတွင် ဖိုင်များ သို့မဟုတ် လမ်းညွှန်များကို တိုက်ရိုက်လွှဲပြောင်းပါ။

လက်ခံစက်တွင် စတင်စောင့်ကြည့်ပြီး လက်ခံခြင်းနှင့် သိမ်းဆည်းခြင်းလမ်းကြောင်းကို သတ်မှတ်ပါ-

```bash
sync0 recv 0.0.0.0:9000 ./backup
```

ပေးပို့သည့်စက်မှ ဖိုင်တစ်ခု သို့မဟုတ် လမ်းညွှန်တစ်ခုလုံးကို ပို့ပါ-

```bash
sync0 send ./project 192.168.1.10:9000
```

အသုံးများသော ကန့်သတ်ချက်များ

```bash
# လက်ခံရရှိသည့်အဆုံးတွင်ရှိသော်လည်း ပေးပို့သည့်အဆုံးတွင်မဟုတ်သော ထပ်နေသောဖိုင်များကို ဖျက်ပါ (မှန်ချပ်ထပ်တူပြုခြင်း)
sync0 send ./project 192.168.1.10:9000 --delete

# ပေးပို့မှုနှုန်းကို ကန့်သတ်ပါ (ယူနစ်- bytes/second၊ ဥပမာ 50 MB/s)
sync0 send ./project 192.168.1.10:9000 --rate 50000000

# အသံတိတ်မုဒ် (တိုးတက်မှုဘားကိုပြသထားသည်)
sync0 send ./project 192.168.1.10:9000 -q
```

### 2. မျှဝေထားသော လမ်းညွှန်များကို ထုတ်ဝေခြင်းနှင့် node အများအပြားမှ ဆွဲထုတ်ခြင်း။

မူရင်းဆာဗာတွင် မျှဝေထားသော လမ်းညွှန် ( `dataset`) ကို ထုတ်ဝေပါ-

```bash
sync0 share dataset ./data --region SHA
```

အခြားစက်များတွင် မျှဝေထားသော လမ်းညွှန်ကို ဆွဲယူပါ (တစ်ပြိုင်နက် ဆွဲယူရန် ကော်မာများဖြင့် ခြားထားသော တစ်ချိန်တည်းတွင် များစွာသော node လိပ်စာများကို သင်ဖြည့်နိုင်သည်)

```bash
sync0 pull 10.0.0.1:9000,10.0.0.2:9000 dataset ./local_data
```

မျှဝေထားသော လမ်းညွှန်ချက်အတွင်းမှ အချို့သော လမ်းကြောင်းခွဲတစ်ခုကိုသာ ဆွဲယူပါ-

```bash
sync0 pull 10.0.0.1:9000 dataset ./local_data --subpath 2026/logs
```

စက်တွင်းပြောင်းလဲမှုများကို အဝေးထိန်း မျှဝေထားသော လမ်းညွှန်သို့ ပြန်ပို့ပါ-

```bash
sync0 push 10.0.0.1:9000 dataset ./local_data
```

### 3. ကတ်တလောက် အော်တိုအပ်ဒိတ်များအတွက် စာရင်းသွင်းပါ။

အရင်းအမြစ် node ၏ မျှဝေထားသော လမ်းညွှန်ကို စာရင်းသွင်းပါ။ ဖိုင်တစ်ခုကို အရင်းအမြစ်လမ်းညွှန်တွင် ထည့်သွင်းခြင်း သို့မဟုတ် ပြင်ဆင်သည့်အခါ၊ ၎င်းကို စက်တွင်းကွန်ပျူတာသို့ အလိုအလျောက် ထပ်တူပြုပါမည်။ တစ်ချိန်တည်းမှာပင်၊ စက်တွင်းစက်သည် အခြားစက်များကို ဆွဲယူရန် node တစ်ခုအဖြစ် အလိုအလျောက် လုပ်ဆောင်ပေးလိမ့်မည်-

```bash
sync0 sub 10.0.0.1:9000 dataset ./local_mirror
```

### 4. စက်ပေါင်းစုံအုပ်စုများကို နှစ်လမ်းသွားတူအောင်ပြုလုပ်ခြင်း။

စက်များစွာသည် အုပ်စုအမည်တစ်ခုတည်းတွင် ပါဝင်ပြီး မည်သည့် node လမ်းညွှန်တွင်မဆို အပြောင်းအလဲများကို အဖွဲ့ရှိ အခြား node များသို့ အလိုအလျောက် ထပ်တူပြုပါမည်။

```bash
sync0 group team-docs ./docs 10.0.0.1:9000,10.0.0.2:9000
```

### 5. Node အထောက်အထားနှင့် ကိုယ်ပိုင်စီးပွားရေးကတ်

node တစ်ခုစီသည် အသုံးပြုသူအမည်၊ မြို့၊ အီးမေးလ်၊ ဝဘ်ဆိုက်နှင့် ပုဂ္ဂိုလ်ရေးသီးသန့်ပြုလုပ်ထားသော လက်မှတ် (အများဆုံး 256 လုံး) ကို သတ်မှတ်ခြင်းအား ပံ့ပိုးပေးကာ ဒေသဆိုင်ရာ သီးသန့်သော့လက်မှတ်ကို စစ်မှန်ကြောင်းအတည်ပြုခြင်းကို ဖြတ်သန်းသည်-

```bash
# ဒေသတွင်း အများသူငှာသော့ ID ကို ကြည့်ပါ (သော့ကို ဆက်ရှိနေစေရန် ဖွဲ့စည်းမှုလမ်းညွှန်ကို သတ်မှတ်ပါ)
sync0 id -c ~/.config/sync0

# စိတ်ကြိုက် လက်မှတ်များဖြင့် node လုပ်ငန်းကတ်များကို ထုတ်လုပ်ပြီး ပြသပါ။
sync0 profile -c ~/.config/sync0 \
  -u alice \
  --region SHA \
  --email alice@example.com \
  --url https://example.com \
  -b "Shanghai backup node"
```

`share`၊ `pull`၊ `sub`၊ `group`ကိုလည်း ဤပရိုဖိုင် ကန့်သတ်ချက်များဖြင့် စတင်နိုင်သည်-

```bash
sync0 share dataset ./data -c ~/.config/sync0 -u alice --region SHA -b "Shanghai backup node"
```

### 6. ဘာသာစကားမျိုးစုံ ကူးပြောင်းခြင်း။

`sync0`ဘာသာစကား 75 ခုကို ပံ့ပိုးပေးသည်။ ပုံမှန်အားဖြင့်၊ သက်ဆိုင်ရာဘာသာစကားရှိ command line အကူအညီနှင့် prompts များသည် operating system ၏ဘာသာစကားပတ်ဝန်းကျင်အရ အလိုအလျောက်ပြသပါသည်။ စနစ်ဘာသာစကားကို ပံ့ပိုးထားသောစာရင်းတွင် မပါဝင်ပါက၊ အင်္ဂလိပ်ကို မူရင်းအတိုင်း အသုံးပြုပါသည်။

ဘာသာစကားကို ကိုယ်တိုင်သတ်မှတ်ရန်၊ ပတ်၀န်းကျင်ပြောင်းလဲနိုင်သော `SYNC0_LANG`:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
