# sync0

`sync0` הוא כלי לשיתוף קבצים וסנכרון מרובה מכונות (P2P) המתחרה עם Resilio Sync.

כל מכונה היא גם שרת וגם לקוח: כל צומת יכול לפרסם קבוצות שיתוף קבצים מרובות. לאחר הצטרפות של צמתים אחרים, הם יכולים להשיג באופן אוטומטי צמתים זמינים משרת העמיתים ולמשוך אותם במקביל ממספר מקורות. לאחר השלמת הסנכרון, ייווצרו זרעים אוטומטית לצמתים נוספים כדי להאיץ הורדות.

## דגשים הליבה

- **כולם הם גם שרת וגם לקוח**: ניתן להשוות ל-Resilio Sync, ללא תלות מרכזית בשרת. כל צומת יכול ליצור מספר קבוצות שיתוף קבצים, ויכול גם להצטרף לקבוצות שיתוף של אנשים אחרים; צמתים מחליפים ומשיגים צמתים זמינים באופן אוטומטי כדי להשיג משיכה במקביל וסנכרון בזמן אמת של מספר מכונות.
- **כתובת צומת ללא IP**: כברירת מחדל, מפתח הצומת וכתובת `iroh` המקודדת נוצרות אוטומטית ב-`~/.config/sync0` ללא צורך לזכור או לחשוף את ה-IP הציבורי.
- **סנכרון רב בחירה לפי דרישה**: תומך בסנכרון של כל קבוצת השיתוף, וכן תומך בסנכרון לפי דרישה על ידי בחירת מספר קבצים או ספריות משנה בו זמנית.
- **הרשאות היררכיות של חברי קבוצה ובקרת ספריית העלאה**: תומך בהרשאות קריאה בלבד (`ro`), העלאת קריאה-כתיבה (`rw`) וניהול (`admin`), ויכול לציין בנפרד את קידומת הנתיב שכל חבר רשאי להעלות (כברירת מחדל, העלאה לספריית הבסיס של השיתוף מותרת).
- **סנכרון מהיר ומצטבר בין רשתות**: שידור במקביל של קבצים גדולים, צבירה של קבצים קטנים מאסיביים בזיכרון, ורק בלוקי נתונים מסונכרנים כאשר קבצים משתנים חלקית.

## לְהַתְקִין

### שיטה 1: התקנה באמצעות מטען

```bash
cargo install sync0
```

### שיטה 2: הורד קבצים בינאריים מהודרים מראש

עבור אל [GitHub Releases](https://github.com/webc-site/sync0/releases) כדי להוריד את החבילה הדחוסה `.tar.xz` עבור המערכת המתאימה (תומכת ב-Linux, macOS, Windows, Android, FreeBSD, NetBSD), פתח את ה-zip והכנס אותה לספרייה `PATH`:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## התחל מהר

`sync0` משתמש ב-`~/.config/sync0` בתור ספריית התצורה כברירת מחדל (אם עליך לעבור לספריות אחרות, תוכל להוסיף את `-c <directory>`).

### 1. הצג את כתובת הצומת המקומית ואת כרטיס הביקור ההגדרה

```bash
# הצג את כתובת הצומת המקומית (המפתח נוצר אוטומטית ב-~/.config/sync0 בפעם הראשונה)
sync0 id

# צור כרטיס ביקור אישי לצומת (תומך בשם משתמש, עיר, דוא"ל, אתר אינטרנט וחתימה תוך 256 מילים)
sync0 profile -u alice --region SHA --email alice@example.com --url https://example.com -b "Shanghai node"
```

### 2. פרסם קבוצות שיתוף קבצים מרובות והגדר הרשאות לחברי הקבוצה (`.nt` תצורה)

`sync0` מוגדר בפורמט [NestedText](https://nestedtext.org) (`.nt`). לכל משתמש יש קובץ תצורה נפרד `.nt`. אתה יכול לציין את ספריית פרופיל המשתמש דרך `users_dir` ב-`config.nt` (שכוללת אוטומטית את כל הקבצים `.nt` בספרייה זו). גם המשתמש וגם קידומת הנתיב המותרת להעלאה משתמשים ברשימה לא מסודרת (`-`). **כאשר קידומת נתיב ההעלאה אינה ממולאת, העלאה לספריית הבסיס של השיתוף מותרת כברירת מחדל**.

1. צור `.nt` קובצי תצורה נפרדים עבור כל חבר בספרייה `~/.config/sync0/users/`:

`~/.config/sync0/users/alice.nt` (חבר לקריאה בלבד, שיעור מוגבל `80MB`, `rate` תומך ביחידות `GB`, `MB`, `KB`):

```yaml
id: 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c
perm: ro
rate: 80MB
```

`~/.config/sync0/users/bob.nt` (חברי העלאה מוגבלים: מותר רק להעלות לספריות `uploads/bob` ו-`shared/common`):

```yaml
id: 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f
perm: rw
write_prefix:
  - uploads/bob
  - shared/common
```

`~/.config/sync0/users/charlie.nt` (העלאת חבר ברירת מחדל: כאשר `write_prefix` מושמט, העלאה לספריית הבסיס של השיתוף מותרת כברירת מחדל):

```yaml
id: 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
perm: rw
```

2. הגדר את ספריית המשתמש וקבוצות שיתוף מרובות ב-`~/.config/sync0/config.nt`:

```yaml
users_dir: ./users

groups:
  dataset:
    path: ./data
    auth: false
    perm: ro
    rate: 50MB

  models:
    path: ./models
    auth: false
    perm: ro
    rate: 1GB

  team-vault:
    path: ./vault
    auth: true
    perm: ro
    rate: 512KB
    users:
      - alice
      - bob
      - charlie
```

התחל שירות שיתוף:

```bash
# הפעלה ישירה (טוען אוטומטית את כל תצורות המשתמש .nt בספריות ~/.config/sync0/config.nt ו-users_dir)
sync0 share --region SHA

# או פרסם במהירות קבוצות שיתוף מרובות ואשר לחברי קבוצה ישירות דרך שורת הפקודה
sync0 share dataset:./data team-vault:./vault \
  --auth \
  --allow-ro 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c \
  --allow-rw 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f:uploads/bob,shared/common \
  --allow-rw 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
```

### 3. משוך את כל התוכן או בחר מספר קבצים וספריות (`sync0 pull`)

התחבר לכל צומת עמית כדי לקבל באופן אוטומטי את כל צמתי ה-Seed הזמינים בקבוצת השיתוף, ומשך ממספר צמתים מוקדמים בו-זמנית:

```bash
# משוך את כל קבוצת השיתוף של מערך הנתונים אל ה-./local_data המקומי
sync0 pull dataset:// ./local_data -p <כתובת צומת>

# סנכרון מרובה בחירה: משוך בו זמנית את הקובץ הבודד docs/readme.md ואת ספריות המשנה assets/icons, src/core
sync0 pull dataset://docs/readme.md,assets/icons,src/core ./local_data -p <כתובת צומת>
```

### 4. העלה קובץ או ספרייה לקבוצת שיתוף (`sync0 push`)

חברים עם הרשאות העלאה (`rw` או `admin`) יכולים להעלות קבצים מקומיים או ספריות לקבוצות שיתוף מרחוק:

```bash
# חברים עם הרשאת העלאת ספריית שורש: העלה ישירות לספריית השורש המשותפת
sync0 push team-vault:// ./new_release -p <כתובת צומת>

# רק חברים המורשים לקידומת ספציפית (כגון העלאות/בוב): העלה לקידומת הנתיב המותרת
sync0 push team-vault://uploads/bob/report.pdf ./report.pdf -p <כתובת צומת>
```

### 5. הירשם לסנכרון וזרימה אוטומטית (`sync0 sub`)

לאחר הרשמה לקבוצת השיתוף של צומת מסוים, השרת המקומי הוא גם לקוח מקבל וגם שרת זריעה חדש; כאשר קובץ צומת המקור מתעדכן, הוא מסונכרן אוטומטית ומספק הורדות חתיכות עבור צמתים אחרים:

```bash
# הירשם לכל קבוצת השיתוף ותראה אוטומטית
sync0 sub dataset:// ./local_mirror -p <כתובת צומת>

# רק בחירה מרובה כדי להירשם לקבצים ולתיקיות המשנה שצוינו ולהתחיל אותם
sync0 sub dataset://models/llama.onnx,configs ./local_mirror -p <כתובת צומת>
```

### 6. סנכרון עמיתים בקבוצות מרובות מכונות (`sync0 group`)

מכונות מרובות מצטרפות לאותה קבוצת שיתוף, אחת מהשנייה מגלה אוטומטית צמתים זמינים ושומרת על סנכרון דו-כיווני (תומך בסנכרון מלא או בחירה מרובה של קבצים וספריות):

```bash
# הצטרפות מלאה לקבוצה וסנכרון דו כיווני
sync0 group team-docs:// ./docs -p <כתובת צומת>

# רק ספריית wal וקובץ meta.json בקבוצת הסנכרון מרובת הבחירה
sync0 group team-docs://wal,meta.json ./docs -p <כתובת צומת>
```

### 7. שידור ישיר מנקודה לנקודה בין שני מכונות (`send` / `recv`)

אין צורך להגדיר מראש קבוצה, ואתה יכול להעביר באופן זמני קבצים או ספריות ישירות בין שני מכונות:

```bash
# ניטור מקלט
sync0 recv 0.0.0.0:9000 ./backup

# קצה השליחה מעביר ישירות קבצים או ספריות (אופציונלי --מחק מראה כדי לנקות קבצים עודפים, --מגבלת מהירות קצב)
sync0 send ./project 192.168.1.10:9000
```

### 8. מיתוג רב שפות

`sync0` תומך ב-75 שפות, ועובר אוטומטית בהתאם לסביבת שפת המערכת כברירת מחדל; ניתן לציין אותו גם באופן ידני דרך `SYNC0_LANG`:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
