# sync0

`sync0` הוא כלי שורת פקודה להעברת קבצים בין רשתות, סנכרון מצטבר של ספריות והפצת נתונים במקביל למספר מכונות.

## כוונה עיצובית מקורית

בחדרים חוצי מכונות, מדינות או סביבות עם עיכובים ברשת ואובדן מנות, כלים כגון `rsync` ו-`scp` מבוססים על אישור רצף חיבור יחיד, המגביל את ניצול רוחב הפס; כאשר מספר מכונות מושכות נתונים מאותו שרת בו-זמנית, כרטיס הרשת של שרת המקור יכול להפוך בקלות לצוואר בקבוק.

המטרה של `sync0` היא לפתור שתי בעיות:

1. תן לסנכרון הקובץ והספריות בין שני המכונות לפעול ברוחב פס פיזי מלא, והעבר את החלק שהשתנה רק כאשר הקובץ משתנה באופן חלקי.
2. מכונות מרובות יכולות להעביר בלוקים של נתונים זה לזה בעת סנכרון של אותה ספרייה, להפחית את העומס על שרת המקור ולקצר את זמן הסנכרון הכולל.

## השוואת מהירות עם rsync

סביבת בדיקה: צומת אירופאי $\leftrightarrow$ צפון אמריקאי, עיכוב הלוך ושוב של 86 אלפיות השנייה, מדידת זמן רב הכולל סריקת ספריות, השוואת כפילויות, שידור רשת ואימות מיקום דיסק:

| תרחיש שידור | גודל נתונים | `sync0` | `rsync` | מְרוּבֶּה |
| :--- | :---: | :---: | :---: | :---: |
| 10,000 קבצים קטנים | 77.6 MB | 0.90 s (688 Mbps) | 4.86 s (128 Mbps) | 5.4x |
| קוד וחבילות ארכיון (`.tar`) | 512 MB | 1.94 s (2111 Mbps) | 9.36 s (438 Mbps) | 4.8x |
| קובץ וידאו (`.mp4`) | 512 MB | 7.36 s (556 Mbps) | 12.11 s (338 Mbps) | 1.6x |
| סנכרון מצטבר (שנה 1% תוכן) | 512 MB | 0.12 s | 1.85 s | 15.4x |

## שיטות לשיפור ביצועים

- **שידור בו-זמני של UDP**: שלח בלוקים של נתונים דרך UDP, ושדר רק קטעים שאבדו כדי למנוע אובדן מנה בודד שחוסם העברות קבצים עוקבות.
- **פילוח תוכן ומניעת כפילות**: פיצלו את הקובץ לקוביות נתונים לפי תוכן וחשבו את ערך ההמחאה. באותו תוכן שכבר נמצא בצד המקבל נעשה שימוש חוזר ישירות באופן מקומי מבלי לשכפל את הרשת.
- **התאמה אוטומטית של הדחיסה לפי מהירות הרשת**: הפעל דחיסה עבור תוכן דחוס כגון טקסט וקוד; דלג אוטומטית על דחיסה עבור סרטונים, תמונות, חבילות דחוסות או תחת LAN במהירות גבוהה כדי להפחית את צריכת ה-CPU.
- **משיכת מספר צמתים בקרבת מקום**: כאשר מספר מכונות מושכות את אותה ספרייה, בלוקי נתונים יימשכו במקביל מצמתים שהורדו באותה עיר או עם זמן אחזור נמוך יותר.

## לְהַתְקִין

### שיטה 1: התקנה באמצעות מטען

```bash
cargo install sync0
```

### שיטה 2: הורד קבצים בינאריים מהודרים מראש

עבור אל [GitHub Releases](https://github.com/webc-site/sync0/releases) כדי להוריד את `.tar.xz` החבילה הדחוסה עבור המערכת המתאימה (תומך ב-Linux x86_64/ARM64, macOS Apple Silicon/Intel, Windows x64/ARM64, Android ARM64/x86_64, FreeBSD, NetBSD). לאחר פתיחת המיקוד, מקם את `sync0` בספרייה `PATH`:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## מדריך למשתמש

### 1. העבר קבצים או ספריות ישירות בין שני מכונות

התחל לנטר במכונה המקבלת וציין את נתיב הקבלה והשמירה:

```bash
sync0 recv 0.0.0.0:9000 ./backup
```

שלח קובץ בודד או ספרייה שלמה מהמכונה השולחת:

```bash
sync0 send ./project 192.168.1.10:9000
```

פרמטרים נפוצים:

```bash
# מחק קבצים מיותרים שקיימים בקצה המקבל אך לא בקצה השולח (סנכרון מראה)
sync0 send ./project 192.168.1.10:9000 --delete

# הגבל את קצב השליחה (יחידה: בייטים/שנייה, למשל 50 מגה-בייט/שנייה)
sync0 send ./project 192.168.1.10:9000 --rate 50000000

# מצב שקט (לא מוצג סרגל התקדמות)
sync0 send ./project 192.168.1.10:9000 -q
```

### 2. פרסום ספריות משותפות ומשיכת צמתים מרובים

פרסם ספרייה משותפת (בשם `dataset`) בשרת המקור:

```bash
sync0 share dataset ./data --region SHA
```

משוך את הספרייה המשותפת במחשבים אחרים (תוכל למלא מספר כתובות של צומת בו-זמנית, מופרדים בפסיקים כדי למשוך בו-זמנית):

```bash
sync0 pull 10.0.0.1:9000,10.0.0.2:9000 dataset ./local_data
```

משוך רק ספריית משנה מסוימת בספרייה המשותפת:

```bash
sync0 pull 10.0.0.1:9000 dataset ./local_data --subpath 2026/logs
```

דחף שינויים מקומיים בחזרה לספרייה המשותפת המרוחקת:

```bash
sync0 push 10.0.0.1:9000 dataset ./local_data
```

### 3. הירשם לעדכונים אוטומטיים של הקטלוג

הירשם לספרייה המשותפת של צומת המקור. כאשר קובץ מתווסף או משתנה בספריית המקור, הוא יסונכרן אוטומטית למחשב המקומי. במקביל, המכונה המקומית תשמש אוטומטית כצומת למכונות אחרות למשוך:

```bash
sync0 sub 10.0.0.1:9000 dataset ./local_mirror
```

### 4. סנכרון דו כיווני של קבוצות מרובות מכונות

מכונות מרובות מצטרפות לאותו שם קבוצה, ושינויים בכל ספריית צמתים יסונכרנו אוטומטית לצמתים אחרים בקבוצה:

```bash
sync0 group team-docs ./docs 10.0.0.1:9000,10.0.0.2:9000
```

### 5. זהות צומת וכרטיס ביקור אישי

כל צומת תומך בהגדרת שם המשתמש, העיר, האימייל, האתר וחתימה אישית (מקסימום 256 תווים), ומעביר את אימות חתימת המפתח הפרטי המקומי:

```bash
# הצג את מזהה המפתח הציבורי המקומי (ציין את ספריית התצורה כדי להתמיד במפתח)
sync0 id -c ~/.config/sync0

# צור והצג כרטיסי ביקור של צומת עם חתימות מותאמות אישית
sync0 profile -c ~/.config/sync0 \
  -u alice \
  --region SHA \
  --email alice@example.com \
  --url https://example.com \
  -b "Shanghai backup node"
```

ניתן להפעיל את `share`, `pull`, `sub`, `group` גם עם פרמטרי הפרופיל הבאים:

```bash
sync0 share dataset ./data -c ~/.config/sync0 -u alice --region SHA -b "Shanghai backup node"
```

### 6. מיתוג רב שפות

`sync0` תומך ב-75 שפות. כברירת מחדל, עזרה והנחיות בשורת הפקודה בשפה המתאימה מוצגות אוטומטית בהתאם לסביבת השפה של מערכת ההפעלה; אם שפת המערכת אינה ברשימה הנתמכת, האנגלית משמשת כברירת מחדל.

כדי לציין את השפה באופן ידני, הגדר את משתנה הסביבה `SYNC0_LANG`:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
