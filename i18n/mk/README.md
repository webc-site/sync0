# sync0

`sync0` е алатка за командна линија за пренос на датотеки низ мрежи, постепено синхронизирање директориуми и истовремено дистрибуција на податоци на повеќе машини.

## Оригинална дизајнерска намера

Во меѓу-машински простории, земји или околини со доцнење на мрежата и загуба на пакети, алатките како што се `rsync` и `scp` се засноваат на потврда за една секвенца на поврзување, што го ограничува искористувањето на пропусниот опсег; кога повеќе машини повлекуваат податоци од истиот сервер во исто време, мрежната картичка на изворниот сервер лесно може да стане тесно грло.

Целта на `sync0` е да се решат два проблема:

1. Дозволете синхронизацијата на датотеката и директориумот помеѓу двете машини да работи со целосен физички пропусен опсег и да го пренесете променетиот дел само кога датотеката е делумно изменета.
2. Повеќе машини можат да префрлаат податочни блокови едни на други кога синхронизираат ист директориум, намалувајќи го оптоварувањето на изворниот сервер и скратувајќи го целокупното време на синхронизација.

## Споредба на брзина со rsync

Тест опкружување: Европски јазол $\leftrightarrow$ Северноамерикански јазол, доцнење со повратен пат од 86 ms, мерење на целосно одзема време, вклучувајќи скенирање директориуми, споредба на дедупликација, мрежен пренос и проверка на поставување на дискот:

| Сценарио за пренос | Големина на податоци | `sync0` | `rsync` | повеќекратни |
| :--- | :---: | :---: | :---: | :---: |
| 10.000 мали датотеки | 77.6 MB | 0.90 s (688 Mbps) | 4.86 s (128 Mbps) | 5.4x |
| Код и архивски пакети (`.tar`) | 512 MB | 1.94 s (2111 Mbps) | 9.36 s (438 Mbps) | 4.8x |
| Видео датотека (`.mp4`) | 512 MB | 7.36 s (556 Mbps) | 12.11 s (338 Mbps) | 1.6x |
| Инкрементална синхронизација (измени 1% содржина) | 512 MB | 0.12 s | 1.85 s | 15.4x |

## Методи за подобрување на перформансите

- **УДП истовремен пренос**: Испраќајте блокови на податоци преку UDP и преемитувајте само изгубени фрагменти за да избегнете загуба на еден пакет што ги блокира следните преноси на датотеки.
- **Сегментација и дедупликација на содржината**: Поделете ја датотеката на податочни блокови според содржината и пресметајте ја вредноста на проверката. Истата содржина што е веќе на приемниот крај повторно се користи директно локално без дуплирање на мрежата.
- **Автоматско прилагодување на компресија според брзината на мрежата**: Вклучете ја компресија за компресибилна содржина како што се текст и код; автоматски прескокнете ја компресија за видеа, слики, компресирани пакети или под LAN со голема брзина за да ја намалите потрошувачката на процесорот.
- **Повлекување на повеќе јазли во близина**: кога повеќе машини го повлекуваат истиот директориум, блоковите на податоци ќе се повлекуваат истовремено од преземените јазли во истиот град или со помала латентност.

## Инсталирајте

### Метод 1: Инсталирајте преку Карго

```bash
cargo install sync0
```

### Метод 2: Преземете претходно компајлирани бинарни датотеки

Одете во [GitHub Releases](https://github.com/webc-site/sync0/releases) за да го преземете `.tar.xz` компресираниот пакет за соодветниот систем (подржува Linux x86_64/ARM64, macOS Apple Silicon/Intel, Windows x64/ARM64, Android ARM64/x86_64, FreeBSD, NetBSD). По отпакувањето, ставете `sync0` во директориумот `PATH`:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## Упатство за употреба

### 1. Директно пренесувајте датотеки или директориуми помеѓу две машини

Започнете со следење на машината што прима и наведете ја патеката за примање и зачувување:

```bash
sync0 recv 0.0.0.0:9000 ./backup
```

Испратете една датотека или цел директориум од машината за испраќање:

```bash
sync0 send ./project 192.168.1.10:9000
```

Најчесто користени параметри:

```bash
# Избришете ги непотребните датотеки што постојат на приемниот крај, но не и на крајот што испраќа (синхронизација со огледало)
sync0 send ./project 192.168.1.10:9000 --delete

# Ограничете ја брзината на испраќање (единица: бајти/секунда, на пример 50 MB/s)
sync0 send ./project 192.168.1.10:9000 --rate 50000000

# Тивок режим (не е прикажана лента за напредок)
sync0 send ./project 192.168.1.10:9000 -q
```

### 2. Објавување споделени директориуми и повлекување од повеќе јазли

Објавете споделен директориум (именуван `dataset`) на серверот за потекло:

```bash
sync0 share dataset ./data --region SHA
```

Повлечете го споделениот директориум на други машини (можете да пополните повеќе адреси на јазли во исто време, одделени со запирки за да се повлечете истовремено):

```bash
sync0 pull 10.0.0.1:9000,10.0.0.2:9000 dataset ./local_data
```

Повлечете само одреден поддиректориум во споделениот директориум:

```bash
sync0 pull 10.0.0.1:9000 dataset ./local_data --subpath 2026/logs
```

Вратете ги локалните промени во далечинскиот споделен директориум:

```bash
sync0 push 10.0.0.1:9000 dataset ./local_data
```

### 3. Претплатете се на автоматски ажурирања на каталогот

Претплатете се на споделениот директориум на изворниот јазол. Кога датотеката е додадена или изменета во изворниот директориум, таа автоматски ќе се синхронизира со локалниот компјутер. Во исто време, локалната машина автоматски ќе служи како јазол за повлекување на другите машини:

```bash
sync0 sub 10.0.0.1:9000 dataset ./local_mirror
```

### 4. Двонасочна синхронизација на повеќе-машински групи

Повеќе машини се придружуваат на истото име на групата и промените во кој било директориум на јазли автоматски ќе се синхронизираат со другите јазли во групата:

```bash
sync0 group team-docs ./docs 10.0.0.1:9000,10.0.0.2:9000
```

### 5. Идентификација на јазол и лична визит-картичка

Секој јазол поддржува поставување на корисничко име, град, е-пошта, веб-локација и персонализиран потпис (максимум 256 знаци) и ја пренесува автентикацијата на локалниот приватен клуч за потпис:

```bash
# Прикажи го ID на локалниот јавен клуч (наведете го директориумот за конфигурација за да остане клучот)
sync0 id -c ~/.config/sync0

# Генерирајте и прикажувајте визит-картички на јазли со персонализирани потписи
sync0 profile -c ~/.config/sync0 \
  -u alice \
  --region SHA \
  --email alice@example.com \
  --url https://example.com \
  -b "Shanghai backup node"
```

`share`, `pull`, `sub`, `group` исто така може да се стартуваат со овие параметри на профилот:

```bash
sync0 share dataset ./data -c ~/.config/sync0 -u alice --region SHA -b "Shanghai backup node"
```

### 6. Префрлување на повеќе јазици

`sync0` Поддржува 75 јазици. Стандардно, помошта на командната линија и потсетниците на соодветниот јазик автоматски се прикажуваат според јазичната средина на оперативниот систем; ако јазикот на системот не е во поддржаната листа, стандардно се користи англискиот јазик.

За рачно да го одредите јазикот, поставете ја променливата на околината `SYNC0_LANG`:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
