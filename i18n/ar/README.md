# sync0

`sync0` هي أداة لمشاركة الملفات ومزامنة الأجهزة المتعددة من نظير إلى نظير (P2P) وتتنافس مع Resilio Sync.

كل جهاز هو خادم وعميل في نفس الوقت: يمكن لأي عقدة نشر مجموعات متعددة لمشاركة الملفات. بعد انضمام العقد الأخرى، يمكنها تلقائيًا الحصول على العقد الأولية المتاحة من الخادم النظير وسحبها بشكل متزامن من مصادر متعددة. بعد اكتمال المزامنة، سيتم إنشاء البذور تلقائيًا لمزيد من العقد لتسريع التنزيلات.

## أبرز النقاط الأساسية

- **الجميع عبارة عن خادم وعميل في نفس الوقت**: يمكن مقارنته بـ Resilio Sync، ولا توجد تبعية للخادم المركزي. يمكن لأي عقدة إنشاء مجموعات متعددة لمشاركة الملفات، ويمكنها أيضًا الانضمام إلى مجموعات مشاركة الأشخاص الآخرين؛ تقوم العقد تلقائيًا بتبادل العقد الأولية المتاحة والحصول عليها لتحقيق السحب المتزامن والمزامنة في الوقت الفعلي لأجهزة متعددة.
- **عنوان العقدة الخالية من IP**: افتراضيًا، يتم إنشاء مفتاح العقدة وعنوان `base64url` المشفر `iroh` تلقائيًا في `~/.config/sync0` دون الحاجة إلى تذكر عنوان IP العام أو الكشف عنه.
- **مزامنة التحديد المتعدد عند الطلب**: يدعم مزامنة مجموعة المشاركة بأكملها، ويدعم أيضًا المزامنة عند الطلب عن طريق تحديد ملفات أو أدلة فرعية متعددة في نفس الوقت.
- **الأذونات الهرمية لأعضاء المجموعة والتحكم في دليل التحميل**: يدعم أذونات القراءة فقط (`ro`)، وتحميل القراءة والكتابة (`rw`)، والإدارة (`admin`)، ويمكن تحديد بادئة المسار بشكل فردي والتي يُسمح لكل عضو بتحميلها (افتراضيًا، يُسمح بالتحميل إلى الدليل الجذر للمشاركة).
- **مزامنة كاملة السرعة ومتزايدة عبر الشبكات**: النقل المتزامن للملفات الكبيرة، وتجميع الملفات الصغيرة الضخمة في الذاكرة، وكتل البيانات المتزامنة فقط عندما يتم تعديل الملفات جزئيًا.

## ثَبَّتَ

### الطريقة الأولى: التثبيت عبر Cargo

```bash
cargo install sync0
```

### الطريقة الثانية: تنزيل الثنائيات المترجمة مسبقًا

انتقل إلى [إصدارات GitHub](https://github.com/webc-site/sync0/releases) لتنزيل الحزمة المضغوطة `.tar.xz` للنظام المقابل (يدعم Linux وmacOS وWindows وAndroid وFreeBSD وNetBSD)، وقم بفك ضغطها ووضعها في الدليل `PATH`:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## ابدأ بسرعة

يستخدم `sync0` `~/.config/sync0` كدليل التكوين افتراضيًا (إذا كنت بحاجة إلى التبديل إلى أدلة أخرى، فيمكنك إضافة `-c <directory>`).

### 1. عرض عنوان العقدة المحلية وإعداد بطاقة العمل

```bash
# عرض عنوان العقدة المحلية (يتم إنشاء المفتاح تلقائيًا في ~/.config/sync0 لأول مرة)
sync0 id

# إنشاء بطاقة عمل عقدة شخصية (تدعم اسم المستخدم والمدينة والبريد الإلكتروني والموقع الإلكتروني والتوقيع في حدود 256 كلمة)
sync0 profile -u alice --region SHA --email alice@example.com --url https://example.com -b "Shanghai node"
```

### 2. نشر مجموعات متعددة لمشاركة الملفات وتعيين أذونات أعضاء المجموعة (`.nt` التكوين)

تم تكوين `sync0` بتنسيق [NestedText](https://nestedtext.org) (`.nt`). كل مستخدم لديه ملف تكوين `.nt` منفصل. يمكنك تحديد دليل ملف تعريف المستخدم من خلال `users_dir` في `config.nt` (والذي يتضمن تلقائيًا جميع ملفات `.nt` الموجودة في هذا الدليل). يستخدم كل من المستخدم وبادئة المسار المسموح بتحميلهما قائمة غير مرتبة (`-`). ** عندما لا يتم ملء بادئة مسار التحميل، يُسمح بالتحميل إلى الدليل الجذر للمشاركة بشكل افتراضي **.

1. قم بإنشاء ملفات تكوين `.nt` منفصلة لكل عضو في الدليل `~/.config/sync0/users/`:

`~/.config/sync0/users/alice.nt` (عضو للقراءة فقط، معدل محدود `80MB`، `rate` يدعم `GB`، `MB`، `KB` الوحدات):

```yaml
id: 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c
perm: ro
rate: 80MB
```

`~/.config/sync0/users/bob.nt` (أعضاء التحميل المقيدون: يُسمح لهم فقط بالتحميل إلى المجلدين `uploads/bob` و`shared/common`):

```yaml
id: 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f
perm: rw
write_prefix:
  - uploads/bob
  - shared/common
```

`~/.config/sync0/users/charlie.nt` (تحميل العضو الافتراضي: عند حذف `write_prefix`، يُسمح بالتحميل إلى الدليل الجذر للمشاركة افتراضيًا):

```yaml
id: 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
perm: rw
```

2. قم بتكوين دليل المستخدم ومجموعات مشاركة الملفات المتعددة في `~/.config/sync0/config.nt`:

```yaml
users_dir: ./users

groups:
  dataset:
    path: ./data
    auth: false
    perm: ro
    rate: 50MB

  models:
    path: ./models
    auth: false
    perm: ro
    rate: 1GB

  team-vault:
    path: ./vault
    auth: true
    perm: ro
    rate: 512KB
    users:
      - alice
      - bob
      - charlie
```

ابدأ خدمة المشاركة:

```bash
# بدء التشغيل المباشر (يقوم تلقائيًا بتحميل جميع تكوينات مستخدم .nt في مجلدات ~/.config/sync0/config.nt وusers_dir)
sync0 share --region SHA

# أو قم بنشر مجموعات مشاركة متعددة بسرعة وتفويض أعضاء المجموعة مباشرة من خلال سطر الأوامر
sync0 share dataset:./data team-vault:./vault \
  --auth \
  --allow-ro 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c \
  --allow-rw 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f:uploads/bob,shared/common \
  --allow-rw 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
```

### 3. سحب كل المحتوى أو تحديد ملفات وأدلة متعددة (`sync0 pull`)

اتصل بأي عقدة نظيرة للحصول تلقائيًا على جميع العقد الأولية المتاحة في مجموعة المشاركة، واسحب من العقد الأولية المتعددة بشكل متزامن:

```bash
# اسحب مجموعة مشاركة مجموعة البيانات بأكملها إلى ./local_data المحلي
sync0 سحب مجموعة البيانات::// ./local_data -p <عنوان العقدة>

# مزامنة التحديد المتعدد: اسحب في الوقت نفسه الملف الفردي docs/readme.md وأصول/أيقونات الدلائل الفرعية، src/core
sync0 سحب مجموعة البيانات://docs/readme.md,assets/icons,src/core ./local_data -p <عنوان العقدة>
```

### 4. تحميل ملف أو دليل إلى مجموعة مشاركة (`sync0 push`)

يمكن للأعضاء الذين لديهم أذونات التحميل (`rw` أو `admin`) تحميل الملفات أو الدلائل المحلية إلى مجموعات المشاركة عن بعد:

```bash
# الأعضاء الذين لديهم إذن تحميل الدليل الجذر: التحميل مباشرة إلى الدليل الجذر المشترك
sync0 دفع فريق vault:// ./new_release -p <عنوان العقدة>

# الأعضاء المسموح لهم فقط ببادئة محددة (مثل التحميلات/البوب): التحميل إلى بادئة المسار المسموح بها
sync0 Push-vault://uploads/bob/report.pdf ./report.pdf -p <عنوان العقدة>
```

### 5. الاشتراك في المزامنة التلقائية والبذر (`sync0 sub`)

بعد الاشتراك في مجموعة المشاركة لعقدة معينة، يصبح الخادم المحلي عميلًا متلقيًا وخادمًا جديدًا للتلقيح؛ عندما يتم تحديث ملف العقدة المصدر، تتم مزامنته تلقائيًا ويوفر تنزيلات مقسمة للعقد الأخرى:

```bash
# اشترك في مجموعة المشاركة بأكملها وقم بالبذور تلقائيًا
sync0 مجموعة البيانات الفرعية: // ./local_mirror -p <عنوان العقدة>

# فقط التحديد المتعدد للاشتراك في الملفات والأدلة الفرعية المحددة وزرعها
مجموعة البيانات الفرعية sync0://models/llama.onnx,configs ./local_mirror -p <عنوان العقدة>
```

### 6. مزامنة نظير مجموعة أجهزة متعددة (`sync0 group`)

تنضم أجهزة متعددة إلى نفس مجموعة المشاركة، ويكتشف بعضها البعض تلقائيًا العقد الأولية المتاحة ويحافظ على المزامنة ثنائية الاتجاه (يدعم المزامنة الكاملة أو التحديد المتعدد للملفات والأدلة):

```bash
# الانضمام الكامل إلى المجموعة والمزامنة في اتجاهين
sync0 group team-docs:// ./docs -p <عنوان العقدة>

# فقط دليل wal وملف meta.json موجودان في مجموعة المزامنة متعددة التحديد
sync0 group team-docs://wal,meta.json ./docs -p <عنوان العقدة>
```

### 7. النقل المباشر من نقطة إلى نقطة بين جهازين (`send` / `recv`)

ليست هناك حاجة لتكوين مجموعة مسبقًا، ويمكنك نقل الملفات أو الدلائل مؤقتًا مباشرة بين جهازين:

```bash
# مراقبة المتلقي
sync0 recv 0.0.0.0:9000 ./backup

# يقوم الطرف المرسل بنقل الملفات أو الدلائل مباشرة (اختياري --حذف المرآة لتنظيف الملفات الزائدة، --حد سرعة المعدل)
sync0 send ./project 192.168.1.10:9000
```

### 8. تبديل متعدد اللغات

`sync0` يدعم 75 لغة، ويتحول تلقائيًا وفقًا لبيئة لغة النظام بشكل افتراضي؛ ويمكن أيضًا تحديده يدويًا من خلال `SYNC0_LANG`:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
