# sync0

`sync0` هي أداة سطر أوامر لنقل الملفات عبر الشبكات، ومزامنة الدلائل بشكل متزايد، وتوزيع البيانات بشكل متزامن على أجهزة متعددة.

## نية التصميم الأصلي

في الغرف المشتركة بين الأجهزة، أو البلدان، أو البيئات التي تعاني من تأخيرات في الشبكة وفقدان الحزم، تعتمد الأدوات مثل `rsync` و`scp` على تأكيد تسلسل اتصال واحد، مما يحد من استخدام عرض النطاق الترددي؛ عندما تقوم أجهزة متعددة بسحب البيانات من نفس الخادم في نفس الوقت، يمكن أن تصبح بطاقة شبكة الخادم المصدر عنق الزجاجة بسهولة.

الهدف من `sync0` هو حل مشكلتين:

1. اسمح لمزامنة الملف والدليل بين الجهازين بتشغيل النطاق الترددي الفعلي الكامل، ونقل الجزء الذي تم تغييره فقط عندما يتم تعديل الملف جزئيًا.
2. يمكن لأجهزة متعددة نقل كتل البيانات إلى بعضها البعض عند مزامنة نفس الدليل، مما يقلل الحمل على الخادم المصدر ويقلل وقت المزامنة الإجمالي.

## مقارنة السرعة مع rsync

بيئة الاختبار: العقدة الأوروبية $\leftrightarrow$، عقدة أمريكا الشمالية، تأخير ذهابًا وإيابًا 86 مللي ثانية، قياس الوقت المستغرق بالكامل بما في ذلك فحص الدليل، ومقارنة إلغاء البيانات المكررة، ونقل الشبكة، والتحقق من وضع القرص:

| سيناريو الإرسال | حجم البيانات | `sync0` | `rsync` | عديد |
| :--- | :---: | :---: | :---: | :---: |
| 10.000 ملف صغير | 77.6 MB | 0.90 s (688 Mbps) | 4.86 s (128 Mbps) | 5.4x |
| حزم التعليمات البرمجية والأرشيف (`.tar`) | 512 MB | 1.94 s (2111 Mbps) | 9.36 s (438 Mbps) | 4.8x |
| ملف الفيديو (`.mp4`) | 512 MB | 7.36 s (556 Mbps) | 12.11 s (338 Mbps) | 1.6x |
| المزامنة المتزايدة (تعديل محتوى 1٪) | 512 MB | 0.12 s | 1.85 s | 15.4x |

## أساليب تحسين الأداء

- **الإرسال المتزامن لـ UDP**: أرسل كتل البيانات من خلال UDP، وأعد إرسال الأجزاء المفقودة فقط لتجنب فقدان حزمة واحدة مما يؤدي إلى حظر عمليات نقل الملفات اللاحقة.
- **تجزئة المحتوى وإلغاء البيانات المكررة**: قم بتقسيم الملف إلى كتل بيانات وفقًا للمحتوى وحساب قيمة التحقق. يتم إعادة استخدام نفس المحتوى الموجود بالفعل على الطرف المتلقي مباشرة محليًا دون تكرار الشبكة.
- **ضبط الضغط تلقائيًا وفقًا لسرعة الشبكة**: قم بتشغيل الضغط للمحتوى القابل للضغط مثل النص والتعليمات البرمجية؛ تخطي الضغط تلقائيًا لمقاطع الفيديو أو الصور أو الحزم المضغوطة أو ضمن شبكة LAN عالية السرعة لتقليل استهلاك وحدة المعالجة المركزية.
- **سحب قريب متعدد العقد**: عندما تسحب أجهزة متعددة نفس الدليل، سيتم سحب كتل البيانات بشكل متزامن من العقد التي تم تنزيلها في نفس المدينة أو بزمن وصول أقل.

## ثَبَّتَ

### الطريقة الأولى: التثبيت عبر Cargo

```bash
cargo install sync0
```

### الطريقة الثانية: تنزيل الثنائيات المترجمة مسبقًا

انتقل إلى [إصدارات GitHub](https://github.com/webc-site/sync0/releases) لتنزيل الحزمة المضغوطة `.tar.xz` للنظام المقابل (يدعم Linux x86_64/ARM64 وmacOS Apple Silicon/Intel وWindows x64/ARM64 وAndroid ARM64/x86_64 وFreeBSD وNetBSD). بعد فك الضغط، ضع `sync0` في الدليل `PATH`:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## دليل المستخدم

### 1. نقل الملفات أو الدلائل مباشرة بين جهازين

ابدأ المراقبة على جهاز الاستقبال وحدد مسار الاستلام والحفظ:

```bash
sync0 recv 0.0.0.0:9000 ./backup
```

أرسل ملفًا واحدًا أو دليلاً كاملاً من جهاز الإرسال:

```bash
sync0 send ./project 192.168.1.10:9000
```

المعلمات شائعة الاستخدام:

```bash
# حذف الملفات الزائدة الموجودة على الطرف المتلقي ولكن ليس على الطرف المرسل (مزامنة المرآة)
sync0 send ./project 192.168.1.10:9000 --delete

# الحد من معدل الإرسال (الوحدة: بايت/ثانية، على سبيل المثال 50 ميجابايت/ثانية)
sync0 send ./project 192.168.1.10:9000 --rate 50000000

# الوضع الصامت (لا يوجد شريط تقدم معروض)
sync0 send ./project 192.168.1.10:9000 -q
```

### 2. نشر الدلائل المشتركة والسحب من عقد متعددة

نشر دليل مشترك (يُسمى `dataset`) على الخادم الأصلي:

```bash
sync0 share dataset ./data --region SHA
```

اسحب الدليل المشترك على الأجهزة الأخرى (يمكنك ملء عناوين العقد المتعددة في نفس الوقت، مفصولة بفواصل للسحب بشكل متزامن):

```bash
sync0 pull 10.0.0.1:9000,10.0.0.2:9000 dataset ./local_data
```

اسحب دليلًا فرعيًا معينًا فقط في الدليل المشترك:

```bash
sync0 pull 10.0.0.1:9000 dataset ./local_data --subpath 2026/logs
```

ادفع التغييرات المحلية مرة أخرى إلى الدليل المشترك البعيد:

```bash
sync0 push 10.0.0.1:9000 dataset ./local_data
```

### 3. الاشتراك في التحديثات التلقائية للكتالوج

اشترك في الدليل المشترك للعقدة المصدر. عند إضافة ملف أو تعديله في الدليل المصدر، ستتم مزامنته تلقائيًا مع الكمبيوتر المحلي. في الوقت نفسه، ستعمل الآلة المحلية تلقائيًا كعقدة يمكن للأجهزة الأخرى سحبها:

```bash
sync0 sub 10.0.0.1:9000 dataset ./local_mirror
```

### 4. مزامنة ثنائية الاتجاه لمجموعات متعددة الأجهزة

تنضم أجهزة متعددة إلى نفس اسم المجموعة، وستتم مزامنة التغييرات في أي دليل عقدة تلقائيًا مع العقد الأخرى في المجموعة:

```bash
sync0 group team-docs ./docs 10.0.0.1:9000,10.0.0.2:9000
```

### 5. هوية العقدة وبطاقة العمل الشخصية

تدعم كل عقدة تعيين اسم المستخدم والمدينة والبريد الإلكتروني والموقع الإلكتروني والتوقيع الشخصي (بحد أقصى 256 حرفًا)، وتمرير مصادقة توقيع المفتاح الخاص المحلي:

```bash
# عرض معرف المفتاح العام المحلي (حدد دليل التكوين للاستمرار في المفتاح)
sync0 id -c ~/.config/sync0

# إنشاء وعرض بطاقات عمل العقدة مع التوقيعات الشخصية
sync0 profile -c ~/.config/sync0 \
  -u alice \
  --region SHA \
  --email alice@example.com \
  --url https://example.com \
  -b "Shanghai backup node"
```

يمكن أيضًا إطلاق `share`، `pull`، `sub`، `group` باستخدام معلمات ملف التعريف هذه:

```bash
sync0 share dataset ./data -c ~/.config/sync0 -u alice --region SHA -b "Shanghai backup node"
```

### 6. تبديل متعدد اللغات

`sync0` يدعم 75 لغة. افتراضيًا، يتم عرض تعليمات سطر الأوامر والمطالبات باللغة المقابلة تلقائيًا وفقًا لبيئة اللغة الخاصة بنظام التشغيل؛ إذا لم تكن لغة النظام مدرجة في القائمة المدعومة، فسيتم استخدام اللغة الإنجليزية بشكل افتراضي.

لتحديد اللغة يدويًا، قم بتعيين متغير البيئة `SYNC0_LANG`:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
