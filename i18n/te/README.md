# sync0

`sync0` అనేది నెట్‌వర్క్‌ల అంతటా ఫైల్‌లను బదిలీ చేయడానికి, డైరెక్టరీలను క్రమంగా సమకాలీకరించడానికి మరియు బహుళ మెషీన్‌లకు ఏకకాలంలో డేటాను పంపిణీ చేయడానికి కమాండ్ లైన్ సాధనం.

## అసలు డిజైన్ ఉద్దేశం

నెట్‌వర్క్ ఆలస్యం మరియు ప్యాకెట్ నష్టంతో క్రాస్-మెషిన్ గదులు, దేశాలు లేదా పరిసరాలలో, `rsync` మరియు `scp` వంటి సాధనాలు బ్యాండ్‌విడ్త్ వినియోగాన్ని పరిమితం చేసే సింగిల్ కనెక్షన్ సీక్వెన్స్ నిర్ధారణపై ఆధారపడి ఉంటాయి; బహుళ యంత్రాలు ఒకే సర్వర్ నుండి ఒకే సమయంలో డేటాను లాగినప్పుడు, సోర్స్ సర్వర్ నెట్‌వర్క్ కార్డ్ సులభంగా అడ్డంకిగా మారుతుంది.

`sync0` యొక్క లక్ష్యం రెండు సమస్యలను పరిష్కరించడం:

1. రెండు మెషీన్‌ల మధ్య ఫైల్ మరియు డైరెక్టరీ సింక్రొనైజేషన్ పూర్తి భౌతిక బ్యాండ్‌విడ్త్‌ను అమలు చేయనివ్వండి మరియు ఫైల్ పాక్షికంగా సవరించబడినప్పుడు మాత్రమే మార్చబడిన భాగాన్ని బదిలీ చేయండి.
2. ఒకే డైరెక్టరీని సమకాలీకరించేటప్పుడు, సోర్స్ సర్వర్‌పై లోడ్‌ను తగ్గించడం మరియు మొత్తం సమకాలీకరణ సమయాన్ని తగ్గించడం ద్వారా బహుళ యంత్రాలు డేటా బ్లాక్‌లను ఒకదానికొకటి బదిలీ చేయగలవు.

## rsync తో వేగం పోలిక

పరీక్షా వాతావరణం: యూరోపియన్ నోడ్ $\leftrightarrow$ ఉత్తర అమెరికా నోడ్, రౌండ్-ట్రిప్ ఆలస్యం 86 ms, డైరెక్టరీ స్కానింగ్, డీప్లికేషన్ పోలిక, నెట్‌వర్క్ ట్రాన్స్‌మిషన్ మరియు డిస్క్ ప్లేస్‌మెంట్ ధృవీకరణతో సహా పూర్తి సమయం తీసుకుంటుంది:

| ప్రసార దృశ్యం | డేటా పరిమాణం | `sync0` | `rsync` | బహుళ |
| :--- | :---: | :---: | :---: | :---: |
| 10,000 చిన్న ఫైళ్లు | 77.6 MB | 0.90 s (688 Mbps) | 4.86 s (128 Mbps) | 5.4x |
| కోడ్ మరియు ఆర్కైవ్ ప్యాకేజీలు (`.tar`) | 512 MB | 1.94 s (2111 Mbps) | 9.36 s (438 Mbps) | 4.8x |
| వీడియో ఫైల్ (`.mp4`) | 512 MB | 7.36 s (556 Mbps) | 12.11 s (338 Mbps) | 1.6x |
| ఇంక్రిమెంటల్ సింక్రొనైజేషన్ (1% కంటెంట్‌ని సవరించండి) | 512 MB | 0.12 s | 1.85 s | 15.4x |

## పనితీరు మెరుగుదల పద్ధతులు

- **UDP ఏకకాల ప్రసారం**: UDP ద్వారా డేటా బ్లాక్‌లను పంపండి మరియు తదుపరి ఫైల్ బదిలీలను నిరోధించే ఒకే ప్యాకెట్ నష్టాన్ని నివారించడానికి కోల్పోయిన శకలాలను మాత్రమే తిరిగి ప్రసారం చేయండి.
- **కంటెంట్ సెగ్మెంటేషన్ మరియు తగ్గింపు**: కంటెంట్ ప్రకారం ఫైల్‌ను డేటా బ్లాక్‌లుగా విభజించండి మరియు చెక్ విలువను లెక్కించండి. ఇప్పటికే స్వీకరించే ముగింపులో ఉన్న అదే కంటెంట్ నెట్‌వర్క్‌ను నకిలీ చేయకుండా నేరుగా స్థానికంగా మళ్లీ ఉపయోగించబడుతుంది.
- ** నెట్‌వర్క్ వేగం ప్రకారం కంప్రెషన్‌ను స్వయంచాలకంగా సర్దుబాటు చేయండి**: టెక్స్ట్ మరియు కోడ్ వంటి కంప్రెసిబుల్ కంటెంట్ కోసం కంప్రెషన్‌ను ఆన్ చేయండి; CPU వినియోగాన్ని తగ్గించడానికి వీడియోలు, చిత్రాలు, కంప్రెస్డ్ ప్యాకేజీలు లేదా హై-స్పీడ్ LAN కోసం కంప్రెషన్‌ను స్వయంచాలకంగా దాటవేయండి.
- **మల్టీ-నోడ్ సమీపంలోని లాగడం**: బహుళ యంత్రాలు ఒకే డైరెక్టరీని లాగినప్పుడు, అదే నగరంలో లేదా తక్కువ జాప్యంతో డౌన్‌లోడ్ చేయబడిన నోడ్‌ల నుండి డేటా బ్లాక్‌లు ఏకకాలంలో లాగబడతాయి.

## ఇన్‌స్టాల్ చేయండి

### విధానం 1: కార్గో ద్వారా ఇన్‌స్టాల్ చేయండి

```bash
cargo install sync0
```

### విధానం 2: ప్రీకంపైల్డ్ బైనరీలను డౌన్‌లోడ్ చేయండి

సంబంధిత సిస్టమ్ కోసం `.tar.xz` కంప్రెస్డ్ ప్యాకేజీని డౌన్‌లోడ్ చేయడానికి [GitHub విడుదలలు](https://github.com/webc-site/sync0/releases)కి వెళ్లండి (Linux x86_64/ARM64, macOS Apple Silicon/Intel, Windows x64/ARM64, Android ARM64/x86_64, NetBSD, FreeBSDకి మద్దతు ఇస్తుంది). అన్జిప్ చేసిన తర్వాత, `sync0`ని `PATH` డైరెక్టరీలో ఉంచండి:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## వినియోగదారు గైడ్

### 1. రెండు మెషీన్‌ల మధ్య ఫైల్‌లు లేదా డైరెక్టరీలను నేరుగా బదిలీ చేయండి

స్వీకరించే యంత్రంపై పర్యవేక్షణ ప్రారంభించండి మరియు స్వీకరించే మరియు సేవ్ చేసే మార్గాన్ని పేర్కొనండి:

```bash
sync0 recv 0.0.0.0:9000 ./backup
```

పంపే యంత్రం నుండి ఒకే ఫైల్ లేదా మొత్తం డైరెక్టరీని పంపండి:

```bash
sync0 send ./project 192.168.1.10:9000
```

సాధారణంగా ఉపయోగించే పారామితులు:

```bash
# రిసీవింగ్ ఎండ్‌లో ఉన్న రిడెండెంట్ ఫైల్‌లను తొలగించండి కానీ పంపే చివరలో కాదు (మిర్రర్ సింక్రొనైజేషన్)
sync0 send ./project 192.168.1.10:9000 --delete

# పంపే రేటును పరిమితం చేయండి (యూనిట్: బైట్లు/సెకను, ఉదాహరణకు 50 MB/s)
sync0 send ./project 192.168.1.10:9000 --rate 50000000

# సైలెంట్ మోడ్ (ప్రోగ్రెస్ బార్ చూపబడలేదు)
sync0 send ./project 192.168.1.10:9000 -q
```

### 2. భాగస్వామ్య డైరెక్టరీలను ప్రచురించడం మరియు బహుళ నోడ్‌ల నుండి లాగడం

మూలం సర్వర్‌లో భాగస్వామ్య డైరెక్టరీని (`dataset` పేరుతో) ప్రచురించండి:

```bash
sync0 share dataset ./data --region SHA
```

ఇతర మెషీన్‌లలో భాగస్వామ్య డైరెక్టరీని లాగండి (మీరు ఒకే సమయంలో బహుళ నోడ్ చిరునామాలను పూరించవచ్చు, ఏకకాలంలో లాగడానికి కామాలతో వేరు చేయవచ్చు):

```bash
sync0 pull 10.0.0.1:9000,10.0.0.2:9000 dataset ./local_data
```

భాగస్వామ్య డైరెక్టరీలో నిర్దిష్ట ఉప డైరెక్టరీని మాత్రమే లాగండి:

```bash
sync0 pull 10.0.0.1:9000 dataset ./local_data --subpath 2026/logs
```

స్థానిక మార్పులను రిమోట్ భాగస్వామ్య డైరెక్టరీకి తిరిగి పుష్ చేయండి:

```bash
sync0 push 10.0.0.1:9000 dataset ./local_data
```

### 3. కేటలాగ్ ఆటోమేటిక్ అప్‌డేట్‌లకు సభ్యత్వం పొందండి

సోర్స్ నోడ్ యొక్క భాగస్వామ్య డైరెక్టరీకి సభ్యత్వం పొందండి. సోర్స్ డైరెక్టరీలో ఫైల్ జోడించబడినప్పుడు లేదా సవరించబడినప్పుడు, అది స్వయంచాలకంగా స్థానిక కంప్యూటర్‌కు సమకాలీకరించబడుతుంది. అదే సమయంలో, ఇతర యంత్రాలు లాగడానికి స్థానిక యంత్రం స్వయంచాలకంగా నోడ్‌గా పనిచేస్తుంది:

```bash
sync0 sub 10.0.0.1:9000 dataset ./local_mirror
```

### 4. బహుళ-యంత్ర సమూహాల యొక్క రెండు-మార్గం సమకాలీకరణ

బహుళ యంత్రాలు ఒకే సమూహం పేరులో చేరతాయి మరియు ఏదైనా నోడ్ డైరెక్టరీలో మార్పులు స్వయంచాలకంగా సమూహంలోని ఇతర నోడ్‌లకు సమకాలీకరించబడతాయి:

```bash
sync0 group team-docs ./docs 10.0.0.1:9000,10.0.0.2:9000
```

### 5. నోడ్ గుర్తింపు మరియు వ్యక్తిగత వ్యాపార కార్డ్

ప్రతి నోడ్ వినియోగదారు పేరు, నగరం, ఇమెయిల్, వెబ్‌సైట్ మరియు వ్యక్తిగతీకరించిన సంతకాన్ని (గరిష్టంగా 256 అక్షరాలు) సెట్ చేయడానికి మద్దతు ఇస్తుంది మరియు స్థానిక ప్రైవేట్ కీ సంతకం ప్రమాణీకరణను పాస్ చేస్తుంది:

```bash
# స్థానిక పబ్లిక్ కీ IDని వీక్షించండి (కీని కొనసాగించడానికి కాన్ఫిగరేషన్ డైరెక్టరీని పేర్కొనండి)
sync0 id -c ~/.config/sync0

# వ్యక్తిగతీకరించిన సంతకాలతో నోడ్ వ్యాపార కార్డ్‌లను రూపొందించండి మరియు ప్రదర్శించండి
sync0 profile -c ~/.config/sync0 \
  -u alice \
  --region SHA \
  --email alice@example.com \
  --url https://example.com \
  -b "Shanghai backup node"
```

`share`, `pull`, `sub`, `group`ని కూడా ఈ ప్రొఫైల్ పారామితులతో ప్రారంభించవచ్చు:

```bash
sync0 share dataset ./data -c ~/.config/sync0 -u alice --region SHA -b "Shanghai backup node"
```

### 6. బహుళ-భాష మార్పిడి

`sync0` 75 భాషలకు మద్దతు ఇస్తుంది. డిఫాల్ట్‌గా, ఆపరేటింగ్ సిస్టమ్ యొక్క భాషా వాతావరణం ప్రకారం సంబంధిత భాషలో కమాండ్ లైన్ సహాయం మరియు ప్రాంప్ట్‌లు స్వయంచాలకంగా ప్రదర్శించబడతాయి; సిస్టమ్ భాష మద్దతు ఉన్న జాబితాలో లేకుంటే, డిఫాల్ట్‌గా ఇంగ్లీష్ ఉపయోగించబడుతుంది.

భాషను మాన్యువల్‌గా పేర్కొనడానికి, ఎన్విరాన్‌మెంట్ వేరియబుల్ `SYNC0_LANG`ని సెట్ చేయండి:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
