# sync0

`sync0` అనేది పీర్-టు-పీర్ (P2P) ఫైల్ షేరింగ్ మరియు రెసిలియో సింక్‌తో పోటీపడే బహుళ-మెషిన్ సింక్రొనైజేషన్ సాధనం.

ప్రతి యంత్రం సర్వర్ మరియు క్లయింట్ రెండూ: ఏదైనా నోడ్ బహుళ ఫైల్ షేరింగ్ సమూహాలను ప్రచురించగలదు. ఇతర నోడ్‌లు చేరిన తర్వాత, వారు స్వయంచాలకంగా పీర్ సర్వర్ నుండి అందుబాటులో ఉన్న సీడ్ నోడ్‌లను పొందవచ్చు మరియు వాటిని బహుళ మూలాల నుండి ఏకకాలంలో లాగవచ్చు. సింక్రొనైజేషన్ పూర్తయిన తర్వాత, డౌన్‌లోడ్‌లను వేగవంతం చేయడానికి మరిన్ని నోడ్‌ల కోసం విత్తనాలు స్వయంచాలకంగా సృష్టించబడతాయి.

## కోర్ ముఖ్యాంశాలు

- **ప్రతి ఒక్కరు సర్వర్ మరియు క్లయింట్**: Resilio సమకాలీకరణతో పోల్చవచ్చు, సెంట్రల్ సర్వర్ డిపెండెన్సీ లేదు. ఏదైనా నోడ్ బహుళ ఫైల్ షేరింగ్ సమూహాలను సృష్టించగలదు మరియు ఇతరుల భాగస్వామ్య సమూహాలలో కూడా చేరవచ్చు; నోడ్‌లు స్వయంచాలకంగా మార్పిడి మరియు బహుళ యంత్రాల యొక్క ఏకకాలిక లాగడం మరియు నిజ-సమయ సమకాలీకరణను సాధించడానికి అందుబాటులో ఉన్న సీడ్ నోడ్‌లను పొందుతాయి.
- **IP-రహిత నోడ్ చిరునామా**: డిఫాల్ట్‌గా, నోడ్ కీ మరియు `base64url` ఎన్‌కోడ్ చేసిన `iroh` చిరునామాలు పబ్లిక్ IPని గుర్తుంచుకోవాల్సిన అవసరం లేకుండా లేదా బహిర్గతం చేయకుండా `~/.config/sync0`లో స్వయంచాలకంగా రూపొందించబడతాయి.
- **డిమాండ్‌పై బహుళ-ఎంపిక సమకాలీకరణ**: మొత్తం భాగస్వామ్య సమూహం యొక్క సమకాలీకరణకు మద్దతు ఇస్తుంది మరియు అదే సమయంలో బహుళ ఫైల్‌లు లేదా ఉప డైరెక్టరీలను ఎంచుకోవడం ద్వారా డిమాండ్‌పై సమకాలీకరణకు కూడా మద్దతు ఇస్తుంది.
- **సమూహ సభ్యుల క్రమానుగత అనుమతులు మరియు అప్‌లోడ్ డైరెక్టరీ నియంత్రణ**: చదవడానికి-మాత్రమే (`ro`), రీడ్-రైట్ అప్‌లోడ్ (`rw`), మరియు నిర్వహణ (`admin`) అనుమతులకు మద్దతు ఇస్తుంది మరియు ప్రతి సభ్యుడు రూట్‌ను అప్‌లోడ్ చేయడానికి అనుమతించబడిన రూట్ ప్రిఫిక్స్‌ను వ్యక్తిగతంగా పేర్కొనవచ్చు (డిఫాల్ట్‌గా అప్‌లోడ్ చేయడం ద్వారా).
- **నెట్‌వర్క్‌లలో పూర్తి-స్పీడ్ మరియు ఇంక్రిమెంటల్ సింక్రొనైజేషన్**: పెద్ద ఫైల్‌ల ఏకకాల ప్రసారం, మెమరీలో భారీ చిన్న ఫైల్‌ల సముదాయం మరియు ఫైల్‌లు పాక్షికంగా సవరించబడినప్పుడు మాత్రమే సమకాలీకరించబడిన డేటా బ్లాక్‌లు.

## ఇన్‌స్టాల్ చేయండి

### విధానం 1: కార్గో ద్వారా ఇన్‌స్టాల్ చేయండి

```bash
cargo install sync0
```

### విధానం 2: ప్రీకంపైల్డ్ బైనరీలను డౌన్‌లోడ్ చేయండి

సంబంధిత సిస్టమ్ (Linux, macOS, Windows, Android, FreeBSD, NetBSDకి మద్దతు ఇస్తుంది) కోసం `.tar.xz` కంప్రెస్డ్ ప్యాకేజీని డౌన్‌లోడ్ చేయడానికి [GitHub Releases](https://github.com/webc-site/sync0/releases)కి వెళ్లండి, అన్జిప్ చేసి, `PATH` డైరెక్టరీలో ఉంచండి:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## త్వరగా ప్రారంభించండి

`sync0` డిఫాల్ట్‌గా `~/.config/sync0`ని కాన్ఫిగరేషన్ డైరెక్టరీగా ఉపయోగిస్తుంది (మీరు ఇతర డైరెక్టరీలకు మారాలంటే, మీరు `-c <directory>`ని జోడించవచ్చు).

### 1. స్థానిక నోడ్ చిరునామా మరియు సెట్టింగ్ వ్యాపార కార్డ్‌ని వీక్షించండి

```bash
# స్థానిక నోడ్ చిరునామాను వీక్షించండి (కీ మొదటిసారిగా ~/.config/sync0లో స్వయంచాలకంగా రూపొందించబడింది)
sync0 id

# వ్యక్తిగత నోడ్ వ్యాపార కార్డ్‌ను రూపొందించండి (256 పదాలలో వినియోగదారు పేరు, నగరం, ఇమెయిల్, వెబ్‌సైట్ మరియు సంతకానికి మద్దతు ఇస్తుంది)
sync0 profile -u alice --region SHA --email alice@example.com --url https://example.com -b "Shanghai node"
```

### 2. బహుళ ఫైల్ షేరింగ్ సమూహాలను ప్రచురించండి మరియు సమూహ సభ్యుల అనుమతులను సెట్ చేయండి (`.nt` కాన్ఫిగరేషన్)

`sync0` [NestedText](https://nestedtext.org) (`.nt`) ఫార్మాట్‌లో కాన్ఫిగర్ చేయబడింది. ప్రతి వినియోగదారుకు ప్రత్యేక `.nt` కాన్ఫిగరేషన్ ఫైల్ ఉంటుంది. మీరు `config.nt`లో `users_dir` ద్వారా వినియోగదారు ప్రొఫైల్ డైరెక్టరీని పేర్కొనవచ్చు (ఈ డైరెక్టరీలోని అన్ని `.nt` ఫైల్‌లు స్వయంచాలకంగా ఉంటాయి). అప్‌లోడ్ చేయడానికి అనుమతించబడిన వినియోగదారు మరియు పాత్ ప్రిఫిక్స్ రెండూ క్రమం లేని జాబితాను ఉపయోగిస్తాయి (`-`). ** అప్‌లోడ్ పాత్ ప్రిఫిక్స్ పూరించబడనప్పుడు, షేర్ యొక్క రూట్ డైరెక్టరీకి అప్‌లోడ్ చేయడం డిఫాల్ట్‌గా అనుమతించబడుతుంది**.

1. `~/.config/sync0/users/` డైరెక్టరీలో ప్రతి సభ్యునికి ప్రత్యేక `.nt` కాన్ఫిగరేషన్ ఫైల్‌లను సృష్టించండి:

`~/.config/sync0/users/alice.nt` (చదవడానికి-మాత్రమే సభ్యుడు, రేట్ పరిమితం `80MB`, `rate` `GB`, `MB`, `KB` యూనిట్‌లకు మద్దతు ఇస్తుంది):

```yaml
id: 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c
perm: ro
rate: 80MB
```

`~/.config/sync0/users/bob.nt` (పరిమితం చేయబడిన అప్‌లోడ్ సభ్యులు: `uploads/bob` మరియు `shared/common` డైరెక్టరీలకు మాత్రమే అప్‌లోడ్ చేయడానికి అనుమతించబడతారు):

```yaml
id: 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f
perm: rw
write_prefix:
  - uploads/bob
  - shared/common
```

`~/.config/sync0/users/charlie.nt` (డిఫాల్ట్ మెంబర్ అప్‌లోడ్: `write_prefix` విస్మరించబడినప్పుడు, షేర్ యొక్క రూట్ డైరెక్టరీకి అప్‌లోడ్ చేయడం డిఫాల్ట్‌గా అనుమతించబడుతుంది):

```yaml
id: 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
perm: rw
```

2. `~/.config/sync0/config.nt`లో వినియోగదారు డైరెక్టరీ మరియు బహుళ ఫైల్ షేరింగ్ సమూహాలను కాన్ఫిగర్ చేయండి:

```yaml
users_dir: ./users

groups:
  dataset:
    path: ./data
    auth: false
    perm: ro
    rate: 50MB

  models:
    path: ./models
    auth: false
    perm: ro
    rate: 1GB

  team-vault:
    path: ./vault
    auth: true
    perm: ro
    rate: 512KB
    users:
      - alice
      - bob
      - charlie
```

సేవను భాగస్వామ్యం చేయడం ప్రారంభించండి:

```bash
# డైరెక్ట్ స్టార్టప్ (~/.config/sync0/config.nt మరియు users_dir డైరెక్టరీలలో అన్ని .nt వినియోగదారు కాన్ఫిగరేషన్‌లను స్వయంచాలకంగా లోడ్ చేస్తుంది)
sync0 share --region SHA

# లేదా బహుళ భాగస్వామ్య సమూహాలను త్వరగా ప్రచురించండి మరియు కమాండ్ లైన్ ద్వారా నేరుగా సమూహ సభ్యులకు అధికారం ఇవ్వండి
```

### 3. మొత్తం కంటెంట్‌ని లాగండి లేదా బహుళ ఫైల్‌లు మరియు డైరెక్టరీలను ఎంచుకోండి (`sync0 pull`)

షేరింగ్ గ్రూప్‌లో అందుబాటులో ఉన్న అన్ని సీడ్ నోడ్‌లను స్వయంచాలకంగా పొందేందుకు ఏదైనా పీర్ నోడ్‌కి కనెక్ట్ చేయండి మరియు ఏకకాలంలో బహుళ సీడ్ నోడ్‌ల నుండి లాగండి:

```bash
# మొత్తం డేటాసెట్ షేరింగ్ గ్రూప్‌ను లోకల్ ./local_dataకి లాగండి
sync0 pull dataset:// ./local_data -p <node address>

# బహుళ-ఎంపిక సమకాలీకరణ: ఏకకాలంలో ఒకే ఫైల్ docs/readme.md మరియు ఉప డైరెక్టరీలు ఆస్తులు/చిహ్నాలు, src/core లాగండి
sync0 pull dataset://docs/readme.md,assets/icons,src/core ./local_data -p <node address>
```

### 4. భాగస్వామ్య సమూహానికి ఫైల్ లేదా డైరెక్టరీని అప్‌లోడ్ చేయండి (`sync0 push`)

అప్‌లోడ్ అనుమతులు కలిగిన సభ్యులు (`rw` లేదా `admin`) స్థానిక ఫైల్‌లు లేదా డైరెక్టరీలను రిమోట్ షేరింగ్ గ్రూపులకు అప్‌లోడ్ చేయవచ్చు:

```bash
# రూట్ డైరెక్టరీ అప్‌లోడ్ అనుమతి ఉన్న సభ్యులు: షేర్ చేసిన రూట్ డైరెక్టరీకి నేరుగా అప్‌లోడ్ చేయండి
sync0 push team-vault:// ./new_release -p <node address>

# నిర్దిష్ట ఉపసర్గకు (అప్‌లోడ్‌లు/బాబ్ వంటివి) అధికారం కలిగిన సభ్యులు మాత్రమే: అనుమతించబడిన పాత్ ప్రిఫిక్స్‌కి అప్‌లోడ్ చేయండి
sync0 push team-vault://uploads/bob/report.pdf ./report.pdf -p <node address>
```

### 5. స్వయంచాలక సమకాలీకరణ మరియు సీడింగ్‌కు సభ్యత్వం పొందండి (`sync0 sub`)

నిర్దిష్ట నోడ్ యొక్క భాగస్వామ్య సమూహానికి సభ్యత్వాన్ని పొందిన తర్వాత, స్థానిక సర్వర్ స్వీకరించే క్లయింట్ మరియు కొత్త సీడింగ్ సర్వర్; సోర్స్ నోడ్ ఫైల్ నవీకరించబడినప్పుడు, అది స్వయంచాలకంగా సమకాలీకరించబడుతుంది మరియు ఇతర నోడ్‌ల కోసం చంక్డ్ డౌన్‌లోడ్‌లను అందిస్తుంది:

```bash
# మొత్తం భాగస్వామ్య సమూహానికి సభ్యత్వాన్ని పొందండి మరియు స్వయంచాలకంగా సీడ్ చేయండి
sync0 sub dataset:// ./local_mirror -p <node address>

# పేర్కొన్న ఫైల్‌లు మరియు సబ్‌డైరెక్టరీలకు సబ్‌స్క్రైబ్ చేయడానికి మరియు వాటిని సీడ్ చేయడానికి బహుళ-ఎంపిక మాత్రమే
sync0 sub dataset://models/llama.onnx,configs ./local_mirror -p <node address>
```

### 6. మల్టీ-మెషిన్ గ్రూప్ పీర్ సింక్రొనైజేషన్ (`sync0 group`)

బహుళ యంత్రాలు ఒకే భాగస్వామ్య సమూహంలో చేరతాయి, ఒకదానికొకటి స్వయంచాలకంగా అందుబాటులో ఉన్న సీడ్ నోడ్‌లను కనుగొంటుంది మరియు రెండు-మార్గం సమకాలీకరణను నిర్వహిస్తుంది (పూర్తి సమకాలీకరణ లేదా ఫైల్‌లు మరియు డైరెక్టరీల బహుళ ఎంపికకు మద్దతు ఇస్తుంది):

```bash
# సమూహం మరియు రెండు-మార్గం సమకాలీకరణలో పూర్తిగా చేరండి
sync0 group team-docs:// ./docs -p <node address>

# బహుళ-ఎంపిక సమకాలీకరణ సమూహంలో wal డైరెక్టరీ మరియు meta.json ఫైల్ మాత్రమే
sync0 group team-docs://wal,meta.json ./docs -p <node address>
```

### 7. రెండు యంత్రాల మధ్య పాయింట్-టు-పాయింట్ డైరెక్ట్ ట్రాన్స్‌మిషన్ (`send` / `recv`)

సమూహాన్ని ముందుగా కాన్ఫిగర్ చేయవలసిన అవసరం లేదు మరియు మీరు తాత్కాలికంగా ఫైల్‌లు లేదా డైరెక్టరీలను నేరుగా రెండు మెషీన్‌ల మధ్య బదిలీ చేయవచ్చు:

```bash
# రిసీవర్ పర్యవేక్షణ
sync0 recv 0.0.0.0:9000 ./backup

# పంపే ముగింపు నేరుగా ఫైల్‌లు లేదా డైరెక్టరీలను బదిలీ చేస్తుంది (అదనపు ఫైల్‌లను శుభ్రం చేయడానికి ఐచ్ఛికం --డిలీట్ మిర్రర్, --రేట్ వేగ పరిమితి)
sync0 send ./project 192.168.1.10:9000
```

### 8. బహుళ-భాష మార్పిడి

`sync0` 75 భాషలకు మద్దతు ఇస్తుంది మరియు డిఫాల్ట్‌గా సిస్టమ్ భాషా వాతావరణం ప్రకారం స్వయంచాలకంగా మారుతుంది; దీన్ని `SYNC0_LANG` ద్వారా మాన్యువల్‌గా కూడా పేర్కొనవచ్చు:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
