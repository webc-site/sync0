# sync0

<б ид="1"> је алатка командне линије за пренос датотека преко мрежа, постепено синхронизовање директоријума и истовремену дистрибуцију података на више машина.

## Оригинална намера дизајна

У више-машинским собама, земљама или окружењима са кашњењима на мрежи и губитком пакета, алати као што су <б ид="1"> и <б ид="2"> се заснивају на једној потврди секвенце везе, што ограничава коришћење пропусног опсега; када више машина повлачи податке са истог сервера у исто време, мрежна картица изворног сервера може лако постати уско грло.

Циљ <б ид="1"> је да реши два проблема:

1. Нека синхронизација датотека и директоријума између две машине ради пуну физичку пропусност и пренесите промењени део само када је датотека делимично измењена.
2. Више машина може да преноси блокове података један другом приликом синхронизације истог директоријума, смањујући оптерећење на изворном серверу и скраћујући укупно време синхронизације.

## Поређење брзине са рсинц-ом

Тестно окружење: европски чвор $\лефтригхтарров$ северноамерички чвор, кашњење повратног пута 86 мс, мерење потпуног времена, укључујући скенирање директоријума, поређење дедупликације, мрежни пренос и верификацију постављања диска:

| Сценарио преноса | Величина података | `sync0` | `rsync` | вишеструко |
| :--- | :---: | :---: | :---: | :---: |
| 10.000 малих фајлова | 77.6 MB | 0.90 s (688 Mbps) | 4.86 s (128 Mbps) | 5.4x |
| Код и архивски пакети (<б ид="1">) | 512 MB | 1.94 s (2111 Mbps) | 9.36 s (438 Mbps) | 4.8x |
| Видео датотека (<б ид="1">) | 512 MB | 7.36 s (556 Mbps) | 12.11 s (338 Mbps) | 1.6x |
| Инкрементална синхронизација (измени 1% садржаја) | 512 MB | 0.12 s | 1.85 s | 15.4x |

## Методе побољшања перформанси

- **УДП истовремени пренос**: Шаљите блокове података преко УДП-а и поново преносите само изгубљене фрагменте да бисте избегли губитак једног пакета који блокира наредне преносе датотека.
- **Сегментација садржаја и дедупликација**: Поделите датотеку на блокове података према садржају и израчунајте вредност провере. Исти садржај који се већ налази на пријемној страни се поново користи директно локално без дуплирања мреже.
- **Аутоматски прилагодите компресију према брзини мреже**: Укључите компресију за садржај који се може компресовати као што су текст и код; аутоматски прескочи компресију за видео записе, слике, компримоване пакете или под брзим ЛАН-ом да смањи потрошњу процесора.
- **Повлачење са више чворова у близини**: Када више машина повлачи исти директоријум, блокови података ће се истовремено повлачити са преузетих чворова у истом граду или са мањим кашњењем.

## Инсталирај

### Метод 1: Инсталирајте преко Царго-а

```bash
cargo install sync0
```

### Метод 2: Преузмите унапред компајлиране бинарне датотеке

Идите на [ГитХуб Релеасес](https://github.com/webc-site/sync0/releases) да преузмете <б ид="2"> компримовани пакет за одговарајући систем (подржава Линук к86_64/АРМ64, мацОС Аппле Силицон/Интел, Виндовс к64/АРМ64, Андроид АРМ64/к86_64, ФрееБСД, НетБСД). Након распакивања, ставите <б ид="3"> у директоријум <б ид="4">:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## Упутство за употребу

### 1. Директно преносите датотеке или директоријуме између две машине

Започните праћење на пријемној машини и одредите путању за пријем и чување:

```bash
sync0 recv 0.0.0.0:9000 ./backup
```

Пошаљите једну датотеку или цео директоријум са машине за слање:

```bash
sync0 send ./project 192.168.1.10:9000
```

Често коришћени параметри:

```bash
# Избришите сувишне датотеке које постоје на пријемној страни, али не и на крају за слање (зрцална синхронизација)
sync0 send ./project 192.168.1.10:9000 --delete

# Ограничите брзину слања (јединица: бајтова у секунди, на пример 50 МБ/с)
sync0 send ./project 192.168.1.10:9000 --rate 50000000

# Нечујни режим (није приказана трака напретка)
sync0 send ./project 192.168.1.10:9000 -q
```

### 2. Објављивање дељених директоријума и повлачење са више чворова

Објавите дељени директоријум (назван <б ид="1">) на изворном серверу:

```bash
sync0 share dataset ./data --region SHA
```

Повуците дељени директоријум на другим машинама (можете да унесете више адреса чворова у исто време, раздвојених зарезима да бисте истовремено повукли):

```bash
sync0 pull 10.0.0.1:9000,10.0.0.2:9000 dataset ./local_data
```

Повуците само одређени поддиректоријум у дељеном директоријуму:

```bash
sync0 pull 10.0.0.1:9000 dataset ./local_data --subpath 2026/logs
```

Вратите локалне промене у удаљени дељени директоријум:

```bash
sync0 push 10.0.0.1:9000 dataset ./local_data
```

### 3. Претплатите се на аутоматска ажурирања каталога

Претплатите се на дељени директоријум изворног чвора. Када се датотека дода или измени у изворном директоријуму, она ће се аутоматски синхронизовати са локалним рачунаром. У исто време, локална машина ће аутоматски служити као чвор за друге машине за повлачење:

```bash
sync0 sub 10.0.0.1:9000 dataset ./local_mirror
```

### 4. Двосмерна синхронизација вишемашинских група

Више машина се придружује истом имену групе, а промене у било ком директоријуму чворова ће се аутоматски синхронизовати са другим чворовима у групи:

```bash
sync0 group team-docs ./docs 10.0.0.1:9000,10.0.0.2:9000
```

### 5. Идентитет чвора и лична визит карта

Сваки чвор подржава подешавање корисничког имена, града, е-поште, веб локације и персонализованог потписа (максимално 256 карактера) и пролази аутентификацију потписа локалног приватног кључа:

```bash
# Погледајте ИД локалног јавног кључа (наведите директоријум конфигурације да бисте задржали кључ)
sync0 id -c ~/.config/sync0

# Генеришите и прикажите визиткарте чворова са персонализованим потписима
sync0 profile -c ~/.config/sync0 \
  -u alice \
  --region SHA \
  --email alice@example.com \
  --url https://example.com \
  -b "Shanghai backup node"
```

<б ид="1">, <б ид="2">, <б ид="3">, <б ид="4"> такође могу да се покрену са овим параметрима профила:

```bash
sync0 share dataset ./data -c ~/.config/sync0 -u alice --region SHA -b "Shanghai backup node"
```

### 6. Пребацивање на више језика

<б ид="1"> Подржава 75 језика. Подразумевано, помоћ командне линије и упити на одговарајућем језику се аутоматски приказују у складу са језичким окружењем оперативног система; ако системски језик није на листи подржаних, подразумевано се користи енглески.

Да бисте ручно одредили језик, подесите променљиву окружења <б ид="1">:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
