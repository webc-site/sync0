# sync0

`sync0` یک ابزار اشتراک‌گذاری فایل همتا به همتا (P2P) و همگام‌سازی چند ماشینی است که با Resilio Sync رقابت می‌کند.

هر ماشین هم یک سرور و هم یک سرویس گیرنده است: هر گره می تواند چندین گروه اشتراک گذاری فایل را منتشر کند. پس از پیوستن سایر گره ها، آنها می توانند به طور خودکار گره های اولیه موجود را از سرور همتا دریافت کنند و آنها را همزمان از چندین منبع بکشند. پس از تکمیل همگام‌سازی، دانه‌ها به‌طور خودکار برای گره‌های بیشتر برای سرعت بخشیدن به دانلودها ایجاد می‌شوند.

## نکات برجسته اصلی

- **همه هم سرور و هم مشتری هستند**: قابل مقایسه با Resilio Sync، بدون وابستگی به سرور مرکزی. هر گره ای می تواند چندین گروه به اشتراک گذاری فایل ایجاد کند و همچنین می تواند به گروه های اشتراک گذاری افراد دیگر بپیوندد. گره ها به طور خودکار مبادله می کنند و گره های بذر موجود را برای دستیابی به کشیدن همزمان و همگام سازی در زمان واقعی چندین ماشین انجام می دهند.
- **آدرس گره بدون IP**: به طور پیش فرض، کلید گره و آدرس `base64url` رمزگذاری شده `iroh` بطور خودکار در `~/.config/sync0` بدون نیاز به به خاطر سپردن یا افشای IP عمومی تولید می شوند.
- **همگام سازی چند انتخابی در صورت تقاضا**: از همگام سازی کل گروه اشتراک گذاری پشتیبانی می کند و همچنین از همگام سازی در صورت تقاضا با انتخاب چندین فایل یا زیر شاخه ها به طور همزمان پشتیبانی می کند.
- **مجوزهای سلسله مراتبی اعضای گروه و کنترل دایرکتوری آپلود**: از مجوزهای فقط خواندنی (`ro`)، آپلود خواندن-نوشتن (`rw`) و مدیریت (`admin`) پشتیبانی می کند و می تواند به صورت جداگانه پیشوند مسیری را که هر عضو مجاز به آپلود آن است مشخص کند (به طور پیش فرض، آپلود دایرکتوری اصلی اشتراک گذاری در دایرکتوری اصلی است).
- **همگام سازی با سرعت کامل و افزایشی در سراسر شبکه**: انتقال همزمان فایل های بزرگ، انباشته شدن فایل های کوچک عظیم در حافظه، و فقط بلوک های داده های همگام سازی شده زمانی که فایل ها تا حدی اصلاح می شوند.

## نصب کنید

### روش 1: نصب از طریق بار

```bash
cargo install sync0
```

### روش 2: باینری های از پیش کامپایل شده را دانلود کنید

برای دانلود بسته فشرده `.tar.xz` برای سیستم مربوطه (پشتیبانی از Linux، macOS، Windows، Android، FreeBSD، NetBSD) به [GitHub Releases](https://github.com/webc-site/sync0/releases) بروید، آن را از حالت فشرده خارج کنید و در فهرست `PATH` قرار دهید:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## سریع شروع کنید

`sync0` به طور پیش‌فرض از `~/.config/sync0` به‌عنوان دایرکتوری پیکربندی استفاده می‌کند (اگر نیاز دارید به فهرست‌های دیگر تغییر دهید، می‌توانید `-c <directory>` را اضافه کنید).

### 1. مشاهده آدرس گره محلی و تنظیم کارت ویزیت

```bash
# مشاهده آدرس گره محلی (کلید برای اولین بار به طور خودکار در ~/.config/sync0 تولید می شود)
sync0 id

# یک کارت ویزیت گره شخصی (پشتیبانی از نام کاربری، شهر، ایمیل، وب سایت و امضا در 256 کلمه)
sync0 profile -u alice --region SHA --email alice@example.com --url https://example.com -b "Shanghai node"
```

### 2. چند گروه اشتراک‌گذاری فایل را منتشر کنید و مجوزهای اعضای گروه را تنظیم کنید (`.nt` پیکربندی)

`sync0` در قالب [NestedText](https://nestedtext.org) (`.nt`) پیکربندی شده است. هر کاربر یک فایل پیکربندی `.nt` جداگانه دارد. می‌توانید فهرست راهنمای نمایه کاربر را از طریق `users_dir` در `config.nt` تعیین کنید (که به طور خودکار همه فایل‌های `.nt` را در این فهرست شامل می‌شود). هم کاربر و هم پیشوند مسیر مجاز برای آپلود از یک لیست نامرتب (`-`) استفاده می کنند. **زمانی که پیشوند مسیر آپلود پر نمی شود، آپلود در دایرکتوری ریشه اشتراک به طور پیش فرض مجاز است**.

1. فایل‌های پیکربندی `.nt` جداگانه برای هر عضو در فهرست `~/.config/sync0/users/` ایجاد کنید:

`~/.config/sync0/users/alice.nt` (عضو فقط خواندنی، نرخ محدود `80MB`، `rate` از واحدهای `GB`، `MB`، `KB` پشتیبانی می‌کند):

```yaml
id: 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c
perm: ro
rate: 80MB
```

`~/.config/sync0/users/bob.nt` (اعضای بارگذاری محدود: فقط مجاز به آپلود در فهرست‌های `uploads/bob` و `shared/common` هستند):

```yaml
id: 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f
perm: rw
write_prefix:
  - uploads/bob
  - shared/common
```

`~/.config/sync0/users/charlie.nt` (آپلود پیش‌فرض اعضا: وقتی `write_prefix` حذف می‌شود، آپلود در فهرست اصلی اشتراک‌گذاری به‌طور پیش‌فرض مجاز است):

```yaml
id: 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
perm: rw
```

2. دایرکتوری کاربر و چندین گروه اشتراک گذاری فایل را در `~/.config/sync0/config.nt` پیکربندی کنید:

```yaml
users_dir: ./users

groups:
  dataset:
    path: ./data
    auth: false
    perm: ro
    rate: 50MB

  models:
    path: ./models
    auth: false
    perm: ro
    rate: 1GB

  team-vault:
    path: ./vault
    auth: true
    perm: ro
    rate: 512KB
    users:
      - alice
      - bob
      - charlie
```

شروع سرویس اشتراک گذاری:

```bash
# راه‌اندازی مستقیم (به‌طور خودکار همه پیکربندی‌های کاربر nt را در فهرست‌های ~/.config/sync0/config.nt و users_dir بارگیری می‌کند)
sync0 share --region SHA

# یا به سرعت چندین گروه به اشتراک گذاری را منتشر کنید و مستقیماً از طریق خط فرمان به اعضای گروه اجازه دهید
sync0 share dataset:./data team-vault:./vault \
  --auth \
  --allow-ro 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c \
  --allow-rw 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f:uploads/bob,shared/common \
  --allow-rw 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
```

### 3. تمام محتوا را بکشید یا چندین فایل و فهرست را انتخاب کنید (`sync0 pull`)

به هر گره همتا متصل شوید تا به طور خودکار تمام گره‌های بذر موجود در گروه اشتراک‌گذاری را به دست آورید و همزمان از چندین گره بذر بکشید:

```bash
# کل گروه اشتراک‌گذاری مجموعه داده را به ./local_data محلی بکشید
sync0 pull database:// ./local_data -p <آدرس گره>

# همگام سازی چند انتخابی: به طور همزمان تک فایل docs/readme.md و زیر شاخه ها، دارایی ها/آیکون ها، src/core را بکشید
sync0 pull مجموعه داده://docs/readme.md,assets/icons,src/core ./local_data -p <آدرس گره>
```

### 4. آپلود یک فایل یا دایرکتوری در یک گروه اشتراک گذاری (`sync0 push`)

اعضای دارای مجوزهای آپلود (`rw` یا `admin`) می‌توانند فایل‌ها یا فهرست‌های محلی را در گروه‌های اشتراک‌گذاری از راه دور آپلود کنند:

```bash
# اعضای دارای مجوز آپلود دایرکتوری ریشه: مستقیماً در دایرکتوری ریشه مشترک آپلود کنید
sync0 push team-vault:// ./new_release -p <آدرس گره>

# فقط اعضای مجاز به یک پیشوند خاص (مانند آپلود/باب): به پیشوند مسیر مجاز آپلود کنید
sync0 push team-vault://uploads/bob/report.pdf ./report.pdf -p <آدرس گره>
```

### 5. مشترک شدن در همگام‌سازی و کاشت خودکار (`sync0 sub`)

پس از عضویت در گروه اشتراک گذاری یک گره خاص، سرور محلی هم یک مشتری دریافت کننده و هم یک سرور کاشت جدید است. هنگامی که فایل گره منبع به‌روزرسانی می‌شود، به‌طور خودکار همگام‌سازی می‌شود و بارگیری‌های تکه‌شده را برای گره‌های دیگر فراهم می‌کند:

```bash
# در کل گروه اشتراک‌گذاری مشترک شوید و به‌طور خودکار دانه‌بندی کنید
زیر مجموعه داده sync0:// ./local_mirror -p <آدرس گره>

# فقط چند انتخاب کنید تا در فایل ها و زیرشاخه های مشخص شده مشترک شوید و آنها را ذخیره کنید
زیر مجموعه داده sync0://models/llama.onnx,configs ./local_mirror -p <آدرس گره>
```

### 6. همگام سازی همتا گروه چند ماشینی (`sync0 group`)

چندین ماشین به یک گروه اشتراک‌گذاری می‌پیوندند، یکدیگر به‌طور خودکار گره‌های اولیه موجود را کشف می‌کنند و همگام‌سازی دو طرفه را حفظ می‌کنند (از همگام‌سازی کامل یا انتخاب چندگانه فایل‌ها و فهرست‌ها پشتیبانی می‌کند):

```bash
# به طور کامل به گروه و همگام سازی دو طرفه بپیوندید
sync0 group team-docs:// ./docs -p <آدرس گره>

# فقط دایرکتوری wal و فایل meta.json در گروه همگام سازی چند انتخابی
گروه sync0 team-docs://wal,meta.json ./docs -p <آدرس گره>
```

### 7. انتقال مستقیم نقطه به نقطه بین دو ماشین (`send` / `recv`)

نیازی به پیکربندی از قبل یک گروه نیست و می توانید به طور موقت فایل ها یا دایرکتوری ها را مستقیماً بین دو ماشین انتقال دهید:

```bash
# نظارت بر گیرنده
sync0 recv 0.0.0.0:9000 ./backup

# پایان ارسال مستقیماً فایل‌ها یا دایرکتوری‌ها را منتقل می‌کند (اختیاری - حذف آینه برای پاک کردن فایل‌های اضافی، - نرخ سرعت محدود)
sync0 send ./project 192.168.1.10:9000
```

### 8. سوئیچینگ چند زبانه

`sync0` از 75 زبان پشتیبانی می کند و به طور خودکار مطابق با محیط زبان سیستم به طور پیش فرض تغییر می کند. همچنین می توان آن را به صورت دستی از طریق `SYNC0_LANG` مشخص کرد:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
