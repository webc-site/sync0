# sync0

`sync0` යනු Resilio Sync සමඟ තරඟ කරන peer-to-peer (P2P) ගොනු හුවමාරු සහ බහු යන්ත්‍ර සමමුහුර්ත කිරීමේ මෙවලමකි.

සෑම යන්ත්‍රයක්ම සේවාදායකයක් සහ සේවාදායකයෙක් වේ: ඕනෑම නෝඩයකට බහු ගොනු හුවමාරු කණ්ඩායම් ප්‍රකාශනය කළ හැක. අනෙකුත් නෝඩ් සම්බන්ධ වූ පසු, ඔවුන්ට ස්වයංක්‍රීයව සම සේවාදායකයෙන් ලබා ගත හැකි බීජ නෝඩ් ලබා ගත හැකි අතර ඒවා බහු මූලාශ්‍රවලින් සමගාමීව අදින්න. සමමුහුර්තකරණය සම්පූර්ණ වූ පසු, බාගැනීම් වේගවත් කිරීම සඳහා තවත් නෝඩ් සඳහා බීජ ස්වයංක්‍රීයව සාදනු ඇත.

## මූලික ඉස්මතු කිරීම්

- **සියලු දෙනාම සේවාදායකයෙක් සහ සේවාදායකයෙක් වේ**: Resilio Sync හා සැසඳිය හැකි, මධ්‍යම සේවාදායක පරායත්තතාවයක් නොමැත. ඕනෑම නෝඩයකට ගොනු බෙදාගැනීමේ කණ්ඩායම් කිහිපයක් සෑදිය හැකි අතර, වෙනත් පුද්ගලයින්ගේ බෙදාගැනීමේ කණ්ඩායම්වලටද සම්බන්ධ විය හැක; බහු යන්ත්‍රවල සමගාමී ඇද ගැනීම සහ තත්‍ය කාලීන සමමුහුර්තකරණය ලබා ගැනීම සඳහා නෝඩ් ස්වයංක්‍රීයව හුවමාරු කර ලබා ගත හැකි බීජ නෝඩ් ලබා ගනී.
- **IP-නිදහස් නෝඩ් ලිපිනය**: පෙරනිමියෙන්, නෝඩ් යතුර සහ `base64url` කේතනය කළ `iroh` ලිපිනය පොදු IP මතක තබා ගැනීමට හෝ නිරාවරණය කිරීමට අවශ්‍ය නොවී `~/.config/sync0` හි ස්වයංක්‍රීයව ජනනය වේ.
- **ඉල්ලුම මත බහු-තේරුම් සමමුහුර්තකරණය**: සම්පූර්ණ බෙදාගැනීමේ කණ්ඩායමෙහි සමමුහුර්තකරණයට සහය වන අතර, එකවර ගොනු කිහිපයක් හෝ උප බහලුම් තෝරාගැනීමෙන් ඉල්ලුම මත සමමුහුර්ත කිරීමට ද සහාය වේ.
- ** සමූහ සාමාජික ධුරාවලියේ අවසර සහ උඩුගත බහලුම පාලනය**: කියවීමට පමණක් (`ro`), කියවීමට-ලිවීමට උඩුගත කිරීමට (`rw`) සහ කළමනාකරණයට (`admin`) අවසර සඳහා සහය දක්වයි, සහ එක් එක් සාමාජිකයාට root උඩුගත කිරීමට අවසර දී ඇති මාර්ග උපසර්ගය තනි තනිව සඳහන් කළ හැකිය (පෙරනිමියෙන් උඩුගත කිරීමේ පෙරනිමියෙන්).
- **ජාල හරහා පූර්ණ-වේගය සහ වර්ධක සමමුහුර්තකරණය**: විශාල ගොනු සමගාමී සම්ප්‍රේෂණය, මතකයේ ඇති දැවැන්ත කුඩා ගොනු එකතු කිරීම සහ ගොනු අර්ධ වශයෙන් වෙනස් කළ විට පමණක් සමමුහුර්ත කළ දත්ත අවහිර කිරීම්.

```bash

sudo mv sync0 /usr/local/bin/
```

### 1. දේශීය නෝඩ් ලිපිනය සහ ව්‍යාපාරික කාඩ්පත සැකසීම බලන්න

```bash
# ප්‍රාදේශීය නෝඩ් ලිපිනය බලන්න (ප්‍රථම වරට යතුර ස්වයංක්‍රීයව ~/.config/sync0 තුළ ජනනය වේ)
sync0 id

# පුද්ගලික නෝඩ් ව්‍යාපාරික කාඩ්පතක් ජනනය කරන්න (පරිශීලක නාමය, නගරය, විද්‍යුත් තැපෑල, වෙබ් අඩවිය සහ වචන 256ක් තුළ අත්සන සඳහා සහය දක්වයි)
sync0 profile -u alice --region SHA --email alice@example.com --url https://example.com -b "Shanghai node"
```

### 2. බහු ගොනු බෙදාගැනීමේ කණ්ඩායම් ප්‍රකාශනය කර කණ්ඩායම් සාමාජික අවසර සකසන්න (`.nt` වින්‍යාසය)

`sync0` [NestedText](https://nestedtext.org) (`.nt`) ආකෘතියෙන් වින්‍යාස කර ඇත. සෑම පරිශීලකයෙකුටම වෙනම `.nt` වින්‍යාස ගොනුවක් ඇත. ඔබට `users_dir` `config.nt` හරහා පරිශීලක පැතිකඩ නාමාවලිය සඳහන් කළ හැක (මෙම නාමාවලියෙහි ඇති සියලුම `.nt` ගොනු ස්වයංක්‍රීයව ඇතුළත් වේ). උඩුගත කිරීමට අවසර දී ඇති පරිශීලකයා සහ මාර්ග උපසර්ගය යන දෙකම ඇණවුම් නොකළ ලැයිස්තුවක් භාවිතා කරයි (`-`). ** උඩුගත කිරීමේ මාර්ග උපසර්ගය පුරවා නොමැති විට, කොටසෙහි මූල නාමාවලිය වෙත උඩුගත කිරීම පෙරනිමියෙන් අවසර දෙනු ලැබේ**.

1. `~/.config/sync0/users/` බහලුම තුළ එක් එක් සාමාජිකයා සඳහා වෙන වෙනම `.nt` වින්‍යාස ගොනු සාදන්න:

`~/.config/sync0/users/alice.nt` (කියවීමට-පමණි සාමාජික, අනුපාත සීමිත `80MB`, `rate` `GB`, `MB`, `KB` ඒකක සඳහා සහය දක්වයි):

```yaml
id: 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c
perm: ro
rate: 80MB
```

`~/.config/sync0/users/bob.nt` (සීමා සහිත උඩුගත කිරීමේ සාමාජිකයින්: `uploads/bob` සහ `shared/common` නාමාවලි වෙත උඩුගත කිරීමට පමණක් අවසර ඇත):

```yaml
id: 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f
perm: rw
write_prefix:
  - uploads/bob
  - shared/common
```

`~/.config/sync0/users/charlie.nt` (පෙරනිමි සාමාජික උඩුගත කිරීම: `write_prefix` ඉවත් කර ඇති විට, කොටසෙහි මූල නාමාවලිය වෙත උඩුගත කිරීමට පෙරනිමියෙන් අවසර දෙනු ලැබේ):

```yaml
id: 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
perm: rw
```

2. `~/.config/sync0/config.nt` හි පරිශීලක නාමාවලිය සහ බහු ගොනු හුවමාරු කණ්ඩායම් වින්‍යාස කරන්න:

```yaml
users_dir: ./users

groups:
  dataset:
    path: ./data
    auth: false
    perm: ro
    rate: 50MB

  models:
    path: ./models
    auth: false
    perm: ro
    rate: 1GB

  team-vault:
    path: ./vault
    auth: true
    perm: ro
    rate: 512KB
    users:
      - alice
      - bob
      - charlie
```

බෙදාගැනීමේ සේවාව ආරම්භ කරන්න:

```bash
# සෘජු ආරම්භය (~/.config/sync0/config.nt සහ users_dir නාමාවලි තුළ සියලුම .nt පරිශීලක වින්‍යාසයන් ස්වයංක්‍රීයව පූරණය කරයි)
sync0 share --region SHA

# නැතහොත් බහු බෙදාගැනීමේ කණ්ඩායම් ඉක්මනින් ප්‍රකාශයට පත් කර කණ්ඩායම් සාමාජිකයින්ට විධාන රේඛාව හරහා කෙලින්ම අවසර දෙන්න
sync0 share dataset:./data team-vault:./vault \
  --auth \
  --allow-ro 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c \
  --allow-rw 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f:uploads/bob,shared/common \
  --allow-rw 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
```

### 3. සියලුම අන්තර්ගතයන් අදින්න හෝ බහු ගොනු සහ නාමාවලි තෝරන්න (`sync0 pull`)

බෙදාගැනීමේ කණ්ඩායම තුළ පවතින සියලුම බීජ නෝඩ් ස්වයංක්‍රීයව ලබා ගැනීමට ඕනෑම සම වයසේ නෝඩයකට සම්බන්ධ වන්න, සහ බහු බීජ නෝඩ් වලින් සමගාමීව අදින්න:

```bash
# සම්පූර්ණ දත්ත කට්ටල බෙදාගැනීමේ කණ්ඩායම දේශීය ./local_data වෙත අදින්න
sync0 pull dataset:// ./local_data -p <node address>

# බහු-තේරුම් සමමුහුර්තකරණය: එකවර තනි ගොනුව docs/readme.md සහ උප බහලුම් වත්කම්/අයිකන, src/core අදින්න
sync0 pull dataset://docs/readme.md,assets/icons,src/core ./local_data -p <node address>
```

### 4. බෙදාගැනීමේ කණ්ඩායමකට ගොනුවක් හෝ නාමාවලියක් උඩුගත කරන්න (`sync0 push`)

උඩුගත කිරීමේ අවසර ඇති සාමාජිකයින්ට (`rw` හෝ `admin`) දුරස්ථ බෙදාගැනීමේ කණ්ඩායම් වෙත දේශීය ගොනු හෝ නාමාවලි උඩුගත කළ හැක:

```bash
# මූල නාමාවලිය උඩුගත කිරීමේ අවසරය ඇති සාමාජිකයින්: හවුල් මූල නාමාවලිය වෙත කෙලින්ම උඩුගත කරන්න
sync0 push team-vault:// ./new_release -p <node address>

# නිශ්චිත උපසර්ගයකට (උඩුගත කිරීම්/බොබ් වැනි) බලයලත් සාමාජිකයින්ට පමණක් අවසර දී ඇති මාර්ග උපසර්ගය වෙත උඩුගත කරන්න
sync0 push team-vault://uploads/bob/report.pdf ./report.pdf -p <node address>
```

### 5. ස්වයංක්‍රීය සමමුහුර්ත කිරීම සහ බීජ කිරීම සඳහා දායක වන්න (`sync0 sub`)

යම් නෝඩයක බෙදාගැනීමේ කණ්ඩායමට දායක වීමෙන් පසුව, දේශීය සේවාදායකය ලබා ගන්නා සේවාදායකයෙකු සහ නව සීඩින් සේවාදායකයක් වේ; මූලාශ්‍ර නෝඩ් ගොනුව යාවත්කාලීන වූ විට, එය ස්වයංක්‍රීයව සමමුහුර්ත වන අතර අනෙකුත් නෝඩ් සඳහා කුට්ටි බාගැනීම් සපයයි:

```bash
# සම්පූර්ණ බෙදාගැනීමේ කණ්ඩායමට දායක වී ස්වයංක්‍රීයව බීජ කරන්න
sync0 sub dataset:// ./local_mirror -p <node address>

# නිශ්චිත ගොනු සහ උප බහලුම් වලට දායක වීමට සහ ඒවා බීජ කිරීමට බහු-තේරීම පමණි
sync0 උප දත්ත කට්ටලය://models/llama.onnx,configs ./local_mirror -p <node address>
```

### 6. බහු යන්ත්‍ර සමූහ සමමුහුර්තකරණය (`sync0 group`)

බහු යන්ත්‍ර එකම බෙදාගැනීමේ කණ්ඩායමකට සම්බන්ධ වේ, එකිනෙකා ස්වයංක්‍රීයව පවතින බීජ නෝඩ් සොයා ගන්නා අතර ද්වි-මාර්ග සමමුහුර්තකරණය පවත්වා ගනී (සම්පූර්ණ සමමුහුර්තකරණයට හෝ ගොනු සහ නාමාවලි බහු තේරීම සඳහා සහය දක්වයි):

```bash
# කණ්ඩායමට සම්පූර්ණයෙන්ම සම්බන්ධ වී ද්වි-මාර්ග සමමුහුර්තකරණය
sync0 group team-docs:// ./docs -p <node address>

# බහු-තේරුම් සමමුහුර්ත කිරීමේ කණ්ඩායම තුළ wal නාමාවලිය සහ meta.json ගොනුව පමණි
sync0 group team-docs://wal,meta.json ./docs -p <node address>
```

### 7. යන්ත්‍ර දෙකක් අතර ලක්ෂ්‍යයෙන් ඍජු සම්ප්‍රේෂණය (`send` / `recv`)

සමූහයක් පෙර-වින්‍යාස කිරීමට අවශ්‍ය නොවන අතර, ඔබට තාවකාලිකව යන්ත්‍ර දෙකක් අතර ගොනු හෝ නාමාවලි සෘජුවම මාරු කළ හැක:

```bash
# ග්රාහක නිරීක්ෂණ
sync0 recv 0.0.0.0:9000 ./backup

# යැවීමේ අවසානය සෘජුවම ගොනු හෝ නාමාවලි මාරු කරයි (විකල්ප --අතිරික්ත ගොනු පිරිසිදු කිරීමට කැඩපත මකන්න, --අනුපාත වේග සීමාව)
sync0 send ./project 192.168.1.10:9000
```

### 8. බහු භාෂා මාරු කිරීම

`sync0` භාෂා 75කට සහය දක්වන අතර පෙරනිමියෙන් පද්ධති භාෂා පරිසරයට අනුව ස්වයංක්‍රීයව මාරු වේ; එය `SYNC0_LANG` හරහා අතින් ද නියම කළ හැක:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
