# sync0

`sync0` යනු ජාල හරහා ගොනු මාරු කිරීම, නාමාවලි සමමුහුර්ත කිරීම සහ සමගාමීව බහු යන්ත්‍ර වෙත දත්ත බෙදා හැරීම සඳහා වන විධාන රේඛා මෙවලමකි.

## මුල් නිර්මාණ අරමුණ

ජාල ප්‍රමාදයන් සහ පැකට් නැතිවීම සහිත හරස් යන්ත්‍ර කාමර, රටවල්, හෝ පරිසරයන් තුළ, `rsync` සහ `scp` වැනි මෙවලම් කලාප පළල භාවිතය සීමා කරන තනි සම්බන්ධතා අනුක්‍රමික තහවුරු කිරීම මත පදනම් වේ; යන්ත්‍ර කිහිපයක් එකවර එකම සේවාදායකයෙන් දත්ත ඇද ගන්නා විට, මූලාශ්‍ර සේවාදායක ජාල කාඩ්පත පහසුවෙන් බාධාවක් විය හැක.

`sync0` හි අරමුණ ගැටළු දෙකක් විසඳීමයි:

1. යන්ත්‍ර දෙක අතර ගොනු සහ නාමාවලි සමමුහුර්තකරණයට සම්පූර්ණ භෞතික කලාප පළලක් ධාවනය කිරීමට ඉඩ දෙන්න, සහ ගොනුව අර්ධ වශයෙන් වෙනස් කළ විට පමණක් වෙනස් කළ කොටස මාරු කරන්න.
2. එකම නාමාවලිය සමමුහුර්ත කිරීමේදී, ප්‍රභව සේවාදායකයේ බර අඩු කිරීමේදී සහ සමස්ත සමමුහුර්ත කිරීමේ කාලය කෙටි කිරීමේදී බහු යන්ත්‍රවලට දත්ත කුට්ටි එකිනෙක මාරු කළ හැකිය.

## rsync සමඟ වේගය සංසන්දනය කිරීම

පරීක්ෂණ පරිසරය: යුරෝපීය නෝඩය $\leftrightarrow$ උතුරු ඇමරිකානු නෝඩය, වට-ගමන් ප්‍රමාදය ms 86, නාමාවලි පරිලෝකනය, අඩුකිරීම් සංසන්දනය, ජාල සම්ප්‍රේෂණය සහ තැටි ස්ථානගත කිරීම් සත්‍යාපනය ඇතුළුව සම්පූර්ණ කාලය ගත කිරීම මැනීම:

| සම්ප්රේෂණ දර්ශනය | දත්ත ප්රමාණය | `sync0` | `rsync` | බහු |
| :--- | :---: | :---: | :---: | :---: |
| කුඩා ගොනු 10,000 ක් | 77.6 MB | 0.90 s (688 Mbps) | 4.86 s (128 Mbps) | 5.4x |
| කේතය සහ සංරක්ෂිත පැකේජ (`.tar`) | 512 MB | 1.94 s (2111 Mbps) | 9.36 s (438 Mbps) | 4.8x |
| වීඩියෝ ගොනුව (`.mp4`) | 512 MB | 7.36 s (556 Mbps) | 12.11 s (338 Mbps) | 1.6x |
| වර්ධක සමමුහුර්තකරණය (1% අන්තර්ගතය වෙනස් කරන්න) | 512 MB | 0.12 s | 1.85 s | 15.4x |

## කාර්ය සාධනය වැඩි දියුණු කිරීමේ ක්රම

- **UDP සමගාමී සම්ප්‍රේෂණය**: UDP හරහා දත්ත වාරණ යවන්න, පසුව ගොනු මාරු කිරීම් අවහිර කිරීම තනි පැකට් පාඩුවක් වළක්වා ගැනීමට නැතිවූ කොටස් පමණක් නැවත සම්ප්‍රේෂණය කරන්න.
- **අන්තර්ගත ඛණ්ඩනය සහ අඩුකිරීම**: අන්තර්ගතයට අනුව ගොනුව දත්ත කොටස්වලට බෙදන්න සහ පිරික්සුම් අගය ගණනය කරන්න. දැනටමත් ලැබෙන අන්තයේ ඇති එකම අන්තර්ගතය ජාලය අනුපිටපත් නොකර සෘජුවම දේශීයව නැවත භාවිත කෙරේ.
- **ජාල වේගය අනුව සම්පීඩනය ස්වයංක්‍රීයව සකසන්න**: පෙළ සහ කේතය වැනි සම්පීඩිත අන්තර්ගතයන් සඳහා සම්පීඩනය ක්‍රියාත්මක කරන්න; CPU පරිභෝජනය අඩු කිරීම සඳහා වීඩියෝ, පින්තූර, සම්පීඩිත පැකේජ හෝ අධිවේගී LAN යටතේ සම්පීඩනය ස්වයංක්‍රීයව මඟ හරින්න.
- **Multi-node near pulling**: බහු යන්ත්‍ර එකම නාමාවලිය ඇද ගන්නා විට, එකම නගරයේ හෝ අඩු ප්‍රමාදයකින් බාගත කළ නෝඩ් වලින් දත්ත වාරණ සමගාමීව ඇද ගනු ලැබේ.

## ස්ථාපනය කරන්න

### ක්රමය 1: භාණ්ඩ හරහා ස්ථාපනය කරන්න

```bash
cargo install sync0
```

### ක්රමය 2: පෙර සම්පාදනය කරන ලද ද්විමය බාගත කරන්න

අදාළ පද්ධතිය සඳහා `.tar.xz` සම්පීඩිත පැකේජය බාගැනීමට [GitHub Releases](https://github.com/webc-site/sync0/releases) වෙත යන්න (Linux x86_64/ARM64, macOS Apple Silicon/Intel, Windows x64/ARM64, Android ARM64/x86_64, NetBSD, FreeBSD සඳහා සහය දක්වයි). සිප් ඉවත් කිරීමෙන් පසු, `sync0` `PATH` බහලුම තුළට දමන්න:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## පරිශීලක මාර්ගෝපදේශය

### 1. යන්ත්‍ර දෙකක් අතර ලිපිගොනු හෝ නාමාවලි සෘජුවම මාරු කරන්න

ලැබීමේ යන්ත්‍රය නිරීක්ෂණය කිරීම අරඹන්න සහ ලැබීමේ සහ සුරැකීමේ මාර්ගය සඳහන් කරන්න:

```bash
sync0 recv 0.0.0.0:9000 ./backup
```

යවන යන්ත්‍රයෙන් තනි ගොනුවක් හෝ සම්පූර්ණ නාමාවලියක් යවන්න:

```bash
sync0 send ./project 192.168.1.10:9000
```

බහුලව භාවිතා වන පරාමිතීන්:

```bash
# ලැබෙන අන්තයේ පවතින නමුත් යැවීමේ අන්තයේ නොමැති අතිරික්ත ගොනු මකන්න (කැඩපත් සමමුහුර්තකරණය)
sync0 send ./project 192.168.1.10:9000 --delete

# යැවීමේ අනුපාතය සීමා කරන්න (ඒකකය: බයිට්/තත්පර, උදාහරණයක් ලෙස 50 MB/s)
sync0 send ./project 192.168.1.10:9000 --rate 50000000

# නිහඬ මාදිලිය (ප්‍රගති තීරුවක් නොපෙන්වයි)
sync0 send ./project 192.168.1.10:9000 -q
```

### 2. හවුල් නාමාවලි ප්‍රකාශ කිරීම සහ බහු නෝඩ් වලින් ඇද ගැනීම

සම්භව සේවාදායකයේ හවුල් නාමාවලියක් (`dataset` නම්) ප්‍රකාශයට පත් කරන්න:

```bash
sync0 share dataset ./data --region SHA
```

අනෙකුත් යන්ත්‍රවල බෙදාගත් නාමාවලිය අදින්න (ඔබට එකවර නෝඩ් ලිපින කිහිපයක් පිරවිය හැක, සමගාමීව අදින්න කොමාවෙන් වෙන් කර ඇත):

```bash
sync0 pull 10.0.0.1:9000,10.0.0.2:9000 dataset ./local_data
```

හවුල් නාමාවලියෙහි යම් උප බහලුමක් පමණක් අදින්න:

```bash
sync0 pull 10.0.0.1:9000 dataset ./local_data --subpath 2026/logs
```

දේශීය වෙනස්කම් දුරස්ථ බෙදාගත් නාමාවලිය වෙත තල්ලු කරන්න:

```bash
sync0 push 10.0.0.1:9000 dataset ./local_data
```

### 3. නාමාවලිය ස්වයංක්‍රීය යාවත්කාලීන සඳහා දායක වන්න

මූලාශ්‍ර නෝඩයේ හවුල් නාමාවලියට දායක වන්න. මූලාශ්‍ර නාමාවලිය තුළ ගොනුවක් එකතු කළ විට හෝ වෙනස් කළ විට, එය ස්වයංක්‍රීයව දේශීය පරිගණකයට සමමුහුර්ත වේ. ඒ අතරම, දේශීය යන්ත්‍රය ස්වයංක්‍රීයව අනෙකුත් යන්ත්‍ර සඳහා නෝඩයක් ලෙස ක්‍රියා කරයි:

```bash
sync0 sub 10.0.0.1:9000 dataset ./local_mirror
```

### 4. බහු යන්ත්‍ර කණ්ඩායම් ද්වි-මාර්ග සමමුහුර්තකරණය

බහු යන්ත්‍ර එකම කණ්ඩායම් නාමයට සම්බන්ධ වන අතර, ඕනෑම නෝඩ් නාමාවලියක වෙනස්කම් ස්වයංක්‍රීයව සමූහයේ අනෙකුත් නෝඩ් වෙත සමමුහුර්ත වනු ඇත:

```bash
sync0 group team-docs ./docs 10.0.0.1:9000,10.0.0.2:9000
```

### 5. නෝඩ් හැඳුනුම්පත සහ පුද්ගලික ව්‍යාපාරික කාඩ්පත

සෑම නෝඩයක්ම පරිශීලක නාමය, නගරය, විද්‍යුත් තැපෑල, වෙබ් අඩවිය සහ පුද්ගලාරෝපිත අත්සනක් (උපරිම අක්ෂර 256) සැකසීමට සහය දක්වන අතර දේශීය පුද්ගලික යතුරු අත්සන සත්‍යාපනය සමත් කරයි:

```bash
# ප්‍රාදේශීය පොදු යතුරු ID බලන්න (යතුර දිගටම පැවතීමට වින්‍යාස නාමාවලිය සඳහන් කරන්න)
sync0 id -c ~/.config/sync0

# පුද්ගලීකරණය කළ අත්සන් සහිත නෝඩ් ව්‍යාපාරික කාඩ්පත් උත්පාදනය කර ප්‍රදර්ශනය කරන්න
sync0 profile -c ~/.config/sync0 \
  -u alice \
  --region SHA \
  --email alice@example.com \
  --url https://example.com \
  -b "Shanghai backup node"
```

`share`, `pull`, `sub`, `group` ද මෙම පැතිකඩ පරාමිතීන් සමඟ දියත් කළ හැක:

```bash
sync0 share dataset ./data -c ~/.config/sync0 -u alice --region SHA -b "Shanghai backup node"
```

### 6. බහු භාෂා මාරු කිරීම

`sync0` භාෂා 75කට සහය දක්වයි. පෙරනිමියෙන්, මෙහෙයුම් පද්ධතියේ භාෂා පරිසරයට අනුව විධාන රේඛා උපකාර සහ අනුරූප භාෂාවේ විමසීම් ස්වයංක්‍රීයව දර්ශනය වේ; පද්ධති භාෂාව සහය දක්වන ලැයිස්තුවේ නොමැති නම්, ඉංග්‍රීසි පෙරනිමියෙන් භාවිතා වේ.

භාෂාව අතින් නියම කිරීමට, පරිසර විචල්‍යය `SYNC0_LANG` සකසන්න:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
