# sync0

`sync0` යනු `rsync` ප්‍රතිස්ථාපනය කිරීමට භාවිතා කරන විමධ්‍යගත P2P ගොනු බෙදාගැනීම, තත්‍ය-කාලීන සමමුහුර්තකරණය සහ බහු-මූලාශ්‍ර බෙදා හැරීමේ මෙවලමකි - ට්‍රාන්ස්කොන්ටිනෙන්ටල් WAN හි මනින ලද වේගය `rsync`'s **5.89×** (තනි ලක්ෂ්‍ය ජ්‍යාමිතික සාමාන්‍ය වේගය **26 P× ජ්‍යාමිතික සාමාන්‍ය වේගය **2. **3.16×**), සහ transoceanic අධි-ප්‍රමාද සම්බන්ධක P2P ත්වරණය **7.68×** දක්වා වේ (සම්පූර්ණ සබැඳි 24-දර්ශන විස්තීරණ ජ්‍යාමිතික මධ්‍යන්‍ය වේගය **2.56×**).

සෑම යන්ත්‍රයක්ම සේවාදායකයක් සහ සේවාදායකයෙක් වේ: මධ්‍යම සේවාදායකයක් හෝ පොදු ජාල ලිපිනයක් අවශ්‍ය නොවේ, ස්වයංක්‍රීය සිදුරු සිදුරු කිරීම බෙදා හරින ලද ජාල පොදු යතුරු ලිපිනය මත පදනම් වේ, සහ එය යන්ත්‍ර දෙකක් අතර සෘජු සම්ප්‍රේෂණය, බහු-බෙදාගැනීමේ කණ්ඩායම් අවසර සත්කාරකත්වය, ඉල්ලුම මත උප බහලුම් කිහිපයක් තෝරා ගැනීම, මිලි තත්පර මට්ටමේ තත්‍ය කාලීන බහුකාර්ය සමමුහුර්තකරණය සහ Pcurrent-Synchronization.

## ස්ථාපනය කරන්න

### ක්රමය 1: භාණ්ඩ ස්ථාපනය

```bash
cargo install sync0
```

### ක්රමය 2: පෙර සම්පාදනය කරන ලද ද්විමය බාගත කරන්න

පද්ධතියට අනුරූප වන `.tar.xz` සම්පීඩිත පැකේජය බාගැනීමට [GitHub Releases](https://github.com/webc-site/sync0/releases) වෙත යන්න (Linux, macOS, Windows, Android, iOS, FreeBSD සඳහා සහය දක්වයි), unzip කර `PATH` තුළට දමන්න:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## ඉක්මනින් පටන් ගන්න

### 1. යන්ත්‍ර දෙකක් අතර ශුන්‍ය-වින්‍යාස සෘජු සම්ප්‍රේෂණය (`send` / `recv`)

බෙදාගැනීමේ කණ්ඩායමක් වින්‍යාස කිරීමට අවශ්‍ය නැත, යන්ත්‍ර දෙකක් අතර වේගයෙන් ගොනු හෝ නාමාවලි සෘජුවම මාරු කරන්න:

```bash
# ලැබෙන අන්තය වරායට සවන් දී ./backup වෙත ලියයි
sync0 recv 0.0.0.0:9000 ./backup

# යවන්නාගෙන් සෘජු සම්ප්‍රේෂණය (විකල්ප --අතිරික්ත ගොනු පිරිසිදු කිරීමට දර්පණය මකන්න, --අනුපාත 50MB වේග සීමාව)
sync0 send ./project 192.168.1.10:9000
```

### 2. පළ කිරීම් බෙදාගැනීම සහ ඉල්ලුම මත අදින්න/උඩුගත කිරීම (`share` / `pull` / `push`)

```bash
# සේවාදායකය: එක් විධාන රේඛාවක් සමඟ බෙදාගැනීමේ කණ්ඩායම ප්‍රකාශයට පත් කරන්න (ආරම්භයෙන් පසු IP-නිදහස් ඉරෝ නෝඩ් ලිපිනය ප්‍රතිදානය කරන්න)
sync0 share dataset:./data

# සේවාලාභියා: සම්පූර්ණ දත්ත කට්ටල බෙදාගැනීමේ කණ්ඩායම දේශීය ./local_data වෙත අදින්න
sync0 pull dataset:// ./local_data -p <node address>

# සේවාලාභියා: ඉල්ලුම මත බහු තේරීම් අදින්න (නිශ්චිත තනි ගොනු සහ උප බහලුම් පමණක් සමමුහුර්ත කරන්න)
sync0 pull dataset://docs/readme.md,assets/icons,src/core ./local_data -p <node address>

# සේවාලාභියා: බලයලත් බෙදාගැනීමේ කණ්ඩායම් වෙත ගොනු හෝ නාමාවලි උඩුගත කරන්න
sync0 push dataset://releases/v1 ./build_output -p <node address>
```

### 3. තත්‍ය කාලීන දායකත්ව බීජ කිරීම සහ බහු යන්ත්‍ර ද්වි-මාර්ග සමමුහුර්තකරණය (`sub` / `group`)

දිගු සම්බන්ධතාවයක් ස්ථාපිත කිරීමෙන් පසු, ඕනෑම ගොනුවක් **එකතු කිරීම, වෙනස් කිරීම, මකා දැමීම, අවසර වෙනස් කිරීම හෝ වෙනස් කිරීමේ කාලය** දුරස්ථ අන්තයේ සිදු වුවහොත්, දේශීය නාමාවලිය තථ්‍ය කාලය තුළ මිලි තත්පර වලින් සමමුහුර්තව යාවත්කාලීන කරනු ලැබේ (නව/වෙනස් කළ විශාල ගොනු පමණක් වෙනස් බ්ලොක් ඇද ඒවා තැනින් තැන යාවත්කාලීන කරයි, ගොනු ස්වයංක්‍රීයව මකා දමනු ඇත. සෘජුවම අවහිර කරයි):

- **`sync0 sub`(එක්-මාර්ග තත්‍ය කාලීන දර්පණය + ස්වයංක්‍රීය බීජ කිරීම)**: දේශීය තත්‍ය කාලය බෙදාගැනීමේ අවසානයෙහි එකතු කිරීම්, මකාදැමීම් සහ වෙනස් කිරීම් අනුගමනය කරයි, සහ අනෙකුත් ඇදීමේ නෝඩ් සඳහා සමගාමී ත්වරණය සැපයීම සඳහා ස්වයංක්‍රීයව P2P බීජ ප්‍රභවයක් ලෙස ක්‍රියා කරයි.
- **`sync0 group`(Multi-machine peer-to-peer two-way real-time synchronization)**: සමූහයේ ඕනෑම යන්ත්‍රයක ගොනු එකතු කිරීම, මකා දැමීම හෝ වෙනස් කිරීම සිදු කරන්නේ නම්, අනෙකුත් සියලුම සබැඳි නෝඩ් තථ්‍ය කාලය තුළ සමමුහුර්තව යාවත්කාලීන කර එකිනෙකා සඳහා බීජ ලෙස ක්‍රියා කරයි.

```bash
# සම්පූර්ණ බෙදාගැනීමේ කණ්ඩායමට දායක වන්න: දුරස්ථ එකතු කිරීම්, මකාදැමීම් සහ වෙනස් කිරීම් තථ්‍ය කාලය තුළ දේශීයව සමමුහුර්ත කර ස්වයංක්‍රීයව බීජ කරනු ලැබේ
sync0 sub dataset:// ./local_mirror -p <node address>

# ඉල්ලුම මත බහු-තේරීම් දායකත්වය: නියම කල තනි ගොනු සහ උප බහලුම් පමණක් සමමුහුර්ත කර බීජ කරන්න
sync0 උප දත්ත කට්ටලය://models/llama.onnx,configs ./local_mirror -p <node address>

# බහු යන්ත්‍ර සම වයසේ කණ්ඩායම් ද්වි-මාර්ග තත්‍ය කාලීන සමමුහුර්තකරණය (සම්පූර්ණ හෝ කොමා බහු-තේරුම් මාර්ග සඳහාද සහය දක්වයි)
sync0 group team-docs:// ./docs -p <node address>
```

### 4. කණ්ඩායම් බහු-බෙදාගැනීමේ කණ්ඩායම සහ සාමාජික අවසර වින්‍යාසය (`.nt` වින්‍යාසය)

පෙරනිමි වින්‍යාස නාමාවලිය `~/.config/sync0` (`-c <directory>` හරහා මාරු කළ හැක), අවම [NestedText](https://nestedtext.org) (`.nt`) ආකෘතිය භාවිතයෙන්:
- **පොදු ජාල කියවීම සීමා කිරීමට සහය දක්වයි (බලය ලත් පරිශීලකයින්ට පමණක් කියවිය හැක)**: බෙදාගැනීමේ කණ්ඩායම `users:` සාමාජික ලැයිස්තුවක් සමඟ වින්‍යාස කර ඇති තාක් කල් (හෝ විධාන රේඛාව මඟින් `--allow-r` / `--allow-rw` / `--allow-w` / `--auth`, පද්ධතිය සම්පූර්ණයෙන්ම සක්‍රිය වේ (ස්වයංක්‍රීයව සක්‍රීය වේ). id="6">)** සහ පොදු ජාල නිර්නාමික නෝඩ් ගණන් කිරීම හෝ කියවීම තහනම් කරයි, සහ P2P සීඩින් නෝඩ් වලට ග්‍රාහකත්වය ලබා දීමෙන් අවසර ලත් පරිශීලකයින්ට පමණක් කියවීමට ඉඩ සලසමින් එකවර සුදු ලැයිස්තුව උරුම වේ; `users` සමඟ වින්‍යාස කර නොමැති බෙදාගැනීමේ කණ්ඩායම් පොදු සහ පෙරනිමියෙන් කියවීමට පමණි (ඔබට පොදු සහ කියවීමට පමණක් සහ උඩුගත කිරීම් සඳහා විවෘත කිරීමට අවශ්‍ය නම්, ඔබට පැහැදිලිවම `auth: false` සැකසිය හැක).
- ** සියුම් ලෙස කියවීමට-ලිවීමේ සහ උප බහලුම් බෙදා හැරීමේ අවසර**: සාමාජිකයින් පෙරනිමියෙන් කියවීමට පමණි (`r` පැහැදිලිව ලිවීමට අවශ්‍ය නොවේ), සහ සහාය `r` (කියවීමට පමණි), `w` (ඩ්‍රොප් පෙට්ටියට පමණක් ලියන්න, සහ <b>කියවිය නොහැක), `write_prefix` (උඩුගත කිරීම සඳහා අවසර දී ඇති උප බහලුම් උපසර්ගය සීමා කරන්න).

**සාමාජික වින්‍යාස උදාහරණය (`~/.config/sync0/users/`):**

```yaml
# ~/.config/sync0/users/alice.nt (පෙරනිමි කියවීමට පමණි, වේග සීමාව 80MB)
id: 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c
rate: 80MB
```

```yaml
# ~/.config/sync0/users/bob.nt (කියවීමට සහ ලිවීමට අවසර, නිශ්චිත උප බහලුම වෙත උඩුගත කිරීමට පමණක් අවසර ඇත)
id: 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f
perm: rw
write_prefix:
  - uploads/bob
  - shared/common
```

```yaml
# ~/.config/sync0/users/charlie.nt (බෙදාහැරීමේ අවසරය ලියන්න පමණි, කියවීම තහනම්)
id: 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
perm: w
```

**බෙදාගැනීමේ කණ්ඩායම් වින්‍යාස උදාහරණය (`~/.config/sync0/config.nt`):**

```yaml
users_dir: ./users

groups:
  # වින්‍යාස නොකළ පරිශීලකයින්: පෙරනිමි පොදු ජාලය කියවීමට පමණි
  dataset:
    path: ./data
    rate: 50MB

  # වින්‍යාස කළ පරිශීලකයින්: පොදු ජාල කියවීම ස්වයංක්‍රීයව සීමා කරන්න (කියවිය හැක්කේ ඇලිස් සහ බොබ්ට පමණි, චාලිට බෙදා හැරීමට සහ උඩුගත කිරීමට පමණි)
  team-vault:
    path: ./vault
    users:
      - alice
      - bob
      - charlie
```

සේවාව ආරම්භ කරන්න (වින්‍යාස ගොනුව පූරණය කරන්න හෝ පොදු ජාල කියවීම සීමා කිරීමට සහ සාමාජිකයින්ට බලය පැවරීමට විධාන රේඛා පරාමිතීන් කෙලින්ම භාවිතා කරන්න):

```bash
# ආරම්භ කිරීමට ~/.config/sync0/config.nt පූරණය කරන්න
sync0 share --region SHA

# නැතහොත් පිරිසිදු විධාන රේඛාව හරහා පුද්ගලික බෙදාගැනීමේ කණ්ඩායමක් ප්‍රකාශනය කරන්න (පොදු ජාල කියවීම ස්වයංක්‍රීයව සීමා කිරීමට --allow-* සඳහන් කරන්න සහ බලයලත් පරිශීලකයින්ට පමණක් එයට ප්‍රවේශ විය හැක)
sync0 share team-vault:./vault \
  --allow-r 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c \
  --allow-rw 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f:uploads/bob,shared/common \
  --allow-w 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
```

### 5. නෝඩ් ලිපිනය, ව්‍යාපාරික කාඩ්පත සහ බහු භාෂා

```bash
# දේශීය IP-නිදහස් නෝඩ් ලිපිනය බලන්න (පළමු ධාවනය සඳහා යතුර ස්වයංක්‍රීයව ජනනය වේ)
sync0 id

# Ed25519 ස්වයං-අත්සන් නෝඩ් ව්‍යාපාරික කාඩ්පත ජනනය කරන්න (අන්වර්ථ නාමය, නගර කේතය, විද්‍යුත් තැපෑල, වෙබ් අඩවිය, හැඳින්වීම)
sync0 profile -u alice --region SHA --email alice@example.com -b "Shanghai node"

# පද්ධති භාෂාව පෙරනිමියෙන් අනුගමනය කරන සහ පරිසර විචල්‍යයන් හරහා මාරු කළ හැකි ගොඩනඟන ලද භාෂා 75 ක් ඇත.
SYNC0_LANG=en sync0 --help
```

### මූලික නිෂ්පාදන විශේෂාංග

- **පොදු යතුරු ලිපින ස්වයංක්‍රීය සිදුරු සිදුරු කිරීම**: මධ්‍යම සේවාදායකයක් සහ පොදු ජාල ලිපිනයක් අවශ්‍ය නොවේ, බෙදා හරින ලද ජාල පොදු යතුරු ලිපිනය මත පදනම්ව ස්වයංක්‍රීය NAT සිදුරු සිදුරු කිරීම.
- **මිලි තත්ත්පර මට්ටමේ තත්‍ය කාලීන සමමුහුර්තකරණය සහ පාරදත්ත දැනුවත් කිරීම**: ස්වදේශීය ගොනු සිදුවීම් නිරීක්ෂණය මත පදනම්ව (`FSEvents` / `inotify` / `ReadDirectoryChangesW`), ගොනු එකතු කිරීම්, මකාදැමීම්, POSIX අවසරයන් (`mode`) සහ millisecond (`mode`) සහ millisecond; අවසර හෝ වේලාව පමණක් වෙනස් කළ විට දත්ත අවහිර සම්ප්‍රේෂණය ශුන්‍ය වේ.
- **BT-විලාසය එකවර බාගත කිරීම සහ උඩුගත කිරීම සහ කලාපීය සම්බන්ධතා උපලේඛනගත කිරීම**: බාගැනීම් නෝඩය සම්පූර්ණ මුදල බාගත කිරීම සඳහා රැඳී සිටීමට අවශ්‍ය නොවේ. 128-බිට් හැෂ් චෙක්පත සමත් වූ සියලුම වාරණ කාල අන්තරයන් (`Op::Have`) අනෙකුත් නෝඩ් වලට සමගාමීව අදින්න සඳහා මතකය/තාවකාලික සංචිතය තුළ වහාම අගුලු දමනු ලැබේ. ගතික PEX node exchange සහ Slow node half preemption (Work-Stealing) සමඟ එක්ව, පොකුරු ප්‍රතිදානය උපරිම වේ.
- **ප්‍රති-ද්‍රෝහී නෝඩ් ටැම්පරින් සහ පොකුරු විෂ ප්‍රතිශක්තිය**: බලයලත් මූලාශ්‍ර ලැයිස්තුව `root_hash` ස්වයං-අනුකූල අගුලු දැමීම + අනිවාර්ය දෘඪාංග ත්වරණය `gxhash128` එක් එක් බ්ලොක් තැටිය මත තබා බාහිරව සීඩ් කිරීමට පෙර දිරවන සත්‍යාපනය; විකෘති වූ බ්ලොක් එකක් හමු වුවහොත්, මිලි තත්පර මට්ටමේ පරිපථ කඩනය අනිෂ්ට නෝඩය අවහිර කර අවංක මූලාශ්‍රයෙන් ස්වයංක්‍රීයව යථා තත්ත්වයට පත් කරයි.
- **FastCDC ස්ථානීය වර්ධක සහ කුඩා ගොනු එකතු කිරීම**: විශාල ගොනු අර්ධ වශයෙන් වෙනස් කිරීම සඳහා අවකල කුට්ටි පමණක් මාරු කර තැටියේ තබා ඇත; දැවැන්ත කුඩා ගොනු මතක ඇසුරුම් සහ උපසර්ග අවකල සම්පීඩනය ගොනුවෙන් ගොනුව වට-ගමන් උඩිස් ඉවත් කරයි.
- **විදුලිය ඇනහිටීමෙන් පසු ස්වයං-සුව කිරීම සහ නැවත ආරම්භ කිරීමෙන් පසු නැවත ආරම්භ කිරීම**: සීඩින් තත්ත්වය සහ ගොනු ලැයිස්තුව දිගටම පවත්වා ගැනීමට Redis-like RDB + AOF දෙමුහුන් ආකෘතිය (`.s0_subs.bin`) භාවිතා කරයි, දෛනික වෙනස්කම් මයික්‍රෝ තත්පර වලින් එකතු කරනු ලැබේ, සහ ස්වයංක්‍රීයව නැවත ලියා සංවිධානය කරනු ලැබේ. සේවාදායකය නැවත ආරම්භ කිරීමෙන් පසුව, නොබැඳි වෙනස්කම් ස්වයංක්‍රීයව සීඩින් නෝඩයට තල්ලු වේ.

## තාක්ෂණික ගෘහ නිර්මාණ ශිල්පය සහ ලියකියවිලි

- ** ද්විත්ව ගුවන් යානා විසන්ධි කිරීමේ ප්‍රොටෝකෝලය**:
  - **පාලනය සහ තත්‍ය කාලීන වෙනස්වීම් මතුපිට (`iroh` QUIC / TCP, පළමු බයිටය `PROTO_VERSION` අනුවාදය අතට අත දීම) **: Ed25519 ව්‍යාපාරික කාඩ්පත් සත්‍යාපනය, අවසර සත්‍යාපනය, රංචු බීජ සොයාගැනීම සහ `u64::MAX` level mass change streaming batching සහ <b>comid pressed batching> 4 සඳහා සහය සඳහා වගකිව යුතුය. තත්‍ය කාලීන තල්ලුව (`FsOp::Upsert` / `FsOp::Remove` / `FsOp::Meta` ප්‍රාථමික තුන).
  - **දත්ත බෙදා හැරීමේ මතුපිට (දේශීය UDP + `compio` අසමමුහුර්ත I/O) **: 20B සංයුක්ත ශීර්ෂකය, 18B TACK ආවර්තිතා ප්‍රතිපෝෂණ, BBRv3/Copa දෙමුහුන් තදබදය පාලනය, RACK-TLP පැකට් පාඩු ප්‍රතිසාධනය, පළමු වාරණ `gxhash128` අන්තයේ සිට අවසානය දක්වා සත්‍යාපනය අවහිර කරන්න.
