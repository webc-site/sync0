# sync0

`sync0` არის ბრძანების ხაზის ხელსაწყო ფაილების გადასატანად ქსელებში, კატალოგების თანდათანობით სინქრონიზაციისთვის და მონაცემების რამდენიმე კომპიუტერზე ერთდროულად განაწილებისთვის.

## ორიგინალური დიზაინის განზრახვა

მანქანებს შორის ოთახებში, ქვეყნებში ან გარემოში, სადაც ქსელის შეფერხებები და პაკეტების დაკარგვაა, ისეთი ხელსაწყოები, როგორიცაა `rsync` და `scp` ეფუძნება ერთიანი კავშირის თანმიმდევრობის დადასტურებას, რაც ზღუდავს გამტარუნარიანობის გამოყენებას; როდესაც რამდენიმე მანქანა ერთდროულად აგროვებს მონაცემებს ერთი და იმავე სერვერიდან, წყაროს სერვერის ქსელის ბარათი ადვილად შეიძლება გახდეს ბოსტნე.

`sync0`-ის მიზანია ორი პრობლემის გადაჭრა:

1. ნება მიეცით ფაილის და დირექტორიას სინქრონიზაციას ორ მანქანას შორის სრული ფიზიკური გამტარუნარიანობა და მხოლოდ შეცვლილი ნაწილის გადატანა, როდესაც ფაილი ნაწილობრივ შეცვლილია.
2. რამდენიმე მანქანას შეუძლია მონაცემთა ბლოკების გადაცემა ერთმანეთზე ერთი და იმავე დირექტორიას სინქრონიზაციისას, წყაროს სერვერზე დატვირთვის შემცირებას და სინქრონიზაციის საერთო დროის შემცირებას.

## სიჩქარის შედარება rsync-თან

სატესტო გარემო: ევროპული კვანძი $\მარცხნივ მარჯვნივ-arrow$ ჩრდილოეთ ამერიკის კვანძი, ორმხრივი დაყოვნება 86 ms, გაზომვის სრული დრო შრომატევადი დირექტორია სკანირების ჩათვლით, დუბლირების შედარება, ქსელის გადაცემა და დისკის განთავსების შემოწმება:

| გადაცემის სცენარი | მონაცემთა ზომა | `sync0` | `rsync` | მრავალჯერადი |
| :--- | :---: | :---: | :---: | :---: |
| 10000 პატარა ფაილი | 77.6 MB | 0.90 s (688 Mbps) | 4.86 s (128 Mbps) | 5.4x |
| კოდის და არქივის პაკეტები (`.tar`) | 512 MB | 1.94 s (2111 Mbps) | 9.36 s (438 Mbps) | 4.8x |
| ვიდეო ფაილი (`.mp4`) | 512 MB | 7.36 s (556 Mbps) | 12.11 s (338 Mbps) | 1.6x |
| დამატებითი სინქრონიზაცია (შეცვალეთ 1% შინაარსი) | 512 MB | 0.12 s | 1.85 s | 15.4x |

## შესრულების გაუმჯობესების მეთოდები

- **UDP კონკურენტული გადაცემა**: გაგზავნეთ მონაცემთა ბლოკები UDP-ის საშუალებით და მხოლოდ დაკარგული ფრაგმენტების ხელახლა გადაცემა, რათა თავიდან აიცილოთ ერთი პაკეტის დაკარგვა, რომელიც დაბლოკავს ფაილების შემდგომ გადაცემას.
- **შინაარსის სეგმენტაცია და დედუპლიკაცია**: დაყავით ფაილი მონაცემთა ბლოკებად შინაარსის მიხედვით და გამოთვალეთ შემოწმების მნიშვნელობა. იგივე კონტენტი უკვე მიმღებ ბოლოზე ხელახლა გამოიყენება პირდაპირ ადგილობრივად ქსელის დუბლირების გარეშე.
- **შეკუმშვის ავტომატური რეგულირება ქსელის სიჩქარის მიხედვით**: ჩართეთ შეკუმშვა შეკუმშვადი შინაარსისთვის, როგორიცაა ტექსტი და კოდი; ავტომატურად გამოტოვეთ შეკუმშვა ვიდეოებისთვის, სურათებისთვის, შეკუმშული პაკეტებისთვის ან მაღალსიჩქარიანი LAN-ის ქვეშ, CPU-ს მოხმარების შესამცირებლად.
- **მრავალ კვანძთან ახლოს გაყვანა**: როდესაც რამდენიმე მანქანა იჭერს ერთსა და იმავე დირექტორიას, მონაცემთა ბლოკები ერთდროულად გაიყვანება გადმოწერილი კვანძებიდან იმავე ქალაქში ან დაბალი შეყოვნებით.

## დააინსტალირეთ

### მეთოდი 1: ინსტალაცია Cargo-ს მეშვეობით

```bash
cargo install sync0
```

### მეთოდი 2: ჩამოტვირთეთ წინასწარ კომპილირებული ბინარები

გადადით [GitHub Releases](https://github.com/webc-site/sync0/releases), რომ ჩამოტვირთოთ `.tar.xz` შეკუმშული პაკეტი შესაბამისი სისტემისთვის (მხარდაჭერილია Linux x86_64/ARM64, macOS Apple Silicon/Intel, Windows x64/ARM64, Android ARM64/x86_64, FreeBSD, NetBSD). განშლის შემდეგ მოათავსეთ `sync0` `PATH` დირექტორიაში:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## მომხმარებლის სახელმძღვანელო

### 1. პირდაპირ გადაიტანეთ ფაილები ან დირექტორიები ორ მანქანას შორის

დაიწყეთ მონიტორინგი მიმღებ მანქანაზე და მიუთითეთ მიღებისა და შენახვის გზა:

```bash
sync0 recv 0.0.0.0:9000 ./backup
```

გაგზავნეთ ერთი ფაილი ან მთელი დირექტორია გამგზავნი მანქანიდან:

```bash
sync0 send ./project 192.168.1.10:9000
```

ხშირად გამოყენებული პარამეტრები:

```bash
# წაშალეთ ზედმეტი ფაილები, რომლებიც არსებობს მიმღებ ბოლოში, მაგრამ არა გაგზავნის ბოლოში (სარკის სინქრონიზაცია)
sync0 send ./project 192.168.1.10:9000 --delete

# გაგზავნის სიჩქარის შეზღუდვა (ერთეული: ბაიტი/წამი, მაგალითად 50 მბ/წმ)
sync0 send ./project 192.168.1.10:9000 --rate 50000000

# ჩუმი რეჟიმი (პროგრესის ზოლი არ არის ნაჩვენები)
sync0 send ./project 192.168.1.10:9000 -q
```

### 2. საზიარო დირექტორიების გამოქვეყნება და მრავალი კვანძიდან ამოღება

გამოაქვეყნეთ გაზიარებული დირექტორია (სახელწოდებით `dataset`) საწყისი სერვერზე:

```bash
sync0 share dataset ./data --region SHA
```

გაიყვანეთ გაზიარებული დირექტორია სხვა მანქანებზე (შეგიძლიათ შეავსოთ რამდენიმე კვანძის მისამართი ერთდროულად, გამოყოფილი მძიმებით, რათა ერთდროულად ამოიყვანოთ):

```bash
sync0 pull 10.0.0.1:9000,10.0.0.2:9000 dataset ./local_data
```

გაიყვანეთ მხოლოდ გარკვეული ქვეცნობარი საერთო დირექტორიაში:

```bash
sync0 pull 10.0.0.1:9000 dataset ./local_data --subpath 2026/logs
```

დააბრუნეთ ადგილობრივი ცვლილებები დისტანციურ საზიარო დირექტორიაში:

```bash
sync0 push 10.0.0.1:9000 dataset ./local_data
```

### 3. გამოიწერეთ კატალოგის ავტომატური განახლებები

გამოიწერეთ წყაროს კვანძის გაზიარებული დირექტორია. როდესაც ფაილი დაემატება ან იცვლება წყაროს დირექტორიაში, ის ავტომატურად სინქრონიზდება ადგილობრივ კომპიუტერთან. ამავდროულად, ლოკალური მანქანა ავტომატურად ემსახურება როგორც კვანძს სხვა მანქანების გასაყვანად:

```bash
sync0 sub 10.0.0.1:9000 dataset ./local_mirror
```

### 4. მრავალ მანქანური ჯგუფების ორმხრივი სინქრონიზაცია

მრავალი მანქანა უერთდება იმავე ჯგუფის სახელს და ნებისმიერი კვანძის დირექტორიაში ცვლილებები ავტომატურად სინქრონიზდება ჯგუფის სხვა კვანძებთან:

```bash
sync0 group team-docs ./docs 10.0.0.1:9000,10.0.0.2:9000
```

### 5. კვანძის პირადობა და პირადი სავიზიტო ბარათი

თითოეული კვანძი მხარს უჭერს მომხმარებლის სახელის, ქალაქის, ელ.ფოსტის, ვებსაიტის და პერსონალიზებული ხელმოწერის დაყენებას (მაქსიმუმ 256 სიმბოლო) და გადის ადგილობრივი პირადი გასაღების ხელმოწერის ავთენტიფიკაციას:

```bash
# იხილეთ ადგილობრივი საჯარო გასაღების ID (მიუთითეთ კონფიგურაციის დირექტორია, რომ დარჩეს გასაღები)
sync0 id -c ~/.config/sync0

# შექმენით და აჩვენეთ კვანძის სავიზიტო ბარათები პერსონალიზებული ხელმოწერებით
sync0 profile -c ~/.config/sync0 \
  -u alice \
  --region SHA \
  --email alice@example.com \
  --url https://example.com \
  -b "Shanghai backup node"
```

`share`, `pull`, `sub`, `group` ასევე შეიძლება გაშვებული იყოს ამ პროფილის პარამეტრებით:

```bash
sync0 share dataset ./data -c ~/.config/sync0 -u alice --region SHA -b "Shanghai backup node"
```

### 6. მრავალენოვანი გადართვა

`sync0` მხარს უჭერს 75 ენას. ნაგულისხმევად, ბრძანების ხაზის დახმარება და მოთხოვნა შესაბამის ენაზე ავტომატურად გამოჩნდება ოპერაციული სისტემის ენობრივი გარემოს მიხედვით; თუ სისტემის ენა არ არის მხარდაჭერილ სიაში, ინგლისური გამოიყენება ნაგულისხმევად.

ენის ხელით დასაზუსტებლად დააყენეთ გარემოს ცვლადი `SYNC0_LANG`:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
