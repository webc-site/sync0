# sync0

`sync0` पूरे नेटवर्क में फ़ाइलों को स्थानांतरित करने, निर्देशिकाओं को क्रमिक रूप से सिंक्रनाइज़ करने और एक साथ कई मशीनों में डेटा वितरित करने के लिए एक कमांड लाइन टूल है।

## मूल डिज़ाइन इरादा

क्रॉस-मशीन रूम, देशों या नेटवर्क विलंब और पैकेट हानि वाले वातावरण में, `rsync` और `scp` जैसे उपकरण एकल कनेक्शन अनुक्रम पुष्टिकरण पर आधारित होते हैं, जो बैंडविड्थ उपयोग को सीमित करता है; जब कई मशीनें एक ही समय में एक ही सर्वर से डेटा खींचती हैं, तो स्रोत सर्वर नेटवर्क कार्ड आसानी से एक बाधा बन सकता है।

`sync0` का लक्ष्य दो समस्याओं को हल करना है:

1. दो मशीनों के बीच फ़ाइल और निर्देशिका सिंक्रनाइज़ेशन को पूर्ण भौतिक बैंडविड्थ पर चलने दें, और फ़ाइल आंशिक रूप से संशोधित होने पर केवल परिवर्तित भाग को स्थानांतरित करें।
2. एक ही निर्देशिका को सिंक्रनाइज़ करते समय एकाधिक मशीनें डेटा ब्लॉक को एक-दूसरे में स्थानांतरित कर सकती हैं, जिससे स्रोत सर्वर पर लोड कम हो जाता है और समग्र सिंक्रनाइज़ेशन समय कम हो जाता है।

## rsync के साथ गति की तुलना

परीक्षण वातावरण: यूरोपीय नोड $\leftrightarrow$ उत्तर अमेरिकी नोड, राउंड-ट्रिप विलंब 86 एमएस, निर्देशिका स्कैनिंग, डिडुप्लीकेशन तुलना, नेटवर्क ट्रांसमिशन और डिस्क प्लेसमेंट सत्यापन सहित पूर्ण समय लेने वाली माप:

| ट्रांसमिशन परिदृश्य | डेटा का आकार | `sync0` | `rsync` | एकाधिक |
| :--- | :---: | :---: | :---: | :---: |
| 10,000 छोटी फ़ाइलें | 77.6 MB | 0.90 s (688 Mbps) | 4.86 s (128 Mbps) | 5.4x |
| कोड और संग्रह पैकेज (`.tar`) | 512 MB | 1.94 s (2111 Mbps) | 9.36 s (438 Mbps) | 4.8x |
| वीडियो फ़ाइल (`.mp4`) | 512 MB | 7.36 s (556 Mbps) | 12.11 s (338 Mbps) | 1.6x |
| वृद्धिशील तुल्यकालन (1% सामग्री संशोधित करें) | 512 MB | 0.12 s | 1.85 s | 15.4x |

## प्रदर्शन सुधार के तरीके

- **यूडीपी समवर्ती ट्रांसमिशन**: यूडीपी के माध्यम से डेटा ब्लॉक भेजें, और बाद के फ़ाइल स्थानांतरण को अवरुद्ध करने वाले एकल पैकेट हानि से बचने के लिए केवल खोए हुए टुकड़ों को पुनः प्रेषित करें।
- **सामग्री विभाजन और डिडुप्लीकेशन**: फ़ाइल को सामग्री के अनुसार डेटा ब्लॉक में विभाजित करें और चेक मान की गणना करें। प्राप्तकर्ता छोर पर पहले से मौजूद समान सामग्री को नेटवर्क की नकल किए बिना सीधे स्थानीय रूप से पुन: उपयोग किया जाता है।
- **नेटवर्क स्पीड के अनुसार संपीड़न को स्वचालित रूप से समायोजित करें**: पाठ और कोड जैसी संपीड़ित सामग्री के लिए संपीड़न चालू करें; सीपीयू खपत को कम करने के लिए वीडियो, चित्र, संपीड़ित पैकेज या हाई-स्पीड लैन के तहत स्वचालित रूप से संपीड़न छोड़ें।
- **मल्टी-नोड पास पुलिंग**: जब कई मशीनें एक ही निर्देशिका खींचती हैं, तो डेटा ब्लॉक एक ही शहर में या कम विलंबता के साथ डाउनलोड किए गए नोड्स से समवर्ती रूप से खींचे जाएंगे।

## स्थापित करना

### विधि 1: कार्गो के माध्यम से स्थापित करें

```bash
cargo install sync0
```

### विधि 2: पूर्व संकलित बायनेरिज़ डाउनलोड करें

संबंधित सिस्टम के लिए संपीड़ित पैकेज डाउनलोड करने के लिए [GitHub रिलीज़](https://github.com/webc-site/sync0/releases) पर जाएं (लिनक्स x86_64/ARM64, macOS Apple सिलिकॉन/इंटेल, Windows x64/ARM64, Android ARM64/x86_64, FreeBSD, NetBSD का समर्थन करता है)। अनज़िप करने के बाद, `sync0` को `PATH` डायरेक्टरी में रखें:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## उपयोगकर्ता गाइड

### 1. दो मशीनों के बीच फ़ाइलों या निर्देशिकाओं को सीधे स्थानांतरित करें

प्राप्तकर्ता मशीन पर निगरानी प्रारंभ करें और प्राप्त करने और सहेजने का पथ निर्दिष्ट करें:

```bash
sync0 recv 0.0.0.0:9000 ./backup
```

भेजने वाली मशीन से एक फ़ाइल या संपूर्ण निर्देशिका भेजें:

```bash
sync0 send ./project 192.168.1.10:9000
```

आमतौर पर उपयोग किए जाने वाले पैरामीटर:

```bash
# उन अनावश्यक फ़ाइलों को हटाएं जो प्राप्त करने वाले छोर पर मौजूद हैं लेकिन भेजने वाले छोर पर नहीं (मिरर सिंक्रोनाइज़ेशन)
sync0 send ./project 192.168.1.10:9000 --delete

# भेजने की दर सीमित करें (इकाई: बाइट्स/सेकंड, उदाहरण के लिए 50 एमबी/सेकेंड)
sync0 send ./project 192.168.1.10:9000 --rate 50000000

# साइलेंट मोड (कोई प्रगति पट्टी नहीं दिखाई गई)
sync0 send ./project 192.168.1.10:9000 -q
```

### 2. साझा निर्देशिकाओं को प्रकाशित करना और एकाधिक नोड्स से खींचना

मूल सर्वर पर एक साझा निर्देशिका (नाम `dataset`) प्रकाशित करें:

```bash
sync0 share dataset ./data --region SHA
```

अन्य मशीनों पर साझा निर्देशिका को खींचें (आप एक ही समय में कई नोड पते भर सकते हैं, समवर्ती रूप से खींचने के लिए अल्पविराम से अलग किए जा सकते हैं):

```bash
sync0 pull 10.0.0.1:9000,10.0.0.2:9000 dataset ./local_data
```

साझा निर्देशिका में केवल एक निश्चित उपनिर्देशिका खींचें:

```bash
sync0 pull 10.0.0.1:9000 dataset ./local_data --subpath 2026/logs
```

स्थानीय परिवर्तनों को दूरस्थ साझा निर्देशिका में वापस पुश करें:

```bash
sync0 push 10.0.0.1:9000 dataset ./local_data
```

### 3. कैटलॉग स्वचालित अपडेट की सदस्यता लें

स्रोत नोड की साझा निर्देशिका की सदस्यता लें। जब किसी फ़ाइल को स्रोत निर्देशिका में जोड़ा या संशोधित किया जाता है, तो यह स्वचालित रूप से स्थानीय कंप्यूटर से सिंक्रनाइज़ हो जाएगी। उसी समय, स्थानीय मशीन स्वचालित रूप से अन्य मशीनों को खींचने के लिए एक नोड के रूप में काम करेगी:

```bash
sync0 sub 10.0.0.1:9000 dataset ./local_mirror
```

### 4. मल्टी-मशीन समूहों का दो-तरफ़ा सिंक्रनाइज़ेशन

एकाधिक मशीनें एक ही समूह के नाम से जुड़ती हैं, और किसी भी नोड निर्देशिका में परिवर्तन स्वचालित रूप से समूह के अन्य नोड्स के साथ सिंक्रनाइज़ हो जाएंगे:

```bash
sync0 group team-docs ./docs 10.0.0.1:9000,10.0.0.2:9000
```

### 5. नोड पहचान और व्यक्तिगत व्यवसाय कार्ड

प्रत्येक नोड उपयोगकर्ता नाम, शहर, ईमेल, वेबसाइट और एक वैयक्तिकृत हस्ताक्षर (अधिकतम 256 अक्षर) सेट करने का समर्थन करता है, और स्थानीय निजी कुंजी हस्ताक्षर प्रमाणीकरण पास करता है:

```bash
# स्थानीय सार्वजनिक कुंजी आईडी देखें (कुंजी को जारी रखने के लिए कॉन्फ़िगरेशन निर्देशिका निर्दिष्ट करें)
sync0 id -c ~/.config/sync0

# वैयक्तिकृत हस्ताक्षरों के साथ नोड बिजनेस कार्ड बनाएं और प्रदर्शित करें
sync0 profile -c ~/.config/sync0 \
  -u alice \
  --region SHA \
  --email alice@example.com \
  --url https://example.com \
  -b "Shanghai backup node"
```

`share`, `pull`, `sub`, `group` को इन प्रोफ़ाइल मापदंडों के साथ भी लॉन्च किया जा सकता है:

```bash
sync0 share dataset ./data -c ~/.config/sync0 -u alice --region SHA -b "Shanghai backup node"
```

### 6. बहुभाषी स्विचिंग

`sync0` 75 भाषाओं का समर्थन करता है। डिफ़ॉल्ट रूप से, संबंधित भाषा में कमांड लाइन सहायता और संकेत ऑपरेटिंग सिस्टम के भाषा वातावरण के अनुसार स्वचालित रूप से प्रदर्शित होते हैं; यदि सिस्टम भाषा समर्थित सूची में नहीं है, तो डिफ़ॉल्ट रूप से अंग्रेजी का उपयोग किया जाता है।

भाषा को मैन्युअल रूप से निर्दिष्ट करने के लिए, पर्यावरण चर सेट करें `SYNC0_LANG`:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
