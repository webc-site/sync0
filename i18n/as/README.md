# sync0

`sync0` এটা পিয়ৰ-টু-পিয়ৰ (P2P) ফাইল অংশীদাৰী আৰু বহু-মেচিন সমন্বয় সঁজুলি যি Resilio Sync ৰ সৈতে প্ৰতিযোগিতা কৰে।

প্ৰতিটো যন্ত্ৰ এটা চাৰ্ভাৰ আৰু এটা ক্লাএন্ট দুয়োটা: যিকোনো ন'ডে একাধিক নথিপত্ৰ অংশীদাৰী গোট প্ৰকাশ কৰিব পাৰে। অন্য ন'ডসমূহে যোগদান কৰাৰ পিছত, সিহঁতে স্বয়ংক্ৰিয়ভাৱে সমনীয়া চাৰ্ভাৰৰ পৰা উপলব্ধ বীজ ন'ডসমূহ লাভ কৰিব পাৰে আৰু সিহতক একাধিক উৎসৰ পৰা একেলগে টানিব পাৰে। সমন্বয় সম্পূৰ্ণ হোৱাৰ পিছত, ডাউনলোডসমূহ ত্বৰান্বিত কৰিবলে অধিক ন'ডৰ বাবে বীজসমূহ স্বয়ংক্ৰিয়ভাৱে সৃষ্টি কৰা হ'ব।

## মূল হাইলাইটসমূহ

- **সকলো এটা চাৰ্ভাৰ আৰু এটা ক্লাএন্ট দুয়োটা**: Resilio Sync ৰ সৈতে তুলনাযোগ্য, কোনো কেন্দ্ৰীয় চাৰ্ভাৰ নিৰ্ভৰশীলতা নাই । যিকোনো ন'ডে একাধিক নথিপত্ৰ অংশীদাৰী গোট সৃষ্টি কৰিব পাৰে, আৰু অন্য মানুহৰ অংশীদাৰী গোটসমূহতো যোগদান কৰিব পাৰে; ন'ডসমূহে স্বয়ংক্ৰিয়ভাৱে বিনিময় আৰু উপলব্ধ বীজ ন'ডসমূহ লাভ কৰে যাতে একাধিক মেচিনৰ সমান্তৰাল টানি আৰু বাস্তৱ-সময়ৰ সমন্বয় লাভ কৰিব পাৰি।
- **IP-মুক্ত ন'ড ঠিকনা**: অবিকল্পিতভাৱে, ন'ড চাবি আৰু `base64url` এনকোড কৰা `iroh` ঠিকনা স্বয়ংক্ৰিয়ভাৱে `~/.config/sync0` ত সৃষ্টি কৰা হয় ৰাজহুৱা IP মনত ৰখা বা উন্মোচন কৰাৰ প্ৰয়োজন নোহোৱাকৈ ।
- **চাহিদা অনুসৰি বহু-নিৰ্বাচন কৰক সমন্বয়**: সমগ্ৰ অংশীদাৰী গোটৰ সমন্বয় সমৰ্থন কৰে, আৰু একে সময়তে একাধিক নথিপত্ৰ বা উপডাইৰেকটৰি নিৰ্ব্বাচন কৰি চাহিদা অনুসৰি সমন্বয় সমৰ্থন কৰে।
- **গোট সদস্য হাইৰাৰ্কিকেল অনুমতি আৰু আপল'ড পঞ্জিকা নিয়ন্ত্ৰণ**: কেৱল পঢ়া (`ro`), পঢ়া-লিখা আপলোড (`rw`), আৰু ব্যৱস্থাপনা (`admin`) অনুমতি সমৰ্থন কৰে, আৰু পৃথকে পৃথকে পথ উপসৰ্গ ধাৰ্য্য কৰিব পাৰে যি প্ৰতিজন সদস্যক আপলোড কৰিবলৈ অনুমতি দিয়া হৈছে (অবিকল্পিতভাৱে, অংশীদাৰী ৰ ৰূট পঞ্জিকালৈ আপলোড কৰাৰ অনুমতি দিয়া হৈছে)।
- **নেটৱাৰ্কসমূহৰ মাজেৰে সম্পূৰ্ণ-গতি আৰু বৃদ্ধিশীল সমন্বয়**: বৃহৎ নথিপত্ৰসমূহৰ সমান্তৰাল সংক্ৰমণ, মেমৰিত বৃহৎ সৰু নথিপত্ৰসমূহৰ সংগ্ৰহ, আৰু কেৱল সমন্বয় কৰা তথ্য ব্লকসমূহ যেতিয়া নথিপত্ৰসমূহ আংশিকভাৱে পৰিবৰ্তন কৰা হয়।

## স্থাপন কৰা

### পদ্ধতি ১: কাৰ্গোৰ জৰিয়তে সংস্থাপন কৰক

```bash
cargo install sync0
```

### পদ্ধতি ২: প্ৰিকম্পাইল কৰা বাইনাৰীসমূহ ডাউনলোড কৰক

সংশ্লিষ্ট চিস্টেমৰ বাবে `.tar.xz` সংকোচিত পেকেইজ ডাউনলোড কৰিবলে [GitHub Releases](https://github.com/webc-site/sync0/releases) লৈ যাওক (Linux, macOS, Windows, Android, FreeBSD, NetBSD সমৰ্থন কৰে), আনজিপ কৰক আৰু ইয়াক `PATH` ডাইৰেকটৰীত ৰাখক:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## সোনকালে আৰম্ভ কৰক

`sync0` এ `~/.config/sync0` অবিকল্পিতভাৱে বিন্যাস পঞ্জিকা হিচাপে ব্যৱহাৰ কৰে (যদি আপুনি অন্য পঞ্জিকালৈ সলনি কৰিব লাগে, আপুনি `-c <directory>` যোগ কৰিব পাৰে) ।

### 1. স্থানীয় ন'ড ঠিকনা আৰু বিজনেছ কাৰ্ড সংহতি চাওক

```bash
# স্থানীয় ন'ড ঠিকনা চাওক (কি' স্বয়ংক্ৰিয়ভাৱে ~/.config/sync0 ত প্ৰথমবাৰৰ বাবে সৃষ্টি কৰা হয়)
sync0 id

# এটা ব্যক্তিগত ন'ড বিজনেছ কাৰ্ড সৃষ্টি কৰক (256 শব্দৰ ভিতৰত ব্যৱহাৰকাৰীৰ নাম, চহৰ, ইমেইল, ৱেবছাইট আৰু স্বাক্ষৰ সমৰ্থন কৰে)
sync0 profile -u alice --region SHA --email alice@example.com --url https://example.com -b "Shanghai node"
```

### 2. একাধিক নথিপত্ৰ অংশীদাৰী গোট প্ৰকাশ কৰক আৰু গোট সদস্যৰ অনুমতিসমূহ সংহতি কৰক (`.nt` বিন্যাস)

`sync0` ক [NestedText](https://nestedtext.org) (`.nt`) বিন্যাসত বিন্যাস কৰা হৈছে । প্ৰতিজন ব্যৱহাৰকাৰীৰ এটা পৃথক `.nt` বিন্যাস নথিপত্ৰ আছে । আপুনি ব্যৱহাৰকাৰী আলেখ্যন পঞ্জিকা `users_dir` ৰ যোগেদি `config.nt` ত ধাৰ্য্য কৰিব পাৰে (যি স্বয়ংক্ৰিয়ভাৱে এই পঞ্জিকাৰ সকলো `.nt` নথিপত্ৰ অন্তৰ্ভুক্ত কৰে) । ব্যৱহাৰকাৰী আৰু আপলোড কৰিবলৈ অনুমতি দিয়া পথ উপসৰ্গ দুয়োটাই এটা অক্ৰমবদ্ধ তালিকা ব্যৱহাৰ কৰে (`-`)। **যেতিয়া আপল'ড পথ উপসৰ্গ পূৰণ কৰা নহয়, অংশীদাৰিত্বৰ ৰূট পঞ্জিকালৈ আপল'ড কৰাৰ অবিকল্পিতভাৱে অনুমতি দিয়া হয়** ।

1. `~/.config/sync0/users/` পঞ্জিকাত প্ৰতিটো সদস্যৰ বাবে পৃথক `.nt` বিন্যাস নথিপত্ৰ সৃষ্টি কৰক:

`~/.config/sync0/users/alice.nt` (কেৱল পঢ়িব পৰা সদস্য, হাৰ সীমিত `80MB`, `rate` এ `GB`, `MB`, `KB` এককসমূহ সমৰ্থন কৰে):

```yaml
id: 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c
perm: ro
rate: 80MB
```

`~/.config/sync0/users/bob.nt` (নিষিদ্ধ আপল'ড সদস্যসকল: কেৱল `uploads/bob` আৰু `shared/common` ডাইৰেকটৰিসমূহত আপল'ড কৰাৰ অনুমতি দিয়া হৈছে):

```yaml
id: 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f
perm: rw
write_prefix:
  - uploads/bob
  - shared/common
```

`~/.config/sync0/users/charlie.nt` (অবিকল্পিত সদস্য আপল'ড: যেতিয়া `write_prefix` বাদ দিয়া হয়, অংশীদাৰিত্বৰ ৰূট পঞ্জিকালৈ আপলোড কৰাৰ অবিকল্পিতভাৱে অনুমতি দিয়া হয়):

```yaml
id: 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
perm: rw
```

2. `~/.config/sync0/config.nt`ত ব্যৱহাৰকাৰী পঞ্জিকা আৰু একাধিক নথিপত্ৰ অংশীদাৰী গোট বিন্যাস কৰক:

```yaml
users_dir: ./users

groups:
  dataset:
    path: ./data
    auth: false
    perm: ro
    rate: 50MB

  models:
    path: ./models
    auth: false
    perm: ro
    rate: 1GB

  team-vault:
    path: ./vault
    auth: true
    perm: ro
    rate: 512KB
    users:
      - alice
      - bob
      - charlie
```

শ্বেয়াৰিং সেৱা আৰম্ভ কৰক:

```bash
# প্ৰত্যক্ষ আৰম্ভণি (~/.config/sync0/config.nt আৰু users_dir পঞ্জিকাসমূহত সকলো .nt ব্যৱহাৰকাৰী বিন্যাস স্বয়ংক্ৰিয়ভাৱে ল'ড কৰে)
sync0 share --region SHA

# অথবা একাধিক অংশীদাৰী গোট দ্ৰুতভাৱে প্ৰকাশ কৰক আৰু গোটৰ সদস্যসকলক আদেশ শাৰীৰ যোগেদি পোনপটীয়াকৈ অনুমোদন কৰক
sync0 share dataset:./data team-vault:./vault \
  --auth \
  --allow-ro 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c \
  --allow-rw 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f:uploads/bob,shared/common \
  --allow-rw 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
```

### 3. সকলো বিষয়বস্তু টানিব বা একাধিক ফাইল আৰু ডাইৰেকটৰি নিৰ্ব্বাচন কৰক (`sync0 pull`)

অংশীদাৰী গোটত সকলো উপলব্ধ বীজ ন'ড স্বয়ংক্ৰিয়ভাৱে লাভ কৰিবলে যিকোনো সমনীয়া ন'ডৰ সৈতে সংযোগ কৰক, আৰু একাধিক বীজ ন'ডৰ পৰা একেলগে টানিব:

```bash
# সম্পূৰ্ণ ডাটাছেট অংশীদাৰী গোটক স্থানীয় ./local_data লৈ টানিব
sync0 pull dataset:// ./local_data -p <ন'ড ঠিকনা>

# বহু-নিৰ্বাচন সমন্বয়: একেলগে একক নথিপত্ৰ docs/readme.md আৰু উপডাইৰেকটৰিসমূহ assets/icons, src/core টানিব
sync0 টানি ডাটাছেট://docs/readme.md,assets/icons,src/core ./স্থানীয়_ডাটা -p <ন'ড ঠিকনা>
```

### 4. এটা নথিপত্ৰ বা পঞ্জিকা এটা অংশীদাৰী গোটলৈ আপল'ড কৰক (`sync0 push`)

আপল'ড অনুমতি থকা সদস্যসকলে (`rw` বা `admin`) স্থানীয় নথিপত্ৰ বা পঞ্জিকাসমূহ দূৰৱৰ্তী অংশীদাৰী গোটসমূহলে আপল'ড কৰিব পাৰে:

```bash
# ৰূট পঞ্জিকা আপল'ড অনুমতি থকা সদস্যসমূহ: অংশীদাৰী ৰূট পঞ্জিকালৈ পোনপটীয়াকৈ আপল'ড কৰক
sync0 push team-vault:// ./new_release -p <ন'ড ঠিকনা>

# কেৱল এটা নিৰ্দিষ্ট উপসৰ্গলৈ অনুমোদিত সদস্যসকল (যেনে আপল'ড/বব): অনুমোদিত পথ উপসৰ্গলৈ আপল'ড কৰক
sync0 push team-vault://uploads/bob/report.pdf ./report.pdf -p <ন'ড ঠিকনা>
```

### 5. স্বয়ংক্ৰিয় ছিংক আৰু বীজ সিঁচাৰ বাবে চাবস্ক্ৰাইব কৰক (`sync0 sub`)

এটা নিৰ্দিষ্ট ন'ডৰ অংশীদাৰী গোটত স্বাক্ষৰণ কৰাৰ পিছত, স্থানীয় চাৰ্ভাৰ এটা গ্ৰহণকাৰী ক্লাএন্ট আৰু এটা নতুন বীজ চাৰ্ভাৰ দুয়োটা; যেতিয়া উৎস ন'ড নথিপত্ৰ আপডেইট কৰা হয়, ই স্বয়ংক্ৰিয়ভাৱে সমন্বয় কৰা হয় আৰু অন্য ন'ডসমূহৰ বাবে টুকুৰা কৰা ডাউনল'ডসমূহ প্ৰদান কৰে:

```bash
# সমগ্ৰ শ্বেয়াৰিং গ্ৰুপটো চাবস্ক্ৰাইব কৰক আৰু স্বয়ংক্ৰিয়ভাৱে ছিড কৰক
sync0 sub dataset:// ./local_mirror -p <ন'ড ঠিকনা>

# কেৱল ধাৰ্য্য কৰা নথিপত্ৰ আৰু উপডাইৰেকটৰিসমূহলে স্বাক্ষৰণ কৰিবলে আৰু সিহতক বীজ কৰিবলে বহু-নিৰ্বাচন কৰক
sync0 উপ ডাটাছেট://models/llama.onnx,configs ./local_mirror -p <ন'ড ঠিকনা>
```

### 6. বহু-মেচিন গোট সমনীয়া সমন্বয় (`sync0 group`)

একাধিক মেচিনে একেটা অংশীদাৰী গোটত যোগদান কৰে, ইটোৱে সিটোৱে স্বয়ংক্ৰিয়ভাৱে উপলব্ধ বীজ ন'ডসমূহ আৱিষ্কাৰ কৰে আৰু দুমুখীয়া সমন্বয় ৰক্ষণাবেক্ষণ কৰে (সম্পূৰ্ণ সমন্বয় বা নথিপত্ৰ আৰু পঞ্জিকাসমূহৰ একাধিক নিৰ্বাচন সমৰ্থন কৰে):

```bash
# গোটত সম্পূৰ্ণৰূপে যোগদান কৰক আৰু দুমুখীয়া সমন্বয়
sync0 গোট team-docs:// ./docs -p <ন'ড ঠিকনা>

# বহু-নিৰ্বাচিত সমন্বয় গোটত কেৱল wal পঞ্জিকা আৰু meta.json নথিপত্ৰ
sync0 গোট team-docs://wal,meta.json ./docs -p <ন'ড ঠিকনা>
```

### 7. দুটা মেচিনৰ মাজত পইণ্ট-টু-পইণ্ট প্ৰত্যক্ষ সংক্ৰমণ (`send` / `recv`)

এটা গোট পূৰ্ব-বিন্যাস কৰাৰ প্ৰয়োজন নাই, আৰু আপুনি অস্থায়ীভাৱে নথিপত্ৰ বা পঞ্জিকাসমূহ প্ৰত্যক্ষভাৱে দুটা যন্ত্ৰৰ মাজত স্থানান্তৰ কৰিব পাৰিব:

```bash
# ৰিচিভাৰ নিৰীক্ষণ
sync0 recv 0.0.0.0:9000 ./backup

# প্ৰেৰণ কৰা শেষে প্ৰত্যক্ষভাৱে নথিপত্ৰ বা পঞ্জিকাসমূহ স্থানান্তৰ কৰে (অতিৰিক্ত নথিপত্ৰসমূহ পৰিষ্কাৰ কৰিবলে বৈকল্পিক --delete mirror, --rate speed limit)
sync0 send ./project 192.168.1.10:9000
```

### 8. বহু ভাষাৰ চুইচিং

`sync0` এ ৭৫টা ভাষা সমৰ্থন কৰে, আৰু স্বয়ংক্ৰিয়ভাৱে অবিকল্পিতভাৱে চিস্টেম ভাষা পৰিৱেশ অনুসৰি সলনি কৰে; ইয়াক `SYNC0_LANG`ৰ যোগেদিও হস্তচালিতভাৱে ধাৰ্য্য কৰিব পাৰি:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
