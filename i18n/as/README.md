# sync0

`sync0` হৈছে এটা বিকেন্দ্ৰীকৃত P2P ফাইল অংশীদাৰী, বাস্তৱ-সময় সমন্বয় আৰু বহু-উৎস বিতৰণ সঁজুলি যিটো `rsync`ৰ ঠাইত ব্যৱহাৰ কৰা হয় - মহাদেশীয় WAN ৰ জুখিব পৰা গতি `rsync`ৰ **5.89×** (একক বিন্দু জ্যামিতিক গড় গতি **2.67×**, P2P দ্বৈত-উৎস জ্যামিতিক গড় গতি)লৈকে **৩.১৬×**), আৰু ট্ৰেন্সঅ'চেনিক হাই-লেটেন্সি লিংক P2P ত্বৰণ **৭.৬৮×** (সম্পূৰ্ণ-লিংক ২৪-পৰিস্থিতিৰ বিস্তৃত জ্যামিতিক গড় গতি **২.৫৬×**) পৰ্যন্ত।

প্ৰতিটো মেচিন এটা চাৰ্ভাৰ আৰু এটা ক্লাএন্ট দুয়োটা: এটা কেন্দ্ৰীয় চাৰ্ভাৰ বা এটা ৰাজহুৱা নে'টৱৰ্ক ঠিকনাৰ প্ৰয়োজন নাই, স্বয়ংক্ৰিয় ফুটা পাঞ্চিং বিতৰিত নে'টৱৰ্ক ৰাজহুৱা কি' ঠিকনাৰ ওপৰত ভিত্তি কৰি কৰা হয়, আৰু ই দুটা মেচিনৰ মাজত প্ৰত্যক্ষ সংক্ৰমণ, বহু-অংশীদাৰী গোট অনুমতি হ'ষ্টিং, চাহিদা অনুসৰি উপডাইৰেকটৰীৰ একাধিক নিৰ্বাচন, মিলিছেকেণ্ড-স্তৰৰ বাস্তৱ-সময় বৃদ্ধিমূলক সমন্বয় আৰু P2P বহু-উৎস সমকালীন ত্বৰণ সমৰ্থন কৰে।

## স্থাপন কৰা

### পদ্ধতি ১: কাৰ্গো স্থাপন

```bash
cargo install sync0
```

### পদ্ধতি ২: প্ৰিকম্পাইল কৰা বাইনাৰীসমূহ ডাউনলোড কৰক

চিস্টেমৰ সৈতে সংগতি ৰাখি `.tar.xz` সংকোচিত পেকেইজ ডাউনলোড কৰিবলৈ [GitHub Releases](https://github.com/webc-site/sync0/releases) লৈ যাওক (Linux, macOS, Windows, Android, iOS, FreeBSD সমৰ্থন কৰে), আনজিপ কৰক আৰু `PATH`ত ৰাখক:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## সোনকালে আৰম্ভ কৰক

### 1. দুটা মেচিনৰ মাজত শূন্য-বিন্যাস প্ৰত্যক্ষ সংক্ৰমণ (`send` / `recv`)

এটা অংশীদাৰী গোট বিন্যাস কৰাৰ প্ৰয়োজন নাই, প্ৰত্যক্ষভাৱে নথিপত্ৰ বা পঞ্জিকাসমূহ দুটা যন্ত্ৰৰ মাজত উচ্চ গতিৰে স্থানান্তৰ কৰক:

```bash
# গ্ৰহণকাৰী শেষে পৰ্টে শুনি থাকে আৰু ./backup লৈ লিখে
sync0 recv 0.0.0.0:9000 ./backup

# প্ৰেৰকৰ পৰা প্ৰত্যক্ষ সংক্ৰমণ (ঐচ্ছিক --অতিৰিক্ত ফাইলসমূহ পৰিষ্কাৰ কৰিবলৈ মিৰ'ৰ মচি পেলাওক, --হাৰ 50MB গতি সীমা)
sync0 send ./project 192.168.1.10:9000
```

### 2. পোষ্ট শ্বেয়াৰিং আৰু অন-ডিমাণ্ড পুল/আপলোড (`share` / `pull` / `push`)

```bash
# চাৰ্ভাৰ: আদেশৰ এটা শাৰীৰ সৈতে অংশীদাৰী গোট প্ৰকাশ কৰক (আৰম্ভণিৰ পিছত IP-মুক্ত iroh ন'ড ঠিকনা আউটপুট কৰক)
sync0 share dataset:./data

# ক্লাএন্ট: সমগ্ৰ ডাটাছেট অংশীদাৰী গোটক স্থানীয় ./local_data লৈ টানিব
sync0 pull dataset:// ./local_data -p <ন'ড ঠিকনা>

# ক্লাএন্ট: চাহিদা অনুসৰি একাধিক নিৰ্ব্বাচন টানিব (কেৱল ধাৰ্য্য কৰা একক নথিপত্ৰ আৰু উপডাইৰেকটৰিসমূহ সমন্বয় কৰক)
sync0 টানি ডাটাছেট://docs/readme.md,assets/icons,src/core ./স্থানীয়_ডাটা -p <ন'ড ঠিকনা>

# ক্লাএন্ট: ফাইলসমূহ বা ডাইৰেকটৰিসমূহ অনুমোদিত অংশীদাৰী গোটসমূহলে আপল'ড কৰক
sync0 push dataset://releases/v1 ./build_output -p <ন'ড ঠিকনা>
```

### 3. বাস্তৱ সময়ৰ চাবস্ক্ৰিপচন বীজ আৰু বহু-মেচিন দুমুখীয়া সমন্বয় (`sub` / `group`)

এটা দীঘলীয়া সংযোগ স্থাপন কৰাৰ পিছত, যদি কোনো নথিপত্ৰ **যোগ কৰা, পৰিবৰ্তন কৰা, মচি পেলোৱা, অনুমতিসমূহ পৰিবৰ্তন কৰা বা পৰিবৰ্তনৰ সময়** দূৰৱৰ্তী শেষত ঘটে, স্থানীয় পঞ্জিকাক বাস্তৱ সময়ত মিলিছেকেণ্ডত সমকালীনভাৱে আপডেইট কৰা হ'ব (নতুন/পৰিৱৰ্তিত বৃহৎ নথিপত্ৰসমূহে কেৱল পাৰ্থক্য ব্লকসমূহ টানিব আৰু সিহতক ঠাইত আপডেইট কৰিব, মচি পেলোৱা নথিপত্ৰসমূহে স্বয়ংক্ৰিয়ভাৱে স্থানীয় নথিপত্ৰসমূহ আৰু খালী পঞ্জিকাসমূহ পৰিষ্কাৰ কৰিব, আৰু কেৱল অনুমতি বা সময়ৰেম সলনি কৰিব শূন্য ডাটা ব্লক প্ৰত্যক্ষভাৱে):

- **`sync0 sub`(একমুখী বাস্তৱ-সময় প্ৰতিফলন + স্বয়ংক্ৰিয় বীজ সিঁচা)**: স্থানীয় বাস্তৱ-সময়ই অংশীদাৰী শেষৰ যোগ, বিলোপ আৰু পৰিবৰ্তন অনুসৰণ কৰে, আৰু স্বয়ংক্ৰিয়ভাৱে অন্য টানি ন'ডসমূহৰ বাবে সমান্তৰাল ত্বৰণ প্ৰদান কৰিবলে এটা P2P বীজ উৎস হিচাপে কাম কৰে।
- **`sync0 group`(বহু-মেচিন পিয়ৰ-টু-পিয়ৰ দু-পথ বাস্তৱ-সময় সমন্বয়)**: যদি ফাইলসমূহ গোটৰ যিকোনো মেচিনত যোগ কৰা হয়, মচি পেলোৱা হয়, বা পৰিবৰ্তন কৰা হয়, অন্য সকলো অনলাইন ন'ড বাস্তৱ সময়ত সমন্বয়ভাৱে আপডেইট কৰা হ'ব আৰু ইটোৱে সিটোৰ বাবে বীজ হিচাপে কাম কৰিব।

```bash
# সম্পূৰ্ণ অংশীদাৰী গোটত চাবস্ক্ৰাইব কৰক: দূৰৱৰ্তী সংযোজন, মচি পেলোৱা, আৰু পৰিবৰ্তনসমূহ বাস্তৱ সময়ত স্থানীয়ভাৱে সমন্বয় কৰা হয় আৰু স্বয়ংক্ৰিয়ভাৱে বীজ কৰা হয়
sync0 sub dataset:// ./local_mirror -p <ন'ড ঠিকনা>

# অন-ডিমাণ্ড বহু-নিৰ্বাচিত স্বাক্ষৰণ: কেৱল ধাৰ্য্য কৰা একক নথিপত্ৰ আৰু উপডাইৰেকটৰিসমূহ বাস্তৱ সময়ত সমন্বয় আৰু বীজ কৰক
sync0 উপ ডাটাছেট://models/llama.onnx,configs ./local_mirror -p <ন'ড ঠিকনা>

# বহু-মেচিন সমনীয়া গোট দুমুখীয়া বাস্তৱ-সময় সমন্বয় (সম্পূৰ্ণ বা কমা বহু-নিৰ্বাচিত পথসমূহো সমৰ্থন কৰে)
sync0 গোট team-docs:// ./docs -p <ন'ড ঠিকনা>
```

### 4. দলৰ বহু-অংশীদাৰী গোট আৰু সদস্য অনুমতি বিন্যাস (`.nt` বিন্যাস)

অবিকল্পিত বিন্যাস পঞ্জিকা হৈছে `~/.config/sync0` (`-c <directory>` ৰ যোগেদি সলনি কৰিব পাৰি), নূন্যতম [NestedText](https://nestedtext.org) (`.nt`) বিন্যাস ব্যৱহাৰ কৰি:
- **ৰাজহুৱা নে'টৱৰ্ক পঢ়া নিষিদ্ধ কৰা সমৰ্থন কৰে (কেৱল অনুমোদিত ব্যৱহাৰকাৰীয়ে পঢ়িব পাৰে)**: যেতিয়ালৈকে অংশীদাৰী গোটটো এটা `users:` সদস্য তালিকাৰ সৈতে বিন্যাস কৰা হয় (বা আদেশ শাৰীয়ে `--allow-r` / `--allow-rw` / `--allow-w` / `--auth` ধাৰ্য্য কৰে), চিস্টেমে **স্বয়ংক্ৰিয়ভাৱে ব্যক্তিগত প্ৰমাণীকৰণ অন কৰে (`auth: true`)** আৰু ৰাজহুৱা নে'টৱৰ্ক বেনামী ন'ড গণনা বা পঢ়া নিষিদ্ধ কৰে, আৰু P2P বীজ ন'ডসমূহলে স্বাক্ষৰিত কৰিলেও শ্বেত তালিকা একেলগে উত্তৰাধিকাৰী হ'ব, কেৱল অনুমোদিত ব্যৱহাৰকাৰীসকলক পঢ়াৰ অনুমতি দি; `users` ৰ সৈতে বিন্যাস নকৰা অংশীদাৰী গোটসমূহ অবিকল্পিতভাৱে ৰাজহুৱা আৰু কেৱল পঢ়িব পৰা (যদি আপুনি ৰাজহুৱা আৰু কেৱল পঢ়িব পৰা হ'ব বিচাৰে আৰু কেৱল ধাৰ্য্য কৰা সদস্যসকলৰ বাবে আপলোডসমূহৰ বাবে খোলা বিচাৰে, আপুনি স্পষ্টভাৱে `auth: false` সংহতি কৰিব পাৰে)।
- **সূক্ষ্ম-দানাযুক্ত পঢ়া-লিখা আৰু উপডাইৰেকটৰি প্ৰদানৰ অনুমতিসমূহ**: সদস্যসমূহ অবিকল্পিতভাৱে কেৱল পঢ়িব পৰা (`r` স্পষ্টভাৱে লিখাৰ প্ৰয়োজন নাই), আৰু সমৰ্থন কৰে `r` (কেৱল পঢ়িব পৰা), `w` (কেৱল ড্ৰপ বাকচলৈ লিখা, পঢ়িব নোৱাৰা), `rw` (পঢ়া-লিখা) আৰু `write_prefix` (আপল'ড কৰাৰ বাবে অনুমোদিত উপডাইৰেকটৰ উপসৰ্গ সীমিত কৰক) ।

**সদস্য বিন্যাসৰ উদাহৰণ (`~/.config/sync0/users/`):**

```yaml
# ~/.config/sync0/users/alice.nt (অবিকল্পিত কেৱল পঢ়িব পৰা, গতি সীমা 80MB)
id: 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c
rate: 80MB
```

```yaml
# ~/.config/sync0/users/bob.nt (পঢ়া আৰু লিখাৰ অনুমতি, কেৱল ধাৰ্য্য কৰা উপডাইৰেকটৰিলৈ আপল'ড কৰাৰ অনুমতি)
id: 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f
perm: rw
write_prefix:
  - uploads/bob
  - shared/common
```

```yaml
# ~/.config/sync0/users/charlie.nt (কেৱল ডেলিভাৰীৰ অনুমতি লিখা, পঢ়া নিষিদ্ধ)
id: 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
perm: w
```

**গোট বিন্যাসৰ উদাহৰণ অংশীদাৰী কৰা (`~/.config/sync0/config.nt`):**

```yaml
users_dir: ./users

groups:
  # বিন্যাস কৰা হোৱা নাই ব্যৱহাৰকাৰী: অবিকল্পিত ৰাজহুৱা নে'টৱৰ্ক কেৱল পঢ়িব পৰাকৈ
  dataset:
    path: ./data
    rate: 50MB

  # বিন্যাসিত ব্যৱহাৰকাৰীসকল: স্বয়ংক্ৰিয়ভাৱে ৰাজহুৱা নেটৱৰ্ক পঢ়া নিষিদ্ধ কৰক (কেৱল alice আৰু bob-এ পঢ়িব পাৰে, charlie-এ কেৱল ডেলিভাৰী আৰু আপলোড কৰিব পাৰে)
  team-vault:
    path: ./vault
    users:
      - alice
      - bob
      - charlie
```

সেৱা আৰম্ভ কৰক (বিন্যাস নথিপত্ৰ ল'ড কৰক বা ৰাজহুৱা নে'টৱৰ্ক পঢ়া প্ৰতিবন্ধক কৰিবলে আৰু সদস্যসকলক অনুমোদন কৰিবলে প্ৰত্যক্ষভাৱে আদেশ শাৰী প্ৰাচলসমূহ ব্যৱহাৰ কৰক):

```bash
# আৰম্ভ কৰিবলে ~/.config/sync0/config.nt লোড কৰক
sync0 share --region SHA
```

### মূল প্ৰডাক্টৰ বৈশিষ্ট্যসমূহ

- **ৰাজহুৱা কি' ঠিকনাকৰণ স্বয়ংক্ৰিয় ফুটা পাঞ্চিং**: এটা কেন্দ্ৰীয় চাৰ্ভাৰ আৰু ৰাজহুৱা নে'টৱৰ্ক ঠিকনাৰ প্ৰয়োজন নাই, বিতৰিত নে'টৱৰ্ক ৰাজহুৱা কি' ঠিকনাৰ ওপৰত ভিত্তি কৰি স্বয়ংক্ৰিয় NAT ফুটা পাঞ্চিং।
- **মিলিছেকেণ্ড-স্তৰৰ বাস্তৱ-সময় সমন্বয় আৰু মেটাডাটা সজাগতা**: স্থানীয় ফাইল ইভেন্ট নিৰীক্ষণ (`FSEvents` / `inotify` / `ReadDirectoryChangesW`), ফাইল সংযোজন, মচি পেলোৱা, POSIX অনুমতি (`mode`) আৰু মিলিছেকেণ্ড-স্তৰৰ পৰিবৰ্তন সময় (`mtime`)ৰ বাস্তৱ-সময়ৰ ঠেলাৰ ওপৰত ভিত্তি কৰি; শূন্য ডাটা ব্লক সংক্ৰমণ যেতিয়া কেৱল অনুমতি বা সময় পৰিবৰ্তন কৰা হয়।
- **BT-শৈলীৰ একেলগে ডাউনলোড আৰু আপলোড আৰু আঞ্চলিক আত্মীয়তা সময়সূচী**: ডাউনলোড কৰা ন'ডে সম্পূৰ্ণ পৰিমাণ ডাউনলোড হ'বলৈ অপেক্ষা কৰাৰ প্ৰয়োজন নাই। 128-বিট হেচ পৰীক্ষা পাছ কৰা সকলো ব্লক ব্যৱধান (`Op::Have`) অন্য ন'ডসমূহে সমান্তৰালভাৱে টানিবলে মেমৰি/অস্থায়ী পুলত তৎক্ষণাত লক কৰা হয়। গতিশীল PEX ন'ড বিনিময় আৰু লেহেমীয়া ন'ড হাফ প্ৰিইম্পচন (কাৰ্য্য-চুৰি)ৰ সৈতে একেলগে, ক্লাষ্টাৰ থ্ৰুপুট সৰ্বাধিক কৰা হয়।
- **এন্টি-মেলিচিয়াছ ন'ড টেম্পাৰিং আৰু ক্লাষ্টাৰ পইজনিং ইমিউনিটি**: কৰ্তৃত্বশীল উৎস তালিকা `root_hash` স্ব-সামঞ্জস্যপূৰ্ণ লক কৰা + বাধ্যতামূলক হাৰ্ডৱেৰ ত্বৰণ `gxhash128` প্ৰতিটো ব্লক ডিষ্কত ৰখাৰ আগতে আৰু বাহ্যিকভাৱে বীজ দিয়াৰ আগতে ডাইজেষ্ট পৰীক্ষণ; যদি এটা টেম্পাৰ কৰা ব্লক পোৱা যায়, মিলিছেকেণ্ড-স্তৰৰ চাৰ্কিট ব্ৰেকাৰে ক্ষতিকাৰক ন'ডক ব্লেকআউট কৰিব আৰু সৎ উৎসৰ পৰা স্বয়ংক্ৰিয়ভাৱে পুনৰুদ্ধাৰ কৰিব।
- **FastCDC ইন-চিটু বৃদ্ধি আৰু সৰু নথিপত্ৰ সংগ্ৰহ**: কেৱল ভিন্নতামূলক ব্লকসমূহক বৃহৎ নথিপত্ৰসমূহৰ আংশিক পৰিবৰ্তনৰ বাবে স্থানান্তৰ কৰা হয় আৰু ডিষ্কত ৰখা হয়; বৃহৎ সৰু নথিপত্ৰ মেমৰি পেকেজিং আৰু উপসৰ্গ ভিন্নতামূলক সংকোচনে নথিপত্ৰ-দ্বাৰা-ফাইল ৰাউণ্ড-ট্ৰিপ অভাৰহেড আঁতৰায়।
- **বিদ্যুৎ বিচ্ছিন্ন হোৱাৰ পিছত স্ব-নিৰাময় আৰু পুনৰাৰম্ভৰ পিছত পুনৰাৰম্ভ**: Redis-ৰ দৰে RDB + AOF হাইব্ৰিড বিন্যাস (`.s0_subs.bin`) বীজ সিঁচাৰ অৱস্থা আৰু নথিপত্ৰ তালিকা স্থায়ী কৰিবলে ব্যৱহাৰ কৰা হয়, দৈনিক পৰিবৰ্তনসমূহ মাইক্ৰ'ছেকেণ্ডত সংযুক্ত কৰা হয়, আৰু স্বয়ংক্ৰিয়ভাৱে পুনৰ লিখা আৰু নিয়মিতভাৱে সংগঠিত কৰা হয়। চাৰ্ভাৰ পুনৰাৰম্ভ কৰাৰ পিছত, অফলাইন পৰিবৰ্তনসমূহ স্বয়ংক্ৰিয়ভাৱে ছিডিং ন'ডলৈ ঠেলি দিয়া হয়।

## কাৰিকৰী স্থাপত্য আৰু নথিপত্ৰ

- **ডুৱেল প্লেন ডিকাপলিং প্ৰটোকল**:
  - **নিয়ন্ত্ৰণ আৰু বাস্তৱ-সময় পৰিবৰ্তন পৃষ্ঠ (`iroh` QUIC / TCP, প্ৰথম বাইট `PROTO_VERSION` সংস্কৰণ হেণ্ডশ্বেক) **: Ed25519 বিজনেছ কাৰ্ড সত্যাপন, অনুমতি সত্যাপন, Swarm বীজ আৱিষ্কাৰ, আৰু `u64::MAX` স্তৰ গণ পৰিবৰ্তন ষ্ট্ৰীমিং বেচিং আৰু `mzstd` সংকোচিত `SubPush` বাস্তৱ-সময়ৰ বাবে সমৰ্থনৰ বাবে দায়বদ্ধ push (`FsOp::Upsert` / `FsOp::Remove` / `FsOp::Meta` তিনিটা প্ৰিমিটিভ)।
  - **ডাটা বিতৰণ পৃষ্ঠ (স্থানীয় UDP + `compio` এচিনক্ৰ'নাছ I/O) **: 20B কমপেক্ট হেডাৰ, 18B TACK সময়কালীন প্ৰতিক্ৰিয়া, BBRv3/Copa হাইব্ৰিড কনজেচন নিয়ন্ত্ৰণ, RACK-TLP পেকেট ক্ষতি পুনৰুদ্ধাৰ, প্ৰথম-ব্লক শ্বেনন এণ্ট্ৰপি অভিযোজিত Zstd সংকোচন বাইপাছ, আৰু `gxhash128` ব্লক শেষৰ পৰা শেষলৈ সত্যাপন।
