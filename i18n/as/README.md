# sync0

`sync0` এটা আদেশ শাৰী সঁজুলি নে'টৱৰ্কসমূহৰ মাজেৰে নথিপত্ৰসমূহ স্থানান্তৰ কৰিবলে, বৃদ্ধিশীলভাৱে পঞ্জিকাসমূহ সমন্বয় কৰিবলে, আৰু একেলগে একাধিক যন্ত্ৰসমূহলে তথ্য বিতৰণ কৰিবলে।

## মূল ডিজাইনৰ উদ্দেশ্য

ক্ৰছ-মেচিন কক্ষ, দেশ, বা নে'টৱৰ্ক বিলম্ব আৰু পেকেট হেৰুৱাৰ পৰিৱেশত, সঁজুলি যেনে `rsync` আৰু `scp` একক সংযোগ ক্ৰম নিশ্চিতকৰণৰ ওপৰত ভিত্তি কৰি কৰা হয়, যি বেণ্ডউইডথ ব্যৱহাৰ সীমিত কৰে; যেতিয়া একাধিক মেচিনে একে সময়তে একেটা চাৰ্ভাৰৰ পৰা ডাটা টানে, উৎস চাৰ্ভাৰ নে'টৱৰ্ক কাৰ্ড সহজে এটা বটলনেক হ'ব পাৰে।

`sync0` ৰ লক্ষ্য হৈছে দুটা সমস্যা সমাধান কৰা:

1. দুয়োটা মেচিনৰ মাজত নথিপত্ৰ আৰু পঞ্জিকা সমন্বয়ক সম্পূৰ্ণ ভৌতিক বেণ্ডউইডথ চলাওক, আৰু কেৱল পৰিবৰ্তন কৰা অংশ স্থানান্তৰ কৰক যেতিয়া নথিপত্ৰ আংশিকভাৱে পৰিবৰ্তন কৰা হয় ।
2. একাধিক মেচিনে একে পঞ্জিকা সমন্বয় কৰাৰ সময়ত তথ্য ব্লকসমূহ ইটোৱে সিলৈ স্থানান্তৰ কৰিব পাৰে, উৎস চাৰ্ভাৰত লোড হ্ৰাস কৰি আৰু সামগ্ৰিক সমন্বয় সময় কম কৰি।

## rsync ৰ সৈতে গতি তুলনা

পৰীক্ষা পৰিৱেশ: ইউৰোপীয় ন'ড $\leftrightarrow$ উত্তৰ আমেৰিকান ন'ড, ৰাউণ্ড-ট্ৰিপ বিলম্ব 86 ms, ডাইৰেকটৰি স্কেনিং, ডিডুপ্লিকেচন তুলনা, নে'টৱৰ্ক সংক্ৰমণ আৰু ডিষ্ক স্থাপন সত্যাপন অন্তৰ্ভুক্ত কৰি সম্পূৰ্ণ সময়-ব্যৱহাৰকাৰী জুখি:

| সংক্ৰমণৰ পৰিস্থিতি | তথ্যৰ আকাৰ | `sync0` | `rsync` | একাধিক |
| :--- | :---: | :---: | :---: | :---: |
| ১০ হাজাৰ সৰু ফাইল | 77.6 MB | 0.90 s (688 Mbps) | 4.86 s (128 Mbps) | 5.4x |
| ক'ড আৰু আৰ্কাইভ পেকেইজসমূহ (`.tar`) | 512 MB | 1.94 s (2111 Mbps) | 9.36 s (438 Mbps) | 4.8x |
| ভিডিঅ' ফাইল (`.mp4`) | 512 MB | 7.36 s (556 Mbps) | 12.11 s (338 Mbps) | 1.6x |
| বৃদ্ধিশীল সমন্বয় (১% বিষয়বস্তু পৰিবৰ্তন কৰক) | 512 MB | 0.12 s | 1.85 s | 15.4x |

## কৰ্মক্ষমতা উন্নত কৰাৰ পদ্ধতি

- **UDP সমকালীন সংক্ৰমণ**: UDP ৰ যোগেদি তথ্য ব্লকসমূহ পঠাওক, আৰু কেৱল হেৰুৱা খণ্ডসমূহ পুনৰ প্ৰেৰণ কৰক যাতে এটা পেকেট হেৰুৱাই পৰৱৰ্তী নথিপত্ৰ স্থানান্তৰসমূহ ব্লক কৰে।
- **সামগ্ৰী বিভাজন আৰু ডিডুপ্লিকেচন**: বিষয়বস্তু অনুসৰি ফাইলটোক তথ্য ব্লকসমূহত বিভক্ত কৰক আৰু পৰীক্ষা মান গণনা কৰক। ইতিমধ্যে গ্ৰহণকাৰী শেষত থকা একে বিষয়বস্তুক নে'টৱৰ্কৰ নকল নকৰাকৈ প্ৰত্যক্ষভাৱে স্থানীয়ভাৱে পুনৰ ব্যৱহাৰ কৰা হয়।
- **নেটৱাৰ্কৰ গতি অনুসৰি স্বয়ংক্ৰিয়ভাৱে সংকোচন সামঞ্জস্য কৰক**: সংকোচনযোগ্য বিষয়বস্তু যেনে লিখনী আৰু ক'ডৰ বাবে সংকোচন অন কৰক; ভিডিঅ', ছবি, সংকোচিত পেকেইজসমূহৰ বাবে বা উচ্চ-গতিৰ LAN ৰ অন্তৰ্গত CPU ব্যৱহাৰ হ্ৰাস কৰিবলে স্বয়ংক্ৰিয়ভাৱে সংকোচন এৰি দিয়ক।
- **মাল্টি-ন'ড ওচৰৰ টানি**: যেতিয়া একাধিক মেচিনে একেটা ডাইৰেকটৰি টানে, ডাটা ব্লকসমূহক একে চহৰত ডাউনল'ড কৰা ন'ডসমূহৰ পৰা সমান্তৰালভাৱে বা কম বিলম্বৰ সৈতে টানিব।

## স্থাপন কৰা

### পদ্ধতি ১: কাৰ্গোৰ জৰিয়তে সংস্থাপন কৰক

```bash
cargo install sync0
```

### পদ্ধতি ২: প্ৰিকম্পাইল কৰা বাইনাৰীসমূহ ডাউনলোড কৰক

সংশ্লিষ্ট চিস্টেমৰ বাবে `.tar.xz` সংকোচিত পেকেইজ ডাউনল'ড কৰিবলে [GitHub মুক্তি](https://github.com/webc-site/sync0/releases) লৈ যাওক (Linux x86_64/ARM64, macOS Apple Silicon/Intel, Windows x64/ARM64, Android ARM64/x86_64, FreeBSD, NetBSD সমৰ্থন কৰে)। আনজিপ কৰাৰ পিছত, `sync0`ক `PATH` পঞ্জিকাত ৰাখক:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## ব্যৱহাৰকাৰী সহায়ক

### 1. দুটা মেচিনৰ মাজত নথিপত্ৰ বা পঞ্জিকাসমূহ প্ৰত্যক্ষভাৱে স্থানান্তৰ কৰক

গ্ৰহণকাৰী যন্ত্ৰত পৰ্যবেক্ষণ আৰম্ভ কৰক আৰু গ্ৰহণ আৰু সংৰক্ষণ পথ ধাৰ্য্য কৰক:

```bash
sync0 recv 0.0.0.0:9000 ./backup
```

প্ৰেৰণ কৰা যন্ত্ৰৰ পৰা এটা নথিপত্ৰ বা এটা সম্পূৰ্ণ পঞ্জিকা পঠাওক:

```bash
sync0 send ./project 192.168.1.10:9000
```

সাধাৰণতে ব্যৱহৃত প্ৰাচলসমূহ:

```bash
# গ্ৰহণকাৰী শেষত থকা কিন্তু প্ৰেৰণ কৰা শেষত নথকা অতিৰিক্ত ফাইলসমূহ মচি পেলাওক (মিৰ'ৰ সমন্বয়)
sync0 send ./project 192.168.1.10:9000 --delete

# প্ৰেৰণৰ হাৰ সীমিত কৰক (ইউনিট: বাইট/ছেকেণ্ড, উদাহৰণস্বৰূপে 50 MB/s)
sync0 send ./project 192.168.1.10:9000 --rate 50000000

# নিস্তব্ধ ধৰণ (কোনো অগ্ৰগতি বাৰ দেখুওৱা হোৱা নাই)
sync0 send ./project 192.168.1.10:9000 -q
```

### 2. অংশীদাৰী পঞ্জিকাসমূহ প্ৰকাশ কৰা আৰু একাধিক ন'ডৰ পৰা টানি লোৱা

এটা অংশীদাৰী পঞ্জিকা (নাম `dataset`) উৎপত্তি চাৰ্ভাৰত প্ৰকাশ কৰক:

```bash
sync0 share dataset ./data --region SHA
```

অন্য মেচিনসমূহত অংশীদাৰী পঞ্জিকা টানিব (আপুনি একে সময়তে একাধিক ন'ড ঠিকনা পূৰণ কৰিব পাৰে, একেলগে টানিবলৈ কমা দ্বাৰা পৃথক):

```bash
sync0 pull 10.0.0.1:9000,10.0.0.2:9000 dataset ./local_data
```

অংশীদাৰী পঞ্জিকাত কেৱল এটা নিৰ্দিষ্ট উপডাইৰেকটৰি টানিব:

```bash
sync0 pull 10.0.0.1:9000 dataset ./local_data --subpath 2026/logs
```

স্থানীয় পৰিবৰ্তনসমূহ দূৰৱৰ্তী অংশীদাৰী পঞ্জিকালৈ ঘূৰাই দিয়ক:

```bash
sync0 push 10.0.0.1:9000 dataset ./local_data
```

### 3. কেটেলগ স্বয়ংক্ৰিয় আপডেটসমূহৰ বাবে চাবস্ক্ৰাইব কৰক

উৎস ন'ডৰ অংশীদাৰী পঞ্জিকাত চাবস্ক্ৰাইব কৰক। যেতিয়া এটা নথিপত্ৰ উৎস পঞ্জিকাত যোগ বা পৰিবৰ্তন কৰা হয়, ইয়াক স্বয়ংক্ৰিয়ভাৱে স্থানীয় কমপিউটাৰৰ সৈতে সমন্বয় কৰা হ'ব। একে সময়তে, স্থানীয় মেচিনে স্বয়ংক্ৰিয়ভাৱে অন্য মেচিনসমূহৰ বাবে এটা ন'ড হিচাপে কাম কৰিব:

```bash
sync0 sub 10.0.0.1:9000 dataset ./local_mirror
```

### 4. বহু-মেচিন গোটৰ দুমুখীয়া সমন্বয়

একাধিক মেচিনে একেটা গোটৰ নামত যোগদান কৰে, আৰু যিকোনো ন'ড পঞ্জিকাত পৰিবৰ্তনসমূহ স্বয়ংক্ৰিয়ভাৱে গোটৰ অন্য ন'ডসমূহলে সমন্বয় কৰা হ'ব:

```bash
sync0 group team-docs ./docs 10.0.0.1:9000,10.0.0.2:9000
```

### 5. ন'ড পৰিচয় আৰু ব্যক্তিগত বিজনেছ কাৰ্ড

প্ৰতিটো ন'ডে ব্যৱহাৰকাৰীৰ নাম, চহৰ, ইমেইল, ৱেবছাইট আৰু এটা ব্যক্তিগতকৃত স্বাক্ষৰ সংহতি কৰে (সৰ্বাধিক ২৫৬ আখৰ), আৰু স্থানীয় ব্যক্তিগত কি' স্বাক্ষৰ প্ৰমাণীকৰণ পাছ কৰে:

```bash
# স্থানীয় ৰাজহুৱা চাবি ID চাওক (কি স্থায়ী কৰিবলে বিন্যাস পঞ্জিকা ধাৰ্য্য কৰক)
sync0 id -c ~/.config/sync0

# ব্যক্তিগতকৃত স্বাক্ষৰৰ সৈতে ন'ড বিজনেছ কাৰ্ডসমূহ সৃষ্টি আৰু প্ৰদৰ্শন কৰক
sync0 profile -c ~/.config/sync0 \
  -u alice \
  --region SHA \
  --email alice@example.com \
  --url https://example.com \
  -b "Shanghai backup node"
```

`share`, `pull`, `sub`, `group` এই আলেখ্যন প্ৰাচলসমূহৰ সৈতেও আৰম্ভ কৰিব পাৰি:

```bash
sync0 share dataset ./data -c ~/.config/sync0 -u alice --region SHA -b "Shanghai backup node"
```

### 6. বহু ভাষাৰ চুইচিং

`sync0` ৭৫টা ভাষা সমৰ্থন কৰে। অবিকল্পিতভাৱে, আদেশ শাৰীৰ সহায় আৰু সংশ্লিষ্ট ভাষাত প্ৰমপ্টসমূহ কাৰ্য্যকৰপ্ৰণালীৰ ভাষা পৰিৱেশ অনুসৰি স্বয়ংক্ৰিয়ভাৱে প্ৰদৰ্শিত হয়; যদি ব্যৱস্থাপ্ৰণালীৰ ভাষা সমৰ্থিত তালিকাত নাই, ইংৰাজী অবিকল্পিতভাৱে ব্যৱহাৰ কৰা হয় ।

ভাষাটো হস্তচালিতভাৱে ধাৰ্য্য কৰিবলে, পৰিৱেশ চলক `SYNC0_LANG` সংহতি কৰক:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
