# sync0

`sync0` सञ्जालहरूमा फाइलहरू स्थानान्तरण गर्न, बढ्दो रूपमा डाइरेक्टरीहरू सिङ्क्रोनाइज गर्न, र धेरै मेसिनहरूमा डाटा वितरण गर्नको लागि एक आदेश रेखा उपकरण हो।

## मूल डिजाइन इरादा

क्रस-मेसिन कोठाहरू, देशहरू, वा नेटवर्क ढिलाइ र प्याकेट हराउने वातावरणहरूमा, उपकरणहरू जस्तै `rsync` र `scp` एकल जडान अनुक्रम पुष्टिकरणमा आधारित हुन्छन्, जसले ब्यान्डविथ उपयोगलाई सीमित गर्दछ; जब धेरै मेसिनहरूले एउटै सर्भरबाट एकै समयमा डाटा तान्छन्, स्रोत सर्भर नेटवर्क कार्ड सजिलैसँग बाधा बन्न सक्छ।

`sync0` को लक्ष्य दुई समस्याहरू समाधान गर्नु हो:

1. दुई मेसिनहरू बीचको फाइल र डाइरेक्टरी सिङ्क्रोनाइजेसनलाई पूर्ण भौतिक ब्यान्डविथ चलाउन दिनुहोस्, र फाइल आंशिक रूपमा परिमार्जन हुँदा मात्र परिवर्तन गरिएको भाग स्थानान्तरण गर्नुहोस्।
2. एउटै डाइरेक्टरी सिङ्क्रोनाइज गर्दा, स्रोत सर्भरमा लोड घटाउने र समग्र सिङ्क्रोनाइजेसन समय छोटो पार्दा धेरै मेसिनहरूले डेटा ब्लकहरू एकअर्कामा स्थानान्तरण गर्न सक्छन्।

## rsync संग गति तुलना

परीक्षण वातावरण: युरोपेली नोड $\leftrightarrow$ उत्तर अमेरिकी नोड, राउन्ड-ट्रिप ढिलाइ 86 ms, डाइरेक्टरी स्क्यानिङ, डुप्लिकेशन तुलना, नेटवर्क ट्रान्समिसन र डिस्क प्लेसमेन्ट प्रमाणीकरण सहित पूरा समय-उपभोग मापन गर्दै:

| प्रसारण परिदृश्य | डाटा साइज | `sync0` | `rsync` | धेरै |
| :--- | :---: | :---: | :---: | :---: |
| 10,000 साना फाइलहरू | 77.6 MB | 0.90 s (688 Mbps) | 4.86 s (128 Mbps) | 5.4x |
| कोड र सङ्ग्रह प्याकेजहरू (`.tar`) | 512 MB | 1.94 s (2111 Mbps) | 9.36 s (438 Mbps) | 4.8x |
| भिडियो फाइल (`.mp4`) | 512 MB | 7.36 s (556 Mbps) | 12.11 s (338 Mbps) | 1.6x |
| वृद्धिशील सिंक्रोनाइजेसन (1% सामग्री परिमार्जन गर्नुहोस्) | 512 MB | 0.12 s | 1.85 s | 15.4x |

## प्रदर्शन सुधार विधिहरू

- **UDP समवर्ती प्रसारण**: UDP मार्फत डेटा ब्लकहरू पठाउनुहोस्, र त्यसपछिका फाइल स्थानान्तरणहरू अवरुद्ध गर्ने एकल प्याकेट हानिबाट बच्न हराएको टुक्राहरू मात्र पुन: ट्रान्समिट गर्नुहोस्।
- **सामग्री विभाजन र डुप्लिकेशन**: फाइललाई सामग्री अनुसार डाटा ब्लकहरूमा विभाजन गर्नुहोस् र जाँच मान गणना गर्नुहोस्। पहिले नै प्राप्त गर्ने अन्तमा उही सामग्री नेटवर्कको नक्कल नगरी सीधा स्थानीय रूपमा पुन: प्रयोग गरिन्छ।
- **सञ्जाल गति अनुसार स्वचालित रूपमा कम्प्रेसन समायोजन गर्नुहोस्**: कम्प्रेस गर्न मिल्ने सामग्री जस्तै पाठ र कोडको लागि कम्प्रेसन खोल्नुहोस्; CPU खपत कम गर्न भिडियोहरू, चित्रहरू, संकुचित प्याकेजहरू वा उच्च-गति LAN अन्तर्गत कम्प्रेसनलाई स्वचालित रूपमा छोड्नुहोस्।
- **मल्टी-नोड नजिकैको पुलिङ**: जब धेरै मेसिनहरूले एउटै डाइरेक्टरी तान्छन्, डाटा ब्लकहरू डाउनलोड गरिएका नोडहरूबाट एउटै सहरमा वा कम विलम्बतामा एकैसाथ तानिन्छन्।

## स्थापना गर्नुहोस्

### विधि १: कार्गो मार्फत स्थापना गर्नुहोस्

```bash
cargo install sync0
```

### विधि २: पूर्वकम्पाइल गरिएको बाइनरीहरू डाउनलोड गर्नुहोस्

`.tar.xz` सम्बद्ध प्रणालीका लागि कम्प्रेस गरिएको प्याकेज डाउनलोड गर्न [GitHub Releases](https://github.com/webc-site/sync0/releases) मा जानुहोस् (Linux x86_64/ARM64, macOS Apple Silicon/Intel, Windows x64/ARM64, Android ARM64/x86_64, FreeBSD, NetBSD लाई समर्थन गर्दछ)। अनजिप गरेपछि, `sync0` लाई `PATH` डाइरेक्टरीमा राख्नुहोस्:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## प्रयोगकर्ता गाइड

### 1. दुई मेसिनहरू बीच सीधा फाइलहरू वा डाइरेक्टरीहरू स्थानान्तरण गर्नुहोस्

प्राप्त गर्ने मेसिनमा निगरानी सुरु गर्नुहोस् र प्राप्त गर्ने र बचत गर्ने मार्ग निर्दिष्ट गर्नुहोस्:

```bash
sync0 recv 0.0.0.0:9000 ./backup
```

पठाउने मेसिनबाट एकल फाइल वा सम्पूर्ण डाइरेक्टरी पठाउनुहोस्:

```bash
sync0 send ./project 192.168.1.10:9000
```

सामान्यतया प्रयोग हुने प्यारामिटरहरू:

```bash
# रिडन्डन्ट फाइलहरू मेटाउनुहोस् जुन प्राप्त गर्ने अन्तमा अवस्थित छ तर पठाउने अन्तमा छैन (मिरर सिङ्क्रोनाइजेसन)
sync0 send ./project 192.168.1.10:9000 --delete

# पठाउने दर सीमित गर्नुहोस् (एकाइ: बाइट्स/सेकेन्ड, उदाहरणका लागि ५० MB/s)
sync0 send ./project 192.168.1.10:9000 --rate 50000000

# मौन मोड (कुनै प्रगति पट्टी देखाइएको छैन)
sync0 send ./project 192.168.1.10:9000 -q
```

### 2. साझा डाइरेक्टरीहरू प्रकाशित गर्दै र धेरै नोडहरूबाट तान्दै

मूल सर्भरमा साझा निर्देशिका (`dataset` नाम दिइएको) प्रकाशित गर्नुहोस्:

```bash
sync0 share dataset ./data --region SHA
```

अन्य मेसिनहरूमा साझा डाइरेक्टरी तान्नुहोस् (तपाईले एकै समयमा धेरै नोड ठेगानाहरू भर्न सक्नुहुन्छ, एकैसाथ तान्न अल्पविरामद्वारा विभाजित):

```bash
sync0 pull 10.0.0.1:9000,10.0.0.2:9000 dataset ./local_data
```

साझा डाइरेक्टरीमा केवल एक निश्चित उपनिर्देशिका तान्नुहोस्:

```bash
sync0 pull 10.0.0.1:9000 dataset ./local_data --subpath 2026/logs
```

स्थानीय परिवर्तनहरूलाई रिमोट साझा डाइरेक्टरीमा पुश गर्नुहोस्:

```bash
sync0 push 10.0.0.1:9000 dataset ./local_data
```

### 3. क्याटलग स्वचालित अपडेटहरूको सदस्यता लिनुहोस्

स्रोत नोडको साझा डाइरेक्टरीमा सदस्यता लिनुहोस्। जब फाइल स्रोत डाइरेक्टरीमा थपिन्छ वा परिमार्जन गरिन्छ, यो स्वचालित रूपमा स्थानीय कम्प्युटरमा सिंक्रोनाइज हुनेछ। एकै समयमा, स्थानीय मेसिनले स्वचालित रूपमा अन्य मेसिनहरूलाई तान्नको लागि नोडको रूपमा सेवा गर्नेछ:

```bash
sync0 sub 10.0.0.1:9000 dataset ./local_mirror
```

### 4. बहु-मेसिन समूहहरूको दुई-तरिका सिंक्रोनाइजेसन

धेरै मेसिनहरू एउटै समूह नाममा सामेल हुन्छन्, र कुनै पनि नोड डाइरेक्टरीमा भएका परिवर्तनहरू समूहका अन्य नोडहरूमा स्वचालित रूपमा सिङ्क्रोनाइज हुनेछन्:

```bash
sync0 group team-docs ./docs 10.0.0.1:9000,10.0.0.2:9000
```

### 5. नोड पहिचान र व्यक्तिगत व्यापार कार्ड

प्रत्येक नोडले प्रयोगकर्ता नाम, शहर, इमेल, वेबसाइट र व्यक्तिगत हस्ताक्षर (अधिकतम 256 क्यारेक्टरहरू) सेट गर्न समर्थन गर्दछ, र स्थानीय निजी कुञ्जी हस्ताक्षर प्रमाणीकरण पास गर्दछ:

```bash
# स्थानीय सार्वजनिक कुञ्जी ID हेर्नुहोस् (कुञ्जी जारी राख्न कन्फिगरेसन डाइरेक्टरी निर्दिष्ट गर्नुहोस्)
sync0 id -c ~/.config/sync0

# व्यक्तिगत हस्ताक्षरको साथ नोड व्यापार कार्डहरू उत्पन्न र प्रदर्शन गर्नुहोस्
sync0 profile -c ~/.config/sync0 \
  -u alice \
  --region SHA \
  --email alice@example.com \
  --url https://example.com \
  -b "Shanghai backup node"
```

`share`, `pull`, `sub`, `group` यी प्रोफाइल प्यारामिटरहरूसँग पनि सुरू गर्न सकिन्छ:

```bash
sync0 share dataset ./data -c ~/.config/sync0 -u alice --region SHA -b "Shanghai backup node"
```

### 6. बहु-भाषा स्विचिङ

`sync0` ७५ भाषाहरूलाई समर्थन गर्दछ। पूर्वनिर्धारित रूपमा, कमाण्ड लाइन मद्दत र सम्बन्धित भाषामा प्रम्प्टहरू स्वचालित रूपमा अपरेटिङ सिस्टमको भाषा वातावरण अनुसार प्रदर्शित हुन्छन्; यदि प्रणाली भाषा समर्थित सूचीमा छैन भने, अंग्रेजी पूर्वनिर्धारित रूपमा प्रयोग गरिन्छ।

भाषा म्यानुअल रूपमा निर्दिष्ट गर्न, वातावरण चर सेट गर्नुहोस् `SYNC0_LANG`:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
