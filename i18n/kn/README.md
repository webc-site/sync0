# sync0

`sync0` ಎನ್ನುವುದು ನೆಟ್‌ವರ್ಕ್‌ಗಳಾದ್ಯಂತ ಫೈಲ್‌ಗಳನ್ನು ವರ್ಗಾಯಿಸಲು, ಡೈರೆಕ್ಟರಿಗಳನ್ನು ಹೆಚ್ಚುತ್ತಿರುವ ಸಿಂಕ್ರೊನೈಸ್ ಮಾಡಲು ಮತ್ತು ಏಕಕಾಲದಲ್ಲಿ ಅನೇಕ ಯಂತ್ರಗಳಿಗೆ ಡೇಟಾವನ್ನು ವಿತರಿಸಲು ಆಜ್ಞಾ ಸಾಲಿನ ಸಾಧನವಾಗಿದೆ.

## ಮೂಲ ವಿನ್ಯಾಸದ ಉದ್ದೇಶ

ನೆಟ್‌ವರ್ಕ್ ವಿಳಂಬಗಳು ಮತ್ತು ಪ್ಯಾಕೆಟ್ ನಷ್ಟದೊಂದಿಗೆ ಅಡ್ಡ-ಯಂತ್ರ ಕೊಠಡಿಗಳು, ದೇಶಗಳು ಅಥವಾ ಪರಿಸರಗಳಲ್ಲಿ, `rsync` ಮತ್ತು `scp` ನಂತಹ ಸಾಧನಗಳು ಏಕ ಸಂಪರ್ಕ ಅನುಕ್ರಮ ದೃಢೀಕರಣವನ್ನು ಆಧರಿಸಿವೆ, ಇದು ಬ್ಯಾಂಡ್‌ವಿಡ್ತ್ ಬಳಕೆಯನ್ನು ಮಿತಿಗೊಳಿಸುತ್ತದೆ; ಅನೇಕ ಯಂತ್ರಗಳು ಒಂದೇ ಸರ್ವರ್‌ನಿಂದ ಒಂದೇ ಸಮಯದಲ್ಲಿ ಡೇಟಾವನ್ನು ಎಳೆದಾಗ, ಮೂಲ ಸರ್ವರ್ ನೆಟ್‌ವರ್ಕ್ ಕಾರ್ಡ್ ಸುಲಭವಾಗಿ ಅಡಚಣೆಯಾಗಬಹುದು.

ಎರಡು ಸಮಸ್ಯೆಗಳನ್ನು ಪರಿಹರಿಸುವುದು `sync0` ಗುರಿಯಾಗಿದೆ:

1. ಎರಡು ಯಂತ್ರಗಳ ನಡುವಿನ ಫೈಲ್ ಮತ್ತು ಡೈರೆಕ್ಟರಿ ಸಿಂಕ್ರೊನೈಸೇಶನ್ ಪೂರ್ಣ ಭೌತಿಕ ಬ್ಯಾಂಡ್‌ವಿಡ್ತ್ ಅನ್ನು ಚಲಾಯಿಸಲಿ ಮತ್ತು ಫೈಲ್ ಅನ್ನು ಭಾಗಶಃ ಮಾರ್ಪಡಿಸಿದಾಗ ಮಾತ್ರ ಬದಲಾದ ಭಾಗವನ್ನು ವರ್ಗಾಯಿಸಿ.
2. ಒಂದೇ ಡೈರೆಕ್ಟರಿಯನ್ನು ಸಿಂಕ್ರೊನೈಸ್ ಮಾಡುವಾಗ, ಮೂಲ ಸರ್ವರ್‌ನಲ್ಲಿನ ಲೋಡ್ ಅನ್ನು ಕಡಿಮೆ ಮಾಡುವಾಗ ಮತ್ತು ಒಟ್ಟಾರೆ ಸಿಂಕ್ರೊನೈಸೇಶನ್ ಸಮಯವನ್ನು ಕಡಿಮೆ ಮಾಡುವಾಗ ಬಹು ಯಂತ್ರಗಳು ಡೇಟಾ ಬ್ಲಾಕ್‌ಗಳನ್ನು ಪರಸ್ಪರ ವರ್ಗಾಯಿಸಬಹುದು.

## rsync ನೊಂದಿಗೆ ವೇಗ ಹೋಲಿಕೆ

ಪರೀಕ್ಷಾ ಪರಿಸರ: ಯುರೋಪಿಯನ್ ನೋಡ್ $\leftrightarrow$ ಉತ್ತರ ಅಮೆರಿಕಾದ ನೋಡ್, ರೌಂಡ್-ಟ್ರಿಪ್ ವಿಳಂಬ 86 ms, ಡೈರೆಕ್ಟರಿ ಸ್ಕ್ಯಾನಿಂಗ್, ಡಿಡ್ಪ್ಲಿಕೇಶನ್ ಹೋಲಿಕೆ, ನೆಟ್‌ವರ್ಕ್ ಟ್ರಾನ್ಸ್‌ಮಿಷನ್ ಮತ್ತು ಡಿಸ್ಕ್ ಪ್ಲೇಸ್‌ಮೆಂಟ್ ಪರಿಶೀಲನೆ ಸೇರಿದಂತೆ ಸಂಪೂರ್ಣ ಸಮಯವನ್ನು ಅಳೆಯುತ್ತದೆ:

| ಪ್ರಸರಣ ಸನ್ನಿವೇಶ | ಡೇಟಾ ಗಾತ್ರ | `sync0` | `rsync` | ಬಹು |
| :--- | :---: | :---: | :---: | :---: |
| 10,000 ಸಣ್ಣ ಫೈಲ್‌ಗಳು | 77.6 MB | 0.90 s (688 Mbps) | 4.86 s (128 Mbps) | 5.4x |
| ಕೋಡ್ ಮತ್ತು ಆರ್ಕೈವ್ ಪ್ಯಾಕೇಜುಗಳು (`.tar`) | 512 MB | 1.94 s (2111 Mbps) | 9.36 s (438 Mbps) | 4.8x |
| ವೀಡಿಯೊ ಫೈಲ್ (`.mp4`) | 512 MB | 7.36 s (556 Mbps) | 12.11 s (338 Mbps) | 1.6x |
| ಹೆಚ್ಚುತ್ತಿರುವ ಸಿಂಕ್ರೊನೈಸೇಶನ್ (1% ವಿಷಯವನ್ನು ಮಾರ್ಪಡಿಸಿ) | 512 MB | 0.12 s | 1.85 s | 15.4x |

## ಕಾರ್ಯಕ್ಷಮತೆಯನ್ನು ಸುಧಾರಿಸುವ ವಿಧಾನಗಳು

- **UDP ಏಕಕಾಲಿಕ ಪ್ರಸರಣ**: UDP ಮೂಲಕ ಡೇಟಾ ಬ್ಲಾಕ್‌ಗಳನ್ನು ಕಳುಹಿಸಿ ಮತ್ತು ನಂತರದ ಫೈಲ್ ವರ್ಗಾವಣೆಯನ್ನು ನಿರ್ಬಂಧಿಸುವ ಒಂದು ಪ್ಯಾಕೆಟ್ ನಷ್ಟವನ್ನು ತಪ್ಪಿಸಲು ಕಳೆದುಹೋದ ತುಣುಕುಗಳನ್ನು ಮಾತ್ರ ಮರುಪ್ರಸಾರ ಮಾಡಿ.
- **ವಿಷಯ ವಿಭಜನೆ ಮತ್ತು ಅಪಕರ್ಷಣೆ**: ವಿಷಯಕ್ಕೆ ಅನುಗುಣವಾಗಿ ಫೈಲ್ ಅನ್ನು ಡೇಟಾ ಬ್ಲಾಕ್‌ಗಳಾಗಿ ವಿಭಜಿಸಿ ಮತ್ತು ಚೆಕ್ ಮೌಲ್ಯವನ್ನು ಲೆಕ್ಕಾಚಾರ ಮಾಡಿ. ಈಗಾಗಲೇ ಸ್ವೀಕರಿಸುವ ತುದಿಯಲ್ಲಿರುವ ಅದೇ ವಿಷಯವನ್ನು ನೆಟ್‌ವರ್ಕ್ ಅನ್ನು ನಕಲು ಮಾಡದೆಯೇ ನೇರವಾಗಿ ಸ್ಥಳೀಯವಾಗಿ ಮರುಬಳಕೆ ಮಾಡಲಾಗುತ್ತದೆ.
- **ನೆಟ್‌ವರ್ಕ್ ವೇಗಕ್ಕೆ ಅನುಗುಣವಾಗಿ ಸಂಕೋಚನವನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಹೊಂದಿಸಿ**: ಪಠ್ಯ ಮತ್ತು ಕೋಡ್‌ನಂತಹ ಸಂಕುಚಿತ ವಿಷಯಕ್ಕಾಗಿ ಸಂಕುಚಿತಗೊಳಿಸುವಿಕೆಯನ್ನು ಆನ್ ಮಾಡಿ; CPU ಬಳಕೆಯನ್ನು ಕಡಿಮೆ ಮಾಡಲು ವೀಡಿಯೊಗಳು, ಚಿತ್ರಗಳು, ಸಂಕುಚಿತ ಪ್ಯಾಕೇಜ್‌ಗಳು ಅಥವಾ ಹೆಚ್ಚಿನ ವೇಗದ LAN ಅಡಿಯಲ್ಲಿ ಸಂಕೋಚನವನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಬಿಟ್ಟುಬಿಡಿ.
- **ಮಲ್ಟಿ-ನೋಡ್ ಹತ್ತಿರದ ಎಳೆಯುವಿಕೆ**: ಅನೇಕ ಯಂತ್ರಗಳು ಒಂದೇ ಡೈರೆಕ್ಟರಿಯನ್ನು ಎಳೆದಾಗ, ಅದೇ ನಗರದಲ್ಲಿ ಅಥವಾ ಕಡಿಮೆ ಸುಪ್ತತೆಯೊಂದಿಗೆ ಡೌನ್‌ಲೋಡ್ ಮಾಡಲಾದ ನೋಡ್‌ಗಳಿಂದ ಡೇಟಾ ಬ್ಲಾಕ್‌ಗಳನ್ನು ಏಕಕಾಲದಲ್ಲಿ ಎಳೆಯಲಾಗುತ್ತದೆ.

## ಸ್ಥಾಪಿಸಿ

### ವಿಧಾನ 1: ಕಾರ್ಗೋ ಮೂಲಕ ಸ್ಥಾಪಿಸಿ

```bash
cargo install sync0
```

### ವಿಧಾನ 2: ಪೂರ್ವ ಕಂಪೈಲ್ ಮಾಡಿದ ಬೈನರಿಗಳನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ

ಅನುಗುಣವಾದ ಸಿಸ್ಟಮ್‌ಗಾಗಿ `.tar.xz` ಸಂಕುಚಿತ ಪ್ಯಾಕೇಜ್ ಅನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡಲು [GitHub ಬಿಡುಗಡೆಗಳು](https://github.com/webc-site/sync0/releases) ಗೆ ಹೋಗಿ (Linux x86_64/ARM64, macOS Apple Silicon/Intel, Windows x64/ARM64, Android ARM64/x86_64, NetBSD, FreeBSD ಅನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ). ಅನ್ಜಿಪ್ ಮಾಡಿದ ನಂತರ, `sync0` ಅನ್ನು `PATH` ಡೈರೆಕ್ಟರಿಯಲ್ಲಿ ಇರಿಸಿ:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## ಬಳಕೆದಾರ ಮಾರ್ಗದರ್ಶಿ

### 1. ಎರಡು ಯಂತ್ರಗಳ ನಡುವೆ ಫೈಲ್‌ಗಳು ಅಥವಾ ಡೈರೆಕ್ಟರಿಗಳನ್ನು ನೇರವಾಗಿ ವರ್ಗಾಯಿಸಿ

ಸ್ವೀಕರಿಸುವ ಯಂತ್ರದಲ್ಲಿ ಮೇಲ್ವಿಚಾರಣೆಯನ್ನು ಪ್ರಾರಂಭಿಸಿ ಮತ್ತು ಸ್ವೀಕರಿಸುವ ಮತ್ತು ಉಳಿಸುವ ಮಾರ್ಗವನ್ನು ಸೂಚಿಸಿ:

```bash
sync0 recv 0.0.0.0:9000 ./backup
```

ಕಳುಹಿಸುವ ಯಂತ್ರದಿಂದ ಒಂದೇ ಫೈಲ್ ಅಥವಾ ಸಂಪೂರ್ಣ ಡೈರೆಕ್ಟರಿಯನ್ನು ಕಳುಹಿಸಿ:

```bash
sync0 send ./project 192.168.1.10:9000
```

ಸಾಮಾನ್ಯವಾಗಿ ಬಳಸುವ ನಿಯತಾಂಕಗಳು:

```bash
# ಸ್ವೀಕರಿಸುವ ತುದಿಯಲ್ಲಿ ಅಸ್ತಿತ್ವದಲ್ಲಿರುವ ಅನಗತ್ಯ ಫೈಲ್‌ಗಳನ್ನು ಅಳಿಸಿ ಆದರೆ ಕಳುಹಿಸುವ ತುದಿಯಲ್ಲಿಲ್ಲ (ಕನ್ನಡಿ ಸಿಂಕ್ರೊನೈಸೇಶನ್)
sync0 send ./project 192.168.1.10:9000 --delete

# ಕಳುಹಿಸುವ ದರವನ್ನು ಮಿತಿಗೊಳಿಸಿ (ಯೂನಿಟ್: ಬೈಟ್‌ಗಳು/ಸೆಕೆಂಡ್, ಉದಾಹರಣೆಗೆ 50 MB/s)
sync0 send ./project 192.168.1.10:9000 --rate 50000000

# ಸೈಲೆಂಟ್ ಮೋಡ್ (ಪ್ರಗತಿ ಪಟ್ಟಿಯನ್ನು ತೋರಿಸಲಾಗಿಲ್ಲ)
sync0 send ./project 192.168.1.10:9000 -q
```

### 2. ಹಂಚಿದ ಡೈರೆಕ್ಟರಿಗಳನ್ನು ಪ್ರಕಟಿಸುವುದು ಮತ್ತು ಬಹು ನೋಡ್‌ಗಳಿಂದ ಎಳೆಯುವುದು

ಮೂಲ ಸರ್ವರ್‌ನಲ್ಲಿ ಹಂಚಿದ ಡೈರೆಕ್ಟರಿಯನ್ನು (`dataset` ಎಂಬ ಹೆಸರಿನ) ಪ್ರಕಟಿಸಿ:

```bash
sync0 share dataset ./data --region SHA
```

ಇತರ ಗಣಕಗಳಲ್ಲಿ ಹಂಚಿದ ಡೈರೆಕ್ಟರಿಯನ್ನು ಎಳೆಯಿರಿ (ನೀವು ಒಂದೇ ಸಮಯದಲ್ಲಿ ಬಹು ನೋಡ್ ವಿಳಾಸಗಳನ್ನು ಭರ್ತಿ ಮಾಡಬಹುದು, ಏಕಕಾಲದಲ್ಲಿ ಎಳೆಯಲು ಅಲ್ಪವಿರಾಮದಿಂದ ಬೇರ್ಪಡಿಸಬಹುದು):

```bash
sync0 pull 10.0.0.1:9000,10.0.0.2:9000 dataset ./local_data
```

ಹಂಚಿದ ಡೈರೆಕ್ಟರಿಯಲ್ಲಿ ನಿರ್ದಿಷ್ಟ ಉಪ ಡೈರೆಕ್ಟರಿಯನ್ನು ಮಾತ್ರ ಎಳೆಯಿರಿ:

```bash
sync0 pull 10.0.0.1:9000 dataset ./local_data --subpath 2026/logs
```

ರಿಮೋಟ್ ಹಂಚಿಕೆಯ ಡೈರೆಕ್ಟರಿಗೆ ಸ್ಥಳೀಯ ಬದಲಾವಣೆಗಳನ್ನು ಹಿಂದಕ್ಕೆ ತಳ್ಳಿರಿ:

```bash
sync0 push 10.0.0.1:9000 dataset ./local_data
```

### 3. ಕ್ಯಾಟಲಾಗ್ ಸ್ವಯಂಚಾಲಿತ ನವೀಕರಣಗಳಿಗೆ ಚಂದಾದಾರರಾಗಿ

ಮೂಲ ನೋಡ್‌ನ ಹಂಚಿದ ಡೈರೆಕ್ಟರಿಗೆ ಚಂದಾದಾರರಾಗಿ. ಮೂಲ ಡೈರೆಕ್ಟರಿಯಲ್ಲಿ ಫೈಲ್ ಅನ್ನು ಸೇರಿಸಿದಾಗ ಅಥವಾ ಮಾರ್ಪಡಿಸಿದಾಗ, ಅದು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಸ್ಥಳೀಯ ಕಂಪ್ಯೂಟರ್‌ಗೆ ಸಿಂಕ್ರೊನೈಸ್ ಆಗುತ್ತದೆ. ಅದೇ ಸಮಯದಲ್ಲಿ, ಸ್ಥಳೀಯ ಯಂತ್ರವು ಇತರ ಯಂತ್ರಗಳನ್ನು ಎಳೆಯಲು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ನೋಡ್ ಆಗಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ:

```bash
sync0 sub 10.0.0.1:9000 dataset ./local_mirror
```

### 4. ಬಹು-ಯಂತ್ರ ಗುಂಪುಗಳ ದ್ವಿಮುಖ ಸಿಂಕ್ರೊನೈಸೇಶನ್

ಬಹು ಯಂತ್ರಗಳು ಒಂದೇ ಗುಂಪಿನ ಹೆಸರನ್ನು ಸೇರುತ್ತವೆ ಮತ್ತು ಯಾವುದೇ ನೋಡ್ ಡೈರೆಕ್ಟರಿಯಲ್ಲಿನ ಬದಲಾವಣೆಗಳನ್ನು ಗುಂಪಿನಲ್ಲಿರುವ ಇತರ ನೋಡ್‌ಗಳಿಗೆ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಸಿಂಕ್ರೊನೈಸ್ ಮಾಡಲಾಗುತ್ತದೆ:

```bash
sync0 group team-docs ./docs 10.0.0.1:9000,10.0.0.2:9000
```

### 5. ನೋಡ್ ಗುರುತು ಮತ್ತು ವೈಯಕ್ತಿಕ ವ್ಯಾಪಾರ ಕಾರ್ಡ್

ಪ್ರತಿಯೊಂದು ನೋಡ್ ಬಳಕೆದಾರರ ಹೆಸರು, ನಗರ, ಇಮೇಲ್, ವೆಬ್‌ಸೈಟ್ ಮತ್ತು ವೈಯಕ್ತಿಕಗೊಳಿಸಿದ ಸಹಿಯನ್ನು (ಗರಿಷ್ಠ 256 ಅಕ್ಷರಗಳು) ಹೊಂದಿಸುವುದನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ ಮತ್ತು ಸ್ಥಳೀಯ ಖಾಸಗಿ ಕೀ ಸಿಗ್ನೇಚರ್ ದೃಢೀಕರಣವನ್ನು ರವಾನಿಸುತ್ತದೆ:

```bash
# ಸ್ಥಳೀಯ ಸಾರ್ವಜನಿಕ ಕೀ ಐಡಿಯನ್ನು ವೀಕ್ಷಿಸಿ (ಕೀಲಿಯನ್ನು ಮುಂದುವರಿಸಲು ಕಾನ್ಫಿಗರೇಶನ್ ಡೈರೆಕ್ಟರಿಯನ್ನು ನಿರ್ದಿಷ್ಟಪಡಿಸಿ)
sync0 id -c ~/.config/sync0

# ವೈಯಕ್ತೀಕರಿಸಿದ ಸಹಿಗಳೊಂದಿಗೆ ನೋಡ್ ವ್ಯಾಪಾರ ಕಾರ್ಡ್‌ಗಳನ್ನು ರಚಿಸಿ ಮತ್ತು ಪ್ರದರ್ಶಿಸಿ
sync0 profile -c ~/.config/sync0 \
  -u alice \
  --region SHA \
  --email alice@example.com \
  --url https://example.com \
  -b "Shanghai backup node"
```

`share`, `pull`, `sub`, `group` ಅನ್ನು ಸಹ ಈ ಪ್ರೊಫೈಲ್ ಪ್ಯಾರಾಮೀಟರ್‌ಗಳೊಂದಿಗೆ ಪ್ರಾರಂಭಿಸಬಹುದು:

```bash
sync0 share dataset ./data -c ~/.config/sync0 -u alice --region SHA -b "Shanghai backup node"
```

### 6. ಬಹು-ಭಾಷಾ ಸ್ವಿಚಿಂಗ್

`sync0` 75 ಭಾಷೆಗಳನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ. ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ, ಆಪರೇಟಿಂಗ್ ಸಿಸ್ಟಂನ ಭಾಷಾ ಪರಿಸರದ ಪ್ರಕಾರ ಅನುಗುಣವಾದ ಭಾಷೆಯಲ್ಲಿ ಆಜ್ಞಾ ಸಾಲಿನ ಸಹಾಯ ಮತ್ತು ಪ್ರಾಂಪ್ಟ್‌ಗಳನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಪ್ರದರ್ಶಿಸಲಾಗುತ್ತದೆ; ಸಿಸ್ಟಮ್ ಭಾಷೆ ಬೆಂಬಲಿತ ಪಟ್ಟಿಯಲ್ಲಿ ಇಲ್ಲದಿದ್ದರೆ, ಇಂಗ್ಲಿಷ್ ಅನ್ನು ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ ಬಳಸಲಾಗುತ್ತದೆ.

ಭಾಷೆಯನ್ನು ಹಸ್ತಚಾಲಿತವಾಗಿ ನಿರ್ದಿಷ್ಟಪಡಿಸಲು, ಪರಿಸರ ವೇರಿಯಬಲ್ ಅನ್ನು ಹೊಂದಿಸಿ `SYNC0_LANG`:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
