# sync0

`sync0` ಒಂದು ಪೀರ್-ಟು-ಪೀರ್ (P2P) ಫೈಲ್ ಹಂಚಿಕೆ ಮತ್ತು ಬಹು-ಯಂತ್ರ ಸಿಂಕ್ರೊನೈಸೇಶನ್ ಸಾಧನವಾಗಿದ್ದು ಅದು Resilio ಸಿಂಕ್‌ನೊಂದಿಗೆ ಸ್ಪರ್ಧಿಸುತ್ತದೆ.

ಪ್ರತಿಯೊಂದು ಯಂತ್ರವು ಸರ್ವರ್ ಮತ್ತು ಕ್ಲೈಂಟ್ ಎರಡೂ ಆಗಿದೆ: ಯಾವುದೇ ನೋಡ್ ಬಹು ಫೈಲ್ ಹಂಚಿಕೆ ಗುಂಪುಗಳನ್ನು ಪ್ರಕಟಿಸಬಹುದು. ಇತರ ನೋಡ್‌ಗಳು ಸೇರಿದ ನಂತರ, ಅವರು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಪೀರ್ ಸರ್ವರ್‌ನಿಂದ ಲಭ್ಯವಿರುವ ಸೀಡ್ ನೋಡ್‌ಗಳನ್ನು ಪಡೆಯಬಹುದು ಮತ್ತು ಅವುಗಳನ್ನು ಏಕಕಾಲದಲ್ಲಿ ಅನೇಕ ಮೂಲಗಳಿಂದ ಎಳೆಯಬಹುದು. ಸಿಂಕ್ರೊನೈಸೇಶನ್ ಪೂರ್ಣಗೊಂಡ ನಂತರ, ಡೌನ್‌ಲೋಡ್‌ಗಳನ್ನು ವೇಗಗೊಳಿಸಲು ಹೆಚ್ಚಿನ ನೋಡ್‌ಗಳಿಗಾಗಿ ಬೀಜಗಳನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ರಚಿಸಲಾಗುತ್ತದೆ.

## ಪ್ರಮುಖ ಮುಖ್ಯಾಂಶಗಳು

- **ಎಲ್ಲರೂ ಸರ್ವರ್ ಮತ್ತು ಕ್ಲೈಂಟ್ ಎರಡೂ ಆಗಿದ್ದಾರೆ**: Resilio ಸಿಂಕ್‌ಗೆ ಹೋಲಿಸಬಹುದು, ಕೇಂದ್ರೀಯ ಸರ್ವರ್ ಅವಲಂಬನೆ ಇಲ್ಲ. ಯಾವುದೇ ನೋಡ್ ಬಹು ಫೈಲ್ ಹಂಚಿಕೆ ಗುಂಪುಗಳನ್ನು ರಚಿಸಬಹುದು ಮತ್ತು ಇತರ ಜನರ ಹಂಚಿಕೆ ಗುಂಪುಗಳನ್ನು ಸಹ ಸೇರಬಹುದು; ಏಕಕಾಲೀನ ಎಳೆಯುವಿಕೆ ಮತ್ತು ಬಹು ಯಂತ್ರಗಳ ನೈಜ-ಸಮಯದ ಸಿಂಕ್ರೊನೈಸೇಶನ್ ಸಾಧಿಸಲು ನೋಡ್‌ಗಳು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ವಿನಿಮಯ ಮಾಡಿಕೊಳ್ಳುತ್ತವೆ ಮತ್ತು ಲಭ್ಯವಿರುವ ಬೀಜ ನೋಡ್‌ಗಳನ್ನು ಪಡೆದುಕೊಳ್ಳುತ್ತವೆ.
- **IP-ಮುಕ್ತ ನೋಡ್ ವಿಳಾಸ**: ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ, ನೋಡ್ ಕೀ ಮತ್ತು `base64url` ಎನ್‌ಕೋಡ್ ಮಾಡಿದ `iroh` ವಿಳಾಸವನ್ನು ಸಾರ್ವಜನಿಕ IP ಅನ್ನು ನೆನಪಿಟ್ಟುಕೊಳ್ಳುವ ಅಥವಾ ಬಹಿರಂಗಪಡಿಸುವ ಅಗತ್ಯವಿಲ್ಲದೇ ಸ್ವಯಂಚಾಲಿತವಾಗಿ `~/.config/sync0` ನಲ್ಲಿ ರಚಿಸಲಾಗುತ್ತದೆ.
- ** ಬಹು-ಆಯ್ಕೆ ಸಿಂಕ್ರೊನೈಸೇಶನ್ ಆನ್ ಡಿಮ್ಯಾಂಡ್**: ಸಂಪೂರ್ಣ ಹಂಚಿಕೆ ಗುಂಪಿನ ಸಿಂಕ್ರೊನೈಸೇಶನ್ ಅನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ ಮತ್ತು ಒಂದೇ ಸಮಯದಲ್ಲಿ ಬಹು ಫೈಲ್‌ಗಳು ಅಥವಾ ಉಪ ಡೈರೆಕ್ಟರಿಗಳನ್ನು ಆಯ್ಕೆ ಮಾಡುವ ಮೂಲಕ ಬೇಡಿಕೆಯ ಮೇಲೆ ಸಿಂಕ್ರೊನೈಸೇಶನ್ ಅನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ.
- **ಗುಂಪಿನ ಸದಸ್ಯ ಕ್ರಮಾನುಗತ ಅನುಮತಿಗಳು ಮತ್ತು ಅಪ್‌ಲೋಡ್ ಡೈರೆಕ್ಟರಿ ನಿಯಂತ್ರಣ**: ಓದಲು-ಮಾತ್ರ (`ro`), ಓದಲು-ಬರೆಯಲು ಅಪ್‌ಲೋಡ್ (`rw`), ಮತ್ತು ನಿರ್ವಹಣೆ (`admin`) ಅನುಮತಿಗಳನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ ಮತ್ತು ಪ್ರತಿ ಸದಸ್ಯರಿಗೆ ರೂಟ್ ಪೂರ್ವಪ್ರತ್ಯಯವನ್ನು ಅಪ್‌ಲೋಡ್ ಮಾಡಲು ಅನುಮತಿಸಲಾದ ರೂಟ್ ಪೂರ್ವಪ್ರತ್ಯಯವನ್ನು ಪ್ರತ್ಯೇಕವಾಗಿ ನಿರ್ದಿಷ್ಟಪಡಿಸಬಹುದು.
- **ನೆಟ್‌ವರ್ಕ್‌ಗಳಾದ್ಯಂತ ಪೂರ್ಣ-ವೇಗ ಮತ್ತು ಹೆಚ್ಚುತ್ತಿರುವ ಸಿಂಕ್ರೊನೈಸೇಶನ್**: ದೊಡ್ಡ ಫೈಲ್‌ಗಳ ಏಕಕಾಲಿಕ ಪ್ರಸರಣ, ಮೆಮೊರಿಯಲ್ಲಿ ಬೃಹತ್ ಸಣ್ಣ ಫೈಲ್‌ಗಳ ಒಟ್ಟುಗೂಡಿಸುವಿಕೆ ಮತ್ತು ಫೈಲ್‌ಗಳನ್ನು ಭಾಗಶಃ ಮಾರ್ಪಡಿಸಿದಾಗ ಸಿಂಕ್ರೊನೈಸ್ ಮಾಡಿದ ಡೇಟಾ ಬ್ಲಾಕ್‌ಗಳು.

## ಸ್ಥಾಪಿಸಿ

### ವಿಧಾನ 1: ಕಾರ್ಗೋ ಮೂಲಕ ಸ್ಥಾಪಿಸಿ

```bash
cargo install sync0
```

### ವಿಧಾನ 2: ಪೂರ್ವ ಕಂಪೈಲ್ ಮಾಡಿದ ಬೈನರಿಗಳನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ

ಅನುಗುಣವಾದ ಸಿಸ್ಟಮ್‌ಗಾಗಿ `.tar.xz` ಸಂಕುಚಿತ ಪ್ಯಾಕೇಜ್ ಅನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡಲು [GitHub ಬಿಡುಗಡೆಗಳು](https://github.com/webc-site/sync0/releases) ಗೆ ಹೋಗಿ (Linux, macOS, Windows, Android, FreeBSD, NetBSD ಅನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ), ಅನ್ಜಿಪ್ ಮಾಡಿ ಮತ್ತು ಅದನ್ನು `PATH` ಡೈರೆಕ್ಟರಿಯಲ್ಲಿ ಇರಿಸಿ:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## ತ್ವರಿತವಾಗಿ ಪ್ರಾರಂಭಿಸಿ

`sync0` ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ ಕಾನ್ಫಿಗರೇಶನ್ ಡೈರೆಕ್ಟರಿಯಾಗಿ `~/.config/sync0` ಅನ್ನು ಬಳಸುತ್ತದೆ (ನೀವು ಇತರ ಡೈರೆಕ್ಟರಿಗಳಿಗೆ ಬದಲಾಯಿಸಬೇಕಾದರೆ, ನೀವು `-c <directory>` ಅನ್ನು ಸೇರಿಸಬಹುದು).

### 1. ಸ್ಥಳೀಯ ನೋಡ್ ವಿಳಾಸವನ್ನು ವೀಕ್ಷಿಸಿ ಮತ್ತು ವ್ಯಾಪಾರ ಕಾರ್ಡ್ ಅನ್ನು ಹೊಂದಿಸಿ

```bash
# ಸ್ಥಳೀಯ ನೋಡ್ ವಿಳಾಸವನ್ನು ವೀಕ್ಷಿಸಿ (ಕೀಲಿಯನ್ನು ಮೊದಲ ಬಾರಿಗೆ ~/.config/sync0 ನಲ್ಲಿ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ರಚಿಸಲಾಗಿದೆ)
sync0 id

# ವೈಯಕ್ತಿಕ ನೋಡ್ ವ್ಯಾಪಾರ ಕಾರ್ಡ್ ಅನ್ನು ರಚಿಸಿ (ಬಳಕೆದಾರರ ಹೆಸರು, ನಗರ, ಇಮೇಲ್, ವೆಬ್‌ಸೈಟ್ ಮತ್ತು ಸಹಿಯನ್ನು 256 ಪದಗಳಲ್ಲಿ ಬೆಂಬಲಿಸುತ್ತದೆ)
sync0 profile -u alice --region SHA --email alice@example.com --url https://example.com -b "Shanghai node"
```

### 2. ಬಹು ಫೈಲ್ ಹಂಚಿಕೆ ಗುಂಪುಗಳನ್ನು ಪ್ರಕಟಿಸಿ ಮತ್ತು ಗುಂಪಿನ ಸದಸ್ಯರ ಅನುಮತಿಗಳನ್ನು ಹೊಂದಿಸಿ (`.nt` ಕಾನ್ಫಿಗರೇಶನ್)

`sync0` ಅನ್ನು [NestedText](https://nestedtext.org) (`.nt`) ಫಾರ್ಮ್ಯಾಟ್‌ನಲ್ಲಿ ಕಾನ್ಫಿಗರ್ ಮಾಡಲಾಗಿದೆ. ಪ್ರತಿಯೊಬ್ಬ ಬಳಕೆದಾರರು ಪ್ರತ್ಯೇಕ `.nt` ಕಾನ್ಫಿಗರೇಶನ್ ಫೈಲ್ ಅನ್ನು ಹೊಂದಿದ್ದಾರೆ. ನೀವು ಬಳಕೆದಾರ ಪ್ರೊಫೈಲ್ ಡೈರೆಕ್ಟರಿಯನ್ನು `users_dir` ಮೂಲಕ `config.nt` ನಲ್ಲಿ ನಿರ್ದಿಷ್ಟಪಡಿಸಬಹುದು (ಇದು ಈ ಡೈರೆಕ್ಟರಿಯಲ್ಲಿ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಎಲ್ಲಾ `.nt` ಫೈಲ್‌ಗಳನ್ನು ಒಳಗೊಂಡಿರುತ್ತದೆ). ಅಪ್‌ಲೋಡ್ ಮಾಡಲು ಅನುಮತಿಸಲಾದ ಬಳಕೆದಾರ ಮತ್ತು ಮಾರ್ಗದ ಪೂರ್ವಪ್ರತ್ಯಯ ಎರಡನ್ನೂ ಕ್ರಮಬದ್ಧಗೊಳಿಸದ ಪಟ್ಟಿಯನ್ನು ಬಳಸುತ್ತದೆ (`-`). **ಅಪ್‌ಲೋಡ್ ಪಾಥ್ ಪೂರ್ವಪ್ರತ್ಯಯವನ್ನು ಭರ್ತಿ ಮಾಡದಿದ್ದಾಗ, ಹಂಚಿಕೆಯ ಮೂಲ ಡೈರೆಕ್ಟರಿಗೆ ಅಪ್‌ಲೋಡ್ ಮಾಡುವುದನ್ನು ಡೀಫಾಲ್ಟ್ ಆಗಿ ಅನುಮತಿಸಲಾಗುತ್ತದೆ**.

1. `~/.config/sync0/users/` ಡೈರೆಕ್ಟರಿಯಲ್ಲಿ ಪ್ರತಿ ಸದಸ್ಯರಿಗೆ ಪ್ರತ್ಯೇಕ `.nt` ಕಾನ್ಫಿಗರೇಶನ್ ಫೈಲ್‌ಗಳನ್ನು ರಚಿಸಿ:

`~/.config/sync0/users/alice.nt` (ಓದಲು-ಮಾತ್ರ ಸದಸ್ಯ, ದರ ಸೀಮಿತವಾಗಿದೆ `80MB`, `rate` `GB`, `MB`, `KB` ಘಟಕಗಳನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ):

```yaml
id: 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c
perm: ro
rate: 80MB
```

`~/.config/sync0/users/bob.nt` (ನಿರ್ಬಂಧಿತ ಅಪ್‌ಲೋಡ್ ಸದಸ್ಯರು: `uploads/bob` ಮತ್ತು `shared/common` ಡೈರೆಕ್ಟರಿಗಳಿಗೆ ಮಾತ್ರ ಅಪ್‌ಲೋಡ್ ಮಾಡಲು ಅನುಮತಿಸಲಾಗಿದೆ):

```yaml
id: 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f
perm: rw
write_prefix:
  - uploads/bob
  - shared/common
```

`~/.config/sync0/users/charlie.nt` (ಡೀಫಾಲ್ಟ್ ಸದಸ್ಯರ ಅಪ್‌ಲೋಡ್: `write_prefix` ಅನ್ನು ಬಿಟ್ಟುಬಿಟ್ಟಾಗ, ಹಂಚಿಕೆಯ ಮೂಲ ಡೈರೆಕ್ಟರಿಗೆ ಅಪ್‌ಲೋಡ್ ಮಾಡುವುದನ್ನು ಡೀಫಾಲ್ಟ್ ಆಗಿ ಅನುಮತಿಸಲಾಗುತ್ತದೆ):

```yaml
id: 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
perm: rw
```

2. `~/.config/sync0/config.nt` ನಲ್ಲಿ ಬಳಕೆದಾರರ ಡೈರೆಕ್ಟರಿ ಮತ್ತು ಬಹು ಫೈಲ್ ಹಂಚಿಕೆ ಗುಂಪುಗಳನ್ನು ಕಾನ್ಫಿಗರ್ ಮಾಡಿ:

```yaml
users_dir: ./users

groups:
  dataset:
    path: ./data
    auth: false
    perm: ro
    rate: 50MB

  models:
    path: ./models
    auth: false
    perm: ro
    rate: 1GB

  team-vault:
    path: ./vault
    auth: true
    perm: ro
    rate: 512KB
    users:
      - alice
      - bob
      - charlie
```

ಹಂಚಿಕೆ ಸೇವೆಯನ್ನು ಪ್ರಾರಂಭಿಸಿ:

```bash
# ನೇರ ಪ್ರಾರಂಭ (~/.config/sync0/config.nt ಮತ್ತು users_dir ಡೈರೆಕ್ಟರಿಗಳಲ್ಲಿ ಎಲ್ಲಾ .nt ಬಳಕೆದಾರರ ಕಾನ್ಫಿಗರೇಶನ್‌ಗಳನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಲೋಡ್ ಮಾಡುತ್ತದೆ)
sync0 share --region SHA

# ಅಥವಾ ಬಹು ಹಂಚಿಕೆ ಗುಂಪುಗಳನ್ನು ತ್ವರಿತವಾಗಿ ಪ್ರಕಟಿಸಿ ಮತ್ತು ಆಜ್ಞಾ ಸಾಲಿನ ಮೂಲಕ ನೇರವಾಗಿ ಗುಂಪಿನ ಸದಸ್ಯರನ್ನು ಅಧಿಕೃತಗೊಳಿಸಿ
sync0 share dataset:./data team-vault:./vault \
  --auth \
  --allow-ro 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c \
  --allow-rw 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f:uploads/bob,shared/common \
  --allow-rw 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
```

### 3. ಎಲ್ಲಾ ವಿಷಯವನ್ನು ಎಳೆಯಿರಿ ಅಥವಾ ಬಹು ಫೈಲ್‌ಗಳು ಮತ್ತು ಡೈರೆಕ್ಟರಿಗಳನ್ನು ಆಯ್ಕೆಮಾಡಿ (`sync0 pull`)

ಹಂಚಿಕೆ ಗುಂಪಿನಲ್ಲಿ ಲಭ್ಯವಿರುವ ಎಲ್ಲಾ ಸೀಡ್ ನೋಡ್‌ಗಳನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಪಡೆಯಲು ಯಾವುದೇ ಪೀರ್ ನೋಡ್‌ಗೆ ಸಂಪರ್ಕಪಡಿಸಿ ಮತ್ತು ಏಕಕಾಲದಲ್ಲಿ ಬಹು ಬೀಜ ನೋಡ್‌ಗಳಿಂದ ಎಳೆಯಿರಿ:

```bash
# ಸಂಪೂರ್ಣ ಡೇಟಾಸೆಟ್ ಹಂಚಿಕೆ ಗುಂಪನ್ನು ಸ್ಥಳೀಯ ./local_data ಗೆ ಎಳೆಯಿರಿ
sync0 pull dataset:// ./local_data -p <ನೋಡ್ ವಿಳಾಸ>

# ಬಹು-ಆಯ್ಕೆ ಸಿಂಕ್ರೊನೈಸೇಶನ್: ಏಕಕಾಲದಲ್ಲಿ ಸಿಂಗಲ್ ಫೈಲ್ ಡಾಕ್ಸ್/ರೀಡ್‌ಮೆ.ಎಮ್‌ಡಿ ಮತ್ತು ಉಪ ಡೈರೆಕ್ಟರಿಗಳ ಸ್ವತ್ತುಗಳು/ಐಕಾನ್‌ಗಳು, ಎಸ್‌ಆರ್‌ಸಿ/ಕೋರ್ ಅನ್ನು ಎಳೆಯಿರಿ
sync0 pull dataset://docs/readme.md,assets/icons,src/core ./local_data -p <ನೋಡ್ ವಿಳಾಸ>
```

### 4. ಹಂಚಿಕೆ ಗುಂಪಿಗೆ ಫೈಲ್ ಅಥವಾ ಡೈರೆಕ್ಟರಿಯನ್ನು ಅಪ್‌ಲೋಡ್ ಮಾಡಿ (`sync0 push`)

ಅಪ್‌ಲೋಡ್ ಅನುಮತಿಗಳನ್ನು ಹೊಂದಿರುವ ಸದಸ್ಯರು (`rw` ಅಥವಾ `admin`) ರಿಮೋಟ್ ಹಂಚಿಕೆ ಗುಂಪುಗಳಿಗೆ ಸ್ಥಳೀಯ ಫೈಲ್‌ಗಳು ಅಥವಾ ಡೈರೆಕ್ಟರಿಗಳನ್ನು ಅಪ್‌ಲೋಡ್ ಮಾಡಬಹುದು:

```bash
# ರೂಟ್ ಡೈರೆಕ್ಟರಿಯನ್ನು ಹೊಂದಿರುವ ಸದಸ್ಯರು ಅಪ್‌ಲೋಡ್ ಅನುಮತಿ: ಹಂಚಿಕೊಂಡ ರೂಟ್ ಡೈರೆಕ್ಟರಿಗೆ ನೇರವಾಗಿ ಅಪ್‌ಲೋಡ್ ಮಾಡಿ
sync0 push team-vault:// ./new_release -p <ನೋಡ್ ವಿಳಾಸ>

# ನಿರ್ದಿಷ್ಟ ಪೂರ್ವಪ್ರತ್ಯಯಕ್ಕೆ (ಅಪ್‌ಲೋಡ್‌ಗಳು/ಬಾಬ್‌ನಂತಹ) ಅಧಿಕಾರ ಹೊಂದಿರುವ ಸದಸ್ಯರು ಮಾತ್ರ: ಅನುಮತಿಸಲಾದ ಮಾರ್ಗ ಪೂರ್ವಪ್ರತ್ಯಯಕ್ಕೆ ಅಪ್‌ಲೋಡ್ ಮಾಡಿ
sync0 push team-vault://uploads/bob/report.pdf ./report.pdf -p <ನೋಡ್ ವಿಳಾಸ>
```

### 5. ಸ್ವಯಂಚಾಲಿತ ಸಿಂಕ್ ಮತ್ತು ಸೀಡಿಂಗ್‌ಗೆ ಚಂದಾದಾರರಾಗಿ (`sync0 sub`)

ನಿರ್ದಿಷ್ಟ ನೋಡ್‌ನ ಹಂಚಿಕೆ ಗುಂಪಿಗೆ ಚಂದಾದಾರರಾದ ನಂತರ, ಸ್ಥಳೀಯ ಸರ್ವರ್ ಸ್ವೀಕರಿಸುವ ಕ್ಲೈಂಟ್ ಮತ್ತು ಹೊಸ ಸೀಡಿಂಗ್ ಸರ್ವರ್ ಆಗಿದೆ; ಮೂಲ ನೋಡ್ ಫೈಲ್ ಅನ್ನು ನವೀಕರಿಸಿದಾಗ, ಅದು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಸಿಂಕ್ರೊನೈಸ್ ಆಗುತ್ತದೆ ಮತ್ತು ಇತರ ನೋಡ್‌ಗಳಿಗೆ ಚಂಕ್ಡ್ ಡೌನ್‌ಲೋಡ್‌ಗಳನ್ನು ಒದಗಿಸುತ್ತದೆ:

```bash
# ಸಂಪೂರ್ಣ ಹಂಚಿಕೆ ಗುಂಪಿಗೆ ಚಂದಾದಾರರಾಗಿ ಮತ್ತು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಬೀಜ
sync0 ಉಪ ಡೇಟಾಸೆಟ್:// ./local_mirror -p <ನೋಡ್ ವಿಳಾಸ>

# ನಿರ್ದಿಷ್ಟಪಡಿಸಿದ ಫೈಲ್‌ಗಳು ಮತ್ತು ಉಪ ಡೈರೆಕ್ಟರಿಗಳಿಗೆ ಚಂದಾದಾರರಾಗಲು ಬಹು-ಆಯ್ಕೆ ಮಾಡಿ ಮತ್ತು ಅವುಗಳನ್ನು ಸೀಡ್ ಮಾಡಿ
sync0 ಉಪ ಡೇಟಾಸೆಟ್://models/llama.onnx,configs ./local_mirror -p <ನೋಡ್ ವಿಳಾಸ>
```

### 6. ಬಹು-ಯಂತ್ರ ಗುಂಪು ಪೀರ್ ಸಿಂಕ್ರೊನೈಸೇಶನ್ (`sync0 group`)

ಬಹು ಯಂತ್ರಗಳು ಒಂದೇ ಹಂಚಿಕೆ ಗುಂಪನ್ನು ಸೇರುತ್ತವೆ, ಪರಸ್ಪರ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಲಭ್ಯವಿರುವ ಬೀಜ ನೋಡ್‌ಗಳನ್ನು ಕಂಡುಹಿಡಿಯುತ್ತದೆ ಮತ್ತು ದ್ವಿಮುಖ ಸಿಂಕ್ರೊನೈಸೇಶನ್ ಅನ್ನು ನಿರ್ವಹಿಸುತ್ತದೆ (ಪೂರ್ಣ ಸಿಂಕ್ರೊನೈಸೇಶನ್ ಅಥವಾ ಫೈಲ್‌ಗಳು ಮತ್ತು ಡೈರೆಕ್ಟರಿಗಳ ಬಹು ಆಯ್ಕೆಯನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ):

```bash
# ಗುಂಪು ಮತ್ತು ದ್ವಿಮುಖ ಸಿಂಕ್ರೊನೈಸೇಶನ್ ಅನ್ನು ಸಂಪೂರ್ಣವಾಗಿ ಸೇರಿಕೊಳ್ಳಿ
sync0 group team-docs:// ./docs -p <ನೋಡ್ ವಿಳಾಸ>

# ಬಹು-ಆಯ್ಕೆ ಸಿಂಕ್ರೊನೈಸೇಶನ್ ಗುಂಪಿನಲ್ಲಿ ವಾಲ್ ಡೈರೆಕ್ಟರಿ ಮತ್ತು meta.json ಫೈಲ್ ಮಾತ್ರ
sync0 group team-docs://wal,meta.json ./docs -p <ನೋಡ್ ವಿಳಾಸ>
```

### 7. ಎರಡು ಯಂತ್ರಗಳ ನಡುವೆ ಪಾಯಿಂಟ್-ಟು-ಪಾಯಿಂಟ್ ನೇರ ಪ್ರಸರಣ (`send` / `recv`)

ಗುಂಪನ್ನು ಮೊದಲೇ ಕಾನ್ಫಿಗರ್ ಮಾಡುವ ಅಗತ್ಯವಿಲ್ಲ, ಮತ್ತು ನೀವು ಎರಡು ಯಂತ್ರಗಳ ನಡುವೆ ನೇರವಾಗಿ ಫೈಲ್‌ಗಳು ಅಥವಾ ಡೈರೆಕ್ಟರಿಗಳನ್ನು ತಾತ್ಕಾಲಿಕವಾಗಿ ವರ್ಗಾಯಿಸಬಹುದು:

```bash
# ರಿಸೀವರ್ ಮೇಲ್ವಿಚಾರಣೆ
sync0 recv 0.0.0.0:9000 ./backup

# ಕಳುಹಿಸುವ ಅಂತ್ಯವು ನೇರವಾಗಿ ಫೈಲ್‌ಗಳು ಅಥವಾ ಡೈರೆಕ್ಟರಿಗಳನ್ನು ವರ್ಗಾಯಿಸುತ್ತದೆ (ಐಚ್ಛಿಕ --ಹೆಚ್ಚುವರಿ ಫೈಲ್‌ಗಳನ್ನು ಸ್ವಚ್ಛಗೊಳಿಸಲು ಕನ್ನಡಿಯನ್ನು ಅಳಿಸಿ, --ದರ ವೇಗ ಮಿತಿ)
sync0 send ./project 192.168.1.10:9000
```

### 8. ಬಹು-ಭಾಷಾ ಸ್ವಿಚಿಂಗ್

`sync0` 75 ಭಾಷೆಗಳನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ ಮತ್ತು ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ ಸಿಸ್ಟಮ್ ಭಾಷೆಯ ಪರಿಸರಕ್ಕೆ ಅನುಗುಣವಾಗಿ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಬದಲಾಗುತ್ತದೆ; ಇದನ್ನು `SYNC0_LANG` ಮೂಲಕ ಹಸ್ತಚಾಲಿತವಾಗಿ ನಿರ್ದಿಷ್ಟಪಡಿಸಬಹುದು:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
