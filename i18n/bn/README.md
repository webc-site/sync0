# sync0

`sync0` হল একটি পিয়ার-টু-পিয়ার (P2P) ফাইল শেয়ারিং এবং মাল্টি-মেশিন সিঙ্ক্রোনাইজেশন টুল যা রেসিলিও সিঙ্কের সাথে প্রতিযোগিতা করে।

প্রতিটি মেশিন একটি সার্ভার এবং একটি ক্লায়েন্ট উভয়ই: যেকোনো নোড একাধিক ফাইল শেয়ারিং গ্রুপ প্রকাশ করতে পারে। অন্যান্য নোড যোগদানের পরে, তারা স্বয়ংক্রিয়ভাবে পিয়ার সার্ভার থেকে উপলব্ধ বীজ নোডগুলি পেতে পারে এবং একাধিক উত্স থেকে একই সাথে তাদের টানতে পারে। সিঙ্ক্রোনাইজেশন সম্পন্ন হওয়ার পরে, ডাউনলোডগুলিকে ত্বরান্বিত করার জন্য আরও নোডের জন্য বীজগুলি স্বয়ংক্রিয়ভাবে তৈরি হবে।

## মূল হাইলাইট

- **সবাই একজন সার্ভার এবং ক্লায়েন্ট উভয়ই **: রেসিলিও সিঙ্কের সাথে তুলনীয়, কোন কেন্দ্রীয় সার্ভার নির্ভরতা নেই। যেকোনো নোড একাধিক ফাইল শেয়ারিং গ্রুপ তৈরি করতে পারে, এবং অন্য লোকেদের শেয়ারিং গ্রুপে যোগ দিতে পারে; নোডগুলি স্বয়ংক্রিয়ভাবে বিনিময় করে এবং উপলব্ধ বীজ নোডগুলিকে একযোগে টানা এবং একাধিক মেশিনের রিয়েল-টাইম সিঙ্ক্রোনাইজেশন অর্জন করে।
- **আইপি-মুক্ত নোড ঠিকানা**: ডিফল্টরূপে, নোড কী এবং `base64url` এনকোড করা `iroh` ঠিকানা স্বয়ংক্রিয়ভাবে `~/.config/sync0` এ তৈরি হয় পাবলিক আইপি মনে রাখার বা প্রকাশ করার প্রয়োজন ছাড়াই৷
- **মাল্টি-সিলেক্ট সিঙ্ক্রোনাইজেশন অন ডিমান্ড**: সমগ্র শেয়ারিং গ্রুপের সিঙ্ক্রোনাইজেশন সমর্থন করে এবং একই সময়ে একাধিক ফাইল বা সাবডিরেক্টরি নির্বাচন করে চাহিদা অনুযায়ী সিঙ্ক্রোনাইজেশন সমর্থন করে।
- **গ্রুপ সদস্যদের অনুক্রমিক অনুমতি এবং আপলোড ডিরেক্টরি নিয়ন্ত্রণ**: শুধুমাত্র পঠনযোগ্য (`ro`), পঠন-পাঠন আপলোড (`rw`), এবং পরিচালনা (`admin`) অনুমতি সমর্থন করে এবং প্রতিটি সদস্যকে আপলোড করার অনুমতি দেওয়া হয় এমন পাথ উপসর্গ পৃথকভাবে নির্দিষ্ট করতে পারে (ডিফল্টরূপে, শেয়ার করার ডিরেক্টরি আপলোড করার জন্য অনুমোদিত)।
- **নেটওয়ার্ক জুড়ে ফুল-স্পীড এবং ক্রমবর্ধমান সিঙ্ক্রোনাইজেশন**: বড় ফাইলের একযোগে ট্রান্সমিশন, মেমরিতে বিশাল ছোট ফাইলের একত্রীকরণ, এবং ফাইলগুলি আংশিকভাবে পরিবর্তিত হলে শুধুমাত্র সিঙ্ক্রোনাইজ করা ডেটা ব্লক।

## ইনস্টল করুন

### পদ্ধতি 1: কার্গোর মাধ্যমে ইনস্টল করুন

```bash
cargo install sync0
```

### পদ্ধতি 2: প্রি-কম্পাইল করা বাইনারি ডাউনলোড করুন

সংশ্লিষ্ট সিস্টেমের জন্য `.tar.xz` সংকুচিত প্যাকেজ ডাউনলোড করতে [GitHub Releases](https://github.com/webc-site/sync0/releases) এ যান (লিনাক্স, macOS, Windows, Android, FreeBSD, NetBSD সমর্থন করে), আনজিপ করুন এবং `PATH` ডিরেক্টরিতে রাখুন:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## দ্রুত শুরু করুন

`sync0` ডিফল্টরূপে কনফিগারেশন ডিরেক্টরি হিসাবে `~/.config/sync0` ব্যবহার করে (যদি আপনি অন্য ডিরেক্টরিতে স্যুইচ করতে চান, আপনি `-c <directory>` যোগ করতে পারেন)।

### 1. স্থানীয় নোড ঠিকানা এবং ব্যবসা কার্ড সেটিং দেখুন

```bash
# স্থানীয় নোড ঠিকানা দেখুন (কীটি প্রথমবারের জন্য স্বয়ংক্রিয়ভাবে ~/.config/sync0 তে তৈরি হয়)
sync0 id

# একটি ব্যক্তিগত নোড ব্যবসায়িক কার্ড তৈরি করুন (256 শব্দের মধ্যে ব্যবহারকারীর নাম, শহর, ইমেল, ওয়েবসাইট এবং স্বাক্ষর সমর্থন করে)
sync0 profile -u alice --region SHA --email alice@example.com --url https://example.com -b "Shanghai node"
```

### 2. একাধিক ফাইল শেয়ারিং গ্রুপ প্রকাশ করুন এবং গ্রুপ সদস্যদের অনুমতি সেট করুন (`.nt` কনফিগারেশন)

`sync0` [NestedText](https://nestedtext.org) (`.nt`) ফর্ম্যাটে কনফিগার করা হয়েছে। প্রতিটি ব্যবহারকারীর একটি আলাদা `.nt` কনফিগারেশন ফাইল রয়েছে৷ আপনি `config.nt` (যা স্বয়ংক্রিয়ভাবে এই ডিরেক্টরির সমস্ত `.nt` ফাইল অন্তর্ভুক্ত করে) মধ্যে `users_dir` এর মাধ্যমে ব্যবহারকারী প্রোফাইল ডিরেক্টরি নির্দিষ্ট করতে পারেন। ব্যবহারকারী এবং পাথ উপসর্গ উভয়ই একটি ক্রমবিহীন তালিকা (`-`) ব্যবহার করে আপলোড করার অনুমতি দেয়। **যখন আপলোড পাথ উপসর্গটি পূরণ করা হয় না, শেয়ারের রুট ডিরেক্টরিতে আপলোড করা ডিফল্টরূপে অনুমোদিত**।

1. `~/.config/sync0/users/` ডিরেক্টরিতে প্রতিটি সদস্যের জন্য আলাদা `.nt` কনফিগারেশন ফাইল তৈরি করুন:

`~/.config/sync0/users/alice.nt` (শুধু পড়ার সদস্য, রেট সীমিত `80MB`, `rate` `GB`, `MB`, `KB` ইউনিট সমর্থন করে):

```yaml
id: 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c
perm: ro
rate: 80MB
```

`~/.config/sync0/users/bob.nt` (সীমাবদ্ধ আপলোড সদস্য: শুধুমাত্র `uploads/bob` এবং `shared/common` ডিরেক্টরিতে আপলোড করার অনুমতি দেওয়া হয়েছে):

```yaml
id: 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f
perm: rw
write_prefix:
  - uploads/bob
  - shared/common
```

`~/.config/sync0/users/charlie.nt` (ডিফল্ট সদস্য আপলোড: যখন `write_prefix` বাদ দেওয়া হয়, ডিফল্টরূপে শেয়ারের রুট ডিরেক্টরিতে আপলোড করার অনুমতি দেওয়া হয়):

```yaml
id: 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
perm: rw
```

2. `~/.config/sync0/config.nt`-এ ব্যবহারকারী ডিরেক্টরি এবং একাধিক ফাইল শেয়ারিং গ্রুপ কনফিগার করুন:

```yaml
users_dir: ./users

groups:
  dataset:
    path: ./data
    auth: false
    perm: ro
    rate: 50MB

  models:
    path: ./models
    auth: false
    perm: ro
    rate: 1GB

  team-vault:
    path: ./vault
    auth: true
    perm: ro
    rate: 512KB
    users:
      - alice
      - bob
      - charlie
```

শেয়ারিং পরিষেবা শুরু করুন:

```bash
# সরাসরি স্টার্টআপ (~/.config/sync0/config.nt এবং user_dir ডিরেক্টরিতে স্বয়ংক্রিয়ভাবে সমস্ত .nt ব্যবহারকারী কনফিগারেশন লোড করে)
sync0 share --region SHA

# অথবা দ্রুত একাধিক শেয়ারিং গ্রুপ প্রকাশ করুন এবং কমান্ড লাইনের মাধ্যমে সরাসরি গ্রুপ সদস্যদের অনুমোদন করুন
sync0 share dataset:./data team-vault:./vault \
  --auth \
  --allow-ro 8J9aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789ab_c \
  --allow-rw 7K8bCdEfGhIjKlMnOpQrStUvWxYz0123456789de_f:uploads/bob,shared/common \
  --allow-rw 9M0cDeFgHiJkLmNoPqRsTuVwXyZ0123456789gh_i
```

### 3. সমস্ত সামগ্রী টানুন বা একাধিক ফাইল এবং ডিরেক্টরি নির্বাচন করুন (`sync0 pull`)

শেয়ারিং গ্রুপে সমস্ত উপলব্ধ বীজ নোডগুলি স্বয়ংক্রিয়ভাবে প্রাপ্ত করার জন্য যেকোনো পিয়ার নোডের সাথে সংযোগ করুন এবং একাধিক বীজ নোড থেকে একসাথে টানুন:

```bash
# সমগ্র ডেটাসেট শেয়ারিং গ্রুপটিকে স্থানীয় ./local_data-এ টানুন
sync0 pull dataset:// ./local_data -p <নোড ঠিকানা>

# মাল্টি-সিলেক্ট সিঙ্ক্রোনাইজেশন: একই সাথে একক ফাইল ডক্স/readme.md এবং সাবডিরেক্টরি সম্পদ/আইকন, src/core টানুন
sync0 pull dataset://docs/readme.md,assets/icons,src/core ./local_data -p <নোড ঠিকানা>
```

### 4. একটি শেয়ারিং গ্রুপে একটি ফাইল বা ডিরেক্টরি আপলোড করুন (`sync0 push`)

আপলোড অনুমতি (`rw` বা `admin`) সহ সদস্যরা দূরবর্তী শেয়ারিং গ্রুপে স্থানীয় ফাইল বা ডিরেক্টরি আপলোড করতে পারেন:

```bash
# রুট ডিরেক্টরি আপলোড করার অনুমতি সহ সদস্য: শেয়ার্ড রুট ডিরেক্টরিতে সরাসরি আপলোড করুন
sync0 push team-vault:// ./new_release -p <নোড ঠিকানা>

# শুধুমাত্র সদস্যরা একটি নির্দিষ্ট উপসর্গের জন্য অনুমোদিত (যেমন আপলোড/বব): অনুমোদিত পাথ প্রিফিক্সে আপলোড করুন
sync0 push team-vault://uploads/bob/report.pdf ./report.pdf -p <নোড ঠিকানা>
```

### 5. স্বয়ংক্রিয় সিঙ্ক এবং সিডিং এর সদস্যতা নিন (`sync0 sub`)

একটি নির্দিষ্ট নোডের শেয়ারিং গ্রুপে সাবস্ক্রাইব করার পরে, স্থানীয় সার্ভার হল একটি গ্রহণকারী ক্লায়েন্ট এবং একটি নতুন সিডিং সার্ভার; সোর্স নোড ফাইল আপডেট করা হলে, এটি স্বয়ংক্রিয়ভাবে সিঙ্ক্রোনাইজ হয় এবং অন্যান্য নোডের জন্য খণ্ডিত ডাউনলোড প্রদান করে:

```bash
# সমগ্র শেয়ারিং গ্রুপে সদস্যতা এবং স্বয়ংক্রিয়ভাবে বীজ
sync0 সাব ডেটাসেট:// ./local_mirror -p <নোড ঠিকানা>

# নির্দিষ্ট ফাইল এবং সাবডিরেক্টরিগুলিতে সাবস্ক্রাইব করার জন্য শুধুমাত্র মাল্টি-সিলেক্ট করুন এবং সেগুলি বীজ করুন
sync0 সাব ডেটাসেট://models/llama.onnx,configs ./local_mirror -p <নোড ঠিকানা>
```

### 6. মাল্টি-মেশিন গ্রুপ পিয়ার সিঙ্ক্রোনাইজেশন (`sync0 group`)

একাধিক মেশিন একই শেয়ারিং গ্রুপে যোগ দেয়, একে অপরকে স্বয়ংক্রিয়ভাবে উপলব্ধ বীজ নোডগুলি আবিষ্কার করে এবং দ্বি-মুখী সিঙ্ক্রোনাইজেশন বজায় রাখে (সম্পূর্ণ সিঙ্ক্রোনাইজেশন বা ফাইল এবং ডিরেক্টরিগুলির একাধিক নির্বাচন সমর্থন করে):

```bash
# সম্পূর্ণরূপে গ্রুপে যোগদান করুন এবং দ্বিমুখী সমন্বয়সাধন করুন
sync0 group team-docs:// ./docs -p <node address>

# মাল্টি-সিলেক্ট সিঙ্ক্রোনাইজেশন গ্রুপে শুধুমাত্র wal ডিরেক্টরি এবং meta.json ফাইল
sync0 group team-docs://wal,meta.json ./docs -p <নোড ঠিকানা>
```

### 7. দুটি মেশিনের মধ্যে পয়েন্ট-টু-পয়েন্ট সরাসরি সংক্রমণ (`send` / `recv`)

একটি গ্রুপ পূর্ব-কনফিগার করার কোন প্রয়োজন নেই, এবং আপনি অস্থায়ীভাবে দুটি মেশিনের মধ্যে সরাসরি ফাইল বা ডিরেক্টরি স্থানান্তর করতে পারেন:

```bash
# রিসিভার মনিটরিং
sync0 recv 0.0.0.0:9000 ./backup

# সেন্ডিং এন্ড সরাসরি ফাইল বা ডিরেক্টরি স্থানান্তর করে (ঐচ্ছিক --অতিরিক্ত ফাইল পরিষ্কার করতে মিরর মুছে ফেলুন, --রেট স্পিড লিমিট)
sync0 send ./project 192.168.1.10:9000
```

### 8. মাল্টি-ভাষা স্যুইচিং

`sync0` 75টি ভাষা সমর্থন করে, এবং স্বয়ংক্রিয়ভাবে সিস্টেম ভাষা পরিবেশ অনুযায়ী ডিফল্টভাবে পরিবর্তন করে; এটি `SYNC0_LANG` এর মাধ্যমে নিজেও নির্দিষ্ট করা যেতে পারে:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
