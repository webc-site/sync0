# sync0

`sync0` নেটওয়ার্ক জুড়ে ফাইল স্থানান্তর, ক্রমবর্ধমান ডিরেক্টরি সিঙ্ক্রোনাইজ করার এবং একাধিক মেশিনে একযোগে ডেটা বিতরণ করার জন্য একটি কমান্ড লাইন টুল।

## মূল নকশা অভিপ্রায়

ক্রস-মেশিন রুম, দেশ বা পরিবেশে নেটওয়ার্ক বিলম্ব এবং প্যাকেট লস, টুল যেমন `rsync` এবং `scp` একক সংযোগ ক্রম নিশ্চিতকরণের উপর ভিত্তি করে, যা ব্যান্ডউইথ ব্যবহার সীমিত করে; যখন একাধিক মেশিন একই সার্ভার থেকে একই সময়ে ডেটা টেনে নেয়, তখন সোর্স সার্ভার নেটওয়ার্ক কার্ড সহজেই একটি বাধা হয়ে দাঁড়াতে পারে।

`sync0` এর লক্ষ্য হল দুটি সমস্যা সমাধান করা:

1. দুটি মেশিনের মধ্যে ফাইল এবং ডিরেক্টরি সিঙ্ক্রোনাইজেশন সম্পূর্ণ শারীরিক ব্যান্ডউইথ চালাতে দিন এবং ফাইলটি আংশিকভাবে পরিবর্তিত হলে শুধুমাত্র পরিবর্তিত অংশ স্থানান্তর করুন।
2. একই ডিরেক্টরি সিঙ্ক্রোনাইজ করার সময় একাধিক মেশিন একে অপরের কাছে ডেটা ব্লক স্থানান্তর করতে পারে, সোর্স সার্ভারে লোড হ্রাস করে এবং সামগ্রিক সিঙ্ক্রোনাইজেশন সময়কে ছোট করে।

## rsync-এর সাথে গতির তুলনা

পরীক্ষার পরিবেশ: ইউরোপীয় নোড $\leftrightarrow$ উত্তর আমেরিকান নোড, রাউন্ড-ট্রিপ বিলম্ব 86 ms, ডিরেক্টরি স্ক্যানিং, ডিডুপ্লিকেশন তুলনা, নেটওয়ার্ক ট্রান্সমিশন এবং ডিস্ক স্থাপন যাচাইকরণ সহ সম্পূর্ণ সময়-সাপেক্ষ পরিমাপ:

| ট্রান্সমিশন দৃশ্যকল্প | ডেটা সাইজ | `sync0` | `rsync` | একাধিক |
| :--- | :---: | :---: | :---: | :---: |
| 10,000 ছোট ফাইল | 77.6 MB | 0.90 s (688 Mbps) | 4.86 s (128 Mbps) | 5.4x |
| কোড এবং সংরক্ষণাগার প্যাকেজ (`.tar`) | 512 MB | 1.94 s (2111 Mbps) | 9.36 s (438 Mbps) | 4.8x |
| ভিডিও ফাইল (`.mp4`) | 512 MB | 7.36 s (556 Mbps) | 12.11 s (338 Mbps) | 1.6x |
| ইনক্রিমেন্টাল সিঙ্ক্রোনাইজেশন (1% বিষয়বস্তু পরিবর্তন করুন) | 512 MB | 0.12 s | 1.85 s | 15.4x |

## কর্মক্ষমতা উন্নতির পদ্ধতি

- **UDP সমসাময়িক ট্রান্সমিশন**: UDP-এর মাধ্যমে ডেটা ব্লক পাঠান, এবং শুধুমাত্র একটি প্যাকেটের ক্ষতি এড়াতে হারানো টুকরোগুলিকে পুনরায় প্রেরণ করুন যাতে পরবর্তী ফাইল স্থানান্তরকে ব্লক করে।
- **কন্টেন্ট সেগমেন্টেশন এবং ডিডুপ্লিকেশন**: ফাইলটিকে বিষয়বস্তু অনুযায়ী ডেটা ব্লকে বিভক্ত করুন এবং চেক মান গণনা করুন। ইতিমধ্যে প্রাপ্তির প্রান্তে থাকা একই বিষয়বস্তু নেটওয়ার্কের নকল না করে সরাসরি স্থানীয়ভাবে পুনরায় ব্যবহার করা হয়।
- **নেটওয়ার্কের গতি অনুসারে স্বয়ংক্রিয়ভাবে কম্প্রেশন সামঞ্জস্য করুন**: সংকোচনযোগ্য সামগ্রী যেমন পাঠ্য এবং কোডের জন্য কম্প্রেশন চালু করুন; স্বয়ংক্রিয়ভাবে ভিডিও, ছবি, সংকুচিত প্যাকেজ বা উচ্চ-গতির LAN-এর অধীনে CPU খরচ কমাতে কম্প্রেশন এড়িয়ে যান।
- **মাল্টি-নোড কাছাকাছি টানানো**: যখন একাধিক মেশিন একই ডিরেক্টরি টানে, তখন একই শহরে ডাউনলোড করা নোড থেকে বা কম লেটেন্সি সহ ডেটা ব্লকগুলি একযোগে টানা হবে।

## ইনস্টল করুন

### পদ্ধতি 1: কার্গোর মাধ্যমে ইনস্টল করুন

```bash
cargo install sync0
```

### পদ্ধতি 2: প্রি-কম্পাইল করা বাইনারি ডাউনলোড করুন

সংশ্লিষ্ট সিস্টেমের জন্য `.tar.xz` সংকুচিত প্যাকেজ ডাউনলোড করতে [GitHub Releases](https://github.com/webc-site/sync0/releases) এ যান (লিনাক্স x86_64/ARM64, macOS Apple Silicon/Intel, Windows x64/ARM64, Android ARM64/x86_64, FreeBSD, NetBSD সমর্থন করে)। আনজিপ করার পরে, `sync0`কে `PATH` ডিরেক্টরিতে রাখুন:

```bash
tar -xJf sync0-*.tar.xz
sudo mv sync0 /usr/local/bin/
```

## ব্যবহারকারীর নির্দেশিকা

### 1. দুটি মেশিনের মধ্যে সরাসরি ফাইল বা ডিরেক্টরি স্থানান্তর করুন

রিসিভিং মেশিনে মনিটরিং শুরু করুন এবং রিসিভিং এবং সেভিং পাথ নির্দিষ্ট করুন:

```bash
sync0 recv 0.0.0.0:9000 ./backup
```

পাঠানোর মেশিন থেকে একটি একক ফাইল বা একটি সম্পূর্ণ ডিরেক্টরি পাঠান:

```bash
sync0 send ./project 192.168.1.10:9000
```

সাধারণত ব্যবহৃত পরামিতি:

```bash
# অপ্রয়োজনীয় ফাইলগুলি মুছুন যা প্রাপ্তির প্রান্তে বিদ্যমান কিন্তু প্রেরণের প্রান্তে নয় (মিরর সিঙ্ক্রোনাইজেশন)
sync0 send ./project 192.168.1.10:9000 --delete

# প্রেরণের হার সীমিত করুন (ইউনিট: বাইট/সেকেন্ড, উদাহরণস্বরূপ 50 এমবি/সেকেন্ড)
sync0 send ./project 192.168.1.10:9000 --rate 50000000

# নীরব মোড (কোনও অগ্রগতি বার দেখানো হয়নি)
sync0 send ./project 192.168.1.10:9000 -q
```

### 2. শেয়ার করা ডিরেক্টরি প্রকাশ করা এবং একাধিক নোড থেকে টানা

অরিজিন সার্ভারে একটি শেয়ার করা ডিরেক্টরি (`dataset` নামে) প্রকাশ করুন:

```bash
sync0 share dataset ./data --region SHA
```

অন্যান্য মেশিনে শেয়ার্ড ডিরেক্টরি টানুন (আপনি একই সময়ে একাধিক নোড ঠিকানা পূরণ করতে পারেন, একই সাথে টানতে কমা দ্বারা পৃথক করা হয়):

```bash
sync0 pull 10.0.0.1:9000,10.0.0.2:9000 dataset ./local_data
```

ভাগ করা ডিরেক্টরিতে শুধুমাত্র একটি নির্দিষ্ট সাবডিরেক্টরি টানুন:

```bash
sync0 pull 10.0.0.1:9000 dataset ./local_data --subpath 2026/logs
```

দূরবর্তী শেয়ার্ড ডিরেক্টরিতে স্থানীয় পরিবর্তনগুলি পুশ করুন:

```bash
sync0 push 10.0.0.1:9000 dataset ./local_data
```

### 3. ক্যাটালগ স্বয়ংক্রিয় আপডেট সদস্যতা

সোর্স নোডের শেয়ার করা ডিরেক্টরিতে সদস্যতা নিন। যখন একটি ফাইল সোর্স ডিরেক্টরিতে যোগ বা পরিবর্তন করা হয়, তখন এটি স্বয়ংক্রিয়ভাবে স্থানীয় কম্পিউটারে সিঙ্ক্রোনাইজ হবে। একই সময়ে, স্থানীয় মেশিনটি স্বয়ংক্রিয়ভাবে অন্যান্য মেশিনগুলিকে টানার জন্য একটি নোড হিসাবে কাজ করবে:

```bash
sync0 sub 10.0.0.1:9000 dataset ./local_mirror
```

### 4. মাল্টি-মেশিন গ্রুপের দ্বি-মুখী সিঙ্ক্রোনাইজেশন

একাধিক মেশিন একই গ্রুপের নামে যোগদান করে, এবং যেকোনো নোড ডিরেক্টরিতে পরিবর্তনগুলি স্বয়ংক্রিয়ভাবে গ্রুপের অন্যান্য নোডের সাথে সিঙ্ক্রোনাইজ করা হবে:

```bash
sync0 group team-docs ./docs 10.0.0.1:9000,10.0.0.2:9000
```

### 5. নোড পরিচয় এবং ব্যক্তিগত ব্যবসায়িক কার্ড

প্রতিটি নোড ব্যবহারকারীর নাম, শহর, ইমেল, ওয়েবসাইট এবং একটি ব্যক্তিগতকৃত স্বাক্ষর (সর্বোচ্চ 256 অক্ষর) সেট করতে সমর্থন করে এবং স্থানীয় ব্যক্তিগত কী স্বাক্ষর প্রমাণীকরণ পাস করে:

```bash
# স্থানীয় পাবলিক কী আইডি দেখুন (কীটি বজায় রাখার জন্য কনফিগারেশন ডিরেক্টরি নির্দিষ্ট করুন)
sync0 id -c ~/.config/sync0

# ব্যক্তিগতকৃত স্বাক্ষর সহ নোড ব্যবসায়িক কার্ড তৈরি এবং প্রদর্শন করুন
sync0 profile -c ~/.config/sync0 \
  -u alice \
  --region SHA \
  --email alice@example.com \
  --url https://example.com \
  -b "Shanghai backup node"
```

`share`, `pull`, `sub`, `group` এই প্রোফাইল প্যারামিটারগুলির সাথেও চালু করা যেতে পারে:

```bash
sync0 share dataset ./data -c ~/.config/sync0 -u alice --region SHA -b "Shanghai backup node"
```

### 6. মাল্টি-ভাষা স্যুইচিং

`sync0` 75টি ভাষা সমর্থন করে। ডিফল্টরূপে, অপারেটিং সিস্টেমের ভাষা পরিবেশ অনুসারে সংশ্লিষ্ট ভাষায় কমান্ড লাইন সহায়তা এবং প্রম্পট স্বয়ংক্রিয়ভাবে প্রদর্শিত হয়; সিস্টেম ভাষা সমর্থিত তালিকায় না থাকলে, ইংরেজি ডিফল্টরূপে ব্যবহৃত হয়।

ম্যানুয়ালি ভাষা নির্দিষ্ট করতে, পরিবেশ পরিবর্তনশীল `SYNC0_LANG` সেট করুন:

```bash
SYNC0_LANG=en sync0 --help
SYNC0_LANG=ja sync0 --help
SYNC0_LANG=de sync0 --help
```
